35. 車輛 BOOTSTRAP 驗證 <OUTLANDER (GN#W)（歐洲車輛）>
N8040201N0000200ENG
注意：
啟動車輛時，務必遵守安全預防措施/注意事項。
1.連線程序
  1. 車輛準備
    • 設定車輛駐車煞車。
    • 將電動馬達開關的電源開關轉至開啟（READY 指示燈：熄滅），最長 6 分鐘。
  2. 將電動馬達開關的電源開關轉至開啟（READY 指示燈：亮起）以啟動連線程序。
    （當電動馬達開關轉至開啟時，bootstrap 程序將自動啟動。）
  3. 等待遠端資訊通訊開關上的綠色 LED 亮起，表示連線確認。此程序約需 5 分鐘。
    連線驗證：確認遠端資訊通訊開關上的綠色 LED 已亮起。
綠色 LED 是否已亮起？
是
前往 2.
否
前往 3.
2.完成 bootstrap
若要完成 bootstrap，請執行下列步驟。
  1. 將電動馬達開關的電源開關轉至關閉。
  2. 開啟車門。
  3. 關閉所有車門。
  4. 使用免鑰匙操作鑰匙鎖定車門。
  5. 在不開啟車門的情況下，等待綠色 LED 熄滅（約 1 分鐘）。
  6. 綠色 LED 熄滅後，解鎖並開啟車門。
  7. 等待綠色 LED 亮起。
綠色 LED 是否已亮起？
是
作業結束
否
前往 3.
3.重新啟動連線程序
若要重新啟動連線程序，請依下列步驟執行：
  1. 找到儲存用接頭並將其拉出。
  2. 關閉所有車門。
  3. 使用免鑰匙操作鑰匙鎖定車門。
  4. 等待 2 分鐘。
  5. 使用免鑰匙操作鑰匙解鎖車門。
  6. 壓下儲存用接頭以重新啟動連線程序。
    ＊：此程序僅可重新啟動一次
  7. 等待綠色 LED 亮起，表示連線確認。此程序約需 5 分鐘。
綠色 LED 是否已亮起？
是
前往 2.
否
更換 TCU。然後執行 TCU 更換程序。有關作業程序請參閱維修手冊。
