Code No. P0BCD-00：48V-BSG 控制板溫度感測器合理性
N5025044K0000300ENG
監測執行
連續。
監測執行條件（其他監測項目與感知器）
其他監測項目（下列監測項目未在記憶體中設定暫時性故障碼）
  • 不適用
感知器（下列感知器判定為正常）
  • 馬達發電機逆變器電路板溫度感測器
故障碼設定條件
檢查條件
  • 點火開關位於開啟位置。
  • 12V 電池電壓介於 10.0 至 16.5 伏特之間。
  • 啟動馬達停止運轉。
  • 上述條件滿足後，已經過 2 秒以上。
判定基準
  • 電路板溫度與微電腦溫度之間的差值達 20°C 或以上，持續 7.0 秒。
失效保護與備援功能
  • 48V MILD HYBRID 系統停止。
    1. 12V 側電力供應停止。
    2. 皮帶驅動啟動馬達發電機之引擎輔助與再生功能停止。
  • 充電警告燈亮起。
  • 怠速熄火功能禁止。
  • AS&G 關閉燈閃爍。
OBD-II 駕駛循環模式
請參閱 Diagnostic Function、OBD-II Drive Cycle – Pattern 5駕駛循環模式.
故障排除提示（設定此故障碼最可能的原因：）
  • 皮帶驅動啟動馬達發電機故障。
診斷

1.測試 OBD-II 駕駛循環。
  1. 將點火開關轉至「開啟」位置並清除故障碼。
  2. 執行駕駛循環測試。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5駕駛循環模式.
  3. 檢查故障碼。
Q：是否設定故障碼 P0BCD-00？
是
