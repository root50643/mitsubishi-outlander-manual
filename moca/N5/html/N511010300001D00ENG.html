詳細流程
1.取得症狀資訊
  1. 向客戶詳細詢問症狀（事故／故障發生時的狀況與環境）。
  2. 檢查故障功能之作動狀態。
前往步驟 2.
2.檢查 故障碼
  1. 檢查 故障碼.
  2. 若偵測到故障碼，執行下列程序。
    • 記錄故障碼以及凍結畫面資料（請使用 M.U.T.-III SE 列印）。
    • 清除故障碼.
    • 研究故障碼所偵測之原因與客戶所述症狀之間的關聯。
  3. 查閱相關服務公告以取得資訊。
是否有症狀描述或偵測到任何故障碼？
有症狀描述，故障碼顯示
GO TO 3.
有症狀描述，故障碼未顯示
GO TO 4.
無症狀描述，故障碼顯示
GO TO 5.
3.確認症狀
確認客戶所述之症狀。
亦須研究與該症狀相關之正常作動及失效保護。
查證症狀與症狀被偵測到時之狀況之間的關係。
GO TO 5.
4.確認症狀
嘗試確認客戶描述之症狀。
查證症狀與症狀被偵測到時之狀況之間的關係。
前往步驟 6.
5.執行故障碼確認程序
對偵測到之故障碼執行故障碼確認程序, 然後檢查故障碼是否再次出現。此時，請始終將 M.U.T.-III SE 連接至車輛，並即時檢查診斷結果。
若偵測到兩個或以上 故障碼，請參閱故障碼檢查優先順序表（免鑰匙操作鑰匙單元），故障碼檢查優先順序表故障碼檢查優先順序表（電動尾門控制單元）或 故障碼檢查優先順序表故障碼檢查優先順序表（BCM），並決定故障診斷順序。
注意：
  • 若未偵測到故障碼，定格資料可供參考。
  • 若維修手冊中未收錄故障碼確認程序，則執行元件功能檢查。此簡化檢查程序為有效替代方式，惟在此檢查期間無法偵測故障碼。
    若元件功能檢查結果為 NG，即等同於故障碼確認程序所偵測到之故障碼。
是否偵測到故障碼？
是
前往步驟 7.
否
請參閱 間歇性故障間歇性故障.
6.依症狀診斷偵測故障系統
依步驟 4 所確認之症狀，依照症狀診斷偵測故障系統，並依可能原因與症狀決定故障診斷順序。
是否有症狀描述？
是
前往步驟 7.
否
使用 M.U.T.-III SE 監視相關感測器輸入資料或檢查相關模組端子電壓。
7.依診斷程序找出故障零件
依該系統之診斷程序進行檢查。
是否偵測到故障零件？
是
前往步驟 8.
否
依間歇性故障進行檢查間歇性故障.
8.修復或更換故障零件
  1. 維修或更換故障零件。
  2. 修復及更換後，重新連接診斷程序中拆開之零件或接頭。
  3. 檢查故障碼。若顯示故障碼，請加以清除。
前往步驟 9.
9.最終檢查
於步驟 2 偵測到故障碼時，再次執行故障碼確認程序，然後檢查故障是否已完全修復。
當客戶有症狀描述時，請參閱步驟 3 或 4 所確認之症狀，並檢查該症狀是否不再出現。
是否仍偵測到故障碼且症狀仍存在？
YES-1
偵測到故障碼：前往步驟 7.
YES-2
症狀仍存在：前往步驟 4.
否
將車輛交還客戶前，請務必清除故障碼。
