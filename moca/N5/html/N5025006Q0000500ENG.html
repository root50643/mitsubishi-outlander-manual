引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0303-00: 偵測到第 3 缸失火
N5025006Q0000500ENG
技術說明
  • 引擎運轉中若發生失火，引擎轉速會瞬間改變。
  • ECM 會檢查此類引擎轉速變化。
監視方法說明
監控引擎轉速波動，當引擎轉速負向波動過大時偵測異常。
監視執行
連續。
監視執行條件（其它監視器與感測器）
其它監視器（下列監視項目的記憶體中未設定暫時故障碼）
  • 燃油系統監視器
  • 燃油蒸氣排放淨化系統監控
感測器（下列感測器判定為正常）
  • 車輛 車速 感知器
  • 曲軸角度感知器
  • 空氣流量感測器
  • 引擎冷卻液溫度感測器
  • 大氣壓力感測器
  • 節氣門位置感測器
  • 進氣歧管絕對壓力感測器
  • 燃油噴油嘴（高壓）
  • 燃油壓力感測器
  • 高壓燃油泵
  • 增壓壓力感測器
  • No. 2 進氣溫度感測器
  • No. 3 進氣溫度感測器
故障碼設定條件
檢查條件
  • 引擎轉速大於 600 r/min 且小於 6,000 r/min。
  • 引擎冷卻液溫度大於 -10°C。
  • 大氣壓力大於 76 kPa。
  • 容積效率大於依引擎轉速而定的指定值。
  • 節氣門偏差穩定。
判定基準（失火偵測使用引擎轉速波動）。
  • 在過去 200 次轉動中，失火發生頻率高於允許值 <when the catalyst temperature is more than 1,000°C>。
或
  • 在過去 1,000 次轉動中，失火發生率達 2.0% 或以上（相當於排放標準限值的 1.5 倍）。
失效保護與備援功能
可能切斷失火氣缸的燃油供應。
OBD-II 行駛循環模式
請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 23行駛循環模式.
故障排除提示（設定此故障碼最可能的原因為：）
  • 點火系統相關零件故障。
  • No. 3 燃油噴射器故障。
  • 燃油噴射器電路中線束損壞。
  • 壓縮壓力過低。
  • ECM 故障。
診斷
所需專用工具：
  • MB993028：含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
1.目視檢查故障缸之點火火星。
  • 拆下火花塞並安裝至點火線圈。
  • 連接點火線圈接頭。
  • 斷開所有燃油噴射器接頭。
  • 引擎起動時，檢查火花塞是否產生火花。
問：檢查結果是否正常？
是
前往 2。
否
檢查 Inspection Procedure - 點火電路系統（請參閱點火電路系統).
2.檢查燃油噴射器本身。
  • 燃油噴射器檢查（請參閱噴油嘴 檢查).
問：檢查結果是否正常？
是
前往 3。
否
更換燃油噴射器（請參閱 –噴油嘴拆卸與安裝）。然後前往 8。
3.檢查大電流保險絲、保險絲座與燃油噴射器繼電器接頭之間電源線路損壞。
問：檢查結果是否正常？
是
前往 4。
否
修理接頭或線路。然後前往 8。
4.檢查燃油噴射器繼電器接頭與 No. 3 燃油噴射器接頭之間電源線路損壞。
問：檢查結果是否正常？
是
前往 5。
否
修理接頭或線路。然後前往 8。
5.檢查 No. 3 燃油噴射器接頭與 ECM 接頭之間 INJ3 線路損壞。
問：檢查結果是否正常？
是
前往 6。
否
修理接頭或線路。然後前往 8。
6.檢查故障缸之壓縮壓力。
  • 檢查壓縮壓力（請參閱 引擎 <4B4> – 引擎機械 – 車上服務 –壓縮壓力檢查).
問：檢查結果是否正常？
是
前往 7。
否
修理。然後前往 8。
7.使用 M.U.T.-III SE，讀取故障碼。
  • 故障碼再確認。
Q: 是否設定故障碼 P0303-00？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後前往 8。
否
間歇性故障（請參閱 General Information – General Information – Basic Inspection – Service Information for Electrical Incident –間歇性故障).
8.測試 OBD-II 行駛循環。
  1. 依驅動循環模式進行試車。請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 23行駛循環模式.
  2. 檢查故障碼。
Q: 是否設定故障碼 P0303-00？
是
重新執行故障排除。
否
檢查完成。
