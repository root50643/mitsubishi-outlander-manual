詳細流程
1.故障問診
開始檢查前，釐清客戶反映的問題也很重要。請仔細詢問客戶並完全了解症狀。
進行步驟 2.
2.使用 M.U.T.-III SE 進行自我診斷
使用 M.U.T.-III SE
使用 M.U.T.-III SE 執行「引擎」自我診斷。請參閱 M.U.T.-III SE 功能故障碼讀取與清除方法.
是否偵測到任何故障碼？
是
進行步驟 3.
否
進行步驟 4.
3.故障碼疑難診斷
  1. 檢查「自我診斷結果」中顯示的故障碼。
  2. 當偵測到故障碼時，請依下列指示進行：
    • 記錄故障碼
    • 凍結畫面資料 (FFD)
  3. 依故障碼索引執行相關診斷。請參閱故障碼檢查表.
進行步驟 5.
4.症狀診斷
依症狀診斷圖表執行適用的診斷。請參閱故障症狀檢查表.
進行步驟 5.
5.故障零件維修
維修或更換已判定的故障零件。
進行步驟 6.
6.維修檢查（使用 M.U.T.-III SE 自我診斷）
使用 M.U.T.-III SE
  1. 清除自我診斷結果。
  2. 維修或更換特定項目後，再次執行「引擎」自我診斷。
  3. 檢查「引擎」自我診斷結果中是否偵測到任何故障碼。
是否偵測到任何故障碼？
是
進行步驟 3.
否
GO TO 7.
7.維修檢查（作動測試）
執行作動測試。檢查故障症狀是否已排除，或未出現其他症狀。
是否仍有故障症狀？
是
進行步驟 4.
否
