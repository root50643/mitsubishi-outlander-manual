變速箱與傳動系統 - 變速箱與變速器 - CVT<F1CJD, W1CJD> - 故障碼/電路診斷 - 變速箱（TCM）- U214F-57 CAN comm err (BCM)
診斷程序
N504020170011L00ENG
1.檢查故障碼優先順序
若顯示故障碼 U214F-57 與故障碼 U1327-52 或故障碼 U1327-54，請先執行故障碼 U1327-52 或 U1327-54 的故障診斷。
是否偵測到故障碼 U1327-52 或 U1327-54？
是
請參閱故障碼說明(U1327-52) 或故障碼說明(U1327-54).
否
前往步驟 2。
2.檢查 MAC 診斷
使用 M.U.T.-III SE
使用 M.U.T.-III SE 執行「變速箱」的「MAC Diagnosis」模式。
是否同時偵測到故障碼 U214F-57、故障碼 U2140–57 與故障碼 U2176–57？
是（所有故障碼同時被偵測到）
更換 TCM。請參閱拆卸及安裝.
否（並非所有故障碼同時被偵測到）
转至 3.
3.檢查 網路-故障碼
使用 M.U.T.-III SE
執行「CAN Diag」。
檢查結果是否正常？
是
聯絡 Techline 並回報車輛狀況。
否
修復或更換根本原因。
