1.列印目前校正資料
使用 M.U.T.-III SE
  1. 點火開關為 開啟。
  2. Connect M.U.T.-III SE.
  3. 在「TRANSMISSION」中選擇「CALIB DATA」。
  4. 列印第 1 頁，共 7 頁。
    注意：
    此畫面列印用於保固文件。
前往步驟 2.
2.檢查序號（第一部分）
  1. 記下新控制閥的序號（校正檔案編號）。
  2. 比對 CD、QR 碼標籤及新控制閥上的序號（校正檔案編號）。所有編號必須相符。
CF100A4RAA00ENG
GO TO 3.
3.檢查序號（第二部分）
使用 M.U.T.-III SE
  1. 點火開關為 開啟。
  2. 將隨附的 CD 插入 M.U.T.-III SE。
  3. 在「變速箱」中選擇「特殊功能」。
  4. 選擇「IP characteristics data writing」中的「WRITE IP CHARA - REPLACEMENT AT/CVT」。
  5. 觸碰「File import」，將儲存於 CD 中的校正檔案存入 M.U.T.-III SE。
  6. 觸碰「OK」開啟「Select IP characteristics data file」視窗。
  7. 確認 M.U.T.-III SE 畫面上顯示的序號（校正檔案編號）與新控制閥上的序號（校正檔案編號）相符。
  8. 觸碰「OK」。
GO TO 4.
4.寫入校正資料 (IP CHARACTERISTICS VALUE)
注意：
依下列指示將新電磁閥資料寫入 TCM：
使用 M.U.T.-III SE
  1. 點火開關 開啟，引擎 關閉。
  2. 踩下煞車踏板。
  3. 將油門踏板踩下一半並保持，然後在 M.U.T.-III SE 畫面上按「OK」。
  4. 依 M.U.T.-III SE 畫面上的指示將資料寫入 TCM。
    注意：
    當校正資料已寫入 TCM 時，目前狀態將顯示「Complete」。
GO TO 5.
5.列印新校正資料
使用 M.U.T.-III SE
  1. 在「TRANSMISSION」中選擇「CALIB DATA」。
  2. 列印第 1 頁，共 7 頁。
    注意：
    此畫面列印用於保固文件。
前往步驟 6.
6.執行離合器接合點學習
執行離合器接合點學習。請參閱說明說明.
前往步驟 7.
7.執行選檔學習 (前進/倒檔學習)
注意：
選檔學習前，務必執行離合器接合點學習。
執行選擇學習。請參閱作業程序作業程序.
前往步驟 8.
8.清除 CVT 油液劣化程度資料
使用 M.U.T.-III SE
  1. 在「TRANSMISSION」中選擇「WORK SUPPORT」。
  2. 選擇「CONFORM CVTF DETERIORTN」。
  3. 觸碰「OK」。
  4. 清除可能已設定的任何 故障碼，然後試車。
