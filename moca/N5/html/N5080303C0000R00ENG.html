正面碰撞：碰撞時氣囊未作動
注意：
由於車型及選配等級不同，下方圖表中列出的零件並非全部適用於所有車輛。
工作程序
執行以下任一步驟前，請確認所有車身及結構性修復均已完成。
使用下方表格檢查氣囊元件。
更換任何有明顯損壞跡象的氣囊元件。（凹陷、龜裂及變形等）
使用 M.U.T.-III SE 或氣囊警告燈執行自我診斷。請參閱 DTCIndex故障碼 Index. 以了解詳情。
確認整套氣囊系統運作正常。
工作完成後，確認氣囊警告燈未偵測到任何故障。
氣囊檢查（正面碰撞）
零件
檢查
駕駛座安全氣囊模組
若駕駛座安全氣囊未作動：
  1. 拆下駕駛座安全氣囊模組。檢查線束護蓋及接頭是否損壞、端子是否變形，以及線束是否有束縛。
  2. 將駕駛座安全氣囊模組安裝至方向盤，以檢查與方向盤的配合及對正。
  3. 若未發現損壞，使用新固定件重新安裝。
  4. 若已損壞 - 更換。使用新固定件安裝駕駛座安全氣囊模組。
駕駛座膝部安全氣囊模組
若駕駛座膝部安全氣囊未作動：
  1. 拆下駕駛座膝部安全氣囊模組。檢查線束護蓋及接頭是否損壞、端子是否變形，以及線束是否有束縛。
  2. 將駕駛座膝部安全氣囊模組安裝至儀表板，以檢查與儀表板的配合。
  3. 若未發現損壞，使用新固定件重新安裝。
  4. 若已損壞 - 更換。使用新固定件安裝駕駛座膝部安全氣囊模組。
前乘客座安全氣囊模組
若前乘客座安全氣囊未作動：
  1. 拆下前乘客座安全氣囊模組。檢查線束護蓋及接頭是否損壞、端子是否變形，以及線束是否有束縛。
  2. 將前乘客座安全氣囊模組安裝至儀表板，以檢查與儀表板的配合。
  3. 若未發現損壞，使用新固定件重新安裝。
  4. 若已損壞 - 更換。使用新固定件安裝前乘客座安全氣囊模組。
碰撞區感知器
若前方安全氣囊或安全帶預緊器未作動：
  1. 拆下碰撞區感知器。檢查線束接頭是否損壞、端子是否變形，以及線束是否有束縛。
  2. 檢查碰撞區感知器及支架是否有明顯損壞跡象（凹陷、龜裂、變形）。
  3. 安裝碰撞區感知器以檢查配合。
  4. 若未發現損壞，使用新固定件重新安裝。
  5. 若已損壞 - 使用新固定件更換碰撞區感知器及支架。
安全帶預緊器總成
（所有適用位置：帶扣、卷收器、外側腰帶）
更換安全帶預緊器總成。
使用新固定件安裝。
診斷感知器單元
若所有氣囊元件均未作動：
  1. 檢查外殼是否有凹陷、龜裂或變形。
  2. 檢查接頭是否損壞，以及端子是否變形。
  3. 若未發現損壞，使用新固定件重新安裝。
  4. 若已損壞 - 更換。使用新固定件安裝診斷感知器單元。
方向盤
  1. 目視檢查方向盤是否有變形。
  2. 檢查線束（內建於方向盤）及接頭是否損壞，以及端子是否變形。
  3. 將駕駛座安全氣囊模組安裝至方向盤，以檢查與方向盤的配合及對正。
  4. 檢查方向盤是否有過大游隙。
  5. 若未發現損壞，重新安裝。
  6. 若已損壞 - 更換。
螺旋電纜
若駕駛座前方安全氣囊未展開：
  1. 目視檢查時鐘彈簧及組合開關是否損壞。
  2. 檢查接頭及保護膠帶是否損壞。
  3. 檢查方向盤是否有異音、卡滯或操作笨重。
  4. 若未發現損壞，重新安裝。
  5. 若已損壞 - 更換。
乘員偵測系統（乘客座）
  1. 拆下乘客座總成。
  2. 檢查控制單元外殼是否有凹陷、龜裂或變形。
  3. 檢查接頭是否損壞及端子是否變形。
  4. 檢查座椅框架及坐墊底盤是否有凹陷或變形。
  5. 若未發現損壞，使用新固定件重新安裝座椅。
  6. 若已損壞 - 使用新固定件更換坐墊總成。
線束及接頭
  1. 檢查接頭是否有接觸不良、損壞，以及端子是否變形。
  2. 檢查線束是否有束縛、磨損、割傷或變形。
  3. 若未發現損壞，重新安裝線束及接頭。
  4. 若已損壞 - 更換受損線束。請勿嘗試修復、拼接或改裝任何氣囊線束。
儀表板總成
若乘客座前方安全氣囊未展開：
  1. 目視檢查儀表板是否有損壞。
  2. 若未發現損壞，重新安裝儀表板總成。
  3. 若已損壞 - 更換儀表板總成。
