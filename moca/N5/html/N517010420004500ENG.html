定速控制與駕駛輔助 - 定速控制系統 - 主動式定速控制系統 (ACC) - 症狀診斷 - ACC - 完全無法偵測前方車輛
診斷程序
N517010420004500ENG
當 ACC 系統作動時，即使前方有車輛，ACC 系統也不進行任何控制。
1.檢查 ACC 系統顯示於資訊顯示器
  1. 啟動儀表的自我診斷模式。請參閱儀表板診斷功能（全 TFT 儀表）或儀表板診斷功能（7 吋資訊顯示器車型）。
  2. 確認資訊顯示器正常開啟。
檢查結果是否正常？
是
GO TO 2.
否
更換儀表。
2.目視檢查 (1)
檢查水箱護罩距離感測器區域的污染及異物。
是否有異物附著？
是
GO TO 4.
否
GO TO 3.
3.目視檢查 (2)
  1. 拆下前保桿總成。請參閱前保桿總成拆卸與安裝.
  2. 檢查距離感測器是否有污染及異物。
是否有異物附著？
是
GO TO 4.
否
GO TO 5.
4.清除污垢及異物
清除距離感測器周圍區域的污染及異物。
GO TO 9.
5.目視檢查 (3)
檢查距離感測器是否有龜裂及/或刮傷。
是否有龜裂？
是
GO TO 7.
否
GO TO 6.
6.執行雷達校正
  1. 安裝前保桿總成。請參閱前保桿總成拆卸與安裝.
  2. 執行雷達校正。請參閱作業程序.
  3. 執行 ACC 系統作動測試。請參閱工作程序作業流程.
  4. 確認前方車輛偵測性能改善。
是否改善？
是
檢查結束
否
GO TO 8.
7.更換 DISTANCE 感知器
  1. 更換距離感測器。請參閱拆卸與安裝.
  2. 安裝前保桿總成。請參閱前保桿總成拆卸與安裝.
  3. 執行雷達校正。請參閱作業程序.
  4. 執行 ACC 系統作動測試。請參閱工作程序作業流程.
  5. 確認前方車輛偵測性能改善。
是否改善？
是
檢查結束
否
GO TO 8.
8.更換 ADAS 控制單元 2
更換 ADAS 控制單元 2。請參閱拆卸與安裝.
GO TO 9.
9.檢查 ACC 系統
  1. 清除自我診斷結果，並於作動測試後再次執行「Read All DTCs」。請參閱工作程序作業流程.
  2. 確認 ACC 系統正常。
