引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
代碼編號 U2176-57：與 CDM 的 MAC 通訊失效/故障
N5025012N0000700ENG
故障碼設定條件
檢查條件
  • 點火開關位於「開啟」位置。
判定標準
  • 與 CDM 的 MAC 通訊失效/故障持續 2 秒。
說明
目前故障
  • 失效/故障可能由 ECM 與底盤控制模組之間 CAN 匯流排線路的線束與接頭故障、底盤控制模組內部故障，或 ECM 內部故障所引起。
過去故障
  • 著重 ECM 與底盤控制模組之間 CAN 匯流排線路的線束與接頭故障，進行故障排除。
注意：
若為過去發生的故障，即使 CAN 匯流排存在故障，M.U.T.-III SE 的 CAN 匯流排線路診斷亦無法偵測到故障。因此，請如同處理間歇性故障一般檢查 CAN 匯流排線路（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障）。可從執行 CAN 通訊的各 ECU 所設定的診斷代碼，縮小故障可能性較高的區域（請參閱 Electrical and Power Control - LAN System - CAN Fundamental - Basic Inspection - Diagnosis and Repair Workflow -M.U.T.-III SE CAN 匯流排診斷說明).
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
故障排除提示（設定此代碼最可能的原因為：）
  • 底盤控制模組故障
  • ECM 故障
診斷
所需特殊工具：
  • MB993028: VCI-3 kit with wireless adapters

    2. MB993029: DLC cable
    3. MB993030: USB cable
    4. MB993031: Wireless USB adapter (Qty:2)
  • MB993040: VCI-3 kit without wireless adapters
    1. -: VCI-3 device

    3. MB993030: USB cable
1.使用M.U.T.-III SE讀取其他故障碼。
檢查故障碼編號 U1327-52 是否與故障碼編號 U214F-57 一併設定。
問：是否設定故障碼 U1327-52？
是
執行故障碼編號 U1327-52 的診斷（請參閱故障碼檢查表故障碼檢查表).
否
前往 2。
2.使用 M.U.T.-III SE 讀取故障碼。
問：MAC 通訊 U214F-57 與 U2152-57 的診斷代碼，以及故障碼 U2176-57 是否同時設定？
是（所有診斷代碼同時被偵測到）
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後GO TO 4.
否（並非所有診斷代碼同時被偵測到）
前往步驟 3。
3.使用 M.U.T.-III SE，CAN 匯流排診斷
  • 使用 M.U.T.-III SE，執行 CAN 匯流排線路診斷。
Q：檢查結果是否正常？
是
聯絡 Tecline 並回報車輛狀況。
否
修理或更換偵測到錯誤的零件。然後GO TO 4.
4.測試 OBD-II 行駛循環。
  1. 依駕駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  2. 檢查故障碼。
問：是否設定故障碼 U2176-57？
是
重新執行故障排除。
否
檢查完成。
