CRUISE CONTROL & DRIVER ASSISTANCE - DRIVER ASSISTANCE SYSTEM - ADAS CONTROL UNIT - BASIC INSPECTION - 設定 (ADAS CONTROL UNIT 2)
作業程序
N517020320006600ENG
更換 ADAS control unit 2 後未寫入車輛規格，須使用 M.U.T.-III SE 寫入車輛規格。
此設定作業需要網路連線。M.U.T.-III SE 連接至網路後，從伺服器下載設定資料，再將車輛規格寫入 ADAS control unit 2。
備註：
有關網路連線及作動的詳細說明，請參閱「M.U.T.-III SE 作動 Manual」。
設定作業不需要從 ADAS control unit 2「儲存」設定資料。設定資料一律於伺服器端重新產生後，再下載至 M.U.T.-III SE。
注意：
  • 請依序完成「配置」程序。
  • 若「配置」不正確，可能發生異常。
1.寫入車輛規格
使用 M.U.T.-III SE
依 M.U.T.-III SE 作動手冊「設定」項下之「Automatic 設定」程序，執行寫入車輛規格至 ADAS control unit 2。
備註：
  • 依 M.U.T.-III SE 操作指引登入網路。
  • 有關網路連線及作動的詳細說明，請參閱「M.U.T.-III SE 作動 Manual」。
