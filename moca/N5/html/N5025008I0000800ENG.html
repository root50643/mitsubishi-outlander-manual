引擎<4B4> - 直接燃油噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P062A-00：直接燃油噴射控制 - 燃油壓力
N5025008I0000800ENG
電路作動
  • 電壓由 ECM 接頭端子 HFP+ 施加至燃油泵（高壓）。
  • 電壓由燃油泵（高壓）搭鐵至 ECM 接頭端子 HFP-。
技術說明
  • 燃油泵（高壓）依 ECM 訊號控制燃油壓力。
監控方法說明
直接噴射控制期間，實際燃油壓力與目標燃油壓力之差超過規定值。
監控執行
連續。
監控執行條件（其他監控及感測器）
其他監控（下列監控項目之記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
偵測條件
  • 點火開關置於「開啟」位置或引擎起動後 2 秒。
  • 電池電壓大於 10.5 volts 且小於 16.5 volts。
判定基準
  • DI 控制驅動器狀態變為失效，包括高側短路、低側短路、開路或過電流。
失效保護及備援功能
  • 禁止燃油噴油嘴（高壓）作動，僅以燃油噴油嘴作動進行控制。
  • 扭力受到限制。
OBD-II 行程循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 3行程循環模式.
故障排除提示（此故障碼最可能之設定原因如下：）
  • 燃油泵（高壓）故障。
  • 燃油泵（高壓）電路開路/短路或線束損壞，或接頭接觸鬆動。
  • ECM 故障。
診斷
