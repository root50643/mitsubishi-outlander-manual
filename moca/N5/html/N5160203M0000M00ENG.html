詳細流程
1.取得症狀相關資訊
訪談客戶，盡可能取得故障發生時的條件與環境等相關資訊。
前往步驟 2.
2.檢查症狀
  • 依據自客戶處取得的資訊檢查症狀。
  • 檢查是否存在其他故障。
GO TO 3.
3.檢查 M.U.T.-III SE 自我診斷結果
  1. 連接 M.U.T.-III SE 並執行自我診斷。請參閱故障碼索引(Full TFT 儀表) 或故障碼索引(7 inch information display).
  2. 偵測到故障碼時，請依下列指示進行：
    • 記錄故障碼與凍結畫面資料（Freeze Frame Data）。
自我診斷結果是否正常？
是
GO TO 4.
否
GO TO 5.
4.依症狀診斷縮小故障零件範圍
執行症狀診斷並縮小故障零件範圍。
GO TO 5.
5.維修或更換故障零件
修復或更換故障零件。
備註：
若顯示故障碼，請於修復或更換故障零件後清除故障碼。
GO TO 6.
6.最終檢查
確認儀表中的警示蜂鳴器是否正常作動。
是否正常作動？
是
檢查結束
