詳細流程
1.取得故障症狀資訊
  1. 向客戶取得關於症狀的詳細資訊（事故／故障發生時的狀況與環境）。
  2. 檢查發生故障之功能的作動狀況。
GO TO 2.
2.檢查 故障碼
  1. 檢查 故障碼.
  2. 若偵測到故障碼，執行下列程序。
    • 記錄故障碼與凍結畫面資料（使用 M.U.T.-III SE 列印）。
    • 清除故障碼。
    • 研讀由故障碼所偵測到之原因與客戶描述症狀之間的關聯。
  3. 查閱相關服務技術通報以取得資訊。
是否有描述任何症狀且偵測到任何故障碼？
有描述症狀，已偵測到故障碼
GO TO 3.
有描述症狀，未偵測到故障碼
GO TO 4.
未描述症狀，已偵測到故障碼
GO TO 5.
3.確認症狀
嘗試確認客戶所描述之症狀。
並研讀與該症狀相關之正常作動與失效保護。
確認症狀與症狀發生時之狀況之間的關聯。
GO TO 5.
4.確認症狀
嘗試確認客戶所描述之症狀。
確認症狀與症狀發生時之狀況之間的關聯。
GO TO 6.
5.執行故障碼確認程序
針對所偵測到的故障碼執行故障碼確認程序，然後檢查該故障碼是否再次偵測到。此時，請始終將 M.U.T.-III SE 連接至車輛，並即時檢查自我診斷結果。
若偵測到兩個以上 故障碼，請參閱故障碼檢查優先順序表，並決定故障診斷順序。
注意：
  • 若未偵測到故障碼，凍結畫面資料很有用。
  • 若維修手冊中未包含故障碼確認程序，則執行元件功能檢查。此簡化檢查程序為有效替代方式，雖然在此檢查期間無法偵測到故障碼。
    若元件功能檢查結果為 NG，等同於透過故障碼確認程序所偵測到的故障碼。
是否偵測到故障碼？
是
GO TO 7.
NO
依間歇性故障進行檢查間歇性故障.
6.依症狀診斷偵測故障系統
依步驟 4 所確認之症狀，根據症狀診斷偵測故障系統，並依可能原因與症狀決定故障診斷順序。
是否有描述症狀？
是
GO TO 7.
NO
使用 M.U.T.-III SE 監控相關感測器之輸入資料，或檢查相關模組端子之電壓。
7.依診斷程序偵測故障零件
依該系統之診斷程序進行檢查。
是否偵測到故障零件？
是
GO TO 8.
NO
依間歇性故障進行檢查間歇性故障.
8.維修或更換故障零件
  1. 修復或更換故障零件。
  2. 維修及更換後，重新連接於診斷程序期間斷開之零件或接頭。
  3. 檢查故障碼。若偵測到故障碼，則予以清除。
GO TO 9.
9.最終檢查
當步驟 2 偵測到故障碼時，再次執行故障碼確認程序，然後檢查故障是否已確實修復。
當客戶描述症狀時，請參閱步驟 3 或 4 所確認之症狀，並檢查該症狀是否不再出現。
是否偵測到故障碼且症狀仍存在？
YES-1
已偵測到故障碼：前往步驟 7.
YES-2
症狀仍存在：前往步驟 4.
NO
將車輛交還客戶前，務必清除故障碼。
