定速控制與駕駛輔助 - 駕駛輔助系統 - 駕駛輔助系統 - 故障碼/電路診斷 - 雷射/雷達 (距離感知器) - C2582-97 距離感知器
診斷程序
N51702017006GC00ENG
1.目視檢查 1
檢查前保桿距離感知器區域是否有污染及異物附著。
是否有污染或異物附著？
是
清除前保桿距離感知器區域的污染及異物。
NO
GO TO 2.
2.目視檢查 2
  1. 拆下前保桿。請參閱前保桿總成拆卸與安裝 .
  2. 檢查距離感知器是否有污染及異物。
是否有污染或異物附著？
是
清除距離感知器上的污染及異物。
NO
進行步驟 3。
3.目視檢查 3
檢查距離感知器是否有裂紋及刮傷。
是否發現？
是
更換距離感知器。請參閱拆卸與安裝.
NO
進行步驟 4。
4.執行雷達校正
  1. 使用 M.U.T.-III SE 調整雷達校正。請參閱作業程序.
  2. 執行 AEB 系統作動測試以檢查作動狀態。請參閱作業程序作業程序.
  3. 執行「Read All DTCs」。
  4. 確認在「LASER/RADAR」的「Self Diagnostic Result」中是否偵測到「C2582-97」。
是否偵測到「C2582-97」？
是
更換距離感知器。請參閱拆卸與安裝.
NO
前往步驟 5。
5.訪談
  1. 詢問前保桿距離感知器區域是否曾有污染或異物附著的痕跡。
  2. 詢問行駛中前保桿距離感知器區域是否結霜，或車輛是否行駛於雪地。
  3. 詢問前保桿距離感知器區域是否暫時起霧。（擋風玻璃也可能容易起霧等。）
是否出現上述任一情況？
是
向客戶說明污染偵測功能與偵測到故障時之指示之差異，並告知「此非故障」。
NO
更換距離感知器。請參閱拆卸與安裝.
