變速箱與傳動系統 - 變速箱與變速器 - CVT<F1CJE, W1CJE> - 基本檢查 - 更換 TCM 時之附加服務

注意：
開始之前，務必確認：
  • 所有 M.U.T.-III SE 軟體更新（若有）皆已安裝。
1.儲存校正資料 (IP CHARACTERISTICS VALUE)
注意：
依下列指示，將儲存在 TCM 中的必要資料儲存至 M.U.T.-III SE：
使用 M.U.T.-III SE
  1. 點火開關關閉，並等待 10 秒。
  2. 點火開關開啟。
  3. Connect M.U.T.-III SE.
  4. 在「TRANSMISSION」中選擇「Special Function」。
  5. 選擇「IP characteristics data writing」的「READ IP CHARA - REPLACEMENT TCM」。
  6. 觸碰「OK」。
    注意：
    當校正資料已儲存至 M.U.T.-III SE 時，將顯示「Completed」訊息。
  7. 觸碰「OK」以完成。
前往步驟 2.
2.更換 TCM
  1. 點火開關關閉。
  2. 更換 TCM。請參閱拆卸與安裝.
GO TO 3.
3.執行 TCM 程式設計
使用 M.U.T.-III SE
依 M.U.T.-III SE 使用手冊「Programming」執行 TCM 程式設計。請參閱 M.U.T.-III SE User's Manual.
警告：
程式設計期間，維持下列條件：
  • 點火開關：開啟
  • 電氣負載：關閉
  • 煞車踏板：未踩下
  • 電池電壓：12 – 13.5 V（務必確認電池電壓數值。）
GO TO 4.
4.寫入 MAC KEY
執行 MAC key 寫入，請參閱說明.
GO TO 5.
5.寫入校正資料 (IP CHARACTERISTICS VALUE)
注意：
依下列指示，將儲存在 M.U.T.-III SE 中的資料寫入新的 TCM：
使用 M.U.T.-III SE
  1. 確認車輛處於「Park」(P) 位置，然後將點火開關關閉並等待 10 秒。
  2. 點火開關開啟。
  3. 在「TRANSMISSION」中選擇「Special Function」。
  4. 選擇「IP characteristics data writing」的「WRITE IP CHARA - REPLACEMENT TCM」。
  5. 觸碰「OK」。
    注意：
    當校正資料已寫入 TCM 時，將顯示「Completed」訊息。
  6. 觸碰「OK」以完成。
前往步驟 6.
6.執行扭力轉換器離合器接合點學習
執行扭力轉換器離合器接合點學習。請參閱說明.
前往步驟 7.
7.執行選檔學習 (前進/倒檔學習)
注意：
選檔學習前，務必執行離合器接合點學習。
  1. 執行選檔學習。請參閱作業程序.
  2. 清除可能已設定的任何 故障碼，然後試車。
