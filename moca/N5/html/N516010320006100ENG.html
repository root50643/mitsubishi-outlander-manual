說明
更換或拆卸 Head Up Display 單元時，必須進行顯示扭曲校正及顯示位置調整。
作業程序
1.更換 HEAD UP DISPLAY 單元
更換 Head Up Display 單元。請參閱拆卸與安裝.
GO TO 2.
2.執行校正
執行 Head Up Display 校正。請參閱作業程序診斷程序.
GO TO 3.
3.調整顯示螢幕
調整顯示螢幕位置。請參閱開關名稱及功能.
GO TO 4.
4.作動 檢查
檢查 Head Up Display 的顯示。
顯示是否正常？
是
前往步驟 5。
NO
再次執行顯示調整。GO TO 3.
5.執行 Factory Mode 關閉
點火開關開啟。
在「E-HUD」的「特殊功能」畫面中選擇「工廠模式關閉」。
檢查項目 No.1：Factory Mode，並依設定值執行下列程序。
  • 開啟：選擇「OK」並將設定值變更為「關閉」。
  • 關閉：無需作業，作業完成。
