1.調整轉向角感測器的中立位置
執行轉向角感測器的中立位置調整。請參閱作業程序.
转至 2.
2.執行自我診斷
使用 M.U.T.-III SE
  1. 點火開關關閉（Auto ACC 功能關閉）。
  2. 啟動引擎。
    注意：
    啟動引擎後至少等待 10 秒。
  3. 執行「ABS」自我診斷。
是否偵測到故障碼「C106E-54」？
是
转至 3.
否
檢查結束
3.檢查轉向角度感測器系統
檢查轉向角度感測器系統。
  • C106E-54
  • C106E-55：請參閱診斷程序.
  • C106E-64：請參閱診斷程序.
  • C106F-54：請參閱診斷程序.
  • C1083-86：請參閱診斷程序.
檢查結果是否正常？
是
转至 4.
否
修理/更換線束、接頭或端子。
4.檢查資料監視器
使用 M.U.T.-III SE
  1. 依此順序選擇「ABS」、「資料清單」及「Steering angle」。
  2. 檢查當方向盤由正中位置向左/右轉動時，指示是否隨轉向角度變化。請參閱參考值.
檢查結果是否正常？
是
更換 ABS 作動器與電動單元 (控制單元)。請參閱拆卸及安裝.
否
更換轉向角度感測器。請參閱拆卸及安裝.
