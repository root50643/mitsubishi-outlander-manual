工作流程

詳細流程
1.客戶訪談
檢查前先釐清客戶抱怨。首先，利用下列項目進行訪談診斷工作表並重現症狀，同時充分理解症狀。仔細詢問客戶抱怨內容。必要時，與客戶一同試車檢查症狀。
注意：
客戶並非專業人員。切勿輕易臆測，例如「也許客戶是指……」或「也許客戶提到的是這個症狀」。
前往 2.
2.檢查症狀
根據訪談所獲得之客戶資訊重現客戶所述症狀。同時檢查症狀是否由失效保護模式所造成。請參閱失效保護.
注意：
當症狀為正常作動所造成時，請完整檢查各部位，並取得客戶理解，確認該症狀並非故障所造成。
前往 3.
3.執行自我診斷
使用 M.U.T.-III SE
  1. 點火開關關閉（Auto ACC 功能關閉）至開啟。
  2. 執行「ABS」自我診斷。
是否偵測到故障碼？
是
記錄或列印自我診斷結果與凍結資料（FFD）。GO TO 4.
否
GO TO 6.
4.重新檢查症狀
使用 M.U.T.-III SE
  1. 清除「ABS」的自我診斷結果。
  2. 點火開關關閉（Auto ACC 功能關閉）→ 開啟 → 關閉（Auto ACC 功能關閉）。
  3. 執行偵測到錯誤之系統的故障碼確認程序。
    注意：
    若同時偵測到多個 故障碼，請依據故障碼檢查優先順序表.
是否偵測到故障碼？
是
前往 5.
否
依據訪談所得資訊檢查線束與接頭。請參閱間歇性故障間歇性故障.
5.維修或更換偵測到錯誤之零件
使用 M.U.T.-III SE
  1. 斷開 12V 電瓶負極端子。
  2. 修理或更換偵測到異常的零件。
  3. 維修或更換後，重新連接零件或接頭。
  4. 連接 12V 電瓶負極端子。
  5. 偵測到故障碼時，清除「ABS」的自我診斷結果。
    注意：
    點火開關關閉（Auto ACC 功能關閉）→ 開啟 → 關閉（Auto ACC 功能關閉），於清除自我診斷結果後。
GO TO 7.
6.依症狀診斷辨識故障系統
依據症狀診斷估計故障系統並執行檢查。
是否能辨識故障系統？
是
GO TO 7.
否
依據訪談所得資訊檢查線束與接頭。請參閱間歇性故障間歇性故障.
7.最終檢查
使用 M.U.T.-III SE
  1. 檢查「ABS」的參考值。
  2. 重新確認症狀，並檢查在相同條件下症狀是否未再出現。
症狀是否再現？
是
前往 3.
否
