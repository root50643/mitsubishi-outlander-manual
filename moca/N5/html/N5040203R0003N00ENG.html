注意：
開始前，務必確認：
  • 確認 M.U.T.-III SE 已同步至目前日期。
  • 所有 M.U.T.-III SE 軟體更新（若有）均已安裝。
1.列印目前校正資料
使用 M.U.T.-III SE
  1. 點火開關為開啟。
  2. 連接 M.U.T.-III SE。
  3. 在「TRANSMISSION」中選擇「CALIB DATA」。
  4. 列印第 1 頁，共 7 頁。
    注意：
    此螢幕列印用於保固文件。
转至 2.
2.檢查序號 (第 1 部分)
記下新變速箱總成的序號。
CF100A4QAA00ENG
转至 3.
3.更換 TCM 及變速箱總成
  1. 點火開關為關閉。
  2. 更換 TCM 及變速箱總成。更換拆卸及安裝(TCM) 及拆卸及安裝(變速箱總成)。
转至 4.
4.執行 TCM 程式設計
使用 M.U.T.-III SE
依 M.U.T.-III SE 作動手冊中「Programming」的程序執行 TCM 程式設計。請參閱 M.U.T.-III SE 作動手冊。
注意：
程式設計期間，維持下列條件：
  • 點火開關：開啟
  • 電氣負載：關閉
  • 煞車踏板：未踩下
  • 電瓶電壓：12 – 13.5 V（務必於 M.U.T.-III SE 的「Data monitor」中選擇「電池 VOLT」檢查電瓶電壓值。）
转至 5.
5.寫入 MAC KEY
執行 MAC key 寫入，請參閱說明.
转至 6.
6.檢查序號 (第 2 部分)
使用 M.U.T.-III SE
  1. 點火開關為開啟。
  2. 將隨附 CD 插入 M.U.T.-III SE。
  3. 在「TRANSMISSION」中選擇「Special Function」。
  4. 選擇「IP characteristics data writing」的「WRITE IP CHARA - REPLACEMENT AT/CVT」。
  5. 觸碰「File import」，將 CD 中儲存的校正檔案儲存至 M.U.T.-III SE。
  6. 觸碰「OK」開啟「Select IP characteristics data file」視窗。
  7. 確認 M.U.T.-III SE 螢幕上顯示的序號（校正檔案編號）與變速箱總成上的序號（校正檔案編號）相符。
  8. 觸碰「OK」。
转至 7.
7.寫入校正資料 (IP CHARACTERISTICS VALUE)
注意：
依下列說明將新電磁閥資料寫入 TCM：
使用 M.U.T.-III SE
  1. 點火開關開啟，引擎關閉。
  2. 踩下煞車踏板。
  3. 將油門踏板踩至一半並保持，然後於 M.U.T.-III SE 螢幕上按「OK」。
  4. 依 M.U.T.-III SE 螢幕上的說明將資料寫入 TCM。
    注意：
    當校正資料已寫入 TCM 時，目前狀態將顯示「Complete」。
转至 8.
8.列印新校正資料
使用 M.U.T.-III SE
  1. 在「TRANSMISSION」中選擇「CALIB DATA」。
  2. 列印第 1 頁，共 7 頁。
    注意：
    此螢幕列印用於保固文件。
转至 9.
9.執行 G-感知器校正
執行 G-感知器校正。請參閱 Description說明.
转至 10.
10.執行離合器接合點學習
執行 Clutch Point Learning。請參閱 Description說明.
转至 11.
11.執行換檔作動器學習
執行換檔作動器學習。請參閱說明.
转至 12.
12.執行選擇學習 (DRIVE/REVERSE LEARNING)
注意：
選擇學習前務必執行 Clutch Point Learning。
  1. 執行 Select Learning。請參閱 Work Procedure作業程序.
  2. 清除可能已設定的任何 故障碼，然後試車。
