ELECTRICAL & POWER CONTROL - POWER CONTROL SYSTEM - IPDM E/R - 故障碼/電路診斷 - B120E-42 IPDM E/R（記憶體錯誤）

1.檢查 IPDM E/R 損壞
使用 M.U.T.-III SE
  1. 點火開關 開啟。
  2. 使用 M.U.T.-III SE，於「IPDM E/R」的「資料清單」模式中選擇以下項目。
    • 尾燈（LH）電路故障
    • 尾燈（RH）電路故障
    • 前霧燈（LH）電路故障
    • 前霧燈（RH）電路故障
  3. 檢查監視器狀態。
    監視項目
    監視器狀態
    尾燈（LH）電路故障
    0
    1
    尾燈（RH）電路故障
    0
    1
    前霧燈（LH）電路故障
    0
    1
    前霧燈（RH）電路故障
    0
    1
監視器狀態為何？
“0”
GO TO 2.
“1”
更換 IPDM E/R。請參閱拆卸與安裝.
2.檢查 LIN-BUS（頭燈）錯誤
檢查資訊顯示是否顯示頭燈警示。
是否顯示頭燈警示？
是
執行頭燈故障診斷。請參閱診斷程序（頭燈 RH）及故障碼說明（頭燈 LH）。
否
GO TO 3.
3.檢查 LIN-BUS（電池電流感測器）錯誤
使用 M.U.T.-III SE
  1. 使用 M.U.T.-III SE，於「IPDM E/R」的「資料清單」模式中選擇「電池電流感測器數值（LIN）」。
  2. 檢查監視器數值。
    監視項目
    監視器數值
    電池電流感測器數值（LIN）
    455.34 A
監視器數值為何？
「455.34 A」
執行電池電流感測器故障診斷。請參閱診斷程序.
「455.34 A」以外
檢查結束
