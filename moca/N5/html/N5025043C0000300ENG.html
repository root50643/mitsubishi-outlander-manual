引擎<4B4> - 直接噴射與多點燃油噴射（DI 與 MPI）- 故障排除 - 故障碼程序
Code No. P0514-00：電瓶溫度感測器合理性
N5025043C0000300ENG
技術說明
ECM 監控電瓶溫度感測器的異常特性。
監控方法說明
當 ECM 偵測到電瓶溫度感測器數值與進氣溫度感測器數值之間偏差過大時，即顯示此故障碼。
監測執行
每個行駛循環一次
監測執行條件（其他監測項目與感知器）
其他監測項目（下列監測項目未在記憶體中設定暫時性故障碼）
  • U0142-00：CAN 逾時 (IPDM E/R)
  • U01B0-00：電瓶溫度感測器 LIN 通訊（區域連網通訊）錯誤
  • P0515-00：電瓶溫度感測器電路失效/故障
  • P0516-00：電瓶溫度感測器偏低
  • P0517-00：電瓶溫度感測器偏高
感知器（下列感知器判定為正常）
  • 進氣溫度感測器
故障碼設定條件
檢查條件
  • 浸置 6 小時或更長時間之後。
  • 點火開啟或引擎運轉。
  • 點火開啟或引擎運轉開始後 35 秒以內。
  • 電瓶正極電壓大於 10.0 volts。
判定基準
  • 電瓶溫度感測器數值減去進氣溫度感測器數值為 35°C (95°F) 或以上。
或
  • 電瓶溫度感測器數值減去進氣溫度感測器數值為 -35°C (-31°F) 或以下。
失效保護與備援功能
怠速熄火功能禁止。
OBD-II 駕駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 10駕駛循環模式.
故障排除提示（此故障碼最可能的原因如下：）
  • 電瓶溫度感測器（電瓶電流感測器）失效。
  • IPDM E/R 失效。
診斷
所需特殊工具：
  • MB993028：含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
1.使用 M.U.T.-III SE 讀取故障碼。
  1. 將點火開關轉至「開啟」位置。
  2. 檢查是否設定故障碼 P0095-00、P0096-00、P0097-00、P0098-00。
  3. 將點火開關轉至「LOCK」（關閉）位置。
Q：是否有設定任何故障碼？
是
請參閱故障碼檢查表.
否
前往步驟 2。
2.使用 M.U.T.-III SE 讀取其他系統故障碼。
  1. 將點火開關轉至「開啟」位置。
  2. 讀取 IPDM E/R 故障碼（12V 電瓶電流感測器相關故障碼）。
  3. 將點火開關轉至「LOCK」（關閉）位置。
Q：是否設定 IPDM E/R 故障碼（12V 電瓶電流感測器相關故障碼）？
是
請參閱 Electrical & Power Control - Power Control System - IPDM E/R - ECU Diagnosis Information - IPDM E/R -故障碼索引.
否
前往步驟 3。
3.測試 OBD-II 駕駛循環。
  1. 依行駛循環模式執行路試。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 10駕駛循環模式.
  2. 檢查故障碼。
Q：是否設定故障碼 P0514-00？
是
重新執行故障排除。
否
檢查完成。
