引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0191-00: 供油管路壓力電路範圍/效能異常
N502500600000600ENG
線路作動
  • 檢查 Code No. P0192-00: 供油管路壓力電路輸入偏低（請參閱Code No. P0192-00: Fuel rail pressure circuit low input).
  • 檢查 Code No. P062A-00: 直噴控制 - 燃油壓力（請參閱Code No. P062A-00: Direct fuel injection control - fuel pressure).
技術說明
  • ECM 檢查燃油壓力感測器輸出訊號特性是否有異常狀況。
監視執行
連續。
監視執行條件（其它監視與感測器）
其它監視（下列監視項目的記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 引擎運轉中。
  • 電池正極電壓大於 10 volts。
判定標準
  • 當 DI 噴油嘴作動時，燃油壓力感測器數值保持不變。
或
  • 當高壓燃油泵作動時，燃油壓力感測器數值保持不變。
失效保護與備援功能
  • 在禁止燃油噴油嘴（高壓）作動的同時，僅以燃油噴油嘴作動進行控制。
  • 扭力受到限制。
OBD-II 行駛循環模式
請參閱診斷功能 – OBD-II 行駛循環 – Pattern 1 –行駛循環模式.
故障排除提示（設定此代碼最可能的原因為：）
  • 燃油壓力感測器故障
  • 燃油噴油嘴（高壓）故障
  • 燃油泵（高壓）故障
  • 燃油壓力感測器電路開路/短路或線束損壞，或接頭接觸鬆動
  • 高壓燃油管路阻塞
  • 供油管路（高壓）故障
  • ECM 故障
診斷
