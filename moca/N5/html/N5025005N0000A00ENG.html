引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0131-00：線性 A/F 感測器電路低電壓
N5025005N0000A00ENG
CIRCUIT 作動
線性 A/F 感測器與 ECM 透過下列 3 條線路連接以偵測空燃比。
  • 線性 A/F 感測器與 ECM 接頭端子 L+FL 之間的線路用於偵測空燃比。
  • 線性 A/F 感測器與 ECM 接頭端子 L-FL 之間的線路已連接至搭鐵。
技術說明
  • ECM 依據線性 A/F 感測器的訊號進行空燃比回饋控制。
  • 若線性 A/F 感測器劣化，將由氧氣感測器（後）進行修正。
監視方法說明
若三條線路電壓其中一條過低，或三條線路電壓均過低，即設定故障碼為異常。
監視執行
連續。
監視執行條件（其它監視器與感測器）
其它監視器（下列監視項目的記憶體中未設定暫時故障碼）
  • 線性空燃比感測器監視
  • 線性空燃比感測器加熱器監視
  • 氧氣感測器（後）加熱器監視
  • 缺火監視器
  • 燃油系統監視器
感測器（下列感測器判定為正常）
  • 空氣流量感測器
  • 引擎冷卻液溫度感測器
  • 1 號進氣溫度感測器
  • 大氣壓力感測器
  • 節氣門位置感測器
  • 進氣歧管絕對壓力感測器
故障碼設定條件
檢查條件
  • 電池正極電壓大於 10.5 volts 且小於 16.5 volts。
  • 引擎啟動程序完成後已超過 40 秒。
判定條件
  • 線性空燃感測器正極端子電壓低於 0.8 volts 達 2 秒。
或
  • 線性空燃感測器負極端子電壓低於 0.7 volts 達 2 秒。
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 6行駛循環模式.
故障排除提示（設定此故障碼最可能的原因為：）
  • 線性 A/F 感測器故障
  • 線性 A/F 感測器電路短路或接頭接觸不良
  • ECM 故障
診斷
所需專用工具：
  • MB993028：含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
1.檢查線性 A/F 感測器接頭與 ECM 接頭之間 L+FL 線路對搭鐵短路。
  • 斷開 ECM 接頭與線性 A/F 感測器接頭，並在線束側量測。
  • ECM L+FL 線路端子與車身搭鐵之間的電阻。
    OK: 開路
問：檢查結果是否正常？
是
前往 2。
否
修理接頭或線路。然後前往 4。
2.檢查線性 A/F 感測器接頭與 ECM 接頭之間 L-FL 線路對搭鐵短路。
  • 斷開 ECM 接頭與線性 A/F 感測器接頭，並在線束側量測。
  • ECM L-FL 線路端子與車身搭鐵之間的電阻。
    OK: 開路
問：檢查結果是否正常？
是
前往 3。
否

  • 更換線性 A/F 感測器。然後重新確認是否設定故障碼。
