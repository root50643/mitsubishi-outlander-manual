尾門開啟功能（無電動尾門系統車型）
  • 當 BCM 偵測到尾門開啟開關被按下時，免鑰匙操作鑰匙單元會將要求訊號傳送至免鑰匙操作鑰匙。接著，確認免鑰匙操作鑰匙是否靠近尾門。
  • 若免鑰匙操作鑰匙位於車外鑰匙天線偵測區域內，則會接收要求訊號，並透過遙控免鑰匙進入接收器將鑰匙 ID 訊號傳送至免鑰匙操作鑰匙單元。
  • 免鑰匙操作鑰匙單元接收鑰匙 ID 訊號，並與車輛登錄的鑰匙 ID 進行比對。
  • 若驗證結果為 OK，BCM 會解鎖並開啟尾門。
尾門開啟功能（搭載電動尾門系統車型）
  • 當 BCM 偵測到尾門開啟開關被按下時，免鑰匙操作鑰匙單元會將要求訊號傳送至免鑰匙操作鑰匙。接著，確認免鑰匙操作鑰匙是否靠近尾門。
  • 若免鑰匙操作鑰匙位於車外鑰匙天線偵測區域內，則會接收要求訊號，並透過遙控免鑰匙進入接收器將鑰匙 ID 訊號傳送至免鑰匙操作鑰匙單元。
  • 免鑰匙操作鑰匙單元接收鑰匙 ID 訊號，並與登錄的鑰匙 ID 進行比對。
  • 若驗證結果為 OK，免鑰匙操作鑰匙單元會透過 CAN 通訊將尾門開啟要求訊號傳送至電動尾門控制單元。
  • 電動尾門控制單元將尾門開啟要求訊號傳送至尾門鎖總成，尾門即開啟。
  • 當尾門開啟時，電動尾門系統會執行待命作動，等待下一次尾門關閉作動。
    尾門開啟之作動與電動尾門系統相同，請參閱系統說明.
作動條件
若符合下列條件，即可開啟尾門。
尾門開啟開關作動
作動條件
開啟
  • 所有車門：鎖定
  • 免鑰匙操作鑰匙位於車外鑰匙天線（後保險桿）偵測區域內*
*: 即使登錄的免鑰匙操作鑰匙留在車內，只要鑰匙 ID 不同，仍可使用備用免鑰匙操作鑰匙從車外開啟尾門。
注意：
尾門開啟作動之其他條件詳情，請參閱系統說明.
車外鑰匙天線偵測區域
