懸吊系統 - 道路車輪 & 輪胎 - 症狀診斷 - 胎壓警告燈閃爍
診斷程序
N505040180007U00ENG
1.檢查胎壓感知器安裝
目視檢查各車輪是否正確安裝胎壓感知器。
注意：
下列情況下，胎壓監測系統 (TPMS) 無法運作。
  • 未安裝胎壓感知器。
  • 安裝了其他車輛的胎壓感知器。
三菱原廠胎壓感知器是否正確安裝？
是
前往步驟 2.
否
更換及/或安裝胎壓感知器。請參閱拆卸與安裝. GO TO 3.
2.執行自我診斷
使用 M.U.T.-III SE
執行「BCM」的「自我診斷」。
是否偵測到故障碼？
是
執行故障碼診斷程序。請參閱故障碼索引.
否
GO TO 4.
3.胎壓感知器 ID 註冊
執行胎壓感知器 ID 註冊。請參閱說明.
胎壓感知器 ID 註冊是否完成？
是
將所有車輪胎壓調整至規定值。請參閱輪胎充氣壓力. 檢查結束
否
執行「胎壓感知器 ID 註冊無法完成」的診斷程序。請參閱說明.
4.檢查 BCM 電源及搭鐵電路
執行 BCM 電源及搭鐵電路故障診斷。請參閱診斷程序.
檢查結果是否正常？
是
Repair or 更換 error-detected parts.
否
更換 BCM。請參閱拆卸與安裝.
