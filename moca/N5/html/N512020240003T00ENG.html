故障碼確認程序
1.前置條件
使用 M.U.T.-III SE
  1. 點火開關開啟。
  2. 使用 M.U.T.-III SE 在「IPDM E/R」的「資料清單」模式中選取「T LIGHT LH CIRC MALFUNCTN」及「T LIGHT RH CIRC MALFUNCTN」。
  3. 檢查監視狀態。
    監視項目
    監視狀態
    T LIGHT LH CIRC MALFUNCTN
    0
    1
    T LIGHT RH CIRC MALFUNCTN
    0
    1
監視狀態為何？
“0”
前往 2.
“1”
在尾燈或牌照燈電源供應線路中多次偵測到短路，且 IPDM E/R 內的智慧型 FET 累積損壞。因此，IPDM E/R 無法開啟智慧型 FET。由於在此狀態下無法重現故障碼，請執行診斷程序並在故障零件修理後更換 IPDM E/R。請參閱拆卸與安裝.
2.執行故障碼確認程序
使用 M.U.T.-III SE
  1. 點火開關關閉。
  2. 點火開關開啟。
  3. 將燈光開關轉至 1ST。
  4. 使用 M.U.T.-III SE 選擇「IPDM E/R」的「自我診斷結果」模式。
  5. 檢查 故障碼.
