引擎<4B4> - 直接燃油噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. C0503-00：車輛車速感測器 FL high
N5025042J0000300ENG
技術說明
VDC 監控車輛車速感測器，並將診斷結果 (OK/NOK) 的 CAN 訊號傳送至 ECM。
監控方法說明
當 ECM 從 VDC 接收到車輛車速感測器的 NOK 資訊時，會顯示故障碼。
監控執行
連續。
監控執行條件（其他監控及感測器）
其他監控（下列監控項目之記憶體中未設定暫時性故障碼）
  • U0121-00: ASC time-out
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
偵測條件
  • 引擎運轉中。
  • 電池正極電壓大於 10.5 V 且小於 16.5 V。
判斷標準
  • ECM 持續 3 秒接收到 VDC 失效/故障資訊。
失效保護及備援功能
禁止 Auto Stop。
OBD-II 行程循環模式
請參閱 Diagnostic Function，OBD-II Drive Cycle – Pattern 5行程循環模式.
故障排除提示（此故障碼最可能之設定原因如下：）
請檢查 VDC，並依 VDC 的故障排除程序進行檢查。
診斷
所需特殊工具：
  • MB993028：VCI-3 kit with wireless adapters
    1. -：VCI-3 device
    2. MB993029：DLC cable
    3. MB993030：USB cable
    4. MB993031：Wireless USB adapter (Qty:2)
  • MB993040：VCI-3 kit without wireless adapters
    1. -：VCI-3 device
    2. MB993029：DLC cable
    3. MB993030：USB cable
1.使用 M.U.T.-III SE 讀取其他系統故障碼。
  1. 將點火開關轉至「開啟」位置。
  2. 讀取 ABS 作動器與電動單元（控制單元）故障碼（前 LH 輪感測器相關故障碼）。
  3. 將點火開關轉至「LOCK」（關閉）位置。
Q：ABS 作動器與電動單元（控制單元）故障碼（前 LH 輪感測器相關故障碼）是否已設定？
是
請參閱 煞車 - 煞車控制系統 - 配備 VDC - ECU 診斷資訊 - ABS 作動器及電氣單元 (控制單元) -故障碼索引.
否
進入步驟 2。
2.測試 OBD-II 行程循環。
  1. 將點火開關轉至「開啟」位置並清除故障碼。
  2. 依駕駛循環模式執行測試駕駛。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行程循環模式.
  3. 檢查故障碼。
Q：故障碼 C0503-00 是否已設定？
是
更換 ECM (請參閱 拆卸與安裝引擎-ECU 拆卸與安裝）。然後進入步驟 3。
否
檢查完成。
3.測試 OBD-II 行程循環。
  1. 依駕駛循環模式執行測試駕駛。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行程循環模式.
  2. 檢查故障碼。
Q：故障碼 C0503-00 是否已設定？
是
重新執行故障排除。
否
檢查完成。
