引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0087-00: 燃油系統壓力過低
N5025004Q0000900ENG
電路作動
  • 檢查 Code No. P0192-00: 送油管壓力電路輸入偏低（請參閱Code No. P0192-00: 燃油共軌壓力電路輸入偏低).
  • 檢查 Code No. P062A-00: 直噴燃油控制 - 燃油壓力（請參閱Code No. P062A-00: 直噴燃油控制 - 燃油壓力).
技術說明
  • ECM 監控來自燃油壓力感測器的輸入信號。
  • 根據輸入信號，ECM 檢查燃油壓力是否低於系統最低壓力。
監視執行
連續。
監視執行條件 (其他監視器與感知器)
其他監視器 (以下監視項目在記憶體中未設定暫時性故障碼)
  • 失火監測
感知器 (以下感知器判定為正常)
  • 噴油閥
  • 燃油壓力感知器
  • 高壓燃油泵
故障碼設定條件
檢查條件
  • 引擎啟動後 10 秒。
  • 直噴噴油嘴作動期間。
  • 實際燃油壓力低於目標燃油壓力。
判定基準
  • 實際燃油壓力與目標燃油壓力之差超過 3.5 MPa (508 psi) 達 10 秒。
失效保護與備援功能
  • 禁止燃油噴油嘴（高壓）作動期間，僅以低壓燃油噴油嘴作動進行控制。
  • 扭力受到限制。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 16行駛循環模式.
故障排除提示 (此故障碼最可能的設定原因為：)
  • 燃油壓力感測器電路線束損壞或接頭接觸鬆脫
  • 高壓燃油泵電路線束損壞或接頭接觸鬆脫
  • 燃油壓力感測器失效
  • 燃油管路失效
  • 油箱泵與油位計總成失效
  • 高壓燃油泵失效
  • 燃油噴油嘴（高壓）失效
  • 高壓燃油管路失效
  • ECM 故障
  • 燃油耗盡

2.檢查高壓燃油管路與燃油管路。

  • 拆下火星塞，檢查是否可從火星塞孔聞到燃油氣味。若聞到燃油氣味，檢查燃油噴油嘴（高壓）是否洩漏。
