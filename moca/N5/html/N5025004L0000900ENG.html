引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0045-00: 廢氣門作動器控制伺服馬達迴路高電位
N5025004L0000900ENG
電路作動
  • 控制從 ECM 接頭端子 WGM+、WGM- 施加至電子控制廢氣門作動器的電流。
技術說明
  • ECM 變化施加至廢氣門作動器控制伺服馬達的電流方向與電流量，以控制渦輪增壓器廢氣門調節閥的開啟。
監視方法說明
ECM 偵測到短路故障。
監視執行
連續。
監視執行條件（其它監視與感測器）
其它監視（下列監視項目在記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關在 開啟 位置。
  • 電瓶正極電壓高於 10.5 volts。
  • 引擎啟動程序完成後已超過 2 秒。
判定標準
  • 廢氣門控制驅動器偵測到過電流。
失效保護與備援功能
增壓壓力受到限制。
OBD-II 驅動循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 6驅動循環模式.
故障排除提示（此故障碼最可能的設定原因如下：）
  • 電子控制廢氣門作動器故障。
  • 廢氣門作動器控制伺服馬達迴路開路/短路或線束損壞，或接頭接觸鬆脫。
  • ECM 故障
診斷
所需特殊工具：
  • MB993028：VCI-3 套件（含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：VCI-3 套件（不含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
1.於 ECM 接頭執行電阻測量。
  • 斷開接頭，在線束側測量。
  • 端子 GND1、GND2、GND3、GND4 與車身搭鐵之間的電阻。

  • 故障碼再確認。

  • 點火開關：LOCK（關閉）→ 開啟
  • 啟動引擎。
  • 確認故障碼是否已設定。
