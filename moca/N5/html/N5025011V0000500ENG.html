引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. U0131-00: CAN 逾時 (EPS)
N5025011V0000500ENG
警告：
若 ECM 中設定診斷故障碼 U0131-00，務必執行 CAN 匯流排線路診斷。
警告：
在確實確認通訊電路正常後，更換 ECU。
故障碼設定條件
檢查條件
  • 點火開關轉至「開啟」位置後經過 2 秒。
  • 電瓶正極電壓大於 10.5 V 且小於 16.5 V。
判定標準
  • 無法透過 CAN 匯流排線路接收 EPS-ECU 訊號達 4 秒。
備註
目前故障
  • 失效／故障可能係 ECM 與動力轉向控制單元之間 CAN 匯流排線路上的線束及接頭故障、動力轉向控制單元故障，或 ECM 故障所造成。
過去故障
  • 進行故障排除時，著重於 ECM 與動力轉向控制單元之間 CAN 匯流排線路上的線束及接頭故障。
注意：
若為過去故障，即使 CAN 匯流排有故障，M.U.T.-III SE 的 CAN 匯流排線路診斷也可能無法偵測到故障。因此，應如同對應間歇性故障一般檢查 CAN 匯流排線路（請參閱 General Information – Basic Inspection – Service Information for Electrical Incident –間歇性故障）。可從執行 CAN 通訊的各 ECU 中設定的診斷故障碼，縮小較可能發生故障的區域（請參閱 Electrical and Power Control – LAN System – CAN Fundamental – Basic Inspection – Diagnosis and Repair Workflow –M.U.T.-III SE CAN 匯流排診斷說明).
失效保護與備援功能
  • 正常作動時，禁止自動熄火。
  • 若於自動熄火期間偵測到故障，執行強制自動啟動。
OBD-II 行駛循環模式
請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 3行駛循環模式.
故障排除提示（設定此代碼最可能的原因為：）
  • CAN 匯流排線路故障
  • 8ch CAN 網關電源電路故障
  • 8ch CAN 網關故障
  • 底盤控制模組電源電路故障
  • 底盤控制模組故障
  • EPS-ECU 電源電路故障
  • EPS-ECU 故障
  • ECM 故障
診斷
所需特殊工具：

    2. MB993029: DLC cable
    3. MB993030: USB cable

1.使用 M.U.T.-III SE 讀取故障碼。
  • 故障碼再確認。
再次確認 ECM 中是否設定故障碼。
  1. 清除已設定的故障碼。
  2. 點火開關：LOCK（關閉）→ 開啟
  3. 確認是否設定故障碼。
Q：是否設定故障碼 U0131-00？
是
使用 M.U.T.-III SE 執行 CAN 匯流排線路診斷。（請參閱 Electrical and Power Control – LAN System – CAN Fundamental – Basic Inspection – Diagnosis and Repair Workflow –M.U.T.-III SE CAN 匯流排診斷說明）。然後前往 2。
否
間歇性故障（請參閱 General Information – General Information – Basic Inspection – Service Information for Electrical Incident –間歇性故障).
2.測試 OBD-II 行駛循環。
  1. 以驅動循環模式執行試車。（請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 3行駛循環模式).
  2. 檢查故障碼。
