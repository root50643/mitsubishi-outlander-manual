引擎<4B4> - 直接噴射與多點燃油噴射 (DI 與 MPI) - 故障排除 - 故障碼程序
Code No. P0015-00: 排氣可變汽門正時系統目標值錯誤 (retard)
N5025004E0000700ENG
作動
  • 檢查 Code No. P0013-00 凸輪軸位置作動器電路(EX) (請參閱Code No. P0013-00: 凸輪軸位置作動器電路(EX)).
功能
  • ECM依引擎行駛狀況控制排氣油壓控制閥的滑閥位置，並連續改變排氣凸輪軸的相位。
  • 排氣凸輪軸的相位角是依曲軸角度感測器及排氣凸輪軸位置感測器的訊號波形計算得出。
監控方法說明
實際排氣門開啟正時與目標排氣門開啟正時在 retard 角度側的差值超過規定值。
監視器執行
連續。
監視器執行條件（其他監視器與感知器）
其他監視器（以下監視項目之記憶體中未設定暫時性故障碼）
  • 不適用
感知器（以下感知器判定為正常）
  • Camshaft 位置 感知器
  • 曲軸角度感知器
  • 引擎冷卻液溫度感測器
  • 引擎 oil control 汽門
故障判定
檢查條件
  • 引擎起動程序完成後已超過20秒。
  • 引擎轉速超過1,200 r/min。
  • 引擎冷卻液溫度超過76°C。
判定條件
  • 進氣門開啟正時與目標進氣門開啟正時的差值超過5 degrees CA並持續5秒。
失效保護與備用功能
無。
OBD-II 駕駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 18駕駛循環模式.
可能原因
  • 排氣油壓控制閥故障
  • 排氣油壓控制閥電路損壞或接頭接觸鬆動
  • 排氣正時鏈輪作動故障
  • 機油通道堵塞
  • 排氣凸輪軸故障
  • ECM 失效
診斷程序
所需特殊工具：
  • MB993028：附無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束

  • 資料清單 參考表 (請參閱資料清單 參考表).
