1.檢查故障碼優先順序
若故障碼 "C1F03-23" 與網路故障碼同時顯示，請先診斷網路故障碼。
是否偵測到適用之故障碼？
是
執行適用之診斷。請參閱故障碼索引故障碼索引.
否
GO TO 2.
2.檢查 MI-PILOT Assist 方向盤開關
  1. 將點火開關關閉。
  2. 斷開 MI-PILOT Assist 方向盤開關接頭。
  3. 檢查 MI-PILOT Assist 方向盤開關。請參閱元件檢查.
檢查結果是否正常？
是
GO TO 3.
否
更換 MI-PILOT Assist 方向盤開關。

5.執行 ECM 自我診斷
  1. 連接 MI-PILOT Assist 方向盤開關接頭與 ECM 接頭。
  2. 將點火開關轉至開啟。
  3. 執行「Read All DTCs」。
  4. 檢查「引擎」的「Self Diagnostic Result」是否偵測到任何故障碼。
是否偵測到任何故障碼？
是
針對偵測到的故障碼執行自我診斷，並修理或更換故障零件。請參閱故障碼索引.
否
更換 ADAS 控制單元 2。請參閱拆卸與安裝.
