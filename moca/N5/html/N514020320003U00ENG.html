1.SHIPPING MODE CANCEL 作動
  1. 點火開關關閉。
  2. 按入（開關開啟）延長存放保險絲開關。請參閱檢查方法檢查方法.
  3. 點火開關開啟。
  4. 點火開關關閉，並至少等待 2 秒。
转至 2.
2.SHIPPING MODE CANCEL 檢查
  1. 點火開關開啟。
  2. 檢查資訊顯示器開啟時，未顯示延長存放保險絲警告訊息。
