電氣與電力控制 - LAN 系統 - CAN 網關 - 故障碼/電路診斷 - U278C-88 Ethernet port1 失效/故障
診斷程序
N5140301Z001F800ENG
1.檢查 接頭
  1. 點火開關關閉。
  2. 檢查 Ethernet 線束接頭以及 8CH CAN 網關與 TCU 的端子是否損壞或鬆脫。
檢查結果是否正常？
是
前往 2.
否
修理或更換故障零件，並確實鎖緊線束接頭。
2.執行所有故障碼讀取
  1. 點火開關為開啟。
  2. 使用 M.U.T.-III SE 執行「Read all DTCs and FFD」。
  3. 檢查在「IVC」的「自我診斷」中是否偵測到任何 Ethernet 故障碼（故障碼 "U2754-88"）
是否偵測到任何 Ethernet 故障碼？
是
更換 8CH CAN 網關（請參閱拆卸與安裝），並前往 3.
否
更換 TCU。請參閱拆卸與安裝.
3.執行故障碼確認程序-1
  1. 使用 M.U.T.-III SE 清除所有自我診斷結果。
  2. 再次執行故障碼確認程序。請參閱確認程序.
故障碼「U278C-88」是否被偵測為目前故障？
是
更換 TCU（請參閱拆卸與安裝），並GO TO 4.
否
檢查結束
4.執行故障碼確認程序-2
  1. 使用 M.U.T.-III SE 清除所有自我診斷結果。
  2. 再次執行故障碼確認程序。請參閱確認程序.
故障碼「U278C-88」是否被偵測為目前故障？
是
更換 8CH CAN 網關與 TCU 之間的 Ethernet 線束。
否
檢查結束
