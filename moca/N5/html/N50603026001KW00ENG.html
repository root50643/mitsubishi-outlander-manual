煞車 - 煞車控制系統 - VDC - 故障碼/電路診斷 - C106B-64 煞車燈開關
診斷程序
N50603026001KW00ENG
1.檢查 BCM 系統
使用 M.U.T.-III SE
對「BCM」執行自我診斷。
是否偵測到故障碼？
是
檢查故障碼。請參閱故障碼索引故障碼索引.
否
進行步驟 2.
2.檢查接頭及端子
  1. 斷開 12V 電池負極端子。
  2. 斷開/拔除 BCM 線束接頭。
  3. 斷開 ABS 作動器與電氣單元（控制單元）線束接頭。
  4. 檢查接頭是否脫開或鬆脫。
  5. 檢查端子是否損壞或與線束接頭連接鬆脫。
檢查結果是否正常？
是
進行步驟 3.
否
修理／更換線束、接頭或端子，並確實鎖緊接頭。進行步驟 3.
3.執行自我診斷
使用 M.U.T.-III SE
  1. 連接 BCM 線束接頭。
  2. 連接 ABS 作動器與電氣單元（控制單元）線束接頭。
  3. 連接 12V 電池負極端子。
  4. 清除「ABS」自我診斷結果。
  5. 點火開關關閉 (自動 ACC 功能關閉)。
  6. 啟動引擎。
    注意：
    引擎啟動後至少等待 10 秒。
  7. 執行「ABS」自我診斷。
是否偵測到故障碼「C106B-64」？
是
更換 ABS 作動器與電氣單元（控制單元）。請參閱拆卸及安裝.
否
檢查結束
