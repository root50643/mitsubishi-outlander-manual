詳細流程
1.取得症狀資訊
  1. 向客戶詳細詢問症狀（事故／故障發生時的狀況與環境）。
  2. 檢查故障功能的作動狀況。
前往步驟 2.
2.檢查 故障碼
  1. 檢查 故障碼.
  2. 若偵測到故障碼，執行以下程序。
    • 記錄故障碼及定格資料（使用 M.U.T.-III SE 列印）。
    • 清除故障碼。
    • 研究故障碼偵測到的原因與客戶描述症狀之間的關係。
  3. 查閱相關服務通報以取得資訊。
是否有描述症狀且偵測到故障碼？
有描述症狀，有偵測到故障碼
GO TO 3.
有描述症狀，未偵測到故障碼
GO TO 4.
未描述症狀，有偵測到故障碼
GO TO 5.
3.確認症狀
嘗試確認客戶所描述的症狀。
同時研究與該症狀相關的正常作動及失效保護。
確認症狀與症狀被偵測到時之狀況之間的關係。
GO TO 5.
4.確認症狀
嘗試確認客戶所描述的症狀。
確認症狀與症狀被偵測到時之狀況之間的關係。
GO TO 6.
5.執行故障碼確認程序
針對偵測到的故障碼執行故障碼確認程序，然後檢查故障碼是否再次偵測到。此時一律將 Mair M.U.T.-III SE 連接至車輛，並即時檢查自我診斷結果。
若偵測到兩個以上的 故障碼，請參閱故障碼檢查優先順序圖並決定故障診斷順序。
備註：
  • 若未偵測到故障碼，定格資料將有所幫助。
  • 若服務手冊中未包含故障碼確認程序，則執行元件功能檢查。此簡化檢查程序雖無法在檢查期間偵測故障碼，但仍為有效的替代方法。
    若元件功能檢查結果為 NG，則等同於透過故障碼確認程序偵測到故障碼。
是否偵測到故障碼？
是
GO TO 7.
否
依間歇性故障程序檢查間歇性故障.
6.依症狀診斷偵測故障系統
依步驟 4 確認的症狀，根據症狀診斷偵測故障系統，並依可能原因及症狀決定故障診斷順序。
是否有描述症狀？
是
GO TO 7.
否
使用 M.U.T.-III SE 監控相關感測器輸入資料或檢查相關模組端子的電壓。
7.依診斷程序偵測故障零件
依該系統的診斷程序進行檢查。
是否偵測到故障零件？
是
GO TO 8.
否
依間歇性故障程序檢查間歇性故障.
8.維修或更換故障零件
  1. 維修或更換故障零件。
  2. 維修及更換後，重新連接診斷程序中斷開的零件或接頭。
  3. 檢查故障碼。若偵測到故障碼，將其清除。
GO TO 9.
9.最終檢查
當步驟 2 偵測到故障碼時，再次執行故障碼確認程序，然後檢查故障是否已確實修復。
當客戶描述症狀時，請參閱步驟 3 或 4 確認的症狀，並檢查該症狀是否已不再出現。
是否偵測到故障碼且症狀仍存在？
YES-1
偵測到故障碼：前往步驟 7.
YES-2
症狀仍存在：前往步驟 4.
否
歸還車輛給客戶之前，一律清除故障碼。
