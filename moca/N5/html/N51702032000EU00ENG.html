定速控制&駕駛輔助 - 駕駛輔助系統 - 駕駛輔助系統 - 基本檢查 - 更換前攝影機單元時的額外服務
作業程序
N51702032000EU00ENG
  • 更換前攝影機單元後，務必執行前攝影機單元設定。
  • 拆裝或更換前攝影機單元後，務必執行攝影機瞄準。
注意：
除非執行前攝影機單元設定及攝影機瞄準調整，否則系統無法正常運作。務必執行上述作業。
1.前攝影機單元設定
使用 M.U.T.-III SE 執行前攝影機單元設定。請參閱作業程序.
前往 2.
2.攝影機 瞄準 調整
使用 M.U.T.-III SE 執行攝影機瞄準調整。請參閱作業程序.
前往 3.
3.執行自我診斷
使用 M.U.T.-III SE 執行前攝影機單元自我診斷。檢查是否偵測到任何故障碼。
是否偵測到任何故障碼？
是
對偵測到的故障碼執行故障診斷。請參閱故障碼索引故障碼索引.
否
GO TO 4.
4.作動測試
  1. 執行下列系統作動測試。
    • LDW：請參閱作業程序檢查程序.
    • LDP：請參閱作業程序檢查程序.
    • 主動盲點輔助 [ABSA]：請參閱作業程序.
    • TSR：請參閱作業程序.
  2. 檢查各系統是否正常運作。
前往 5.
5.執行原廠模式關閉
  1. 將點火開關切換至 開啟。
  2. 在「車道攝影機」的「特殊功能」畫面中選擇「原廠模式關閉」。
  3. 檢查項目 No.1：原廠模式，並依設定值執行下列程序。
    • 開啟：選擇「確定」並將設定值變更為「關閉」。
    • 關閉：無需作業，作業完成。
