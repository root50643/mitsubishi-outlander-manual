引擎<4B4> - 直接燃油噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
代碼 No. P0A8D-00: 48V 電池 BMS 系統電壓過低
N502500950000400ENG
監控執行
連續。
監控執行條件（其他監控及感測器）
其他監控（下列監控項目之記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關為 開啟。
  • 12V 電瓶電壓大於 10.5 volts 且小於 16.5 volts。
  • 引擎未在起動中
  • CAN 通訊（ECM - 48V 電池（BMS））正常。
判定基準
  • ECM 透過 CAN 在數秒內接收到異常的 48V 電池 BMS 系統診斷訊號。
失效保護及備援功能
  • 48V MILD HYBRID 系統停止運作。
    1. 停止供應 12V 側電力。
    2. 帶傳動起動發電機之引擎輔助及再生制動停止。
  • 充電警告燈點亮。
  • 禁止 Auto Stop。
  • AS&G 關閉 指示燈閃爍。
OBD-II 行程循環模式
請參閱 Diagnostic Function，OBD-II Drive Cycle – Pattern 5行程循環模式.
故障排除提示（此故障碼最可能之設定原因如下：）
  • 48V 電池故障。
  • 12V 電池故障。
  • DC-DC 轉換器故障。
  • 48V 電池 (鋰離子電池管理器) 接頭故障。
  • 電源供應電路開路/短路或線束損壞，或接頭接觸不良。

1.使用 M.U.T.-III SE 讀取故障碼。
使用 M.U.T.-III SE 檢查並確認是否有設定 P0A8D-00 以外的故障碼。
問: 是否有設定 P0A8D-00 以外的故障碼？
是
針對已設定的故障碼執行故障排除。(請參閱故障碼檢查表).
否
進入步驟 2。
2.檢查大電流保險絲 No.9 與 48V 電池接頭之間 B+ 線路的開路與短路。
Q：檢查結果是否正常？
是
進入步驟 3。
否
修理或更換接頭，或修理損壞的線束導線。然後GO TO 8.
3.檢查 48V 電池接頭與車身搭鐵之間 GND 線路的開路。
Q：檢查結果是否正常？
是
轉至 4.
否
修理或更換接頭，或修理損壞的線束導線。然後GO TO 8.
4.檢查 12V 電池
點火開關: 關閉
檢查 12V 電池 (請參閱電氣與電源控制 - 電源供應、搭鐵與電路元件 - 系統說明 - 零件 -12V 電池).
Q：檢查結果是否正常？
是
GO TO 5.
否
更換 12V 電池 (請參閱電氣與電源控制 - 電源供應、搭鐵與電路元件 - 拆卸與安裝 - 電池 -爆炸圖）。然後進行步驟 5.
5.檢查 12V 電池
點火開關：開啟
檢查 12V 電池 (請參閱電氣與電源控制 - 電源供應、搭鐵與電路元件 - 系統說明 - 零件 -12V 電池).
Q：檢查結果是否正常？
是
GO TO 6.
否
至步驟 1。
6.故障碼重新檢查
確認是否設定故障碼。
Q：是否設定故障碼？
是
更換 48V 電池 (請參閱電氣與電源控制 - 電源供應、搭鐵與電路元件 - 拆卸與安裝 - 48V 電池 - 服務程序維修程序）。然後GO TO 7.
否
GO TO 7.
7.檢查 12V 電池
啟動引擎並讓其怠速運轉。
檢查 12V 電池 (請參閱電氣與電源控制 - 電源供應、搭鐵與電路元件 - 系統說明 - 零件 -12V 電池).
Q：檢查結果是否正常？
是
GO TO 8.
否
至步驟 1。
8.測試 OBD-II 行程循環。
  1. 依駕駛循環模式執行測試駕駛。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行程循環模式.
  2. 檢查故障碼。
問: 是否設定故障碼 P0A8D-00？
是
重新執行故障排除。
否
檢查完成。
