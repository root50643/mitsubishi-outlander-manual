引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0ABB-00：48V 電池端子電壓感測器合理性
N5025043X0000300ENG
監視執行
連續。
監視執行條件（其它監視器與感測器）
其它監視器（下列監視項目的記憶體中未設定暫時故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關為開啟。
  • 12V 電池電壓大於 10.5 V 且小於 16.5 V。
  • 引擎未啟動
  • CAN 通訊（ECM - 48V 電池（BMS））正常。
判定條件
  • ECM 透過 CAN 在數秒內接收到異常的 48V 電池端子電壓感測器診斷訊號。
失效保護與備援功能
  • 48V 輕度混合動力系統停止。
    1. 停止供電至 12V 側。
    2. 皮帶驅動起動馬達發電機的引擎助力與再生停止。
  • 充電警示燈亮起。
  • 禁止 Auto Stop。
  • AS&G 關閉燈閃爍。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
故障排除提示（設定此故障碼最可能的原因為：）
48V 電池故障。
診斷
所需專用工具：
  • MB993028：含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
1.使用 M.U.T.-III SE，讀取故障碼。
  1. 將點火開關轉至「開啟」位置。
  2. 檢查是否設定與皮帶驅動起動馬達發電機或 DC-DC 轉換器相關的故障碼。
  3. 將點火開關轉至「LOCK」（關閉）位置。
Q：是否有設定任何故障碼？
是
請參閱故障碼檢查表.
否
前往 2。
2.使用 M.U.T.-III SE，檢查資料清單。
  1. 將點火開關轉至「開啟」位置。
  2. 檢查資料清單中的下列項目（請參閱資料清單 參考表).
    1. 項目 139：48V 電池 Pack Link 電壓
問：檢查結果是否正常？
是
前往 3。
否
更換 48V 電池（請參閱 Electrical & Power Control - Power Supply, Ground & Circuit Elements - 48V 電池 -維修程序）。然後前往 3。
3.測試 OBD-II 行駛循環。
  1. 將點火開關轉至「開啟」位置並清除故障碼。
  2. 以驅動循環模式執行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  3. 檢查故障碼。
Q：是否設定故障碼 P0ABB-00？

否
檢查完成。
4.測試 OBD-II 行駛循環。
  1. 以驅動循環模式執行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  2. 檢查故障碼。
