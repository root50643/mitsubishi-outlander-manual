引擎<4B4> - 直接燃油噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0182-00：油箱溫度感測器電路低輸入 <Vehicles for Taiwan>
N5025005Y0000500ENG
線路作動
  • 5 V 電源電壓自 ECM 內部電阻，經 ECM 端子 F/TM 施加至油箱溫度感測器輸出端子。
  • 油箱溫度感測器輸出電壓隨電阻增大而升高，隨電阻減小而降低。搭鐵端子搭鐵至車身。
技術說明
  • 油箱溫度感測器將油箱溫度轉換為電壓。
  • ECM 以此輸出電壓偵測油箱溫度。
監控方法說明
油箱溫度感測器輸出電壓超出規定範圍。
監控執行
連續。
監控執行條件（其他監控項目及感測器）
其他監控項目（下列受監控項目的記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器已判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 自引擎啟動程序完成後已超過2秒。
判定標準
  • 油箱溫度感測器輸出電壓低於 0.7 V 持續 2 秒。
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 4 –行駛循環模式.
故障排除提示 (本故障碼最可能設定原因：)
  • 油箱溫度感測器故障。
  • 油箱溫度感測器電路短路，或接頭損壞。
  • ECM 故障。
診斷

GO TO 4.
