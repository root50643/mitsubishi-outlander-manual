工作流程

詳細流程
1.客戶訪談
檢查前應先釐清客戶抱怨。首先進行訪談，並運用重現症狀的方式，以完全了解症狀。請仔細詢問客戶其抱怨內容。必要時，請與客戶一同試車檢查症狀。
注意：
客戶並非專業人員。切勿輕易臆測，例如「也許客戶是指……」或「也許客戶提到的是這個症狀」。
前往 2.
2.檢查症狀
根據訪談取得的客戶資訊，重現客戶所述症狀。同時檢查該症狀是否由保護功能所造成。請參閱保護功能.
注意：
當症狀為正常作動所造成時，請完整檢查各部位，並取得客戶理解，確認該症狀並非故障所造成。
前往 3..
3.執行自我診斷
使用 M.U.T.-III SE
執行自我診斷。
是否偵測到任何故障碼？
是
記錄或列印故障碼。GO TO 4.
否
GO TO 6.
4.重新確認症狀
使用 M.U.T.-III SE
  1. 清除「EPS/DAST 3」的自我診斷結果。
  2. 拉起駐車煞車開關。
    注意：
    確認駐車煞車開關指示燈已點亮。
  3. 點火開關關閉。
  4. 下車並關閉所有車門。
  5. 等待 65 秒。
    注意：
    • 確認駐車煞車開關指示燈已熄滅。
    • 若後輪煞車卡鉗溫度偏高，請等待 1 小時，以避免駐車煞車開關指示燈誤熄滅。
  6. 啟動引擎。
    注意：
    切勿行駛車輛。
  7. 執行故障偵測系統的故障碼確認程序。
注意：
若同時偵測到多個 故障碼，請依據相關資訊決定診斷順序。請參閱故障碼檢查優先順序表.
是否偵測到任何故障碼？
是
前往 5.
否
依據訪談取得的資訊檢查線束與接頭。請參閱診斷工作表.
5.維修或更換故障零件
  • 修理或更換偵測到異常的零件。
  • 維修或更換後，重新連接零件或接頭。
  • 偵測到故障碼時，請清除「EPS/DAST 3」的自我診斷結果。
GO TO 7.
6.依症狀診斷辨識故障系統
依據症狀診斷估計故障系統並執行檢查。
是否能辨識故障系統？
是
GO TO 7.
否
依據訪談取得的資訊檢查線束與接頭。請參閱診斷工作表.
7.最終檢查
使用 M.U.T.-III SE
  1. 檢查動力轉向控制模組的參考值。
  2. 重新確認症狀，並檢查在相同條件下是否不會再現症狀。
症狀是否再現？
是
前往 3.
否
