詳細流程
1.故障問診
開始檢查前，先釐清客戶疑慮非常重要。仔細向客戶問診，並充分了解症狀。
注意：
客戶並非專業人員。切勿臆測「或許客戶是指……」或「或許客戶提到的是這個症狀」。
前往步驟 2。
2.使用 M.U.T.-III SE 自我診斷
M.U.T.-III SE
  1. 執行「Read All DTCs」模式。
  2. 檢查下列項目的「自我診斷結果」中是否偵測到故障碼：
    • 「ACC/ADAS 2」
    • 「LASER/RADAR」
    • 「車道攝影機」
    • 「側向雷達 (Rear left)」
    • “側向雷達 (右後)”
是否偵測到任何故障碼？
是
前往步驟 5。
否
前往步驟 3。
3.作動測試
  1. 執行系統作動測試，檢查下列項目的作動狀態：
    • LDW：請參閱作業程序檢查程序.
    • LDP：請參閱作業程序檢查程序.
    • BSW：請參閱作業程序.
    • 主動盲點輔助 [ABSA]：請參閱作業程序.
    • TSR：請參閱作業程序.
    • RCTA：請參閱作業程序.
    • DAA：請參閱作業程序.
  2. 檢查是否有其他故障發生。
前往步驟 4。
4.症狀診斷
依症狀診斷圖表執行適用之診斷。請參閱症狀表.
GO TO 6.
5.依故障碼進行故障診斷
M.U.T.-III SE
  1. 檢查「自我診斷結果」中的故障碼。
  2. 對下列偵測到的故障碼執行故障診斷：
    • 「ACC/ADAS 2」：請參閱 故障碼 Index故障碼索引.
    • 「LASER/RADAR」：請參閱 故障碼 Index故障碼索引.
    • 「車道攝影機」：請參閱 故障碼 Index故障碼索引.
    • 「側向雷達 (Rear left)」：請參閱 故障碼 Index故障碼索引.
    • 「側向雷達 (右後)」：請參閱 故障碼 Index故障碼索引.
注意：
若偵測到網路故障碼，請先診斷 CAN 通訊系統。
GO TO 6.
6.故障零件維修
維修或更換已確認之故障零件。
GO TO 7.
7.維修檢查（使用 M.U.T.-III SE 自我診斷）
  1. 清除「自我診斷結果」。
  2. 維修或更換特定項目後，執行「Read All DTCs」模式。
  3. 檢查下列項目的自我診斷結果中是否偵測到任何故障碼：
    • 「ACC/ADAS 2」
    • 「LASER/RADAR」
    • 「車道攝影機」
    • 「側向雷達 (Rear left)」
    • “側向雷達 (右後)”
是否偵測到任何故障碼？
是
前往步驟 5。
否
GO TO 8.
8.維修檢查（作動測試）
執行下列系統作動測試。檢查故障症狀是否已排除，或是否無其他症狀發生。
  • LDW：請參閱作業程序檢查程序.
  • LDP：請參閱作業程序檢查程序.
  • BSW：請參閱作業程序.
  • 主動盲點輔助 [ABSA]：請參閱作業程序.
  • TSR：請參閱作業程序.
  • RCTA：請參閱作業程序.
  • DAA：請參閱作業程序.
是否有故障症狀？
是
前往步驟 4。
否
檢查結束。
