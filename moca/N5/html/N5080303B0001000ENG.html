當碰撞時安全氣囊作動
N5080303B0001000ENG
側面及翻覆碰撞：碰撞時氣囊作動
警告：
因車型及配備等級不同，下表所列零件並非適用於所有車輛。
作業程序
執行下列任何步驟前，請確認所有車身及結構修復已完成。
更換下列零件。
  • 前座椅背總成 (側邊安全氣囊作動的一側)。
  • 前座椅背總成 (中央安全氣囊作動的一側)。
  • 車門飾板 (簾式安全氣囊作動的一側)。
  • 彈出式防滾桿總成及彈出式防滾桿蓋。
  • 側邊安全氣囊 (衛星) 感測器 LH/RH (側邊安全氣囊作動的一側)。
  • 診斷感測器單元。
  • 安全帶預緊器總成。
使用下表檢查安全氣囊元件及相關零件。
更換任何氣囊零件及相關零件，若其呈現可見損壞跡象 (凹痕、裂縫、變形等)。
使用 M.U.T.-III SE 及「AIR BAG」警告燈執行自我診斷。請參閱故障碼索引故障碼索引以了解詳情。務必確認整個安全氣囊系統運作正常。
作業完成後，確認安全氣囊警告燈未偵測到任何故障。
若安全氣囊展開後進行緊急呼叫，必須執行下列作業。
使用 M.U.T.-III SE
  1. 使用 M.U.T.-IIISE 選取 "IVC" 的 "Automatic notification prevention lock release" 模式。
  2. 選取 "OK" 以解鎖。
安全氣囊檢查（側面及翻覆碰撞）
零件
檢查
側簾式安全氣囊模組 LH
若左側簾式安全氣囊已展開：
更換左側簾式安全氣囊模組。
使用新固定件安裝。
側簾式安全氣囊模組 RH
若右側簾式安全氣囊已展開：
更換右側�帘式安全氣囊模組。
使用新固定件安裝。
前側安全氣囊模組 LH
若左側前側安全氣囊已展開：
更換左側前座椅背總成。
前側安全氣囊模組 RH
若右側前側安全氣囊已展開：
更換右側前座椅背總成。
前中央安全氣囊模組
若前中央安全氣囊已展開：
更換右側前座椅背總成。
側向安全氣囊（衛星）感測器（LH 或 RH）
若任何氣囊零件已展開：
更換碰撞側的側邊安全氣囊 (衛星) 感測器，並使用新固定件。
車門（衛星）感測器（LH 或 RH）
若任何氣囊零件已展開：
更換碰撞側的車門 (衛星) 感測器，並使用新固定件。
診斷感測器單元
若任何氣囊零件已展開：
更換診斷感測器單元，並使用新固定件。
安全帶預緊器總成
（所有適用位置：扣環、卷收器、外側腰帶）
若駕駛或乘客安全帶預緊器*已作動：
更換所有安全帶預緊器總成，並使用新固定件。
*：僅能使用 M.U.T.-III SE 確認安全帶預緊器作動。
中央內側支柱
  1. 檢查碰撞側中央內側支柱是否有損壞 (凹痕、裂縫、變形)。
  2. 若損壞 - 修復中央內側支柱。
飾板/車頂內裝
  1. 檢查碰撞側內裝飾板是否有可見損壞跡象 (凹痕、裂縫、變形)。
  2. 若損壞 - 更換損壞的飾板零件。
簾式安全氣囊模組 LH
若左側簾式安全氣囊模組已展開：
更換左側車門飾板及簾式安全氣囊模組。
使用新固定件安裝。
簾式安全氣囊模組 RH
若右側簾式安全氣囊模組已展開：
更換右側車門飾板及簾式安全氣囊模組。
使用新固定件安裝。
乘員偵測系統（乘客座）
  1. 拆下乘客座總成。
  2. 檢查控制單元外殼是否有凹痕、裂縫或變形。
  3. 檢查接頭是否損壞，以及端子是否變形。
  4. 檢查座椅框架及坐墊底板是否有凹痕或變形。
  5. 若未發現損壞，使用新固定件重新安裝座椅。
  6. 若損壞 - 使用新固定件更換坐墊總成。
彈出式防滾桿總成
若彈出式防滾桿已展開：
更換彈出式防滾桿總成及彈出式防滾桿蓋。
使用新固定件安裝。
