引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. U2252-08：ADAS 與定速控制系統之間的 CAN 通訊錯誤
N5025012O0000800ENG
故障碼設定條件
檢查條件
  • 點火開關置於「開啟」位置後 2 秒。
  • 12V 電池正極電壓達 9 volts 或以上後 1.5 秒。
  • 配備定速控制或主動式定速控制。
判定標準
  • ADAS 與定速控制系統之間的通訊錯誤持續 300 msecs。
備註
目前故障
  • 失效/故障可能由 ECM（定速控制部分）與 ADAS 控制單元 2 之間 CAN 匯流排線路上的線束與接頭故障、ADAS 控制單元 2 故障或 ECM（定速控制部分）故障所引起。
過去故障
  • 進行故障排除，著重檢查 ECM（定速控制部分）與 ADAS 控制單元 2 之間 CAN 匯流排線路上的線束與接頭故障。
備註：
若為過去曾發生的故障，即使 CAN 匯流排有故障，M.U.T.-III SE 的 CAN 匯流排線路診斷也可能無法檢測到。因此，請如同處理間歇性故障般檢查 CAN 匯流排線路（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障）。可從執行 CAN 通訊的各 ECU 所設定的診斷碼，縮小故障可能性較高的區域（請參閱 Electrical and Power Control - LAN System - CAN Fundamental - Basic Inspection - Diagnosis and Repair Workflow -M.U.T.-III SE CAN 匯流排診斷說明)
失效保護與備援功能
主動式定速控制將轉為系統關閉。
OBD-II 驅動循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 3驅動循環模式.
故障排除提示（此故障碼最可能的設定原因如下：）
  • CAN 匯流排線路故障
  • 8CH CAN 網關電源線路故障
  • 8CH CAN 網關故障
  • ADAS 控制單元 2 電源電路故障
  • ADAS 控制單元 2 故障
  • ECM 故障
診斷

    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：VCI-3 套件（不含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
