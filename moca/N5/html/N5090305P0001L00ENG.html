開關名稱
功能
前座加熱開關 LH
每次按下此開關，前座加熱 LH 依 關閉 → HI → MID → LO → 關閉 順序切換。詳情請參閱系統說明.
開啟·關閉開關
每次按下此開關，空調在 開啟 ↔ 關閉 之間切換。
方向盤加熱開關
每次按下此開關，方向盤加熱在 開啟 ↔ 關閉 之間切換。詳情請參閱系統說明（方向盤加熱）.
溫度控制開關［（後座側）上／下］
  • 依開關作動，通風溫度分別控制（SYNC 開關指示燈）轉為關閉。可在不改變駕駛側與副駕側送風溫度的情況下，變更後座側送風溫度。
  • 使用此開關選擇設定溫度，範圍為 18.0°C（61°F）至 32.0°C（89°F），每次調整 0.5°C（1°F）。
    • 按下：設定溫度升高
    • 按下：設定溫度降低
注意：
全冷時顯示「Lo」，全熱時顯示「Hi」。
風量開關
依開關作動，風量可設定於第 1 段 – 第 7 段範圍內。
  • 按下（大）：風量增加
  • 按下（小）：風量減少
MODE 開關
每次按下此開關，出風口依 VENT → B/L → FOOT → D/F → VENT 順序切換。
DEF 開關
  • 當 DEF 模式轉為開啟時，空調系統變更為下列狀態。
    • 出風口：DEF
    • 風量：風扇最大
    • 進氣：外氣進氣
    • A/C 開關：開啟
注意：
當空調關閉時按下此開關，風量設定為自動控制。
雨刷除冰開關
每次按下此開關，後擋風玻璃除霧器在 開啟 ↔ 關閉 之間切換。詳情請參閱系統說明.
A/C 開關
每次按下此開關，A/C 壓縮機控制在 開啟 ↔ 關閉 之間切換。
前座加熱開關 RH
每次按下此開關，前座加熱 RH 依 關閉 → HI → MID → LO → 關閉 順序切換。詳情請參閱系統說明.
溫度控制旋鈕（副駕側）
  • 依旋鈕作動，通風溫度分別控制（SYNC 開關指示燈）轉為關閉。可在不改變駕駛側與後座側送風溫度的情況下，變更副駕側送風溫度。
  • 依旋鈕作動設定溫度，範圍為 18.0°C（61°F）至 32.0°C（89°F），每次調整 0.5°C（1°F）。
    • 順時針：設定溫度升高
    • 逆時針：設定溫度降低
注意：
全冷時顯示「Lo」，全熱時顯示「Hi」。
SYNC 開關
按下 SYNC 開關時，駕駛側、副駕側與後座空調溫度設定同步，且 SYNC 開關指示燈轉為開啟。
進氣開關
  • 每次按下進氣開關，進氣在內循環（REC）↔ 外氣進氣（FRE）之間切換。
    • 指示燈開啟：內循環
    • 指示燈關閉：外氣進氣
  • 進氣開關指示燈閃爍 2 次，且進氣設定為自動控制（當進氣開關按住 2 秒以上時）。
AUTO 開關
按下此開關時，開關指示燈轉為開啟，空調系統開始自動控制。
注意：
當進氣未手動選擇時，進氣變更為自動控制。
溫度控制旋鈕（駕駛側）
依旋鈕作動設定溫度，範圍為 18.0°C（61°F）至 32.0°C（89°F），每次調整 0.5°C（1°F）。
  • 順時針：設定溫度升高
  • 逆時針：設定溫度降低
注意：
全冷時顯示「Lo」，全熱時顯示「Hi」。全冷與全熱時由空調自動控制。
前座通風座椅開關 LH
每次按下此開關，前座通風座椅 LH 依 關閉→ HI → MID → LO → 關閉 順序切換。詳情請參閱通風座椅.
前座通風座椅開關 RH
每次按下此開關，前座通風座椅 RH 依 關閉→ HI → MID → LO → 關閉 順序切換。詳情請參閱通風座椅.
顯示：於後座空調控制之顯示
後座空調設定溫度狀態於後座空調控制顯示器上指示。
