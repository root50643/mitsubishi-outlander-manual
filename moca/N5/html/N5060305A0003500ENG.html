煞車 - 煞車控制系統 - 附 VDC - 基本檢查 - 轉向角感測器中性位置調整
作業程序
N5060305A0003500ENG
注意：
調整轉向角感測器中性位置時，一律使用 M.U.T.-III SE。（無法以 M.U.T.-III SE 以外的方式調整。）
1.檢查車輛狀態 (1)
以前輪朝正前方位置停車。
車輛是否維持在正前方位置？
是
進至 2.
否
將方向盤轉至正前方位置。停車。
2.調整轉向角感測器中性位置
使用 M.U.T.-III SE
  1. 點火開關開啟。
    注意：
    切勿啟動引擎。
  2. 依序選擇「ABS」、「感測器校正」（於「特殊功能」內）及「ST ANGLE 感測器調整」。
  3. 選擇「OK」。
    注意：
    調整轉向角感測器時，切勿觸碰方向盤。
  4. 顯示「Completed」後，等待約 10 秒並按下「OK」。
  5. 點火開關關閉（自動 ACC 功能關閉），然後再次開啟。
    注意：
    務必執行上述作動。
GO TO 3.
3.檢查資料監控 (1)
使用 M.U.T.-III SE
  1. 車輛已朝正前方，或需移動車輛。於朝正前方時停車。
  2. 依序選擇「ABS」、「資料清單」及「Steering angle」。檢查訊號是否在規定值範圍內。請參閱對照值.
檢查結果是否正常？
是
前往 10.
否
GO TO 4.
4.檢查轉向系統元件
檢查轉向系統元件的安裝狀況。請參閱檢查.
檢查結果是否正常？
是
前往 5.
否
修理或更換發生故障的零件。前往 5.
5.檢查前懸吊系統元件
檢查前懸吊系統元件的安裝狀況。請參閱檢查.
檢查結果是否正常？
是
前往 6.
否
修理或更換發生故障的零件。前往 6.
6.檢查前輪定位
檢查前輪定位。請參閱檢查.
檢查結果是否正常？
是
GO TO 7.
否
調整前輪定位。請參閱調整. GO TO 7.

前往步驟 8.
否

  1. 車輛已朝正前方，或需移動車輛。於朝正前方時停車。
  2. 依序選擇「ABS」、「資料清單」及「Steering angle」。檢查訊號是否在規定值範圍內。請參閱對照值.

9.檢查資料監控 (3)
使用 M.U.T.-III SE
  1. 車輛已朝正前方，或需移動車輛。
    注意：
    • 以約 30 km/h (19MPH) 或以上的速度行駛 300 m (985 ft) 或以上。
    • 切勿使用診斷儀
  2. 車輛已朝正前方，或需移動車輛。於朝正前方時停車。
  3. 依序選擇「ABS」、「資料清單」及「Steering angle」。檢查訊號是否在規定值範圍內。請參閱對照值.

10.清除自我診斷記憶
使用 M.U.T.-III SE
  1. 記錄或列印自我診斷結果及凍結資料 (FFD)。
  2. 清除「ABS」的自我診斷結果。
記憶是否已清除？
是
前往 11.
否
檢查自我診斷所指示的項目。
11.EPS 學習
  1. 拉起駐車煞車開關。
    備註：
    確認駐車煞車開關指示燈已點亮。
  2. 點火開關關閉。
  3. 離開車輛並關閉所有車門。
  4. 等待 65 秒。
    備註：
    • 確認駐車煞車開關指示燈已熄滅。
    • 若後煞車卡鉗處於高溫狀態，請等待一小時，以免駐車煞車開關指示燈熄滅。
  5. 啟動引擎。
    注意：
    切勿駕駛車輛。
