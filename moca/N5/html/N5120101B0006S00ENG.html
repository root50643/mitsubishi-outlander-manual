駕駛控制 - MIRRORS - SYMPTOM DIAGNOSIS - DOOR MIRROR DOES NOT OPERATE
診斷程序
N5120101B0006S00ENG
1.檢查配置資訊
使用 M.U.T.-III SE
  1. 點火開關開啟。
  2. 使用 M.U.T.-III SE，選擇「BCM」的「Special Function」。
  3. 檢查「配置 Information」中的「Passenger DOOR mirror control module」。
檢查結果是否為「Not present」？
是
转至 2.
否
转至 5.
2.檢查 DOOR MIRROR CIRCUIT
檢查 DOOR mirror。請參閱 Diagnosis Procedure診斷程序.
檢查結果是否正常？
是
转至 3.
否
修復或更換故障零件。
3.更換 DOOR MIRROR MOTOR
更換 DOOR mirror motor。請參閱拆卸及安裝.
檢查結果是否正常？
是
檢查結束
否
转至 4.
4.更換 電動窗總開關
更換 電動窗總開關. 請參閱拆卸及安裝.
檢查結果是否正常？
是
檢查結束
否
檢查 間歇性故障. 請參閱 間歇性故障間歇性故障.
5.檢查 AUTOMATIC DRIVE POSITIONER SYSTEM
檢查 DOOR mirror 是否隨 automatic drive positioner system 作動。請參閱系統說明<LHD>,系統說明<RHD>.
檢查結果是否正常？
是
转至 6.
否
檢查 automatic drive positioner system 作動。請參閱 Diagnosis Procedure診斷程序<LHD>,診斷程序<RHD>.
6.檢查 DOOR MIRROR CIRCUIT
檢查 DOOR circuit。
  • DOOR mirror driver side：請參閱 Diagnosis Procedure診斷程序.
  • DOOR mirror passenger side：請參閱診斷程序.
檢查結果是否正常？
是
檢查 間歇性故障. 請參閱 間歇性故障間歇性故障.
否
修復或更換故障零件。
