2.執行自我診斷結果
選擇 "HANDS FREE MODULE" 的 "Self Diagnostic Result" 模式，並檢查是否偵測到故障碼。

是

否

3.檢查 "WORK SUPPORT" 中的 "引擎 START BY 免鑰匙操作 key" 設定
  1. 使用 M.U.T.-III SE 選擇 "HANDS FREE MODULE"。
  2. 在 "Special Function" 的 "Setting change" 模式中選擇 "引擎 START BY I-KEY"。
  3. 檢查 "Special Function" 的 "Setting change" 中的 "引擎 START BY I-KEY"。
檢查結果是否正常？
是
GO TO 4.
否

檢查結果是否正常？

否
