引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0BCE-00：48V-BSG 控制板溫度感測器偏低
N5025044L0000600ENG
監視執行
連續。
監視執行條件（其它監視與感測器）
其它監視（下列監視項目的記憶體中未設定暫時性故障碼）
  • 控制器區域網路 - 引擎 Local CAN（48V 輕度混合動力系統用）
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關位於開啟位置。
  • 12V 電池電壓在 10.0 至 16.5 伏特之間。
  • 啟動馬達停止運轉。
  • 符合上述條件後已經過 2 秒以上。
判定準則
  • 電壓低於 0.1 volt（150°C 以上）持續 2.5 秒。
失效保護與備援功能
  • 48V 輕度混合動力系統停止運作。
    1. 停止對 12V 側供電。
    2. 皮帶驅動啟動馬達發電機的引擎輔助與再生制動停止。
  • 充電警示燈亮起。
  • 禁止自動熄火。
  • AS&G 關閉燈閃爍。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
故障排除提示（設定此代碼最可能的原因為：）
  • 冷卻液液位或濃度不正確。
  • 皮帶驅動起動馬達發電機的冷卻液通道損壞或斷裂。
  • 皮帶驅動啟動馬達發電機故障。
診斷

1.冷卻液檢查
  1. 檢查冷卻液液位（請參閱 引擎 <4B4>－引擎冷卻－開啟－車輛維修－引擎冷卻液檢查).
  2. 檢查冷卻液濃度（請參閱 引擎 <4B4>－引擎冷卻－開啟－車輛維修－引擎冷卻液濃度檢查).
Q：檢查結果是否正常？
是
前往 2。
否
修理。
2.皮帶驅動起動馬達發電機冷卻液通道檢查
檢查皮帶驅動起動馬達發電機的冷卻液通道是否未損壞或斷裂。
Q：檢查結果是否正常？
是
前往步驟 3。
否
修理。
3.測試 OBD-II 行駛循環。
  1. 將點火開關轉至「開啟」位置並清除故障碼。
  2. 依駕駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  3. 檢查故障碼。
Q：是否設定故障碼 P0BCE-00？
是
更換皮帶驅動起動馬達發電機（請參閱 引擎 <4B4>－引擎電系－充電系統－皮帶驅動起動馬達發電機－皮帶驅動啟動馬達發電機拆卸與安裝).
然後GO TO 4.
否

  1. 依駕駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  2. 檢查故障碼。
