2.執行 TCU 配置
使用 M.U.T.-III SE
執行配置（TCU）。請參閱說明.

3.手動將 VIN 資料寫入 TCU
使用 M.U.T.-III SE
  1. 將點火開關轉至 開啟 位置，並至少等待 5 秒。
  2. 使用 M.U.T.-III SE 選擇「特殊功能」項目中的「Chassis No./VIN Registration」。
  3. 在「Chassis No./VIN Registration」畫面觸碰「OK」，將 VIN 資料寫入新的 TCU。
GO TO 4.
4.TCU 啟用
執行 TCU 啟用。請參閱作業程序.
前往 5.
5.檢查網路初始設定
M.U.T.-III SE 特殊功能
配有 MITSUBISHI CONNECT 時
1. 確認點火開關轉至 開啟 位置後已過 90 秒以上，然後選擇「IVC」的「網路 initial settings」。
2. 檢查「Radio wave condition」。若正常，進行下一步。若狀態異常或無法偵測，請將車輛移至電波環境良好的地點，然後從步驟 1 重新開始。
3. 選擇「MULTI AV」的「網路 initial settings」。
4. 檢查「網路 initial setting state」的數值。若顯示「Completed」，表示設定已完成。若 15 分鐘內數值未變為「Completed」，網路設定可能發生錯誤。
未配 MITSUBISHI CONNECT 時
1. 確認點火開關轉至 開啟 位置後已過 90 秒以上，然後選擇「IVC」的「網路 initial settings」。
2. 檢查「Radio wave condition」。若正常，進行下一步。若狀態異常或無法偵測，請將車輛移至電波環境良好的地點，然後從步驟 1 重新開始。
3. 檢查「網路 initial setting state」的數值。若顯示「Completed」，表示設定已完成。若 15 分鐘內數值未變為「Completed」，網路設定可能發生錯誤。
