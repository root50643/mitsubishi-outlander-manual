煞車 - 煞車控制系統 - 附 VDC - 故障碼/線路診斷 - C10AA-63 泵浦馬達
診斷程序
N50603026001M200ENG
1.檢查 接頭
  1. 斷開 12V 電池負極端子。
  2. 檢查 ABS 作動器與電動單元 (控制單元) 線束接頭是否脫落或鬆動。
檢查結果是否正常？
是
GO TO 3.
否
修理/更換線束或接頭，並確實鎖緊接頭。前往步驟 2.
2.執行自我診斷
使用 M.U.T.-III SE
  1. 連接 12 V 電池負極端子，並等待 30 秒。
  2. 以約 50 km/h (31 MPH) 或以上的速度行駛車輛約 2 分鐘。
    備註：
    修理或更換後必須行駛車輛以清除先前的故障碼。
  3. 停止車輛。
  4. 點火開關關閉（Auto ACC 功能關閉）。
  5. 啟動引擎。
    備註：
    引擎啟動後至少等待 10 秒。
  6. 執行「ABS」自我診斷。
是否偵測到故障碼 “C10AA-63”？
是
GO TO 3.
否
檢查結束
3.檢查 ABS 作動器與電動單元 (控制單元) 電源及搭鐵線路
檢查 ABS 作動器與電動單元 (控制單元) 電源及搭鐵線路。請參閱診斷程序.
檢查結果是否正常？
是
GO TO 5.
否
修理/更換線束、接頭、端子、保險絲或大電流保險絲。GO TO 4.
4.清除自我診斷結果 (1)
使用 M.U.T.-III SE
  1. 以約 50 km/h (31 MPH) 或以上的速度行駛車輛約 2 分鐘。
    備註：
    修理或更換後必須行駛車輛以清除先前的故障碼。
  2. 停止車輛。
  3. 清除「ABS」之自我診斷結果。
  4. 點火開關關閉 (Auto ACC 功能關閉) → 開啟 → 關閉 (Auto ACC 功能關閉)。
檢查結束
5.檢查 端子
  1. 斷開 12V 電池負極端子。
  2. 檢查 ABS 作動器與電動單元（控制單元）端子是否有損壞，或與線束接頭連接鬆動。
檢查結果是否正常？
是
更換 ABS 作動器與電動單元 (控制單元)。請參閱拆卸與安裝.
否
修理/更換線束或接頭。GO TO 6.
6.清除自我診斷結果 (2)
使用 M.U.T.-III SE
  1. 連接 12V 電池負極端子。
  2. 以約 50 km/h (31 MPH) 或以上的速度行駛車輛約 2 分鐘。
    備註：
    修理或更換後必須行駛車輛以清除先前的故障碼。
  3. 停止車輛。
  4. 清除「ABS」之自我診斷結果。
  5. 點火開關關閉 (Auto ACC 功能關閉) → 開啟 → 關閉 (Auto ACC 功能關閉)。
檢查結束
