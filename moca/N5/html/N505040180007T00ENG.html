懸吊 - 車輪與輪胎 - 症狀診斷 - 胎壓過低警告燈無法熄滅
診斷程序
N505040180007T00ENG
1.檢查輪胎壓力
  1. 將點火開關轉至開啟。
    警告：
    切勿起動引擎。
  2. 檢查所有車輪之輪胎壓力並調整至規定值。請參閱輪胎充氣壓力.
  3. 重新檢查所有車輪之輪胎壓力。請參閱輪胎充氣壓力.
檢查結果是否正常？
是
前往步驟 2.
否
檢查或修復輪胎或車輪。
2.檢查胎壓過低警告燈作動
檢查胎壓過低警告燈顯示。
檢查結果是否正常？
是
檢查結束
否
GO TO 3.
3.執行自我診斷
使用 M.U.T.-III SE
執行「BCM」的「自我診斷」。
是否偵測到故障碼？
是
執行故障碼診斷程序。請參閱故障碼索引.
否
GO TO 4.
4.檢查 BCM 電源及搭鐵電路
執行電源與搭鐵線路故障診斷。請參閱診斷程序.
檢查結果是否正常？
是
更換 BCM。請參閱拆卸與安裝.
否
Repair or 更換 error-detected parts.
