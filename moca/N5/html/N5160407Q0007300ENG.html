5.執行「校正攝影機影像」
使用 M.U.T.-III SE
  1. 使用 M.U.T.-III SE 於「Multi Around Monitor」的「Special Function」模式中選擇「校正」。
    備註：
    以任意順序，對所有顯示不吻合的攝影機執行作動。
    • 前攝影機：「校正攝影機影像（前攝影機）」
    • 右側攝影機：「校正攝影機影像（右攝影機）」
    • 左側攝影機：「校正攝影機影像（左攝影機）」
    • 後攝影機：「校正攝影機影像（後攝影機）」
  2. 依照下列程序執行「校正攝影機影像（****）」。
    1. 調整「AXIS X」、「AXIS Y」及「Pattern」參數，使顯示於畫面上的校正標記對準地面上的目標線。
    2. 調整「High」參數，使目標線與校正標記大小相符。
  3. Status 變為「APPLIED」後，調整結果顯示於畫面上。若調整後目標線與校正標記仍有間隙，請調整「AXIS X」、「AXIS Y」、「Pattern」及「High」參數，並觸碰「Retry」進行額外調整。
    注意：
    Status 顯示「PROCESSING」時，切勿執行其他操作。
  4. Status 顯示「APPLIED」時，觸碰「OK」。
  5. 觸碰 M.U.T.-III SE 畫面上的「OK」按鈕。調整結果寫入環景監控器控制單元。
    注意：
    Status 顯示「PROCESSING」時，切勿執行其他操作。
GO TO 6.
