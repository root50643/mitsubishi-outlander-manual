引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P1D33-00: DC-DC Converter module#4 溫度感測器過高
N5025047N0000600ENG
監視執行
連續。
監視執行條件 (其他監視器與感知器)
其他監視器 (以下監視項目在記憶體中未設定暫時性故障碼)
  • DC-DC 轉換器控制模組
  • DC-DC 轉換器控制電壓
感知器 (以下感知器判定為正常)
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關位於開啟位置。
  • 12V 電池電壓介於 10.0 與 16.5 伏特之間。
  • 起動馬達關閉。
  • 滿足上述條件後已經過 2 秒以上。
判定準則
  • 電壓為 0.062 伏特或更低（-50°C (-58°F) 或更高）持續 2.5 秒。
失效保護與備援功能
  • 48V MILD HYBRID system 已停止。
    1. 已停止對 12V 側供電。
    2. 皮帶驅動起動馬達發電機的引擎輔助與再生已停止。
  • 充電警告燈亮起。
  • Auto Stop 已禁止。
  • AS&G 關閉燈閃爍。
OBD-II 行駛循環模式
請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 5 –行駛循環模式.
故障排除提示 (設定此故障碼最可能的原因為：)
  • DC-DC 轉換器故障。
診斷
所需特殊工具：
  • MB993028: VCI-3 kit with wireless adapters
    1. -: VCI-3 device
    2. MB993029: DLC cable
    3. MB993030: USB cable
    4. MB993031: Wireless USB adapter (Qty:2)
  • MB993040: VCI-3 kit without wireless adapters
    1. -: VCI-3 device
    2. MB993029: DLC cable
    3. MB993030: USB cable
1.測試 OBD-II 行駛循環。
  1. 將點火開關轉至「開啟」位置並刪除故障碼。
  2. 依驅動循環模式進行試車。請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 5 –行駛循環模式.
  3. 檢查故障碼。

NO
