引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
代碼編號 C0515-00：車輛車速感測器 RR 偏高
N5025042V0000300ENG
技術說明
VDC 監控車輛車速感測器，並將診斷結果（OK/NOK）的 CAN 訊號傳送至 ECM。
監控方式說明
當 ECM 從 VDC 接收到車輛車速感測器的 NOK 資訊時，顯示此故障碼。
監視執行
連續。
監視執行條件（其它監視與感測器）
其它監視（下列監視項目的記憶體中未設定暫時性故障碼）
  • U0121-00：ASC 逾時
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 引擎運轉中。
  • 電瓶正極電壓大於 10.5 V 且小於 16.5 V。
判定準則
  • ECM 在 3 秒內接收到 VDC 失效/故障資訊。
失效保護與備援功能
禁止自動熄火。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
故障排除提示（設定此代碼最可能的原因為：）
檢查 VDC，並依 VDC 的故障排除程序進行檢查。
診斷
所需特殊工具：
  • MB993028: VCI-3 kit with wireless adapters

1.使用 M.U.T.-III SE 讀取其他系統故障碼。
  1. 將點火開關轉至「開啟」位置。
  2. 讀取 ABS 作動器與電氣單元（控制單元）故障碼（右後輪感測器相關故障碼）。
  3. 將點火開關轉至「LOCK」（關閉）位置。
問：ABS 作動器與電氣單元（控制單元）故障碼（右後輪感測器相關故障碼）是否已設定？
是
請參閱 Brakes - BRAKE Control System - with VDC - ECU Diagnosis Information - ABS 作動器 and Electric Unit (Control Unit) -故障碼索引.
否
前往 2。
2.測試 OBD-II 行駛循環。
  1. 將點火開關轉至「開啟」位置並清除故障碼。
  2. 依駕駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  3. 檢查故障碼。
問：故障碼 C0515-00 是否設定？
是
更換 ECM（請參閱 拆卸 and 安裝引擎-ECU 拆卸與安裝）。然後前往步驟 3。
否
檢查完成。
3.測試 OBD-II 行駛循環。
  1. 依駕駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  2. 檢查故障碼。
問：故障碼 C0515-00 是否設定？
是
重新執行故障排除。
否
檢查完成。
