CRUISE CONTROL & DRIVER ASSISTANCE - DRIVER ASSISTANCE SYSTEM - ADAS CONTROL UNIT - 故障碼/CIRCUIT DIAGNOSIS - U2175-57 CAN通訊錯誤 (Multi Around Monitor)

1.檢查故障碼優先順序
若同時顯示故障碼「U2175-57」與故障碼「U1327-52」或「U1327-54」，請先對故障碼「U1327-52」或「U1327-54」執行故障診斷。
是否偵測到故障碼「U1327-52」或「U1327-54」？
是
執行適用之診斷。請參閱下列內容。
  • U1327-52: 故障碼說明故障碼說明
  • U1327-54: 故障碼說明故障碼說明
否
GO TO 2.
2.MAC診斷檢查
使用 M.U.T.-III SE
使用 M.U.T.-III SE 執行「ACC/ADAS 2」的「MAC Diagnosis」模式。
是否同時偵測到故障碼「U2175-57」與故障碼「U214F-57」、「U2176-57」、「U2440-57」、「U244F-57」、「U2465-57」(附雷達系統)及「U2476-57」?
是（所有故障碼同時偵測到）
更換 ADAS 控制單元 2。請參閱拆卸與安裝.
否（所有故障碼並非同時偵測到）
GO TO 3.
3.檢查 網路-故障碼
使用 M.U.T.-III SE
執行「CAN Diag」。
檢查結果是否正常？
是
聯絡 Techline 並回報車輛狀況。
否
修理或更換根本原因零件。
