定速控制 & 駕駛輔助 - 駕駛輔助系統 - 底盤控制 - 故障碼/電路診斷 - U2143-87 引擎-ECU / PHEV-ECU 通訊失效/故障 (receive)
診斷程序
N517020170064B00ENG
1.執行自我診斷
使用 M.U.T.-III SE
  1. 清除「CHASSIS CONTROL」的自我診斷結果。
  2. 點火開關關閉，並等待 10 秒以上。
  3. 點火開關由關閉至開啟。
  4. 執行「CHASSIS CONTROL」自我診斷。
故障碼「U2143-87」是否被偵測？
是
前往 2.
否
檢查結束
2.檢查 ECM 系統 (1)
使用 M.U.T.-III SE
  1. 清除「引擎」的自我診斷結果。
  2. 點火開關關閉，並等待 10 秒以上。
  3. 點火開關由關閉至開啟。
  4. 執行「引擎」的自我診斷。
是否偵測到故障碼？
是
檢查故障碼。請參閱故障碼索引.
否
前往 3.
3.檢查 ECM 系統 (2)
  1. 點火開關關閉。
  2. 斷開/拔除 ECM 線束接頭。
  3. 檢查 ECM 線束接頭端子 (CAN 通訊線路與底盤通訊線路) 是否損壞或連接鬆脫。
檢查結果是否正常？
是
GO TO 4.
否
修理／更換線束、接頭或端子。GO TO 4.
4.清除自我診斷結果
使用 M.U.T.-III SE
  1. 連接 ECM 線束接頭。
  2. 清除「CHASSIS CONTROL」的自我診斷結果。
  3. 點火開關關閉，並等待 10 秒以上。
檢查結束
