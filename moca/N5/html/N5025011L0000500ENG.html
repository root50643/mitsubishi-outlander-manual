引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
代碼編號 P26AC-00：多流控制閥過電流
N5025011L0000500ENG
電路作動
由 ECM 接頭端子 MCV+ 與 MCV- 至多流控制閥接頭端子的電流為受控。
技術說明
  • ECM 控制供給馬達的電流量，使多流控制閥的旋轉角度達到目標位置。
  • ECM 監測供給多流控制閥的電流是否過電流。
監視方法說明
ECM 檢查多流控制閥驅動器是否處於過電流狀態。
監視執行
連續。
監視執行條件（其它監視與感測器）
其它監視（下列監視項目在記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 引擎冷卻液溫度感測器
故障碼設定條件
檢查條件
  • 引擎起動後 2 秒。
  • 電瓶正極電壓高於 10.5 volts。
判定標準
  • 多流控制閥驅動器狀態變為故障狀態，即過電流狀態。
失效保護與備援功能
扭力受到限制。
OBD-II 驅動循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 18驅動循環模式.
故障排除提示（此故障碼最可能的設定原因如下：）
  • 多流控制閥迴路開路/短路或線束損壞，或接頭接觸不良。
  • 多流控制閥故障
  • ECM 故障。
診斷
所需特殊工具：
  • MB993028：VCI-3 套件（含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：VCI-3 套件（不含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
1.使用 M.U.T.-III SE 讀取故障碼。
  • 是否設定診斷碼 P26A6-00、P26A7-00 或 P2B5D-00？

3.檢查多流控制閥接頭與 ECM 接頭之間 MCV- 線路是否短路及損壞。
Q：檢查結果是否正常？
是
GO TO 4.
否

  • 故障碼再確認。

  1. 依驅動循環型式執行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 18驅動循環模式.
