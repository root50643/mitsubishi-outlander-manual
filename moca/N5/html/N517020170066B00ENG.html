定速控制與駕駛輔助 - 駕駛輔助系統 - ADAS 控制單元 - 故障碼/電路診斷 - U19B6-87 乙太網路電路（前攝影機）
診斷程序
N517020170066B00ENG
1.檢查 接頭
  1. 將電動馬達開關關閉。
  2. 檢查 ADAS 控制單元 2 與前攝影機單元之 Ethernet 線束接頭與端子是否有損壞或鬆脫。
檢查結果是否正常？
是
進至 2.
否
修理或更換故障零件，並確實鎖緊線束接頭。
2.執行所有故障碼讀取
  1. 將電動馬達開關開啟。
  2. 使用 M.U.T.-III SE 執行「Read All DTCs」。
  3. 檢查「車道攝影機」的「自我診斷」中是否偵測到乙太網路相關故障碼（故障碼「C250C-88」及/或「U276B-88」）
是否偵測到 Ethernet 相關 故障碼？
是
更換 ADAS 控制單元 2（請參閱拆卸與安裝），以及GO TO 3.
否
更換前攝影機單元。請參閱拆卸與安裝.
3.執行故障碼確認程序-1
  1. 使用 M.U.T.-III SE 清除所有自我診斷結果。
  2. 再次執行故障碼確認程序。請參閱故障碼說明故障碼說明.
故障碼「U19B6-87」是否偵測為目前故障？
是
更換前攝影機單元（請參閱拆卸與安裝），以及GO TO 4.
否
檢查結束
4.執行故障碼確認程序-2
  1. 使用 M.U.T.-III SE 清除所有自我診斷結果。
  2. 再次執行故障碼確認程序。請參閱故障碼說明故障碼說明.
故障碼「U19B6-87」是否偵測為目前故障？
是
更換 ADAS 控制單元 2 與前攝影機單元之間的 Ethernet 線束。
否
檢查結束
