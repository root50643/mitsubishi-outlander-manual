定速控制與駕駛輔助 - 駕駛輔助系統 - 底盤控制 - 故障碼/電路診斷 - U2541-83 CAN COMM CIRCUIT
診斷程序
N51702017006B400ENG
1.執行自我診斷
使用 M.U.T.-III SE
  1. 清除「底盤控制」的自我診斷結果。
  2. 點火開關 關閉，並等待 10 秒以上。
  3. 點火開關開啟。
  4. 執行「底盤控制」自我診斷。
是否偵測到故障碼「U2541-83」？
是
進至 2.
否
檢查結束
2.檢查 TCM 系統 (1)
使用 M.U.T.-III SE
  1. 清除「變速箱」的自我診斷結果。
  2. 點火開關 關閉，並等待 10 秒以上。
  3. 點火開關開啟。
  4. Perform 自我診斷 for "TRANSMISSION".
是否偵測到故障碼？
是
檢查故障碼。請參閱故障碼 Index.
否
GO TO 3.
3.檢查 TCM 系統 (2)
  1. 點火開關關閉。
  2. 斷開/拔除 TCM 線束 接頭.
  3. 檢查 TCM 線束接頭端子（CAN 通訊線路與底盤通訊線路）是否有損壞或鬆脫連接。
檢查結果是否正常？
是
GO TO 4.
否
修復／更換線束、接頭或端子。GO TO 4.

使用 M.U.T.-III SE
  1. Connect TCM 線束 接頭.
  2. 清除「底盤控制」的自我診斷結果。
  3. 點火開關 關閉，並等待 10 秒以上。
