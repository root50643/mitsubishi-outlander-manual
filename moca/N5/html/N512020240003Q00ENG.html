故障碼確認程序
1.前置條件
使用 M.U.T.-III SE
  1. 點火開關開啟。
  2. 使用 M.U.T.-III SE，在「IPDM E/R」的「資料清單」模式中選取「Fr fog light (RH) circ malfunctn」。
  3. 檢查監視器狀態。
    監視項目
    監測狀態
    前霧燈（右側）迴路故障

    1
監測狀態為何？
“0”
進行步驟 2.
“1”
在右側前霧燈電源迴路中多次偵測到短路，且 IPDM E/R 內部的 smart FET 累積損壞。因此，IPDM E/R 不開啟 smart FET。由於在此狀態下無法重現故障碼，請執行診斷程序並在故障部位修復後更換 IPDM E/R。請參閱拆卸及安裝.
2.執行故障碼確認程序
使用 M.U.T.-III SE
  1. 點火開關關閉。
  2. 點火開關開啟。
  3. 將燈光開關切至 2ND，並開啟前霧燈開關。
  4. 使用 M.U.T.-III SE 選擇「IPDM E/R」的「自我診斷結果」模式。
  5. 檢查 故障碼.
