診斷程序
N505040180007Y00ENG
1.變更地點
將車輛移至其他區域，並重複簡易充氣胎壓提醒功能的程序。請參閱簡易充氣胎壓提醒功能簡易充氣胎壓提醒功能.
功能是否正常？
是
正常（依接收條件而定，充氣指示燈可能無法作動。）
否
转至 2.
2.執行胎壓監測系統自我診斷
使用 M.U.T.-III SE
  1. 以 40 km/h（25 MPH）或以上的車速行駛 10 分鐘。
  2. 停止車輛。
  3. 執行「BCM」的「自我診斷」。
是否偵測到任何 故障碼？
是
檢查故障碼。請參閱故障碼索引.
否
转至 3.
3.檢查危險警告燈作動
以危險警告開關檢查危險警告燈作動。
危險警告燈是否閃爍？
是
转至 4.
否
執行危險警告燈故障診斷。請參閱症狀表.
4.執行 TCM 自我診斷
使用 M.U.T.-III SE
執行「變速箱」的「自我診斷結果」。
是否偵測到任何 故障碼？
是
檢查故障碼。請參閱故障碼索引.
否
转至 5.
5.檢查喇叭作動
檢查喇叭作動。
作動是否正常？
是
转至 6.
否
修理或更換檢出異常的零件。

使用 M.U.T.-III SE
執行「BCM」的「自我診斷結果」。
是否偵測到任何 故障碼？
是
