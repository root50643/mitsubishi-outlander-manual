變速箱與傳動系統 - 變速箱總成與變速箱 - CVT<F1CJD, W1CJD> - 故障碼/電路診斷 - 變速箱 (TCM) - U2140-57 CAN comm err (ECM)
診斷程序
N504020170011H00ENG
1.檢查故障碼優先順序
若故障碼 U2140-57 與故障碼 U1327-52 或故障碼 U1327-54 同時顯示，請先對故障碼 U1327-52 或 U1327-54 進行故障診斷。
是否偵測到故障碼 U1327-52 或 U1327-54？
是
請參閱故障碼說明（U1327-52）或故障碼說明（U1327-54）。
否
前往 2。
2.檢查 MAC 診斷
使用 M.U.T.-III SE
使用 M.U.T.-III SE 執行「TRANSMISSION」的「MAC Diagnosis」模式。
故障碼 U2140-57 是否與故障碼 U214F–57 及故障碼 U2176–57 同時被偵測到？
是（所有故障碼同時被偵測到）
更換 TCM。請參閱拆卸與安裝.
否（並非所有故障碼同時被偵測到）
GO TO 3.
3.檢查 網路-故障碼
使用 M.U.T.-III SE
執行「CAN Diag」。
檢查結果是否正常？
是
聯絡 Techline 並回報車輛狀況。
否
修復或更換根本原因。
