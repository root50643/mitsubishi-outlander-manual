引擎<4B4> - 直接燃油噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0054-00：後氧感測器加熱器電阻
N5025004N0000600ENG
線路作動
  • 引擎控制繼電器整合於 IPDM E/R 中。
  • 電源由引擎控制繼電器供應至氧氣感測器 (後) 接頭的加熱器電源端子。
  • 氧氣感測器 (後) 接頭的加熱器由 ECM 接頭端子 OHRL 的功率電晶體控制。
技術說明
  • 當加熱器通電時，ECM 會檢查加熱器電流是否在指定範圍內。
監控方法說明
氧氣感測器 (後) 加熱器電流超出指定範圍。
監控執行
連續。
監控執行條件（其他監控項目及感測器）
其他監控項目（下列受監控項目的記憶體中未設定暫時性故障碼）
  • 線性 A/F 感測器監控
  • 氧氣感測器 (後) 監控
  • 線性 A/F 感測器加熱器監控
  • 氧氣感測器 (後) 加熱器監控
感測器（下列感測器已判定為正常）
  • 淨化控制電磁閥
  • 空氣流量感測器
  • 引擎冷卻液溫度感測器
  • No. 1 進氣溫度感測器
  • 大氣壓力感測器
  • 節氣門位置感測器
  • 進氣歧管絕對壓力感測器
  • 增壓壓力感測器
故障碼設定條件
檢查條件
  • 自引擎起動程序完成後已經過 220 秒以上。
  • 線性 A/F 感測器加熱器為開啟狀態時。
  • 電瓶正極電壓介於 10.5 至 16.5 伏特之間。
  • 進氣溫度高於 -10°C。
  • 氧氣感測器 (後) 加熱器的開啟占空比在 3% 至 97% 之間。
判定標準
  • 氧氣感測器 (後) 元件溫度平均值低於 510°C 達 70 秒。
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 8行駛循環模式.
故障排除提示 (本故障碼最可能設定原因：)
  • 氧氣感測器 (後) 加熱器電路開路/短路或線束損壞，或接頭接觸不良
  • 氧氣感測器 (後) 加熱器故障
  • ECM 故障
診斷

    1. -: VCI-3 裝置
    2. MB993029: DLC 線束
    3. MB993030: USB 線束
    4. MB993031: 無線 USB 轉接器 (Qty:2)
  • MB993040: VCI-3 套件（不含無線轉接器）
    1. -: VCI-3 裝置
    2. MB993029: DLC 線束
    3. MB993030: USB 線束
1.於氧氣感測器 (後) 接頭執行電阻測量。
  • 斷開接頭，並於感測器側進行測量。
  • IPDM E/R ACT2 線路與 ECM OHRL 線路之間的電阻。
    OK：4.9 - 7.6 Ω (at 20°C)
Q：檢查結果是否正常？
是
GO TO 2.
否
更換氧氣感測器 (後) (請參閱 引擎 <4B4> - Intake and Exhaust - Catalytic Converter -空氣濾清器拆卸與安裝）。然後前往第5步。
2.檢查 IPDM E/R 接頭與氧氣感測器 (後) 接頭之間 ACT2 線路的損壞。
Q：檢查結果是否正常？
是
GO TO 3.
否
修理接頭或線路。然後前往第5步。
3.檢查氧氣感測器 (後) 接頭與 ECM 接頭之間 OHRL 線路的損壞。
Q：檢查結果是否正常？
是
GO TO 4.
否
修理接頭或線路。然後前往第5步。
4.使用 M.U.T.-III SE，讀取故障碼。
  • 再次確認診斷碼。
