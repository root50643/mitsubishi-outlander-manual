DRIVER CONTROLS - 內裝燈光系統 - 故障碼/電路診斷 - 室內燈控制電路
元件功能檢查
N5120300V0007100ENG
1.檢查 MAP LIGHT 作動
  1. 將閱讀燈開關切換至 DOOR。
  2. 檢查當任何車門開啟時（尾門除外），閱讀燈是否點亮。
檢查是否正常？
是
前往步驟 2.
否
檢查閱讀燈控制電路。請參閱元件功能檢查.
2.檢查室內燈作動
使用 M.U.T.-III SE
  1. 將閱讀燈開關及室內燈開關切換至 DOOR。
  2. 開啟前車門（駕駛側）。
  3. 點火開關 開啟。
  4. 選擇 BCM 作動器測試項目中的「內裝燈」（於「Special Function」中）。
  5. 操作測試項目時，檢查室內燈是否開啟/關閉。
    開啟
    ：室內燈開啟
    關閉
    ：室內燈關閉
室內燈是否開啟/關閉？
是
室內燈控制電路正常。
否
請參閱診斷程序.
