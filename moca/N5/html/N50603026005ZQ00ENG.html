煞車 - 煞車控制系統 - 附 VDC - 故障碼/電路診斷 - C1067-64 輪速感測器
診斷程序
N50603026005ZQ00ENG
警告：
切勿於輪速感測器線束接頭端子之間進行檢查。
1.檢查輪轂總成
  1. 斷開/拔除 12V 電池負極端子。
  2. 檢查右後輪轂總成是否無過大鬆動。
    • 2WD 車型：請參閱檢查檢查.
    • AWD 車型：請參閱檢查檢查.
檢查結果是否正常？
是
前往步驟 2.
否
修理或更換右後輪轂總成。前往步驟 2.
  • 2WD 車型：請參閱拆卸與安裝.
  • AWD 車型：請參閱拆卸與安裝.
2.檢查 ABS 作動器與電氣單元（控制單元）電源與搭鐵電路
檢查 ABS 作動器與電氣單元（控制單元）電源與搭鐵電路。請參閱診斷程序.
檢查結果是否正常？
是
前往步驟 3.
否
修理/更換線束、接頭、端子、保險絲或大電流保險絲。
3.檢查輪胎
檢查右後輪胎胎壓、磨耗與尺寸。請參閱輪胎胎壓.
檢查結果是否正常？
是
前往步驟 6.
否
調整胎壓或更換右後輪胎。前往步驟 4.
4.檢查資料監視器 (1)
使用 M.U.T.-III SE
  1. 連接 12V 電池負極端子。
  2. 清除「ABS」的自我診斷結果。
  3. 點火開關關閉（Auto ACC 功能關閉）→ 開啟 → 關閉（Auto ACC 功能關閉）。
  4. 啟動引擎。
  5. 選擇「ABS」與「資料清單」，檢查「FR LH 輪速」、「FR RH 輪速」、「RR LH 輪速」及「RR RH 輪速」。
    注意：
    將「資料清單」記錄車速設為「10 msec」。
  6. 讀取所有輪速感測器之輪速數值。
    注意：
    修理或更換後必須行駛車輛，以清除先前之 故障碼。
請注意在 50 km/h (31 MPH) 時，右後輪速感測器與其他輪速感測器所偵測之最高/最低輪速之間的差異，各自是否在 5% 以內？
是
前往步驟 5.
否
前往步驟 6.
5.執行自我診斷 (1)
使用 M.U.T.-III SE
  1. 停止車輛。
  2. 點火開關關閉（Auto ACC 功能關閉）。
  3. 啟動引擎。
    注意：
    啟動引擎後至少等待 10 秒。
  4. 執行「ABS」自我診斷。
是否偵測到故障碼「C1067-64」？
是
前往步驟 6.
否
檢查結束
6.檢查輪速感測器與感測器轉子
  1. 斷開/拔除 12V 電池負極端子。
  2. 斷開/拔除右後輪速感測器線束接頭。
  3. 透過右後輪速感測器安裝孔，以吸塵器清除附著於右後輪速感測器及右後感測器轉子之灰塵與異物。
    警告：
    安裝輪速感測器時不得有背隙與浮動，並將安裝螺栓鎖緊至規定扭力。請參閱分解圖.
前往步驟 7.
7.檢查輪速感測器
檢查右後輪速感測器是否損壞。
檢查結果是否正常？
是
GO TO 11.
否
若您持有輪速感測器測試器（SST：KV991J0080）：前往步驟 8.  
若您未持有輪速感測器測試器（SST：KV991J0080）：前往步驟 9.
8.檢查輪速感測器輸出訊號
  1. 排檔位置 = "P"，電動駐車煞車 = 於電動駐車煞車釋放狀態下將點火開關關閉。
  2. 舉升車輛。
  3. 斷開/拔除右後輪速感測器線束接頭。
  4. 使用適當轉接器，將 ABS 主動式輪速感測器測試器（SST：KV991J0080）連接至右後輪速感測器。
  5. 將 ABS 主動式輪速感測器測試器電源開關開啟。
    注意：
    綠色 POWER 指示燈應亮起。若 POWER 指示燈未亮起，請先更換 ABS 主動式輪速感測器測試器內之電池後再繼續。
  6. 以手轉動車輪，並觀察 ABS 主動式輪速感測器測試器之紅色感測器指示燈。紅色感測器指示燈應閃爍開啟與關閉，以表示輸出訊號。
    右後輪
    紅色感測器指示燈
    停止
    閃爍（規律間隔）
    轉動（車速：5 秒內轉 1 圈）
    閃爍（閃爍週期變短且更接近持續亮起狀態）
    注意：
    輪速感測器相容於 AK 通訊協定，即使車輪靜止時仍會以規律間隔輸出狀態訊號。
    注意：
    若紅色感測器指示燈亮起但不閃爍，請反接測試器導線極性後重新測試。
ABS 主動式輪速感測器測試器是否偵測到訊號？
是
更換 ABS 作動器與電動單元（控制單元）。請參閱拆卸與安裝.
