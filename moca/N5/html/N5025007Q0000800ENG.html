引擎<4B4> - 直接燃油噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0486-00: 廢氣再循環差壓感知器電路 offset
N5025007Q0000800ENG
電路作動
  • 請參閱 code No. P046E-00: 廢氣再循環差壓感知器電路 range/performance problemCode No. P046E-00: EGR 差壓感知器電路 range/performance.
技術說明
  • EGR 差壓感知器偵測 EGR 閥上游區域與下游區域之間的壓差，並將訊號傳送至 ECM。
  • ECM 監控 EGR 差壓感知器傳送的差壓值，並檢查該值是否未偏移。
監控方法說明
ECM 在引擎停止時檢查 EGR 差壓感知器的差壓。
監控執行
連續。
監控執行條件（其他監控及感測器）
其他監控（下列監控項目之記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 淨化控制電磁閥
  • 空氣流量感知器
  • 引擎冷卻液溫度感測器
  • No. 1 進氣溫度感測器
  • 大氣壓力感測器
  • 節氣門位置感測器
  • 進氣歧管絕對壓力感測器
  • 增壓壓力感測器
  • No. 3 進氣溫度感測器
  • 廢氣再循環 (EGR) 閥 (DC motor)
  • EGR 差壓感知器
  • EGR 位置感知器
故障碼設定條件
檢查條件
  • 點火開關位於「LOCK」（關閉）位置。
判定基準
  • 產生差壓時感知器偵測。
失效保護及備援功能
無。
OBD-II 行程循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 18行程循環模式.
故障排除提示（此故障碼最可能之設定原因如下：）
  • EGR 差壓管故障。
  • EGR 差壓閥故障。
  • EGR 差壓軟管堵塞。
  • ECM 故障。
