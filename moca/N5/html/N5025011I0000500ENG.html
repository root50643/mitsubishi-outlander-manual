引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P2610-00: 點火開關關閉浸漬計時器效能
N5025011I0000500ENG
技術說明
當點火開關切換至關閉時，ECM 在預定時間經過後轉為開啟。
監視方法說明
點火開關關閉後，實際浸漬時間與預期浸漬時間之差超出規定範圍。
監視執行
連續。
監視執行條件（其它監視與感測器）
其它監視（下列監視項目在記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關位於「開啟」位置。
判定準則
  • ECU 內部的浸漬時間計數器故障。
失效保護與備援功能
無。
OBD-II 驅動循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 3驅動循環模式.

Q：故障碼是否已設定？
是

否
