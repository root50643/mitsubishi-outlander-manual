引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 症狀程序
檢查程序 5：怠速不穩（怠速抖動、游車）、怠速轉速不當（過高或過低）、怠速時引擎熄火（熄滅）<台灣車輛>
N502501360000A00ENG
故障症狀說明
  • 可能原因廣泛存在於點火系統、空燃比控制系統、電子控制節氣門系統、燃油系統等。引擎突然熄火可能為接頭接觸不良所致。
故障排除提示（此故障碼最可能之設定原因如下：）
  • 點火系統故障
  • 燃油系統故障
  • 空燃比控制系統故障
  • 進氣系統故障
  • EGR 系統作動故障
  • 節氣門周圍污染
  • 正時鏈條錯位
  • 壓縮壓力不正確
  • 曲軸箱強制通風系統故障
  • 可變汽門正時控制系統故障
  • ECM 故障
診斷
1.檢查 EGR 閥門初始化時之作動聲。
  • 請參閱 引擎 <4B4> – 引擎與排放控制 – 排放控制 – 廢氣再循環 (EGR) 系統 –EGR 閥門 (DC MOTOR) 檢查.
是否可聽到作動聲？
是
進入步驟 2。
否
檢查 EGR 閥門驅動電路，必要時進行修理。若電路正常，則更換 EGR 閥門。
2.使用 M.U.T.-III SE 讀取故障碼。
是否設定故障碼？
是
故障碼檢查表（請參閱故障碼檢查表).
否
進入步驟 3。
3.使用 M.U.T.-III SE，檢查資料清單。
  • 資料清單 參考表 (請參閱資料清單 參考表).
    1. 項目 5：進氣溫度感測器
    2. 項目 6：冷卻液（水）溫度感測器
    3. 項目 A8709：MAP 感測器
    4. 項目 8：空氣流量感測器
    5. 項目 12：APS (Main)
    6. 項目 13：APS (Sub)
    7. 項目 9：TPS (Main)
    8. 項目 10：TPS (Sub)
    9. 項目 24：V.V.T. RA (Intake-bank1)
    10. 項目 27：V.V.T. RA (Exhaust-bank1)
    11. 項目 A1501：氧氣感測器 (rear)
    12. 項目 A3301：大氣壓力感測器
    13. A6817：第 2 進氣溫度感測器
    14. 項目 A3417：LAFS (Bank1 Sensor1)
檢查結果是否正常？
是
轉至 4.
否
對顯示異常數據值的感測器執行故障碼分類檢查程序。故障碼檢查表（請參閱故障碼檢查表).
4.檢查進氣軟管與進氣歧管之進氣。
檢查結果是否正常？
是
GO TO 5.
否
修理。
5.檢查正時鏈條上的正時記號。
檢查結果是否正常？
是
GO TO 6.
否
對齊正時記號。
6.檢查節氣門體（節氣門部位）污染。
檢查結果是否正常？
是
GO TO 7.
否
清潔節氣門體（節氣門部位）（請參閱節氣門體（節氣門部位）清潔).
7.目視檢查點火星花。
  • 拆下火花塞並安裝至點火線圈。
  • 連接點火線圈接頭。
  • 斷開所有燃油噴射器接頭。
  • 引擎啟動時，檢查各火花塞是否產生火花。
檢查結果是否正常？
是
GO TO 8.
否
檢查檢查程序 - 點火電路系統（請參閱點火電路系統).
8.檢查淨化控制電磁閥本體。
  • 檢查淨化控制電磁閥本體（請參閱 引擎 <4B4> – 引擎與排放控制 – 排放控制 – 燃油蒸發排放控制系統 –淨化控制電磁閥 檢查).
檢查結果是否正常？
是
GO TO 9.
否
更換淨化控制電磁閥（請參閱 引擎 <4B4> – 引擎大修 –電磁閥與真空軟管拆裝).
9.檢查燃油噴射器噴霧狀況。
  • 檢查各燃油噴射器噴霧狀況（請參閱噴油嘴 檢查).
檢查結果是否正常？
是
GO TO 10.
否
更換燃油噴射器（請參閱噴射器拆裝).
10.檢查壓縮壓力。
  • 檢查壓縮壓力（請參閱 引擎 <4B4> – 引擎機械 – 車上服務 –壓縮壓力檢查).
檢查結果是否正常？
是
GO TO 11.
否
修理。
11.檢查曲軸箱強制通風系統。
  • 請參閱 引擎 <4B4> – 引擎與排放控制 – 排放控制 – 曲軸箱排放控制系統 –曲軸箱強制通風系統檢查.
檢查結果是否正常？
是
更換汽缸蓋罩總成（含 PCV 閥）（請參閱 引擎 <4B4> – 引擎機械 – 汽缸蓋罩 –汽缸蓋罩拆裝）。然後GO TO 12.
否
進行修理。然後確認故障症狀已消除。
12.檢查燃油中是否有異物（水、煤油等均屬此類）。
檢查結果是否正常？
是
GO TO 13.
否
更換燃油
13.檢查故障症狀。
故障症狀是否仍存在？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝).
否
檢查結束。
