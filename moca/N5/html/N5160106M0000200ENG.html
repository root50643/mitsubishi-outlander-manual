設計/用途
Adaptive LED 頭燈指示燈告知駕駛員 Adaptive LED 頭燈系統處於作動狀態。

燈泡檢查
不適用

不適用
於儀表 CAN 通訊中斷或異常訊號時之作動
有關在儀表板中開啟 CAN 通訊中斷的操作。請參閱失效保護.
系統圖
DF100C60AC00ENG
訊號路徑
  • 當 Adaptive LED 頭燈系統作動許可條件成立時，BCM 透過 CAN 通訊將 Adaptive LED 頭燈指示訊號傳送至儀表板。
  • 當儀表板收到 Adaptive LED 頭燈指示訊號時，儀表板點亮 Adaptive LED 頭燈指示燈。
點燈狀況
Adaptive LED 頭燈系統作動許可條件成立。（以下所有條件均成立時）
  • 點火開關開啟
  • 燈光開關 AUTO（僅於自動燈光功能的照明判定為開啟時。請參閱系統說明.)
  • Adaptive LED 頭燈開關開啟
熄滅狀況
Adaptive LED 頭燈系統作動許可條件不成立。
