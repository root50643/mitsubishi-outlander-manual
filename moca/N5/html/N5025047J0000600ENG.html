引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P1D2F-00: DC-DC Converter module#4 current 感知器 low
N5025047J0000600ENG
監視執行
連續。
監視執行條件（其它監視器與感測器）
其它監視器（下列監視項目的記憶體中未設定暫時故障碼）
  • DC-DC 轉換器控制模組
  • DC-DC 轉換器控制電壓
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關在開啟位置。
  • 12V 電池電壓介於 10.0 與 16.5 V 之間。
  • 起動馬達關閉。
  • 上述條件滿足後已經過 2 秒以上。
判定標準
  • 感測器電流為 -100 ampere 或更低，持續 2.5 秒。
失效保護與備援功能
  • 48V 輕度混合動力系統停止。
    1. 停止供電至 12V 側。
    2. 皮帶驅動起動馬達發電機的引擎助力與再生停止。
  • 充電警示燈亮起。
  • 禁止 Auto Stop。
  • AS&G 關閉燈閃爍。
OBD-II 行駛循環模式
請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 5 –行駛循環模式.
故障排除 HINT (The most likely causes for this code to be set are:)
  • DC-DC 轉換器故障。
診斷
所需專用工具：
  • MB993028：含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
1.測試 OBD-II 行駛循環。
  1. 將點火開關轉至「開啟」位置並清除故障碼。
  2. 以 drive cycle pattern 執行測試 drive。請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 5 –行駛循環模式.
  3. 檢查故障碼。
Q：是否設定故障碼 P1D2F-00？
是
更換 DC-DC converter（請參閱 Electrical & Power Control – Power Supply, Ground & Circuit Elements – 拆卸 and 安裝 – 48V 電池 –維修程序）。然後前往 2。
否
間歇性故障（請參閱 General Information – General Information – Basic Inspection – Service Information for Electrical Incident –間歇性故障).
2.測試 OBD-II 行駛循環。
  1. 以 drive cycle pattern 執行測試 drive。請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 5 –行駛循環模式.
  2. 檢查故障碼。
