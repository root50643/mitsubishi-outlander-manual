通風、暖氣及冷氣 - 暖氣及冷氣控制系統 - 自動冷氣 - 症狀診斷 - 冷卻不足
診斷程序
N50903019001J300ENG
注意：
執行症狀診斷前，先使用 M.U.T.-III SE 執行自我診斷。若偵測到任何故障碼，執行對應的診斷。
1.檢查電磁離合器作動
  1. 點火開關開啟。
  2. 按下風扇開關並運作鼓風機馬達。
  3. 按下 A/C 開關。
  4. 確認 A/C 指示燈亮起。目視並以聲音確認 A/C 壓縮機有運作。
  5. 再次按下 A/C 開關。
  6. 確認 A/C 指示燈熄滅。確認 A/C 壓縮機停止運作。
檢查結果是否正常？
是
转至 2.
否
在「症狀診斷」中執行「A/C 壓縮機不運作」的診斷。請參閱診斷程序.
2.檢查驅動皮帶
檢查驅動皮帶張力。請參閱檢查.
檢查結果是否正常？
是
转至 3.
否
依檢查結果調整或更換驅動皮帶。
3.檢查冷媒循環壓力
將回收/循環充填設備連接至車輛，並以壓力錶進行壓力檢查。請參閱症狀表.
檢查結果是否正常？
是
转至 4.
否
依檢查結果修理或更換零件。
4.檢查 ECV
執行 ECV 電路診斷。請參閱診斷程序.
檢查結果是否正常？
是
转至 5.
否
依檢查結果修理或更換零件。
5.檢查各風管漏氣
檢查冷氣系統的風管、出風口等是否有漏氣。
檢查結果是否正常？
是
转至 6.
否
依檢查結果修理或更換零件。
6.檢查日照感測器
執行日照感測器診斷。請參閱診斷程序.
檢查結果是否正常？
是
转至 7.
否
依檢查結果修理或更換零件。
7.檢查溫度設定修整器設定值
  1. 檢查溫度設定修整器的設定值。請參閱 M.U.T.-III SE 功能CONSULT 功能.
  2. 確認溫度設定修整器設定為「+方向」。
    注意：
    可透過溫度設定修整器的設定來調整控制溫度。
  3. 將設定溫度與控制溫度之差值設定為「0」。
檢查結果是否正常？
是
檢查結束
否
更換 A/C 放大器。請參閱A/C 放大器拆卸與安裝.
