變速箱與傳動系統 - 變速箱與變速器 - CVT<F1CJD, W1CJD> - 基本檢查 - 更換 TCM 時之額外服務
作業程序
N5040203R0007W00ENG
注意：
若同時更換 TCM 與變速箱總成，請執行「更換 TCM 與變速箱總成時之額外服務」。請參閱說明.
備註：
開始作業前，務必確認：
  • 務必確認 M.U.T.-III SE 已同步至目前日期。
  • 所有 M.U.T.-III SE 軟體更新（若有）均已安裝。
1.儲存校正資料（IP CHARACTERISTICS VALUE）
備註：
依下列指示，將儲存於 TCM 內之必要資料保存至 M.U.T.-III SE：
使用 M.U.T.-III SE
  1. 點火開關置於關閉位置，並等待 10 秒。
  2. 點火開關為開啟。
  3. 連接 M.U.T.-III SE。
  4. 在「TRANSMISSION」中選取「Special Function」。
  5. 選取「IP characteristics data writing」中的「READ IP CHARA - REPLACEMENT TCM」。
  6. 觸碰「OK」。
    備註：
    當校正資料已儲存至 M.U.T.-III SE 時，畫面將顯示「Completed」訊息。
前往步驟 2.
2.更換 TCM
  1. 點火開關為關閉狀態。
  2. 更換 TCM。請參閱拆卸與安裝.
GO TO 3.
3.執行 TCM 程式設計
使用 M.U.T.-III SE
依 M.U.T.-III SE 操作手冊中「Programming」之作業程序執行 TCM 程式設計。請參閱 M.U.T.-III SE 操作手冊。
注意：
程式設計期間，須維持下列條件：
  • 點火開關：開啟
  • 電氣負載：關閉
  • 煞車踏板：未踩下
  • 電池電壓：12 – 13.5 V（務必於 M.U.T.-III SE 之「Data monitor」中選取「電池 VOLT」確認電池電壓數值。）
GO TO 4.
4.寫入 MAC KEY
執行 MAC key 寫入，請參閱說明.
若自原 TCM 成功儲存校正資料時：GO TO 5.
若無法自原 TCM 儲存校正資料，且自 DXA 取得時：GO TO 6. 
5.寫入校正資料（IP CHARACTERISTICS VALUE）<若自原 TCM 成功儲存校正資料時>
備註：
依下列指示，將儲存於 M.U.T.-III SE 之資料寫入新 TCM：
使用 M.U.T.-III SE
  1. 確認車輛處於「Park」(P) 位置，然後將點火開關置於關閉位置，並等待 10 秒。
  2. 點火開關為開啟。
  3. 在「TRANSMISSION」中選取「Special Function」。
  4. 選取「IP characteristics data writing」中的「WRITE IP CHARA - REPLACEMENT TCM」。
  5. 觸碰「OK」。
    備註：
    當校正資料已寫入 TCM 時，畫面將顯示「Completed」訊息。
GO TO 7.
6.寫入校正資料（IP CHARACTERISTICS VALUE）<若無法自原 TCM 儲存校正資料，且自 DXA 取得時>
備註：
依下列指示，將新電磁閥資料寫入 TCM：
使用 M.U.T.-III SE
  1. 點火開關置於開啟位置，引擎停止。
  2. 踩下煞車踏板。
  3. 將油門踏板踩至一半並保持，然後在 M.U.T.-III SE 畫面上按「OK」。
  4. 依 M.U.T.-III SE 畫面指示將資料寫入 TCM。
    備註：
    當校正資料已寫入 TCM 時，目前狀態將顯示「Complete」。
GO TO 7.
7.執行 G 感測器校正
執行 G 感測器校正。請參閱 Description說明.
GO TO 8.
8.執行離合器接合點學習
執行 Clutch Point Learning。請參閱 Description說明.
GO TO 9.
9.執行 Select Learning（前進／倒車學習）
備註：
務必先執行 Clutch Point Learning，再執行 Select Learning。
  1. 執行 Select Learning。請參閱 Work Procedure作業程序.
  2. 清除可能已設定的 故障碼，然後進行試車。
GO TO 10.
10.執行 FACTORY MODE 關閉
  1. 將點火開關轉至 開啟。
  2. 在「TRANSMISSION」之「Special Function」中選取「Factory Mode 關閉」。
  3. 檢查項目 No. 1「Factory Mode 關閉」，依設定值執行下列作業。
    開啟：選取「OK」，將設定值變更為「關閉」。
    關閉：無需作業，作業已完成。
