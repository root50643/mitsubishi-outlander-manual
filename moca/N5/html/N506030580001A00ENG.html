詳細流程
1.故障問診
開始檢查前，釐清客戶反映的問題也很重要。請仔細詢問客戶並完全了解症狀。
注意：
顧客並非專業人員。切勿臆測「也許顧客是指···」或「也許顧客提到過這個症狀」。
進入步驟 2。
2.使用 M.U.T.-III SE 進行自我診斷
  1. 使用 M.U.T.-III SE 執行「Read All DTCs」。
  2. 檢查下列自我診斷結果中是否偵測到故障碼。
    • "ACC/ADAS 2"
    • "LASER/RADAR"
    • "車道攝影機"
是否偵測到任何故障碼？
是
GO TO 5.
否
進入步驟 3。
3.作動測試
執行下列系統作動測試以檢查作動狀態。請參閱作業程序作業程序.
檢查是否發生其他故障。
轉至 4.
4.症狀診斷
依症狀診斷圖表執行適用的診斷。請參閱症狀表.
GO TO 6.
5.依故障碼進行故障診斷
  1. 檢查自我診斷結果中的故障碼。
  2. 依下列方式對偵測到的故障碼執行故障診斷。
    • "ACC/ADAS 2"：請參閱故障碼索引故障碼索引
    • "LASER/RADAR"：請參閱故障碼索引故障碼索引
    • "車道攝影機"：請參閱故障碼索引故障碼索引.
注意：
若偵測到網路故障碼，請先診斷 CAN 通訊系統。
GO TO 6.
6.故障零件維修
維修或更換已判定的故障零件。
GO TO 7.
7.維修檢查（使用 M.U.T.-III SE 自我診斷）
  1. 清除自我診斷結果。
  2. 修理或更換特定項目後，再次執行「Read All DTCs」。
  3. 檢查下列項目的自我診斷結果中是否偵測到任何故障碼。
    • "ACC/ADAS 2"
    • "LASER/RADAR"
    • "車道攝影機"
是否偵測到任何故障碼？
是
GO TO 5.
否
GO TO 8.
8.維修確認（作動測試）
執行作動測試。確認故障症狀已排除或未發生其他症狀。請參閱作業程序作業程序.
是否仍有故障症狀？
是
進行步驟 4.
否
檢查結束
