煞車 - 煞車控制系統 - 含 VDC - 故障碼/電路診斷 - C1051-13 幫浦馬達
診斷程序
N50603026001J600ENG
1.檢查 接頭
  1. 斷開/拔除 12V 電池負極端子。
  2. 檢查 ABS 作動器及電動單元（控制單元）線束接頭是否脫開或鬆動。
檢查結果是否正常？
是
GO TO 3.
否
修復/更換線束或接頭，確實鎖緊接頭。進至 2.
2.執行自我診斷
使用 M.U.T.-III SE
  1. 連接 12V 電池負極端子並等待 30 秒。
  2. 以約 50 km/h (31 MPH) 或以上的速度行駛約 2 分鐘。
    備註：
    維修或更換後必須行駛車輛，以清除先前的 故障碼。
  3. 停止車輛。
  4. 點火開關關閉（Auto ACC 功能關閉）。
  5. 啟動引擎。
    備註：
    引擎啟動後至少等待 10 秒。
  6. 執行「ABS」自我診斷。
是否偵測到故障碼 "C1051-13"？
是
GO TO 3.
否
檢查結束
3.檢查 ABS 作動器及電動單元（控制單元）電源及搭鐵電路
檢查 ABS 作動器及電動單元（控制單元）之電源及搭鐵電路。請參閱診斷程序.
檢查結果是否正常？
是
前往 5.
否
修理/更換線束、接頭、端子、保險絲或大電流保險絲。GO TO 4.
4.清除自我診斷結果 (1)
使用 M.U.T.-III SE
  1. 以約 50 km/h (31 MPH) 或以上的速度行駛約 2 分鐘。
    備註：
    維修或更換後必須行駛車輛，以清除先前的 故障碼。
  2. 停止車輛。
  3. 清除「ABS」自我診斷結果。
  4. 點火開關關閉（Auto ACC 功能關閉）→ 開啟 → 關閉（Auto ACC 功能關閉）。
檢查結束
5.檢查 端子
  1. 斷開/拔除 12V 電池負極端子。
  2. 檢查 ABS 作動器及電動單元（控制單元）端子是否有損壞，或與線束接頭連接鬆動。
檢查結果是否正常？
是
更換 ABS 作動器及電動單元（控制單元）。請參閱拆卸與安裝.
否
修復/更換線束或接頭。前往 6.
6.清除自我診斷結果 (2)
使用 M.U.T.-III SE
  1. 連接 12V 電池負極端子。
  2. 以約 50 km/h (31 MPH) 或以上的速度行駛約 2 分鐘。
    備註：
    維修或更換後必須行駛車輛，以清除先前的 故障碼。
  3. 停止車輛。
  4. 清除「ABS」自我診斷結果。
  5. 點火開關關閉（Auto ACC 功能關閉）→ 開啟 → 關閉（Auto ACC 功能關閉）。
檢查結束
