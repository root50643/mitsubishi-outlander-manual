故障碼確認程序
1.前置條件
若先前已執行「故障碼確認程序」，請將點火開關關閉並等待至少 60 秒後，再進行下一項測試。
前往 2.
2.執行故障碼確認程序
  1. 點火開關開啟。
  2. 在「SHIFT」中選擇「資料清單」。
  3. Select “Shift 位置 judgment”.
  4. 依下列方式移動排檔桿。（於各位置停留 2 秒以上。）
    H → Nr → R → Nd → D/M → H
  5. Repeat step 4 five times.
  6. 檢查 故障碼.
