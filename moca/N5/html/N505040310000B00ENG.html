詳細流程
1.客戶訪談
檢查前請先釐清客戶抱怨。為此，請事先重現症狀並充分理解。然後詳細詢問客戶。必要時，與客戶一同試車以確認症狀。
注意：
客戶並非專業人員。切勿輕易臆測，例如「也許客戶是指……」或「也許客戶提到的是這個症狀」。
前往 2.
2.檢查胎壓警告燈功能
檢查儀表板中的胎壓警告燈。
胎壓警告燈是否點亮？
是
前往 3.
否
GO TO 6.
3.檢查胎壓
檢查所有車輪的胎壓。請參閱輪胎空氣壓力.
注意：
檢查冷車狀態下的胎壓。
是否符合檢查標準值？
是
GO TO 6.
否
GO TO 4.
4.調整胎壓
  1. 檢查並將所有車輪的胎壓調整至規定值。請參閱輪胎空氣壓力.
  2. 以 40 km/h（25MPH）或以上的速度行駛，總計達 10 分鐘。
胎壓警告燈是否熄滅？
是
前往 5.
否
GO TO 6.
5.檢查漏氣
使用肥皂水等，檢查是否漏氣。
注意：
檢查氣門嘴。
是否偵測到漏氣？
是
修理或更換有異常的零件。更換氣門嘴。執行胎壓感測器 ID 註冊。請參閱說明.
否
檢查結束
6.執行自我診斷
使用 M.U.T.-III SE
執行「BCM」的「自我診斷」。
是否偵測到故障碼？
是
記錄或列印自我診斷結果與凍結資料（FFD）。GO TO 8.
否
GO TO 7.
7.確認症狀
執行症狀診斷。請參閱症狀表症狀表.
修理或更換偵測到異常的零件。GO TO 10.
8.執行確認程序
使用 M.U.T.-III SE
針對偵測到的故障碼執行確認程序，然後檢查該故障碼是否再次出現。
是否偵測到故障碼？
是
GO TO 9.
否
依據訪談所得資訊檢查線束與接頭。請參閱間歇性故障間歇性故障.
9.診斷程序
執行故障碼診斷程序。
修理或更換偵測到異常的零件。GO TO 10.
10.最終檢查
重新確認症狀，並檢查在相同條件下症狀是否未再出現。
症狀是否再現？
是
前往 2.
否
檢查結束
