變速箱與驅動系統 - 變速箱總成與變速箱 - CVT<F1CJD, W1CJD> - 基本檢查 - 更換變速箱總成時的附加服務

注意：
開始前，務必確認：
  • 確認 M.U.T.-III SE 已同步至目前日期。
  • 已安裝所有 M.U.T.-III SE 軟體更新（若有）。
1.列印目前校正資料
使用 M.U.T.-III SE
  1. 點火開關為開啟。
  2. 連接 M.U.T.-III SE。
  3. 在「TRANSMISSION」中選擇「CALIB DATA」。
  4. 列印第 1 頁（共 7 頁）。
    注意：
    此螢幕列印用於保固文件。
進行步驟 2.
2.檢查序號（第 1 部分）
記下新變速箱總成的序號。
CF100A4PAA00ENG
進行步驟 3.
3.檢查序號（第 2 部分）
使用 M.U.T.-III SE
  1. 點火開關為開啟。
  2. 將隨附 CD 插入 M.U.T.-III SE。
  3. 在「TRANSMISSION」中選擇「Special Function」。
  4. 在「IP characteristics data writing」中選擇「WRITE IP CHARA - REPLACEMENT AT/CVT」。
  5. 點選「File import」，將儲存於 CD 中的校正檔案存入 M.U.T.-III SE。
  6. 點選「OK」開啟「Select IP characteristics data file」視窗。
  7. 確認 M.U.T.-III SE 螢幕上顯示的序號（校正檔案編號）與變速箱總成上的序號（校正檔案編號）相符。
  8. 點選「OK」。
進行步驟 4.
4.寫入校正資料（IP 特性值）
注意：
依下列說明將新電磁閥資料寫入 TCM：
使用 M.U.T.-III SE
  1. 點火開關 開啟，引擎 關閉。
  2. 踩下煞車踏板。
  3. 將油門踏板踩至一半並保持，然後在 M.U.T.-III SE 螢幕上按「OK」。
  4. 依 M.U.T.-III SE 螢幕上的說明將資料寫入 TCM。
    注意：
    校正資料寫入 TCM 後，目前狀態將顯示「Complete」。
進行步驟 5.
5.列印新校正資料
使用 M.U.T.-III SE
  1. 在「TRANSMISSION」中選擇「CALIB DATA」。
  2. 列印第 1 頁（共 7 頁）。
    注意：
    此螢幕列印用於保固文件。
進行步驟 6.
6.執行選擇學習（前進/倒車學習）
執行選擇學習。請參閱工作程序作業程序.
GO TO 7.
7.執行換檔作動器學習
執行換檔作動器學習。請參閱說明.
GO TO 8.
8.清除 CVT 油液劣化程度資料
使用 M.U.T.-III SE
  1. 在「TRANSMISSION」中選擇「WORK SUPPORT」。
  2. 選擇「CONFORM CVTF DETERIORTN」。
  3. 點選「OK」。
  4. 清除可能已設定的任何 故障碼，然後試車。
