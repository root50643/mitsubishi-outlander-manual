傳動皮帶自動張力器檢查
N502391120000B00ENG
作動 檢查
在怠速狀態下停止引擎。
檢查傳動皮帶未從傳動皮帶自動張力器的皮帶盤寬度向外突出。
將工具確實套在自動張力器的六角部分。
建議使用工具：
KTC Ratchet box end wrench (Extra long flex) (No. MR15L-14F)
向左方向轉動自動張力器，檢查是否有卡滯。
警告：
務必將工具確實套在六角部分，因自動張力器張力較高，以防工具脫落。
注意：
  • 務必逆時針轉動自動張力器，若順時針轉動可能使六角部分斷裂。
  • 為防止自動張力器皮帶盤損壞，勿轉動皮帶盤至與皮帶驅動起動發電機的自動張力器安裝區域干涉。
  • 為防止自動張力器彈簧斷裂，檢查自動張力器動作時請勿觸碰彈簧。
若程序 2 或 4 有任何問題，更換傳動皮帶自動張力器（請參閱曲軸皮帶盤拆卸與安裝).
功能檢查
可藉由檢查張力來確認傳動皮帶自動張力器是否功能正常。
<測量振動頻率時：建議>
檢查傳動皮帶張力（請參閱傳動皮帶張力檢查與調整).
如圖所示，以手指輕彈皮帶輪之間傳動皮帶的中間部位（箭頭指示位置）。
注意：
  • 測量時，務必確認引擎為冷車狀態。
  • 將曲軸順時針轉動一圈以上後再測量。
  • 請勿讓水、油等污染物沾到麥克風。
  • 若強風吹向麥克風或附近有強烈噪音源，麥克風測得的數值可能與實際值不符。
  • 測量時若麥克風接觸到皮帶，麥克風測得的數值可能與實際值不符。
  • 請勿在車輛引擎運轉時進行測量。
檢查傳動皮帶振動頻率在標準值範圍內。
Standard value (Reference): 117 - 153 Hz
注意：
若要重複測量，請再次彈撥傳動皮帶。
若不在標準值範圍內，更換傳動皮帶自動張力器（請參閱曲軸皮帶盤拆卸與安裝).

<測量張力時>
檢查傳動皮帶張力（請參閱傳動皮帶張力檢查與調整).
使用皮帶張力計於圖中所示皮帶輪之間傳動皮帶的中間部位（箭頭指示位置）測量，檢查傳動皮帶張力是否在標準值範圍內。
Standard value (Reference): 235 - 406 N
注意：
  • 測量時，務必確認引擎為冷車狀態。
  • 將曲軸順時針轉動一圈以上後再測量。
若不在標準值範圍內，更換傳動皮帶自動張力器（請參閱曲軸皮帶盤拆卸與安裝).
