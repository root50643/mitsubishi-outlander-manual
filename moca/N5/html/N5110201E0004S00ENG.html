車身 EXTERIOR, DOORS, ROOF & 車輛 SECURITY - SECURITY CONTROL SYSTEM - 故障碼/CIRCUIT DIAGNOSIS - B2044-4A Electric shift ID 註冊失敗
故障碼診斷程序
N5110201E0004S00ENG
1.檢查 ELECTRIC SHIFT CONTROL MODULE 的故障碼優先順序
使用 M.U.T.-III SE 選取 "SHIFT" 的 "Self Diagnostic Result" 模式。
是否偵測到故障碼？
是
執行與偵測到的故障碼相關的故障診斷。請參閱故障碼 Index<F1CJD, W1CJD> 或故障碼 Index<F1CJE, W1CJE>。
否
進至 2.
2.檢查免鑰匙操作 KEY UNIT 的故障碼優先順序
  1. 使用 M.U.T.-III SE 選取 "HANDS FREE MODULE" 的 "Self Diagnostic Result" 模式。
  2. 若顯示故障碼 B2042-4A 且偵測到兩個以上的 故障碼，請參閱故障碼檢查優先順序表，並判定故障診斷。
是否偵測到故障碼？
是
執行與偵測到的故障碼相關的故障診斷。請參閱故障碼 Index.
否
GO TO 3.
3.執行初始化
  1. 使用 M.U.T.-III SE 執行免鑰匙操作 key unit 的初始化以及所有免鑰匙操作鑰匙的註冊。
    關於初始化與註冊程序，請參閱 M.U.T.-III SE 防盜碼模式並依照螢幕上的指示操作。
  2. 啟動引擎。
引擎是否能夠啟動？
