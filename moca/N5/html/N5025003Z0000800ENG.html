永久故障碼
N5025003Z0000800ENG
永久故障碼（PDiagnosis Code）以永久狀態儲存在 ECM 的 EEPROM 中，用以確認與排放相關元件/系統的故障尚未修復。當偵測到需要點亮引擎警告燈（引擎故障燈）的故障時，ECM 會點亮 MIL，並同時在 EEPROM 中設定對應的故障碼作為 Pdiagnosis code。ECM 最多可儲存 6 個 PDiagnosis Code，因此無法儲存第 7 個及之後的 PDiagnosis Code。若暫時性故障導致引擎警告燈點亮，之後在後續行駛中恢復正常而熄滅，則 Pdiagnosis code 會被清除。另外，若在故障碼修復完成後的行駛中，ECM 確認故障碼故障已排除，Pdiagnosis code 也會被清除。然而，PDiagnosis Code 不會因斷開電池端子或使用 M.U.T.-III SE 清除而被刪除。若在 ECM 重新編程時，所有準備狀態（readiness status）被清除或尚未完成，則可清除 Pdiagnosis code。若車輛已完成修復，可依下列程序清除 Pdiagnosis code。
永久故障碼清除程序
  1. 確認未設定故障碼。若已設定故障碼，請執行故障碼故障排除，並修復故障碼。
  2. 以適用於該永久故障碼的駕駛循環模式行駛車輛。（請參閱行駛循環模式)
  3. 確認永久故障碼已清除。若永久故障碼未清除，請檢查故障碼或暫時性故障碼。若已設定故障碼，請修復故障碼。再次嘗試清除永久故障碼（從步驟 1 至步驟 2）。若未設定故障碼，駕駛循環模式（步驟 2）對故障的監控可能不足。
