煞車 - 煞車控制系統 - 含 VDC - 基本檢查 - 側向 G 感測器校正
作業程序
N5060305A0008J00ENG
注意：
側向 G 感測器校正一律使用 M.U.T.-III SE。（除 M.U.T.-III SE 外無法調整。）
1.檢查車輛狀態
  1. 將方向盤轉至正前方位置。將車輛停於水平路面上。
  2. 停止引擎。
  3. 點火開關關閉 (自動 ACC 功能關閉)。
車輛是否停在正前方位置的水平路面上？
是
進行步驟 2.
否
將方向盤轉至正前方位置。將車輛停於水平路面上。
2.執行側向 G 感測器校正
注意：
  • 切勿有乘客或載重於車上。
  • 校正期間開關車門時，切勿對車身施加振動。
使用 M.U.T.-III SE
  1. 點火開關開啟。
    注意：
    切勿啟動引擎。
  2. 依序選擇「ABS」、「感測器校正（在「Special function」內）」及「SIDE G 感測器校正」。
  3. 選擇「OK」。
  4. 顯示「Completed」後，等待約 10 秒並按下「OK」。
  5. 點火開關關閉（Auto ACC 功能關閉）後再重新開啟。
    注意：
    務必執行上述作動。
進行步驟 3.
3.檢查 DATA MONITOR
使用 M.U.T.-III SE
  1. 行駛車輛。將方向盤轉至正前方位置。將車輛停於水平路面上。
  2. 依序選擇「ABS」、「資料清單」及「Side G 感測器」。確認訊號在指定數值範圍內。請參閱參考值.
檢查結果是否正常？
是
進行步驟 4.
否
前往 1.
4.清除自我診斷記憶
使用 M.U.T.-III SE
清除所有系統的自我診斷結果。
記憶是否已清除？
是
檢查結束
否
檢查自我診斷所指示的項目。
已加入書籤書籤數量過多。
請刪除後重新加入書籤。
