概要
後雨刷由 BCM 各項功能控制。
BCM 控制
  • 組合開關讀取功能
  • 後雨刷控制功能
後雨刷基本作動
  • BCM 透過組合開關讀取功能偵測組合開關狀態。
  • BCM 控制後雨刷啟動或停止。
後雨刷 開啟 作動
  • BCM 依後雨刷 開啟 作動條件供電給後雨刷馬達。
    後雨刷 開啟 作動條件
    • 點火開關 開啟
    • 後雨刷開關 開啟
後雨刷 INT 作動
  • BCM 依 INT 作動條件供電給後雨刷馬達。
    後雨刷 INT 作動條件
    • 點火開關 開啟
    • 後雨刷開關 INT
  • BCM 控制後雨刷作動一次。
  • BCM 偵測後雨刷馬達停止位置。
  • BCM 於後雨刷馬達停止後，經間歇時間再供電給後雨刷馬達。
    CF100BY5AA00ENG
後雨刷自動停止作動
  • 當後雨刷開關轉至 關閉 時，BCM 停止供電給後雨刷馬達。
  • BCM 自後雨刷馬達讀取後雨刷停止位置訊號，以偵測後雨刷馬達位置。
  • 當後雨刷馬達不在停止位置時，BCM 持續供電給後雨刷馬達，直至其返回停止位置。
    CF100BY6AA00ENG
備註：
當點火開關轉至 關閉 時，BCM 停止供電給後雨刷馬達。
後雨刷作動與清洗液連動
  • BCM 依後雨刷與清洗液連動作動條件供電給後雨刷馬達。當後清洗液開關轉至 關閉 時，BCM 控制後雨刷約作動 3 次。
    後雨刷與清洗液連動作動條件
    • 點火開關 開啟
    • 後清洗液開關 開啟
  • BCM 依條件經 CAN 通訊將後清洗液泵浦請求訊號傳送給 IPDM E/R。
  • IPDM E/R 依後清洗液泵浦請求訊號 開啟/關閉 後清洗液泵浦繼電器。IPDM E/R 提供電源以作動前後清洗液泵浦。
後雨刷作動與倒車連動
  • BCM 依後雨刷與倒車連動作動條件，控制後雨刷以 INT 模式作動。
    後雨刷與倒車連動作動條件
    • 點火開關 開啟
    • 前雨刷開關：LO、HI、INT 或 AUTO
    • 後雨刷開關 關閉
    • 排檔桿「R」
  • 當排檔桿排入「R」時，TCM 經 CAN 通訊將倒車開關訊號傳送給 BCM，接著作動後雨刷馬達。
備註：
後雨刷與倒車連動作動可透過儀表設定變更為 開啟 或 關閉。
