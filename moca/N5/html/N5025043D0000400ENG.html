引擎<4B4> - 直接噴射與多點燃油噴射（DI 與 MPI）- 故障排除 - 故障碼程序
Code No. P0515-00：電瓶溫度感測器電路失效/故障
N5025043D0000400ENG
技術說明
IPDM E/R 監控電瓶溫度感測器，並將診斷結果（OK/NOK）的 CAN 訊號傳送給 ECM。
監控方法說明
當 ECM 從 IPDM E/R 收到電瓶溫度感測器的 NOK 資訊時，將顯示故障碼。
監測執行
連續。
監測執行條件（其他監測項目與感知器）
其他監測項目（下列監測項目未在記憶體中設定暫時性故障碼）
  • U0142-00：CAN 逾時 (IPDM E/R)
  • U01B0-00：電瓶溫度感測器 LIN 通訊（區域連網通訊）錯誤
感知器（下列感知器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 引擎運轉中。
  • 電瓶正極電壓大於 10.5 V 且小於 16.5 V。
判定基準
  • ECM 持續 3 秒收到 IPDM E/R 失效/故障資訊。
失效保護與備援功能
怠速熄火功能禁止。
OBD-II 駕駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 1駕駛循環模式.
故障排除提示（此故障碼最可能的原因如下：）
檢查 IPDM E/R，並依 IPDM E/R 的故障排除程序進行檢查。
診斷
所需特殊工具：
  • MB993028：含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
1.使用 M.U.T.-III SE 讀取其他系統故障碼。
  1. 將點火開關轉至「開啟」位置。
  2. 讀取 IPDM E/R 故障碼（12V 電瓶電流感測器相關故障碼）。
  3. 將點火開關轉至「LOCK」（關閉）位置。
Q：是否設定 IPDM E/R 故障碼（12V 電瓶電流感測器相關故障碼）？
是
請參閱 Electrical & Power Control - Power Control System - IPDM E/R - ECU Diagnosis Information - IPDM E/R -故障碼索引.
否
前往步驟 2。
2.測試 OBD-II 駕駛循環。
  1. 以驅動循環模式進行路試。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 1駕駛循環模式.
  2. 檢查故障碼。
Q：是否設定故障碼 P0515-00？
是
重新執行故障排除。
否
