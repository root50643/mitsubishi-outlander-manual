診斷程序
N51601017004NG00ENG
1.檢查 接頭
  1. 點火開關關閉。
  2. 檢查儀表與 8CH CAN 網關之 Ethernet 線束接頭及端子是否有損壞或鬆脫。
檢查結果是否正常？
是
進至 2.
否
修理或更換故障零件，並確實鎖緊線束接頭。
2.執行所有故障碼讀取
  1. 點火開關開啟。
  2. 使用 M.U.T.-III SE 執行「Read All DTCs」。
  3. 檢查在「8ch CAN 網關 2」的「自我診斷結果」中是否偵測到 Ethernet 故障碼（故障碼「U288C-88」）
是否偵測到 Ethernet 故障碼？
是
更換 8CH CAN 網關（請參閱拆卸與安裝），以及GO TO 3.
否
8CH CAN 網關。請參閱拆卸與安裝.
3.執行故障碼確認程序-1
  1. 使用 M.U.T.-III SE 清除所有自我診斷結果。
  2. 再次執行故障碼確認程序。請參閱故障碼說明.
故障碼「U278C-87」是否偵測為目前故障？
是
更換儀表（請參閱拆卸與安裝），以及GO TO 4.
否
檢查結束
4.執行故障碼確認程序-2
  1. 使用 M.U.T.-III SE 清除所有自我診斷結果。
  2. 再次執行故障碼確認程序。請參閱故障碼說明.
故障碼「U278C-87」是否偵測為目前故障？
是
更換儀表與 8CH CAN 網關之間的 Ethernet 線束。
否
檢查結束
