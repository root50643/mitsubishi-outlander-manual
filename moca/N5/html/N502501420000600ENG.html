引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 症狀程序
檢查程序 11：爆震
N502501420000600ENG
故障症狀相關說明
  • 失效/故障可能是由爆震控制系統失效、火星塞熱值不當等原因所造成。
故障排除提示（設定此故障碼最可能的原因為：）
  • 燃油系統失效。
  • 壓縮壓力不當。
  • 爆震感知器失效。
  • 爆震控制系統失效。
  • 火星塞故障。
  • 點火系統失效。
  • ECM 故障。
診斷
1.使用 M.U.T.-III SE，讀取故障碼。
故障碼是否已設定？
是
故障碼檢查表（請參閱故障碼檢查表).
否
前往 2。
2.目視檢查點火花。
  • 拆下火花塞並安裝至點火線圈。
  • 連接點火線圈接頭。
  • 斷開所有燃油噴射器接頭。
  • 引擎啟動時，檢查各火花塞是否產生火花。
檢查結果是否正常？
是
前往 3。
否
檢查 Inspection Procedure - 點火電路系統（請參閱點火電路系統).
3.檢查壓縮壓力。
  • 檢查壓縮壓力（請參閱 引擎 <4B4> – 引擎機械 – 車上服務 –壓縮壓力檢查).
檢查結果是否正常？
是
前往 4。
否
維修。
4.檢查燃油。
  • 檢查燃油中是否有異物（水、柴油等）進入及燃油變質。
檢查結果是否正常？
是
檢查 code No. P0327-00：爆震感知器迴路偏低（請參閱Code No. P0327-00: Knock 感知器 circuit low）。檢查 code No. P0328-00：爆震感知器迴路偏高（請參閱Code No. P0328-00: Knock 感知器 circuit high).
否
更換燃油。
