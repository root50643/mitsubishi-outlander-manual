STEERING - STEERING CONTROL SYSTEM - 故障碼/電路診斷 - C163E-83 底盤控制系統
診斷程序
N507020170016000ENG
1.執行故障碼診斷
使用 M.U.T.-III SE
  1. 點火開關由關閉轉至開啟。
  2. 對「CHASSIS CONTROL」執行故障碼診斷。
是否偵測到任何故障碼？
是
檢查故障碼。請參閱故障碼索引.
否
進行步驟 2.
2.檢查接頭及端子
  1. 點火開關關閉。
  2. 斷開/拔除底盤控制模組單元線束接頭。
  3. 斷開/拔除動力轉向控制模組線束接頭。
  4. 檢查接頭是否脫開或鬆脫。
  5. 檢查端子是否損壞或與線束接頭連接鬆脫。
檢查結果是否正常？
是
進行步驟 3.
否
修復或更換線束、接頭或端子，並確實鎖緊接頭。
3.執行故障碼診斷
使用 M.U.T.-III SE
  1. 連接底盤控制模組線束接頭。
  2. 連接動力轉向控制模組線束接頭。
  3. 點火開關由關閉轉至開啟。
  4. 清除「EPS/DAST 3」的自診斷結果。
  5. 拉動駐車煞車開關。
    注意：
    確認駐車煞車開關指示燈已點亮。
  6. 點火開關關閉。
  7. 下車並關閉所有車門。
  8. 等待 65 秒。
    注意：
    • 確認駐車煞車開關指示燈已熄滅。
    • 若後煞車卡鉗溫度偏高，請等待一小時，以免駐車煞車開關指示燈熄滅。
  9. 點火開關開啟。
  10. 對「EPS/DAST 3」執行故障碼診斷。
是否偵測到故障碼「C1620–83」？
是
更換動力輔助轉向控制模組（轉向齒條總成）。請參閱拆卸與安裝.
否
檢查結束
