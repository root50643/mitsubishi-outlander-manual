備註：
若已更換電動換檔控制模組，請從步驟 2 開始。
1.清除換檔作動器學習值
使用 M.U.T.-III SE
  1. 開啟點火開關。
  2. 在「SHIFT」中選擇「Special Function」。
  3. 在「Learned value clear」中選擇「作動器學習值消除」。
  4. 輕觸「OK」。
GO TO 2.
2.換檔作動器學習
  1. 開啟點火開關。
  2. 在「P」位置踩下煞車踏板，並等待 3 秒。
  3. 啟動引擎。
  4. 踩下煞車踏板。
  5. 切換至「D」位置，並等待 3 秒。
  6. 按壓 P 位置開關。
  7. 將點火開關轉至 關閉，並等待 60 秒。
