CRUISE CONTROL & DRIVER ASSISTANCE - 駕駛輔助系統 - 駕駛輔助系統 - 故障碼/電路診斷 - 雷射/雷達（距離感測器）- C2599-13 乙太網路電路
診斷程序
N51702017006H600ENG
1.檢查 接頭
  1. 點火開關關閉。
  2. 檢查距離感測器與 ADAS 控制單元 2 的乙太網路線束接頭與端子是否有損壞或鬆脫。
檢查結果是否正常？
是
進行步驟 2.
否
修理或更換故障零件，確實鎖緊線束接頭。
2.執行全部故障碼讀取
  1. 點火開關開啟。
  2. 使用 M.U.T.-III SE 執行「Read All DTCs」。
  3. 檢查在「ACC/ADAS 2」的「自診斷結果」中是否偵測到乙太網路相關的 故障碼（故障碼「C1F71-87」、「U2752-87」及/或「U2752-88」）。
是否偵測到任何乙太網路相關故障碼？
是
更換 ADAS 控制單元 2（請參閱拆卸及安裝），並進行步驟 3.
否
更換 ADAS 控制單元 2。請參閱拆卸及安裝.
3.執行故障碼確認程序-1
  1. 使用 M.U.T.-III SE 清除全部自我診斷結果。
  2. 再次執行故障碼確認程序。請參閱故障碼說明故障碼說明.
故障碼「C2599-13」是否被偵測為目前故障？
是
更換距離感測器（請參閱拆卸及安裝），並進行步驟 4.
否
檢查結束
4.執行故障碼確認程序-2
  1. 使用 M.U.T.-III SE 清除全部自我診斷結果。
  2. 再次執行故障碼確認程序。請參閱故障碼說明故障碼說明.
故障碼「C2599-13」是否被偵測為目前故障？
是
更換距離感測器與 ADAS 控制單元 2 之間的乙太網路線束。
否
檢查結束
