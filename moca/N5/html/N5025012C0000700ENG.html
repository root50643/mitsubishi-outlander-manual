引擎<4B4> - 直接噴射與多點燃油噴射（DI 與 MPI）- 故障排除 - 故障碼程序
Code No. U1005-00：CAN 逾時（PAC）
N5025012C0000700ENG
注意：
若在 ECM 中設定故障碼 U1005-00，務必執行 CAN 匯流排線路診斷。
注意：
在確定通訊迴路正常後更換 ECU。
故障碼設定條件
檢查條件
  • 點火開關轉至「開啟」位置後，經過 2 秒。
  • 12V 電池正極電壓大於 10 V 且小於 16.5 V。
判定準則
  • 無法透過 CAN 匯流排線路接收 PAC-ECU 訊號達 4 秒。
註解
目前故障
  • 失效／故障可能由 ECM 與間距警示控制單元之間 CAN 匯流排線路的線束及接頭故障、間距警示控制單元電源供應系統故障、間距警示控制單元本身故障或 ECM 故障所造成。
過去故障
  • 進行故障排除，著重檢查 ECM 與間距警示控制單元之間 CAN 匯流排線路的線束及接頭故障。
    注意：
    在過去故障的情況下，即使 CAN 匯流排存在故障，M.U.T.-III SE 的 CAN 匯流排線路診斷也可能無法偵測到故障。因此，請如同因應間歇性故障一樣檢查 CAN 匯流排線路（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障）。可從執行 CAN 通訊的各 ECU 所設定的診斷碼，縮小高可能性故障區域（請參閱 Electrical and Power Control - LAN System - CAN Fundamental - Basic Inspection - Diagnosis and Repair Workflow -關於 M.U.T.-III SE CAN 匯流排診斷的說明).
失效保護與備援功能
間距警示控制單元所請求的扭力被忽略。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 3行駛循環模式.
故障排除提示（設定此故障碼最可能的原因如下：）
  • 雷達系統失效
診斷
所需特殊工具：
  • MB993028: VCI-3 kit with wireless adapters
    1. -: VCI-3 device
    2. MB993029: DLC cable
    3. MB993030: USB cable
    4. MB993031: Wireless USB adapter (Qty:2)
  • MB993040: VCI-3 kit without wireless adapters
    1. -: VCI-3 device
    2. MB993029: DLC cable
    3. MB993030: USB cable
1.使用 M.U.T.-III SE 讀取故障碼。
  • 故障碼再確認。
再次確認 ECM 中是否設定故障碼。
  1. 清除已設定的故障碼。
  2. 點火開關：LOCK（關閉）→ 開啟
  3. 確認是否設定了故障碼。
Q：故障碼 U1005-00 是否設定？
是

請參閱 Electrical and Power Control - LAN System - CAN Fundamental - Basic Inspection - Diagnosis and Repair Workflow -關於 M.U.T.-III SE CAN 匯流排診斷的說明.
否
GO TO 2.

檢查與間距警示控制單元執行 CAN 通訊的其他控制單元是否設定故障碼。

    • 環景監視系統
    • BCM
  • Code No. U2465-57
    • ADAS-ECU

  • 故障碼再確認。
再次確認 ECM 中是否設定故障碼。
  1. 清除已設定的故障碼。
  2. 點火開關：LOCK（關閉）→ 開啟
  3. 確認是否設定了故障碼。
