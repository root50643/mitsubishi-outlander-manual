CRUISE CONTROL & DRIVER ASSISTANCE - CRUISE CONTROL SYSTEM - MI-PILOT - System Description - SYSTEM - CONVENTIONAL (FIXED 車速) CRUISE CONTROL MODE FUNCTION
系統說明
N5170102T0003700ENG
功能說明
傳統（定速）巡航控制模式可讓車輛以 30 至 144 km/h 之間的車速行駛，而無需持續踩著加速踏板。
注意：
與車距控制模式不同，不會執行與前車距離之控制。MI-PILOT 系統警告及煞車控制亦不會執行。
DF100CEIAH00ENG
作動說明
  • 當車距控制模式關閉時，按住 MI-PILOT 開關 1.5 秒以上，車速控制指示燈亮起，並將控制設定為設定待機狀態。
    注意：
    切換至車距控制模式時，請先將系統關閉，然後按壓 MI-PILOT 開關未滿 1.5 秒，以將車距控制模式設定為設定待機狀態。
  • 系統比較目前車速與設定車速，透過 CAN 通訊向 ECM 傳送指令，並控制扭力使目前車速趨近設定車速。
  • 當系統處於設定待機狀態且車速介於約 30 至 144 km/h 之間時，按下 SET- 開關當下的車速會儲存為設定車速，並開始控制。
  • ADAS 控制單元 2 依下列方式執行控制：
    定速
    比較設定車速與目前車速，透過 CAN 通訊向 ECM 傳送指令以達到設定車速，並控制電子節氣門控制作動器。
作動條件
  • 傳統（定速）巡航控制模式：開啟
    注意：
    當車距控制模式關閉時，按住 MI-PILOT 開關 1.5 秒以上，車速控制指示燈亮起，並將控制設定為設定待機狀態。
  • 車速：約 30 至 144 km/h 之間
取消條件
  • 按下 CANCEL 開關
  • 輕踩煞車踏板
  • 按下 MI-PILOT 開關以關閉系統（MI-PILOT 狀態指示燈熄滅）
  • 任一車門開啟
  • 駕駛員安全帶未繫上
  • 本車車速低於 25 km/h
  • 排檔桿未在 D（Drive）位置或手動換檔模式
  • 電子駐車煞車已作用
  • ASC 系統已關閉
  • AEB 施加煞車
  • ASC（含循跡控制系統）作動
  • 已選擇雪地模式、碎石模式或泥地模式（4WD 車型）
  • 車輪打滑
