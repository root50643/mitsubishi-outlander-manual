衛星感測器

  • 前門衛星感測器安裝於前門板。
    CF100AQTAA00ENG
    : 車輛前方
  • B 柱衛星感測器安裝於前座安全帶捲收器前側中央柱下部。
  • C 柱衛星感測器安裝於行李廂側下飾板拆卸處的 C 柱。
  • 前門衛星感測器配備側向碰撞壓力感測器，可偵測超過車輛規定極限的側向碰撞衝擊。
  • B 柱及 C 柱衛星感測器配備側向碰撞 G 感測器，可偵測超過車輛規定極限的側向碰撞衝擊。
  • 當發生超過車輛規定極限的側向碰撞時，衛星感測器會偵測衝擊。若氣囊診斷感測器單元中的側向碰撞安全確認感測器判定衝擊為碰撞所致，則前側氣囊、前中央氣囊、後側氣囊、窗簾氣囊及安全帶預緊器將作動。
