引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P06EF-00: Auto start failed
N5025008V0000400ENG
技術說明
  • 自動啟動時，ECM 透過 local CAN 傳送啟動命令訊號以啟動皮帶驅動式起動發電機。此舉啟動皮帶驅動式起動發電機以啟動引擎。
故障碼設定條件
檢查條件
  • 點火開關在 開啟 位置。
判定準則
  • 自動啟動期間（3 秒）引擎未啟動。
失效保護與備援功能
  • Auto Stop 已禁止。
  • AS&G 關閉燈閃爍中。
OBD-II 驅動循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 20驅動循環模式.
故障排除提示（此故障碼最可能的設定原因如下：）
  • 48V 系統故障。
  • DI 與 MPI 系統故障。
  • 燃油耗盡
診斷
所需特殊工具：
  • MB993028：VCI-3 套件（含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：VCI-3 套件（不含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
