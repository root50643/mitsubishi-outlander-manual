煞車 - 煞車控制系統 - 附 VDC - 故障碼/電路診斷 - C104E-04 ABS OUT 閥門
診斷程序
N50603026001J200ENG
1.檢查 接頭
  1. 斷開 12V 電池負極端子。
  2. 檢查 ABS 作動器與電動單元 (控制單元) 線束接頭是否脫落或鬆動。
檢查結果是否正常？
是
GO TO 3.
否
修理/更換線束或接頭，並確實鎖緊接頭。前往步驟 2.
2.執行自我診斷
使用 M.U.T.-III SE
  1. 連接 12V 電池負極端子。
  2. 啟動引擎。
    備註：
    引擎啟動後至少等待 10 秒。
  3. 執行 "ABS" 自我診斷。
是否偵測到故障碼「C104E-04」？
是
GO TO 3.
否
檢查結束
3.檢查 ABS 作動器與電動單元 (控制單元) 電源及搭鐵線路
檢查 ABS 作動器與電動單元 (控制單元) 電源及搭鐵線路。請參閱診斷程序.
檢查結果是否正常？
是
GO TO 4.
否
修理/更換線束、接頭、端子、保險絲或大電流保險絲。
4.檢查 端子
  1. 斷開 12V 電池負極端子。
  2. 檢查 ABS 作動器與電動單元（控制單元）端子是否有損壞，或與線束接頭連接鬆動。
檢查結果是否正常？
是
更換 ABS 作動器與電動單元 (控制單元)。請參閱拆卸與安裝.
否
修理/更換線束、接頭或端子。
