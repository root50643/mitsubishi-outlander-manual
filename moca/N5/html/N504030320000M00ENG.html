變速箱與傳動系 - 傳動系 - 分動器 - 基本檢查 - 排氣及初始化油液劣化程度
作業程序
N504030320000M00ENG
1.工作前準備
將車輛設定為下列狀態。
  • 溫度條件為 -10°C (14°F) 或以上。
  • 車輛在平坦位置停妥。
  • 電瓶電壓條件為 14.2 V 或以上。
    注意：
    若電瓶電壓偏低，必須外接增壓器。
前往步驟 2.
2.排氣及初始化油液劣化程度
使用 M.U.T.-III SE
  1. 將點火開關由關閉轉至開啟。
  2. 在「ALL MODE AWD/4WD」的「WORK SUPPORT」中選擇「BLEED AIR & INITIALIZE OIL DETERIORATION LEVEL」。
  3. 選取「OK」。
  4. 依 M.U.T.-III SE 的指示操作。
    注意：
    排氣作動時，車輛下方會聽到作動噪音，但這並非故障。
是否顯示「Completed」?
是
GO TO 3.
否
對「ALL MODE AWD/4WD」執行自我診斷，並檢查偵測到的故障碼。請參閱故障碼索引.
3.檢查 OIL LEVEL
再次檢查電液耦合器油液液位，必要時補充油液。請參閱調整.
注意：
排氣後油液液位可能會降低。
GO TO 4.
4.最終檢查
使用 M.U.T.-III SE
執行故障碼「C1220-54」的故障碼確認程序。請參閱故障碼說明.
是否偵測到故障碼「C1220-54」?
是
繼續進行診斷程序。請參閱診斷程序.
否
