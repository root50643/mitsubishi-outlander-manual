煞車 - 煞車控制系統 - 自動煞車駐車 - 故障碼/電路診斷 - 自動煞車駐車指示燈

1.檢查底盤控制模組電源與搭鐵電路
檢查底盤控制模組電源與搭鐵電路。請參閱診斷程序.
檢查結果是否正常？
是
進行步驟 2.
否
修理或更換電源或搭鐵電路。
2.執行自我診斷
使用 M.U.T.-III SE
對「底盤控制」執行自我診斷。
是否偵測到故障碼？
是
檢查故障碼。請參閱故障碼索引.
否
進行步驟 3.
3.檢查自動煞車駐車指示燈訊號 (1)
使用 M.U.T.-III SE
依序選擇「CHASSIS CONTROL」、「DATA MONITOR」、「ABH indicator light」，檢查自動煞車駐車開關訊號。請參閱參考值.
檢查結果是否正常？
是
檢查結束
否
進行步驟 4.
4.檢查自動煞車駐車指示燈訊號 (2)
使用 M.U.T.-III SE
依序選擇「CHASSIS CONTROL」、「作動器測試」（於「Special Function」內）、「Automatic BRAKE hold light active」，並檢查自動煞車駐車開關訊號。請參閱 M.U.T.-III SE FunctionCONSULT 功能.
檢查結果是否正常？
是
檢查結束
否
進行步驟 5.
5.檢查 儀表
檢查儀表。
  • 全 TFT 儀表：請參閱車上診斷功能.
  • 7 吋資訊顯示器：請參閱車上診斷功能.
檢查結果是否正常？
是
更換底盤控制模組。請參閱拆卸及安裝.
否
修理或更換儀表。
  • 全 TFT 儀表：請參閱拆卸及安裝.
  • 7 吋資訊顯示器：請參閱拆卸及安裝
