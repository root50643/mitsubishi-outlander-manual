引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P2135-00：節氣門位置感測器 (main and sub) range/performance problem
N502501160000800ENG
volts
電路作動
  • 5 V 的電源電壓由 ECM 接頭端子 TPS5 施加至電子控制節氣門接頭端子。
  • 電源電壓由電子控制節氣門接頭端子搭鐵至 ECM 接頭端子 TPSE。
  • 感測器訊號由電子控制節氣門接頭輸出端子輸入至 ECM 接頭端子 TPSM。
  • 感測器訊號由電子控制節氣門接頭輸出端子輸入至 ECM 接頭端子 TPSS。
技術說明
  • ECM 檢查節氣門位置感測器輸出訊號特性是否異常。
監視方法說明
若節氣門位置感測器 (main) 與節氣門位置感測器 (sub) 之間的關係錯誤，則偵測到故障。
監視執行
連續。
監視執行條件（其它監視與感測器）
其它監視（下列監視項目在記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關位於「開啟」位置。
  • 電瓶正極電壓高於 6.2 volts。
判定準則
  • 目標位置與目前位置之差超過 13 degrees。
失效保護與備援功能
  • 節氣門開度位置處於預設位置。
  • 正常作動時，禁止自動停止。
OBD-II 驅動循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 3驅動循環模式.
故障排除提示（此故障碼最可能的設定原因如下：）
  • 節氣門本體總成 (內建節氣門位置感測器) 故障。
  • 線束及接頭故障。
  • ECM 故障。
診斷
所需特殊工具：
  • MB993028：VCI-3 套件（含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：VCI-3 套件（不含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
1.使用 M.U.T.-III SE 讀取故障碼。
  1. 將點火開關轉至「開啟」位置。
  2. 檢查是否設定故障碼 P0121-00、P0122-00、P0123-00、P0222-00、P0223-00、P0652-00、P0653-00 或 P0638-00。
  3. 將點火開關轉至「LOCK」（關閉）位置。
Q: 是否有設定任何故障碼？
是
請參閱故障碼診斷圖表 (請參閱 Diagnostic Code故障碼檢查表.)
否
GO TO 2.
2.檢查 ECM 接頭與電子控制節氣門接頭之間 TPS5、TPSS、TPSM 及 TPSE 線路是否損壞。
Q：檢查結果是否正常？
是
GO TO 3.
否
修理接頭或線路。然後GO TO 5.
3.使用 M.U.T.-III SE 檢查資料清單。
資料清單 參考表 (請參閱資料清單 參考表).
  1. Item No. 11: TPS (Main) Learning value under ETV deactivation
  2. Item No. 40: TPS(MAIN) Learned Value (Closed 位置)
  3. Item No. 41: TPS(MAIN) Learned Value (Full Open 位置)
  4. Item No. 42: TPS(SUB) Learned Value (Closed 位置)
  5. Item No. 43: TPS(SUB) Learned Value (Full Open 位置)
Q：檢查結果是否正常？
是
GO TO 4.
否
點火開關電源由關閉切換至開啟。然後GO TO 4.
4.測試 OBD-II 驅動循環。
  1. 將點火開關轉至「開啟」位置並清除故障碼。
  2. 依驅動循環模式執行路試。請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 3驅動循環模式.
  3. 檢查故障碼。
Q：是否設定故障碼 P2135-00？
是
更換節氣門本體總成 (請參閱 Throttle 車身 總成 -節氣門體總成拆卸與安裝）。然後GO TO 5.
否
間歇性故障 (請參閱 GENERAL INFORMATION - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障).
5.測試 OBD-II 驅動循環。
  1. 依驅動循環模式執行路試。請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 3驅動循環模式.
  2. 檢查故障碼。
Q：是否設定故障碼 P2135-00？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝).
否
檢查完成。
