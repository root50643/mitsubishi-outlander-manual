轉向 - 轉向控制系統 - 故障碼/電路診斷 - C163A-64 ADAS system
診斷程序
N507020170015U00ENG
1.執行自我診斷
使用 M.U.T.-III SE
  1. 點火開關由關閉至開啟。
  2. 執行 "ACC/ADAS 2" 的自我診斷。
是否偵測到任何故障碼？
是
檢查故障碼。請參閱故障碼索引.
否
前往 2.
2.檢查接頭與端子
  1. 點火開關關閉。
  2. 斷開 ADAS Control unit 2 線束接頭。
  3. 斷開動力轉向控制模組線束接頭。
  4. 檢查接頭是否脫開或鬆動。
  5. 檢查端子是否有損壞，或與線束接頭連接鬆脫。
檢查結果是否正常？
是
前往 3.
否
修理或更換線束、接頭或端子，並確實鎖緊接頭。
3.執行自我診斷
使用 M.U.T.-III SE
  1. 連接 ADAS Control unit 2 線束接頭。
  2. 連接動力轉向控制模組線束接頭。
  3. 點火開關由關閉至開啟。
  4. 清除「EPS/DAST 3」的自我診斷結果。
  5. 拉起駐車煞車開關。
    注意：
    確認駐車煞車開關指示燈已點亮。
  6. 點火開關關閉。
  7. 下車並關閉所有車門。
  8. 等待 65 秒。
    注意：
    • 確認駐車煞車開關指示燈已熄滅。
    • 若後輪煞車卡鉗溫度偏高，請等待 1 小時，以避免駐車煞車開關指示燈誤熄滅。
  9. 啟動引擎。
  10. MI-PILOT Assist system 已開啟*1，行駛車輛。
    注意：
    務必安全駕駛。
    注意：
    *1：配備 MI-PILOT Assist system 的車輛
  11. 停止車輛。
  12. 執行「EPS/DAST 3」自我診斷。
是否偵測到故障碼 "C163A-64"？
是
更換 ADAS control unit 2。請參閱拆卸與安裝.
否
檢查結束
已加入書籤書籤數量過多。
請刪除後重新加入書籤。
