正面碰撞：碰撞時安全氣囊作動
注意：
因車型及配備等級不同，下表所列零件並非全部適用於所有車輛。
工作程序
執行以下各步驟前，請確認所有車身及結構性修理均已完成。
更換診斷感測器單元。
拆下前安全氣囊模組、膝部安全氣囊模組、碰撞區感測器總成、支架及安全帶預緊器總成。
使用下表檢查安全氣囊零件。
更換任何有明顯損壞跡象的安全氣囊零件。(凹痕、裂縫及變形等)。
安裝新的前安全氣囊模組、膝部安全氣囊模組、碰撞區感測器總成、支架及安全帶預緊器總成。
使用 M.U.T.-III SE 或安全氣囊警告燈執行自我診斷。請參閱 DTCIndex故障碼索引. 詳細內容請參閱。
確認整體安全氣囊系統運作正常。
工作完成後，確認安全氣囊警告燈未偵測到任何故障。
若安全氣囊展開後有緊急通報，必須執行以下作業。
使用 M.U.T.-III SE
  1. 使用 M.U.T.-IIISE 選擇 "IVC" 的「自動通報防止鎖定解除」模式。
  2. 選擇 "OK" 以解除鎖定。
安全氣囊檢查 (正面碰撞)
零件
檢查
駕駛員安全氣囊模組
若駕駛員安全氣囊已展開：
更換
使用新固定件安裝。
駕駛員膝部安全氣囊模組
若駕駛員膝部安全氣囊已展開：
更換
使用新固定件安裝。
前乘客安全氣囊模組
若前乘客安全氣囊已展開：
更換
使用新固定件安裝。
碰撞區感測器
若任一前方安全氣囊或安全帶預緊器*已作動：
更換 crash zone 感知器及支架，並使用新的固定件。
*：僅可使用 M.U.T.-III SE 確認安全帶預緊器是否作動。
安全帶預緊器總成
（所有適用位置：扣環、捲收器、外側腰帶）
若駕駛席或乘客席安全帶預緊器*已作動：
更換所有安全帶預緊器總成，並使用新的固定件。
*：僅可使用 M.U.T.-III SE 確認安全帶預緊器是否作動。
診斷感知器單元
若任一安全氣囊元件已作動：
更換診斷感測器單元。
使用新固定件安裝。
方向盤
  1. 目視檢查方向盤是否有變形。
  2. 檢查線束（內建於方向盤中）及接頭是否損壞，並檢查端子是否變形。
  3. 將駕駛席安全氣囊模組安裝至方向盤，以檢查配合度及與方向盤之校正。
  4. 檢查方向盤是否鬆動過大。
  5. 若未發現損壞，重新安裝。
  6. 若損壞 ─ 更換。
時鐘彈簧
若駕駛席前方安全氣囊已膨開：
更換時鐘彈簧。
乘員偵測系統（乘客座椅）
若任一安全氣囊元件已作動：
更換座椅墊總成。
使用新固定件安裝。
線束及接頭
  1. 檢查接頭是否連接不良、損壞，並檢查端子是否變形。
  2. 檢查線束是否有束縛、摩擦、割傷或變形。
  3. 若未發現損壞，重新安裝線束及接頭。
  4. 若損壞 ─ 更換損壞的線束。請勿嘗試修理、接合或改裝任何安全氣囊線束。
儀表板總成
若乘客席前方安全氣囊及/或膝部安全氣囊已膨開：
更換儀表板總成。（一體式）
