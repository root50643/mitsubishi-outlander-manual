引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0261-00: 噴油嘴電路低輸入 - 第 1 缸
N5025006A0000500ENG
電路作動
  • 電源由 ECM 繼電器供應至燃油噴油嘴。
  • ECM 接頭端子 INJ1 使單元內的功率電晶體處於 開啟 位置，進而使電流流過燃油噴油嘴。
技術說明
  • ECM 控制燃油噴油嘴的供電間隔。
  • 燃油噴油嘴的噴油量取決於供電間隔。
監控方法說明
ECM 偵測到開路與短路故障。
監視執行
連續。
監視執行條件 (其他監視器與感知器)
其他監視器 (以下監視項目在記憶體中未設定暫時性故障碼)
  • 不適用
感知器 (以下感知器判定為正常)
  • 不適用
故障碼設定條件
檢查條件
  • 引擎運轉中。
  • 電池正極電壓大於 10.5 volts 且小於 16.5 volts。
判定基準
  • 低壓噴油嘴驅動器狀態變為失效狀態，即短路-低。
失效保護與備援功能
單缸斷油。
OBD-II 行駛循環模式
請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 6行駛循環模式.
故障排除提示 (此故障碼最可能的設定原因為：)
  • 燃油噴油嘴故障
  • 燃油噴油嘴電路中開路/短路或線束損壞，或接頭接觸鬆脫
  • ECM 故障
