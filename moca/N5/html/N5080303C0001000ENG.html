限制裝置 - 安全氣囊 - 基本檢查 - 碰撞診斷 - 側面及翻覆碰撞
當碰撞時安全氣囊未作動
N5080303C0001000ENG
側面及翻覆碰撞：碰撞時安全氣囊未作動
警告：
因車型及配備等級不同，下表所列零件並非適用於所有車輛。
作業程序
執行下列任何步驟前，請確認所有車身及結構修復已完成。
使用下表檢查安全氣囊元件及相關零件。
  • 若前座椅背總成損壞，必須更換前座椅背總成。
  • 若後座椅背總成損壞，必須更換後座椅背總成。
  • 若車門飾板總成損壞，必須更換車門飾板總成及簾式安全氣囊模組。
使用 M.U.T.-III SE 及「AIR BAG」警告燈執行自我診斷。請參閱故障碼索引故障碼索引以了解詳情。務必確認整個安全氣囊系統運作正常。
作業完成後，確認安全氣囊警告燈未偵測到任何故障。
安全氣囊檢查（側面及翻覆碰撞）
零件
檢查
側簾式安全氣囊模組 LH
若左側簾式安全氣囊未展開：
  1. 檢查碰撞側中央支柱是否有可見損壞跡象（凹痕、撕裂、變形）。
  2. 若損壞 - 拆下左側簾式安全氣囊模組。
  3. 檢查左側簾式安全氣囊模組是否有可見損壞跡象（撕裂等）。
  4. 檢查線束及接頭是否損壞，以及端子是否變形。
  5. 若未發現損壞，使用新固定件重新安裝左側簾式安全氣囊模組。
  6. 若損壞 - 使用新固定件更換左側簾式安全氣囊模組。
側簾式安全氣囊模組 RH
若右側簾式安全氣囊未展開：
  1. 檢查碰撞側中央支柱是否有可見損壞跡象（凹痕、撕裂、變形）。
  2. 若損壞 - 拆下右側簾式安全氣囊模組。
  3. 檢查右側簾式安全氣囊模組是否有可見損壞跡象（撕裂等）。
  4. 檢查線束及接頭是否損壞，以及端子是否變形。
  5. 若未發現損壞，使用新固定件重新安裝右側簾式安全氣囊模組。
  6. 若損壞 - 使用新固定件更換右側簾式安全氣囊模組。
前側安全氣囊模組 LH
若左前側安全氣囊未展開：
  1. 檢查碰撞側座椅背是否有可見損壞跡象（凹痕、撕裂、變形）。
  2. 檢查線束及接頭是否損壞，以及端子是否變形。
  3. 若損壞 - 更換左前座椅背總成。
前側安全氣囊模組 RH
若右前側安全氣囊未展開：
  1. 檢查碰撞側座椅背是否有可見損壞跡象（凹痕、撕裂、變形）。
  2. 檢查線束及接頭是否損壞，以及端子是否變形。
  3. 若損壞 - 更換右前座椅背總成。
前中央安全氣囊模組
若前中央安全氣囊未展開：
  1. 檢查碰撞側座椅背是否有可見損壞跡象（凹痕、撕裂、變形）。
  2. 檢查線束及接頭是否損壞，以及端子是否變形。
  3. 若損壞 - 更換右前座椅背總成。
側向安全氣囊（衛星）感測器（LH 或 RH）
若所有安全氣囊元件均未作動：
  1. 拆下碰撞側的側向安全氣囊（衛星）感測器（LH 或 RH）。檢查線束接頭是否損壞、端子是否變形，以及線束是否束縛。
  2. 檢查側向安全氣囊（衛星）感測器（LH 或 RH）是否有可見損壞跡象（凹痕、裂縫、變形）。
  3. 安裝側向安全氣囊（衛星）感測器（LH 或 RH）以檢查配合度。
  4. 若未發現損壞，使用新固定件重新安裝側向安全氣囊（衛星）感測器（LH 或 RH）。
  5. 若損壞 - 使用新固定件更換側向安全氣囊（衛星）感測器（LH 或 RH）。
車門（衛星）感測器（LH 或 RH）
若所有安全氣囊元件均未作動：
  1. 拆下碰撞側的車門（衛星）感測器（LH 或 RH）。檢查線束接頭是否損壞、端子是否變形，以及線束是否束縛。
  2. 檢查車門（衛星）感測器（LH 或 RH）是否有可見損壞跡象（凹痕、裂縫、變形）。
  3. 安裝車門（衛星）感測器（LH 或 RH）以檢查配合度。
  4. 若未發現損壞，使用新固定件重新安裝車門（衛星）感測器（LH 或 RH）。
  5. 若損壞 - 使用新固定件更換車門（衛星）感測器（LH 或 RH）。
診斷感測器單元
若所有安全氣囊元件均未作動：
  1. 檢查外殼及支架是否有凹痕、裂縫或變形。
  2. 檢查接頭是否損壞，以及端子是否變形。
  3. 若未發現損壞，使用新固定件重新安裝診斷感測器單元。
  4. 若損壞 - 使用新固定件更換診斷感測器單元。
安全帶預緊器總成
（所有適用位置：扣環、卷收器、外側腰帶）
更換安全帶預緊器總成。
使用新固定件安裝。
座椅（含前側安全氣囊）
若左前或右前側安全氣囊模組未展開：
  1. 目視檢查碰撞側座椅。
  2. 拆下碰撞側座椅，並檢查下列項目是否損壞及變形。
    • 線束、接頭及端子
    • 框架及椅背調整機構（前後座椅），以及調整機構及滑軌（前座椅）
  3. 若未發現損壞，重新安裝座椅。
  4. 若損壞 - 使用新固定件更換損壞的座椅零件。若前座椅背損壞，必須更換前座椅背總成。
座椅（含前中央安全氣囊）
若前中央安全氣囊模組未展開：
  1. 目視檢查駕駛座側座椅。
  2. 拆下駕駛座座椅，並檢查下列項目是否損壞及變形。
    • 線束、接頭及端子
    • 框架及椅背調整機構（前後座椅），以及調整機構及滑軌（前座椅）
  3. 若未發現損壞，重新安裝駕駛座座椅。
  4. 若損壞 - 使用新固定件更換損壞的座椅零件。若前座椅背損壞，必須更換前座椅背總成。
中央內側支柱
  1. 檢查碰撞側中央內側支柱是否損壞（凹痕、裂縫、變形等）。
  2. 若損壞 - 修復中央內側支柱。
飾板/車頂內裝
  1. 檢查碰撞側內裝飾板是否有可見損壞跡象（凹痕、裂縫、變形等）。
  2. 若損壞 - 更換損壞的飾板零件。
簾式安全氣囊模組 LH
若左側簾式安全氣囊未展開：
  1. 檢查碰撞側車門飾板是否有可見損壞跡象（凹痕、撕裂、變形等）。
  2. 若損壞 - 使用新固定件更換左側車門飾板。
  3. 檢查左側簾式安全氣囊模組是否有可見損壞跡象（撕裂等）。
  4. 檢查線束及接頭是否損壞，以及端子是否變形。
  5. 若未發現損壞，重新安裝車門飾板。
    警告：
    從車門飾板拆下簾式安全氣囊模組時，請勿重複使用車門飾板。
  6. 若損壞 - 使用新固定件更換左側車門飾板及左側簾式安全氣囊模組。
簾式安全氣囊模組 RH
若右側簾式安全氣囊未展開：
  1. 檢查碰撞側車門飾板是否有可見損壞跡象（凹痕、撕裂、變形等）。
  2. 若損壞 - 使用新固定件更換右側車門飾板。
  3. 檢查右側簾式安全氣囊模組是否有可見損壞跡象（撕裂等）。
  4. 檢查線束及接頭是否損壞，以及端子是否變形。
  5. 若未發現損壞，重新安裝車門飾板。
    警告：
    從車門飾板拆下簾式安全氣囊模組時，請勿重複使用車門飾板。
  6. 若損壞 - 使用新固定件更換右側車門飾板及右側簾式安全氣囊模組。
乘員偵測系統（乘客座）
  1. 拆下乘客座總成。
  2. 檢查控制單元外殼是否有凹痕、裂縫或變形。
  3. 檢查接頭是否損壞，以及端子是否變形。
  4. 檢查座椅框架及坐墊底板是否有凹痕或變形。
  5. 若未發現損壞，使用新固定件重新安裝座椅。
  6. 若損壞 - 使用新固定件更換坐墊總成。
彈出式防滾架
若彈出式防滾架未展開：
  1. 檢查彈出式防滾架是否有可見損壞跡象（凹痕、撕裂、變形等）。
  2. 若損壞 - 使用新固定件更換彈出式防滾架。
  3. 檢查線束及接頭是否損壞，以及端子是否變形。
  4. 若未發現損壞，使用新固定件重新安裝彈出式防滾架。
  5. 檢查椅背支撐支架總成是否有明顯損壞跡象（凹痕、龜裂、變形等）。
  6. 若已損壞－修理椅背支撐支架總成。
