代碼 No. P161D-64：防盜器故障（因 BCM 之故，引擎 ECU 維持保護狀態）
N5025010C0000800ENG
技術說明
  • ECM 監測 BCM 端是否發生防盜器驗證錯誤。
故障碼設定條件
檢查條件
  • 點火開關位於「開啟」位置。
判定準則
  • BCM 驗證無效。
失效保護與備援功能
  • 無
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
故障排除提示（設定此故障碼最可能的原因如下：）
  • 鑰匙登錄作動異常
  • 智慧型鑰匙系統故障
  • 動力方向盤控制模組故障
  • ECM 故障

1.M.U.T.-III SE 其他系統故障碼
  • 確認免鑰匙操作單元中是否設定故障碼
問：檢查結果是否正常？
是
執行免鑰匙操作單元的故障排除（請參閱 車身 Exterior, Doors, Roof & 車輛 Security - DOOR ＆ Lock - ECU 診斷資訊 - 免鑰匙操作 Key Unit -故障碼索引).
否
GO TO 2.
2.使用 M.U.T.-III SE 讀取故障碼。
  • 故障碼再確認。
Q：是否設定故障碼 P161D-64？
是
間歇性故障 (請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障).
否
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後前往 3.
3.測試 OBD-II 行駛循環。
  1. 依驅動循環模式執行測試行駛。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  2. 檢查故障碼。
Q：是否設定故障碼 P161D-64？
是
重新執行故障排除。
否
檢查完成。
