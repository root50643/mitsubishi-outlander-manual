引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P14C1-29: 煞車開關卡滯 失效/故障
N502501050000700ENG
注意：
若 ECM 中設定故障碼 P14C1-29，務必執行 CAN 匯流排線路診斷。
注意：
確認通訊線路正常後，方可更換 ECU。
故障碼設定條件
檢查條件
  • 點火開關 開啟 位置 2 秒後。
  • 電瓶電壓 9 伏特或以上 1.5 秒後。
  • 配備定速控制或主動式定速控制。
判定條件
  • CAN 訊號 "BrakeSwitchFaillure_V2" = 不可用值持續 500 ms。
故障症狀相關說明
目前故障
  • 失效/故障可能由 ECM 與 BCM 之間 CAN 匯流排線路的線束及接頭故障、BCM 故障或 ECM 故障所造成。
過去故障
  • 進行故障排除，著重檢查 ECM 與 BCM 之間 CAN 匯流排線路的線束及接頭開路故障。
    備註：
    就過去故障而言，即使 CAN 匯流排存在異常，M.U.T.-III SE 的 CAN 匯流排線路診斷也可能無法偵測到故障。因此，請依間歇性故障的處理方式檢查 CAN 匯流排線路（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障）。可從執行 CAN 通訊的各 ECU 所設定的診斷碼，縮小故障可能性較高的區域（請參閱 Electrical and Power Control - LAN System - CAN Fundamental - Basic Inspection - Diagnosis and Repair Workflow -M.U.T.-III SE CAN 匯流排診斷說明).
失效保護與備援功能
定速控制與主動式定速控制將會取消。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 3行駛循環模式.

  • BCM 系統

1.M.U.T.-III SE 其他故障碼
Q：是否設定故障碼 U0141-00？
是
診斷碼檢查表（請參閱故障碼檢查表).
否
前往 2。
2.M.U.T.-III SE 其他系統故障碼
  • 確認 BCM 中是否設定故障碼。
Q：是否設定故障碼？
是
執行 BCM 故障排除（請參閱 Electrical & Power Control - 車身 Control System - ECU Diagnosis Information - BCM -故障碼 Index).
否
前往 3。
3.使用 M.U.T.-III SE，讀取故障碼。
再次確認 ECM 中是否設定故障碼。
  1. 清除已設定的故障碼。
  2. 點火開關：LOCK（關閉）→ 開啟
  3. 確認是否設定故障碼。
Q：是否設定故障碼？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後GO TO 4.
否
ECM 與 BCM 之間 CAN 匯流排線路間歇性故障（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障).
4.測試 OBD-II 行駛循環。
  1. 依駕駛循環模式執行路試。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 3行駛循環模式.
  2. 檢查故障碼。
Q: 是否設定故障碼 P14C1-29？
是
重新執行故障排除。
否
檢查完成。
