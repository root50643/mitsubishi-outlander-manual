引擎<4B4> - 直接噴射與多點燃油噴射（DI 與 MPI）- 故障排除 - 故障碼程序
Code No. P0053-00：Linear A/F 感知器 heater resistance
N5025004M0000600ENG
電路作動
  • 電源由 main 2 繼電器供應至線性空燃比感知器接頭的加熱器電源端子。
  • 線性空燃比感知器接頭的加熱器由 ECM 接頭端子 LHFL 的功率電晶體控制。
技術說明
  • 當加熱器通電時，ECM 會檢查加熱器電流是否在指定範圍內。
監視方法說明
線性空燃比感知器加熱器電流超出指定範圍。
監視執行
連續。
監視執行條件（其他監視與感測器）
其他監視（下列監視項目未在記憶體中設定暫時性故障碼）
  • 線性空燃比感測器監視
  • 後氧感測器監視
  • 線性空燃比感測器加熱器監視
  • 後氧感測器加熱器監視
  • 失火監控
  • 燃油系統監視
  • 燃油分配管壓力控制系統監控
感測器（下列感測器判定為正常）
  • 淨化控制電磁閥
  • 空氣流量感測器
  • 引擎冷卻液溫度感測器
  • 1 號進氣溫度感測器
  • 大氣壓力感測器
  • 進氣歧管絕對壓力感測器
  • 燃油噴油嘴（高壓）
  • 燃油壓力感測器
  • 增壓壓力感測器
故障碼設定條件
檢查條件
  • 引擎啟動程序完成後已超過 220 秒。
  • 當線性空燃比感知器加熱器開啟時。
  • 電池正極電壓介於 10.5 與 16.5 伏特之間。
  • 進氣溫度高於 -10°C。
  • 線性空燃比感知器加熱器開啟占空比介於 3 與 97% 之間。
判定準則
  • 線性空燃比感知器元件溫度平均低於 615°C 達 15 秒。
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 8行駛循環模式.
故障排除提示（設定此故障碼最可能的原因如下：）
  • 線性空燃比感知器加熱器線路開路/短路或線束損壞，或接頭接觸鬆脫
  • 線性空燃比感知器加熱器故障
  • ECM 故障
診斷
所需特殊工具：
  • MB993028: VCI-3 kit with wireless adapters
    1. -: VCI-3 device
    2. MB993029: DLC cable
    3. MB993030: USB cable
    4. MB993031: Wireless USB adapter (Qty:2)
  • MB993040: VCI-3 kit without wireless adapters
    1. -: VCI-3 device
    2. MB993029: DLC cable
    3. MB993030: USB cable
1.於線性空燃比感知器接頭進行電阻測量。
  • 斷開/拔除接頭，並於感知器側進行測量。
  • 端子 main 2 繼電器 L 線與 ECM LHFL 線之間的電阻。
    OK：1.7 - 2.6 Ω（於 20°C）
問：檢查結果是否正常？
是
GO TO 2.
否
更換線性 A/F 感測器（請參閱 引擎 <4B4> - 進排氣 - 三元催化器 -三元催化器拆卸與安裝<2WD>,三元催化器拆卸與安裝<4WD>）。然後前往 5。
2.檢查 main 2 繼電器接頭與線性空燃比感知器接頭之間 L 線的損壞。
問：檢查結果是否正常？
是
前往 3。
否
修理接頭或線路。然後前往 5。
3.檢查線性空燃比感知器接頭與 ECM 接頭之間 LHFL 線的損壞。
問：檢查結果是否正常？
是
前往 4。
否
修理接頭或線路。然後前往 5。
4.使用 M.U.T.-III SE 讀取故障碼。
  • 診斷碼再確認。
Q：是否設定故障碼 P0053-00？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後前往 5。
否
間歇性故障 (請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障).
5.測試 OBD-II 行駛循環。
以驅動循環模式進行試車。請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 8行駛循環模式.
檢查故障碼。
Q：是否設定故障碼 P0053-00？
是
重新執行故障排除。
否
檢查完成。
