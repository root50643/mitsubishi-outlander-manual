引擎<4B4> - 直接燃油噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P014D-00：Linear A/F 感測器慢速反應 - 稀至濃 <Vehicles for Taiwan>
N5025044B0000300ENG
技術說明
  • ECM 依據 Linear A/F 感測器訊號，執行空燃比回饋控制。
  • 若 Linear A/F 感測器已劣化，將由氧氣感測器（後）進行修正。
監控方法說明
在監控期間，若 Linear A/F 感測器濃側與稀側反應時間差值的平均值等於或大於預定值，即設定 Linear A/F 感測器劣化之故障碼。
監控執行
連續。
監控執行條件（其他監控項目及感測器）
其他監控項目（下列受監控項目的記憶體中未設定暫時性故障碼）
  • 線性 A/F 感測器監控
  • 線性 A/F 感測器加熱器監控
  • 氧氣感測器 (後) 加熱器監控
  • 失火監控
  • 燃油系統監控
感測器（下列感測器已判定為正常）
  • 空氣流量感測器
  • 引擎冷卻液溫度感測器
  • No. 1 進氣溫度感測器
  • 大氣壓力感測器
  • 節氣門位置感測器
  • 進氣歧管絕對壓力感測器
故障碼設定條件
檢查條件
  • 引擎轉速介於 1,219 至 3,000 r/min。
  • 容積效率介於 25 至 120%。
  • 引擎冷卻液溫度高於 60°C。
  • 處於閉迴路空燃比控制狀態下。
  • 短期燃油修正介於 -25 至 +25%。
  • 在驅動循環期間，ECM 以累計總時間 10 秒，執行 3 次監控。
判定準則
  • 平均反應時間比率（濃側時間/稀側時間）超過指定值。
  • 依據氧氣感測器（後）補償的空燃比數量超出指定範圍。
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱 Diagnostic Function，OBD-II Drive Cycle – Pattern 18行駛循環模式.
故障排除提示 (本故障碼最可能設定原因：)
Linear A/F 感測器故障。

1.測試 OBD-II 行駛循環。
  1. 將點火開關轉至「開啟」位置並清除故障碼。
  2. 依驅動循環模式執行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 18行駛循環模式.
  3. 檢查故障碼。
