M.U.T.-III SE Data Link 接頭 (DLC) 電路

檢查程序
若 M.U.T.-III SE/GST 無法正確診斷系統，請檢查下列項目。
症狀
檢查項目
M.U.T.-III SE 無法存取任何系統。
  • M.U.T.-III SE DLC 電源電路（端子 8 和 16）及搭鐵電路（端子 4 和 5）
  • 檢查 8CH CAN 網關的電源及搭鐵電路。請參閱
    診斷程序.
  • 檢查 Data Link 接頭分支線路電路。請參閱診斷程序.
  • 檢查診斷 CAN 通訊電路。請參閱診斷程序.
  • 若上述檢查結果正常，則更換 8CH CAN 網關。請參閱拆卸及安裝.
M.U.T.-III SE 無法存取個別系統。（其他系統可存取。）
  • 該系統控制單元的電源及搭鐵電路（詳細電路請參閱各系統配線圖。）
  • 系統與 M.U.T.-III SE DLC 之間的斷路或短路（詳細電路請參閱各系統配線圖。）
  • CAN 通訊線路斷路或短路。請參閱故障診斷流程圖.
注意：
源自 DLC 腳位 12、13、14 和 15 的 DDL1 及 DDL2 電路可能連接至一個以上系統。連接至某一系統控制單元的 DDL 電路若短路，可能影響 M.U.T.-III SE 對其他系統的存取。
若 GST 無法正常運作，請依據 SAE J1962 及 ISO 15031-3 的資訊檢查電路。
