引擎<4B4> - 直接噴射與多點燃油噴射（DI 與 MPI）- 故障排除 - 故障碼程序
Code No. P0AA0-00：48V 繼電器錯誤
N502500970000700ENG
故障碼設定條件
檢查條件
  • 點火開關為 開啟。
  • 12V 電池電壓高於 10.5 volts 且低於 16.5 volts。
  • 引擎未啟動
  • CAN 通訊（ECM - 48V 電池 (BMS)）正常。
判定基準
  • ECM 透過 CAN 在數秒內接收到異常的 48V 繼電器診斷訊號。
失效保護與備援功能
  • 48V MILD HYBRID 系統停止。
    1. 12V 側電力供應停止。
    2. 皮帶驅動啟動馬達發電機之引擎輔助與再生功能停止。
  • 充電警告燈亮起。
  • 怠速熄火功能禁止。
  • AS&G 關閉燈閃爍。
OBD-II 駕駛循環模式
請參閱 Diagnostic Function、OBD-II Drive Cycle – Pattern 5駕駛循環模式.
故障排除提示（此故障碼最可能的原因如下：）
  • 48V 電池（鋰離子電池管理器）故障 [內部電路]。
診斷
所需特殊工具：
  • MB993028：含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
1.使用 M.U.T.-III SE 讀取故障碼。
  • 使用 M.U.T.-III SE 檢查是否設定有 P0AA0-00 以外的故障碼。
Q：是否設定有 P0AA0-00 以外的故障碼？
是
執行已設定故障碼號之故障排除（請參閱故障碼檢查表).
否
更換 48V 電池（請參閱 Electrical & Power Control - Power Supply, Ground & Circuit Elements - 拆卸與安裝 - 48V 電池 -服務程序）。然後前往步驟 2。
2.測試 OBD-II 駕駛循環。
  1. 執行駕駛循環測試。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5駕駛循環模式.
  2. 檢查故障碼。
Q：是否設定故障碼 P0AA0-00？
是
重新執行故障排除。
否
檢查完成。
