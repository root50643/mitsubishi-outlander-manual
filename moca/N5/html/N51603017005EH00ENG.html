駕駛資訊與多媒體 - 雷達系統 - 故障碼/線路診斷 - 雷達 (雷達控制單元) - U2148-57 MAC COMM ERROR [ABS 作動器與電動單元 (控制單元)]
診斷程序
N51603017005EH00ENG
1.檢查故障碼優先順序
若故障碼 U2148-57 與故障碼 U1327-52 或故障碼 U1327-54 同時顯示，請先對故障碼 U1327-52 或 U1327-54 進行故障診斷。
是否偵測到故障碼 U1327-52 或 U1327-54？
是
請參閱故障碼說明(U1327-52) 或故障碼說明(U1327-54)。
否
進入步驟 2。
2.檢查 MAC 診斷
使用 M.U.T.-III SE
使用 M.U.T.-III SE 執行「雷達」的「MAC Diagnosis」模式。
是否同時偵測到故障碼 U2148-57 與故障碼 U2140-57、U2141-57、U214E-57、U214F-57、U2152-57（配備 MI PILOT Assist）、U2156-57、U2159-57、U215B-57、U2175-57（配備環景監控控制單元）及 U2176-57？
是（所有故障碼同時被偵測到）
更換雷達控制單元。請參閱拆卸及安裝.
否（並非所有故障碼同時被偵測到）
進入步驟 3。
3.檢查 網路-故障碼
使用 M.U.T.-III SE
執行「CAN Diag」。
檢查結果是否正常？
是
聯絡 Techline 並回報車輛狀況。
否
修復或更換根本原因。
已加入書籤書籤數量過多。
請刪除後重新加入書籤。
