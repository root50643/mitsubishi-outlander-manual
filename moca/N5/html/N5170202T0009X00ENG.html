功能說明
  • 緊急車道輔助（ELA）系統在車輛以約 60 km/h（37 MPH）（前方偵測）或 50 km/h（31 MPH）（後方偵測）以上速度行駛時作動。
  • 當車輛接近道路邊緣或實線白線時，ELA 系統會以資訊顯示器指示及轉向振動警告駕駛人。
  • 在下列情況下，系統會個別對左或右車輪施加煞車（短暫時間），協助駕駛人將車輛駛回行車道：
    • 當車輛接近道路邊緣時（例如草地、碎石或路緣）。
    • 當車輛接近實線時。
    • 當系統偵測到相鄰車道有對向來車時。
    • 當系統偵測到相鄰車道有超車車輛時。
  • ELA 系統僅在道路上能清楚看見車道標線或道路邊緣時作動。
  • ELA 系統可在車輛行駛於高速公路或雙向分隔道路時提供輔助。
  • ELA 系統會在每次重新啟動引擎時自動開啟。
  • 車道靈敏度（強/正常/弱）可於資訊顯示器上設定。

作動說明
  • 當系統開啟時，ADAS control unit 2 經由 CAN 通訊將儀表顯示訊號傳送至儀表。
  • 前攝影機單元監控行駛車道的車道標線。經由 CAN 通訊將偵測到的車道狀況訊號傳送至 ADAS control unit 2。
  • 前攝影機單元監控行駛車道的車道標線。經由 CAN 通訊將偵測到的車道狀況訊號傳送至 ADAS control unit 2。
  • 距離感知器監控相鄰車道上的對向來車。經由 CAN 通訊將距離感知器訊號傳送至 ADAS control unit 2。
  • 當判定車輛接近車道標線、道路邊緣或對向來車時，ADAS control unit 2 控制下列項目：
    • 由 ADAS control unit 2 作動轉向震動馬達。
    • 經由 CAN 通訊將儀表顯示訊號傳送至儀表。
    • 計算所需的橫擺力矩，並經由 CAN 通訊將目標橫擺力矩訊號傳送至 ABS 作動器與 electric unit (control unit)。
  • 側向雷達偵測相鄰車道上的車輛。經由 CAN 通訊將車輛偵測訊號傳送至 ADAS control unit 2。
  • 當判定車輛接近相鄰車道中的超車車輛時，ADAS control unit 2 控制下列項目：
    • 將 BSW indicator 訊號與 BSW indicator dimmer 訊號傳送至側向雷達。
    • 經由 CAN 通訊將儀表顯示訊號傳送至儀表。
    • 經由 CAN 通訊將蜂鳴器輸出訊號傳送至儀表。
    • 計算所需的橫擺力矩，並將目標橫擺力矩訊號傳送至 ABS 作動器與 electric unit (control unit)。
  • 當接收到目標橫擺力矩訊號時，ABS 作動器與 electric unit (control unit) 分別控制四個車輪的煞車壓力。
  • 當接收到來自 ADAS control unit 2 的訊號時，儀表開啟/關閉 LDP system 顯示。
  • 當接收到儀表顯示訊號時，儀表開啟/關閉 ELA system 顯示。
  • 當接收到蜂鳴器輸出訊號時，儀表作動蜂鳴器。
  • 當接收到 BSW indicator 訊號時，側向雷達開啟/關閉 BSW indicator。
作動條件
ADAS control unit 2 在符合下列條件時執行控制。
  • ELA system：開啟
  • 車輛車速：約 60 km/h(37 MPH)（前方偵測）或 50km/h (31MPH)（後方偵測）以上
注意：
  • 可在資訊顯示畫面中設定 ELA system 開啟/關閉。
  • 當拖曳已裝配 Genuine Mitsubishi Accessory 拖車 hitch 線束之拖車時，ADAS control unit 2 停用 ELA system（僅限相鄰車道中超車車輛之情況）。（多功能資訊顯示器中的開啟/關閉設定選單不會自動切換。）<From 23 Model year>
作動取消條件
當系統符合任一作動取消條件時，ADAS control unit 2 取消作動。
  • 當系統發生故障時。
  • 當踩下煞車踏板時。
  • 當轉動方向盤至車輛變換車道所需的程度時。
  • 當 ELA system 作動期間車輛加速時。
  • 當 Adaptive Cruise Control System (ACC) 接近警告發生時。
  • 當作動危險警告燈時。
  • 當以高車速行駛於彎道時。
  • 當 ASC system 關閉時。
  • 當方向燈作動時（方向燈作動後約 2 秒內 ELA system 會停用。若偵測到超車車輛則不適用此項）。
