引擎<4B4> - 直接噴射與多點燃油噴射（DI 與 MPI）- 故障排除 - 症狀程序
檢查程序 6：起動車輛時引擎熄火（死火），減速時引擎熄火 <台灣車輛>
N502501370000900ENG
註解：故障症狀
  • 失效/故障可能因火星塞失效、踩下加速踏板時空燃比不當等導致失火，因而在加速時引擎熄火。
  • 失效/故障可能因進氣量不足，因而在減速時引擎熄火。
故障排除提示 (本故障碼最可能設定原因：)
  • 點火系統故障
  • 進氣系統失效
  • EGR 系統作動故障
  • 節氣門周圍髒污
  • 壓縮壓力不當
  • 曲軸箱強制通風系統失效
  • ECM 故障
診斷
1.檢查 EGR 閥初始化時的作動聲音。
  • 請參閱 引擎 <4B4> – 引擎與排放控制 – 排放控制 – 廢氣再循環 (EGR) 系統 –EGR 閥（DC MOTOR）檢查.
是否可聽到作動聲音？
是
GO TO 2.
否
檢查 EGR 閥驅動線路，必要時修復。若線路正常，更換 EGR 閥。
2.使用 M.U.T.-III SE，讀取故障碼。
是否設定故障碼？
是
故障碼檢查表（請參閱故障碼檢查表).
否
GO TO 3.
3.使用 M.U.T.-III SE 檢查資料清單。
  • 資料清單 參考表 (請參閱資料清單 參考表).
    1. Item 12：APS (Main)
    2. Item 13：APS (Sub)
    3. Item 9：TPS (Main)
    4. Item 10：TPS (Sub)
檢查結果是否正常？
是
GO TO 4.
否
對顯示異常數值的感測器執行故障碼分類檢查程序。故障碼檢查表（請參閱故障碼檢查表).
4.檢查進氣軟管與進氣歧管的進氣狀況。
檢查結果是否正常？
是
前往第5步。
否
修理。
5.檢查節氣門體（節氣門部分）髒污。
檢查結果是否正常？
是
前往第6步。
否
清潔節氣門體（節氣門部分）（請參閱節氣門體（節氣門區域）清潔).
6.點火火花目視檢查。
  • 拆下火星塞並安裝至點火線圈。
  • 連接點火線圈接頭。
  • 斷開所有燃油噴射器接頭。
  • 引擎啟動時，檢查各火星塞是否產生火花。
檢查結果是否正常？
是
前往第7步。
否
檢查程序 - 點火線路系統（請參閱點火電路系統).
7.檢查壓縮壓力。
  • 檢查壓縮壓力（請參閱 引擎 <4B4> – 引擎機械 – 車上服務 –壓縮壓力檢查).
檢查結果是否正常？
是
前往 8。
否
修理。
8.檢查曲軸箱強制通風系統。
  • 請參閱 引擎 <4B4> – 引擎 and Emission Control – Emission Control – Crankcase Emission Control System –曲軸箱強制通風系統檢查.
檢查結果是否正常？
是
更換汽缸蓋罩總成（內含 PCV 閥），並檢查下列項目，修復或更換故障項目。然後前往 9。
  1. 真空洩漏。
然後確認故障症狀已排除。
否
修復。然後確認故障症狀已排除。
9.檢查故障症狀。
故障症狀是否仍然存在？
是
更換 ECM。
否
間歇性故障（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障).
