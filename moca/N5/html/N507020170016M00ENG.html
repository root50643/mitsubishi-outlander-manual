轉向系統 - STEERING CONTROL SYSTEM - SYMPTOM DIAGNOSIS - 方向盤轉向力不平衡（扭力變化）
診斷程序
N507020170016M00ENG
1.執行自我診斷
使用 M.U.T.-III SE
  1. 拉起駐車煞車開關。
    注意：
    檢查駐車煞車開關指示燈是否亮起。
  2. 點火開關關閉。
  3. 下車並關閉所有車門。
  4. 等待 65 秒。
    注意：
    • 檢查駐車煞車開關指示燈是否熄滅。
    • 若後煞車卡鉗溫度較高，請等待 1 小時，以免駐車煞車開關指示燈熄滅。
  5. 點火開關開啟。
  6. 對「EPS/DAST 3」執行自我診斷。
是否顯示故障系統？
是
檢查故障碼。請參閱故障碼索引.
否
前往步驟 2。
2.檢查動力轉向警告燈點亮
檢查點火開關開啟時動力轉向警告燈是否點亮。然後，引擎啟動後動力轉向警告燈應熄滅。
檢查結果是否正常？
是
转至 3.
否
執行動力轉向警告燈故障診斷。請參閱診斷程序.
3.檢查轉向管柱與轉向機
檢查轉向管柱總成與轉向機總成。
  • 轉向管柱總成。請參閱檢查.
  • 轉向機總成。請參閱檢查.
檢查結果是否正常？
是
转至 4.
否
修理或更換轉向管柱總成或轉向機總成。
4.檢查動力轉向控制模組訊號 (1)
使用 M.U.T.-III SE
  1. 啟動引擎。
    注意：
    切勿駕駛車輛。
  2. 將方向盤從最左轉到底轉至最右轉到底。
  3. 選擇「EPS/DAST 3」、「資料清單」及「Assistance Level」，依此順序。
「資料清單」中的項目是否顯示「100%」？
是
转至 7.
否
转至 5.
5.檢查動力轉向控制模組訊號 (2)
使用 M.U.T.-III SE
選擇「EPS/DAST 3」、「資料清單」及「電池電壓」，依此順序。
顯示值是否為「10.5 V」或以上？
是
转至 6.
否
執行動力轉向控制模組電源與搭鐵故障診斷。請參閱診斷程序.
6.檢查動力轉向控制模組訊號 (3)
使用 M.U.T.-III SE
  1. 選擇「EPS/DAST 3」、「資料清單」及「Assistance Level」，依此順序
  2. 停止 EPS 系統直至項目變為「100%」。
    注意：
    停止 EPS 系統期間，請勿轉動方向盤。
  3. 檢查症狀是否持續。
症狀是否持續？
是
转至 7.
否
由於保護功能，輔助扭力降低。此非故障。檢查結束
7.檢查動力轉向控制模組訊號 (4)
使用 M.U.T.-III SE
  1. 啟動引擎。
    注意：
    切勿駕駛車輛。
  2. 將方向盤從最左轉到底轉至最右轉到底。
  3. 選擇「EPS/DAST 3」、「資料清單」及「Steering torque」，依此順序。
  4. 檢查訊號是否在規定值範圍內。請參閱參考值.
檢查結果是否正常？
是
转至 8.
否
更換動力轉向控制模組（轉向機構總成）。請參閱拆卸與安裝.
8.檢查轉向力
檢查方向盤轉向力。請參閱檢查.
檢查結果是否正常？
是
檢查結束
否
可能存在機械故障。檢查轉向系統。請參閱檢查.
