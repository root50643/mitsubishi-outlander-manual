轉向 - 轉向控制系統 - 故障碼/電路診斷 - C163E-86 底盤控制系統
診斷程序
N507020170016100ENG
1.執行自我診斷
使用 M.U.T.-III SE
  1. 點火開關由關閉轉至開啟。
  2. 執行「CHASSIS CONTROL」的自我診斷。
是否偵測到任何故障碼？
是
檢查故障碼。請參閱故障碼索引.
否
前往步驟 2.
2.檢查接頭與端子
  1. 點火開關關閉。
  2. 斷開/拔除 chassis control module unit 線束接頭。
  3. 斷開/拔除 power steering control module 線束接頭。
  4. 檢查接頭是否有脫落或鬆動。
  5. 檢查端子是否有損壞，或與線束接頭連接鬆動。
檢查結果是否正常？
是
GO TO 3.
否
修理或更換線束、接頭或端子，並確實鎖緊接頭。
3.執行自我診斷
使用 M.U.T.-III SE
  1. 連接 chassis control module 線束接頭。
  2. 連接 power steering control module 線束接頭。
  3. 點火開關由關閉轉至開啟。
  4. 清除「EPS/DAST 3」的自我診斷結果。
  5. 拉動駐車煞車開關。
    備註：
    確認駐車煞車開關指示燈亮起。
  6. 點火開關關閉。
  7. 下車並關閉所有車門。
  8. 等待 65 秒。
    備註：
    • 確認駐車煞車開關指示燈熄滅。
    • 若後輪煞車卡鉗已受熱，請等待 1 小時，以免駐車煞車開關指示燈熄滅。
  9. 點火開關 開啟。
  10. 執行「EPS/DAST 3」的自我診斷。
是否偵測到故障碼「C163E–86」？
是
更換 power steering control module（轉向齒條總成）。請參閱拆卸與安裝.
否
檢查結束
