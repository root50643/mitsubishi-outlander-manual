2.檢查電動變檔控制模組的故障碼優先順序
使用 M.U.T.-III SE 選擇 "SHIFT" 的 "Self Diagnostic Result" 模式。
是否偵測到故障碼？
是
執行與所偵測故障碼相關的故障診斷。請參閱故障碼索引<F1CJD, W1CJD> or故障碼索引<F1CJE, W1CJE>.
NO
GO TO 3.
3.檢查免鑰匙操作鑰匙單元的故障碼優先順序
  1. 使用 M.U.T.-III SE 選擇 "HANDS FREE MODULE" 的 "Self Diagnostic Result" 模式。
  2. 若顯示故障碼 B2042–4A 且偵測到兩個或以上 故障碼，請參閱故障碼檢查優先順序圖，並決定故障診斷方式。
是否偵測到適用的故障碼？
是
執行與所偵測故障碼相關的故障診斷。請參閱故障碼索引.
NO
GO TO 4.
4.執行初始化
  1. 使用 M.U.T.-III SE 執行免鑰匙操作鑰匙單元初始化及所有免鑰匙操作鑰匙的登錄。
    有關初始化及登錄程序，請參閱 M.U.T.-III SE immobilizer mode，並依畫面指示操作。
  2. 啟動引擎。
