BRAKES - BRAKE CONTROL SYSTEM - WITH VDC - 故障碼/電路診斷 - C1087-86 IPDM E/R SYSTEM
診斷程序
N50603026001LW00ENG
1.檢查 IPDM E/R 系統
使用 M.U.T.-III SE
對「IPDM E/R」執行自我診斷。
是否偵測到故障碼？
是
檢查故障碼。請參閱故障碼索引.
否
前往 2.
2.檢查 ABS 作動器與電動單元（控制單元）電源及搭鐵線路
檢查 ABS 作動器與電動單元（控制單元）電源及搭鐵線路。請參閱診斷程序.
檢查結果是否正常？
是
前往 3.
否
修理/更換線束、接頭、端子、保險絲或大電流保險絲。
3.檢查接頭及端子
  1. 斷開/拔除 12V 電瓶負極端子。
  2. 斷開/拔除 IPDM E/R 線束接頭。
  3. 斷開/拔除 ABS 作動器與電動單元（控制單元）線束接頭。
  4. 檢查接頭是否鬆脫或鬆動。
  5. 檢查端子是否損壞，或與線束接頭連接鬆動。
檢查結果是否正常？
是
前往 4.
否
修復/更換線束、接頭或端子，並確實鎖定接頭。前往 4.
4.執行自我診斷
使用 M.U.T.-III SE
  1. 連接 IPDM E/R 線束接頭。
  2. 連接 ABS 作動器與電動單元（控制單元）線束接頭。
  3. 連接 12V 電瓶負極端子。
  4. 清除「ABS」的自我診斷結果。
  5. 點火開關關閉（Auto ACC 功能關閉）。
  6. 啟動引擎。
    注意：
    啟動引擎後至少等待 10 秒。
  7. 對「ABS」執行自我診斷。
是否偵測到故障碼？
是
檢查故障碼。請參閱故障碼索引.
否
檢查結束
