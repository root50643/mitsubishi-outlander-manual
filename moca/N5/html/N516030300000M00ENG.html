詳細流程
1.問診與症狀確認
執行下列項目以檢查故障症狀。
  • 訪談客戶以取得故障資訊（故障發生時的條件與環境）。
  • 檢查雷達感測器上是否未附著泥土或其他異物。
  • 檢查雷達感測器是否無變形、刮痕或其他損壞。
  • 檢查雷達感測器內是否未積水。
  • 檢查症狀。
出現的症狀是否為故障？

否
檢查結束
2.使用 M.U.T.-III SE 診斷
  1. 連接 M.U.T.-III SE 並執行「雷達」的自我診斷。請參閱 M.U.T.-III SE 功能CONSULT 功能.
  2. 偵測到故障碼時，請依下列指示操作：
    • 記錄故障碼與定格資料。
是否顯示故障碼？
是
前往 3.
否
GO TO 4.
3.故障碼故障診斷
  1. 檢查自我診斷結果中指示的故障碼。
  2. 參閱故障碼索引執行相關診斷。請參閱故障碼索引.
前往 5.
4.症狀故障診斷
參閱依症狀診斷圖執行相關診斷。請參閱症狀表.
前往 5.
5.故障零件維修
  1. 維修或更換已判定的故障零件。
  2. 使用 M.U.T.-III SE 執行「雷達」的自我診斷。
  3. 確認症狀未再發生。
