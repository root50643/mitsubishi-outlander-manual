引擎<4B4> - 直接燃油噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. U214F-57：與 BCM 之 MAC 通訊失效／故障
N5025012L0000700ENG
故障碼設定條件
檢查條件
  • 點火開關位於「開啟」位置。
判定標準
  • 與 BCM 之 MAC 通訊失效／故障持續 2 秒。
註解
目前故障
  • 此失效／故障可能由 ECM 與 BCM 間 CAN 匯流排線路上之線束與接頭故障、BCM 內部故障或 ECM 內部故障所造成。
過去故障
  • 進行故障排除，著重檢查 ECM 與 BCM 間 CAN 匯流排線路上之線束與接頭故障。
注意：
若為過去發生之故障，即使 CAN 匯流排存在故障，以 M.U.T.-III SE 執行之 CAN 匯流排線路診斷亦可能無法偵測到。因此，請依間歇性故障對應方式檢查 CAN 匯流排線路（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障）。可透過各執行 CAN 通訊之 ECU 所設定之診斷碼，縮小可能故障區域之範圍（請參閱 Electrical and Power Control - LAN System - CAN Fundamental - Basic Inspection - Diagnosis and Repair Workflow -關於 M.U.T.-III SE CAN 匯流排診斷的說明).
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
故障排除提示 (本故障碼最可能設定原因：)
  • BCM 故障
  • ECM 故障
診斷
所需特殊工具：
  • MB993028: VCI-3 套件（含無線轉接器）
    1. -: VCI-3 裝置
    2. MB993029: DLC 線束
    3. MB993030: USB 線束
    4. MB993031: 無線 USB 轉接器 (Qty:2)
  • MB993040: VCI-3 套件（不含無線轉接器）
    1. -: VCI-3 裝置
    2. MB993029: DLC 線束
    3. MB993030: USB 線束
1.使用 M.U.T.-III SE，讀取其他故障碼。
檢查故障碼 No. U1327-52 是否與故障碼 No. U214F-57 同時設定。
問：故障碼 U1327-52 是否已設定？
是
執行故障碼 No. U1327-52 之診斷（請參閱故障碼檢查表故障碼檢查表).
否
GO TO 2.
2.使用 M.U.T.-III SE，讀取故障碼。
問：MAC 通訊診斷碼 U2152-57、U2176-57 與故障碼 U214F-57 是否同時設定？
是（所有診斷碼同時被偵測到）
更換ECM（請參閱引擎-ECU 拆卸與安裝）。然後GO TO 4.
否（所有診斷碼並非同時被偵測到）
GO TO 3.
3.使用 M.U.T.-III SE，執行 CAN 匯流排診斷
  • 使用 M.U.T.-III SE，執行 CAN 匯流排線路診斷。
Q：檢查結果是否正常？
是
聯絡 Tecline 並回報車輛狀況。
否
修復 CAN 匯流排線路（請參閱 Electrical and Power Control - LAN System - CAN Fundamental - Basic Inspection - Diagnosis and Repair Workflow -關於 M.U.T.-III SE CAN 匯流排診斷的說明）。修復 CAN 匯流排線路後。接著GO TO 4.
4.測試 OBD-II 行駛循環。
  1. 依行駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  2. 檢查故障碼。
問：故障碼 U214F-57 是否已設定？
是
重新執行故障排除。
否
檢查完成。
