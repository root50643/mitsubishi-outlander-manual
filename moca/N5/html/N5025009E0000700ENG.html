引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0ADA-00：48V 繼電器錯誤
N5025009E0000700ENG
故障碼設定條件
檢查條件
  • 點火開關為開啟。
  • 12V 電池電壓大於 10.5 V 且小於 16.5 V。
  • 引擎未在起動中
  • CAN 通訊（ECM - 48V 電池 (BMS)）正常。
判定基準
  • ECM 透過 CAN 在數秒內接收到異常的 48V 繼電器診斷訊號。
失效保護與備援功能
  • 48V MILD HYBRID system 已停止。
    1. 已停止對 12V 側供電。
    2. 皮帶驅動起動馬達發電機的引擎輔助與再生已停止。
  • 充電警告燈亮起。
  • Auto Stop 已禁止。
  • AS&G 關閉燈閃爍。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
故障排除提示 (此故障碼最可能的設定原因為：)
  • 48V 電池（鋰離子電池管理器）[內部電路]故障。
診斷
所需特殊工具：
  • MB993028: VCI-3 kit with wireless adapters
    1. -: VCI-3 device
    2. MB993029: DLC cable
    3. MB993030: USB cable
    4. MB993031: Wireless USB adapter (Qty:2)
  • MB993040: VCI-3 kit without wireless adapters
    1. -: VCI-3 device
    2. MB993029: DLC cable
    3. MB993030: USB cable
