車門開關

ABS 作動器與電氣單元 (控制單元) 透過 CAN 通訊將車輛車速訊號傳送至 BCM。
TCM
TCM 自變速箱範圍開關接收 P/N 位置訊號，然後透過 CAN 通訊將排檔位置訊號傳送至 BCM。
ECM
  • ECM 控制引擎。
  • 當點火開關轉至開啟位置時，免鑰匙操作單元開始與 ECM 通訊，並執行免鑰匙操作單元與 ECM 之間的 ID 驗證。
  • 若驗證結果為 OK，引擎可啟動。若驗證結果為 NG，引擎無法啟動。
IPDM E/R
起動馬達切斷繼電器由 BCM 控制，起動馬達繼電器由 IPDM E/R 在與 BCM 通訊時控制。
BCM
當 BCM 從 ECM 接收起動馬達切斷繼電器需求訊號時，起動馬達切斷繼電器被開啟。
按鈕式點火開關
按鈕開關
  • 按鈕式點火開關內部有按鈕開關，可偵測按鈕式點火開關是否被按下，然後將按鈕開關訊號傳送至免鑰匙操作單元。
  • 免鑰匙操作單元隨按鈕式點火開關作動變更點火開關位置。
  • 免鑰匙操作單元在按鈕式點火開關未操作時維持點火開關位置狀態。

免鑰匙操作鑰匙
免鑰匙操作鑰匙系統是一種可藉由攜帶免鑰匙操作鑰匙來鎖定及解鎖車門鎖（車門鎖定/解鎖功能）的系統，其依據免鑰匙操作鑰匙與車輛（免鑰匙操作單元）之間雙向通訊進行電子 ID 驗證的結果運作。
免鑰匙操作單元
  • 免鑰匙操作單元控制車輛防盜系統。
  • 當免鑰匙操作鑰匙被攜帶進入車內鑰匙天線偵測區域且按下按鈕式點火開關時，免鑰匙操作單元執行免鑰匙操作單元與免鑰匙操作鑰匙之間的 ID 驗證。若 ID 驗證結果為 OK，則可進行點火開關作動。
  • 接著，當點火開關轉至開啟位置時，免鑰匙操作單元執行免鑰匙操作單元與 ECM 之間的 ID 驗證。若 ID 驗證結果為 OK，ECM 可啟動引擎。

系統說明
  • 車輛防盜系統可防止 ID 未登錄至車輛（免鑰匙操作單元）的免鑰匙操作鑰匙啟動引擎。其對於涉及機械鑰匙複製的汽車竊盜具有較高的防護能力。
  • 整合於免鑰匙操作鑰匙中的點火鑰匙無法啟動引擎。當免鑰匙操作鑰匙電池電量耗盡時，在踩下煞車踏板的同時將免鑰匙操作鑰匙背面接觸按鈕式點火開關，免鑰匙操作單元會透過 NATS 天線放大器，在與免鑰匙操作鑰匙一體的轉發器與免鑰匙操作單元之間執行 NATS ID 驗證。若驗證結果為 OK，則可透過按鈕式點火開關作動執行引擎啟動作動。
  • 依車主需求，最多可登錄 4 支免鑰匙操作鑰匙（包含標準點火鑰匙）。
  • 更換 ECM、免鑰匙操作單元或免鑰匙操作鑰匙時，必須使用 M.U.T.-III SE 執行規定的程序（初始化與登錄）。
鑰匙登錄的預防措施/注意事項
ID 登錄是一種先清除目前 NATS ID，再登錄新 ID 的程序。因此，在開始登錄作動之前，請向客戶收取所有已登錄的免鑰匙操作鑰匙。
免鑰匙操作鑰匙接觸按鈕式點火開關時的引擎啟動作動
  1. 當排檔桿在 P 位置且踩下煞車踏板時，免鑰匙操作單元啟動位於按鈕式點火開關後方的 NATS 天線放大器。
  2. 當免鑰匙操作鑰匙（內建轉發器）背面接觸按鈕式點火開關時，免鑰匙操作單元透過 NATS 天線放大器，開始免鑰匙操作單元與免鑰匙操作鑰匙（內建轉發器）之間的 NATS ID 驗證。
  3. 當點火開關轉至開啟位置時，免鑰匙操作單元與 ECM 執行 ID 驗證。當結果為 OK 時，允許引擎啟動。
  4. BCM 偵測排檔桿位置與煞車踏板作動狀態。
  5. 當 ECM 偵測到引擎啟動條件*已滿足時，其向 BCM 傳送起動馬達切斷繼電器需求訊號。
  6. 當 BCM 從 ECM 接收起動馬達切斷繼電器需求訊號時，起動馬達切斷繼電器被開啟。
  7. 當起動馬達切斷繼電器被開啟時，IPDM E/R 開啟起動馬達繼電器並驅動起動馬達。
  8. 當 BCM 從 ECM 接收引擎狀態訊號時，其關閉起動馬達繼電器與起動馬達切斷繼電器並停止起動運轉。
*: 有關引擎啟動條件，請參閱下方的「按鈕式點火開關作動時點火開關位置變更表」。
