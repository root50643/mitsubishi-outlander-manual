電氣 & 電源控制 - 電源控制系統 - IPDM E/R - 系統說明 - 診斷系統 (IPDM E/R)
M.U.T.-III SE Function (IPDM E/R)
N514040530000600ENG
適用項目
M.U.T.-III SE 透過與 IPDM E/R 的 CAN 通訊執行下列功能。
診斷模式
說明
自我診斷結果
顯示 IPDM E/R 記憶的故障碼。
資料清單
顯示 IPDM E/R 即時輸入/輸出資料。
工作支援
  • IPDM E/R 可對電子元件提供驅動訊號以檢查其作動。
  • 可確認 IPDM E/R 零件編號。
配置
讀取並儲存車輛規格。
自我診斷結果
請參閱故障碼索引.
定格資料 (FFD)
IPDM E/R 在偵測到特定故障碼時記錄車輛狀態，並在開啟 M.U.T.-III SE 時顯示。
