引擎<4B4> - 直接噴射與多點燃油噴射（DI 與 MPI）- 故障排除 - 故障碼程序
Code No. P0133-00：Linear A/F感測器電路緩慢反應
N5025005P0000600ENG
技術說明
  • ECM依據來自Linear A/F感測器的訊號進行空燃比回授控制。
  • 若Linear A/F感測器劣化，將由氧氣感測器（後）進行修正。
監控方法說明
若Linear A/F感測器對空燃比變化的反應速度過慢，將設定故障碼為Linear A/F感測器劣化。
監測執行
連續。
監測執行條件（其他監測項目與感知器）
其他監測項目（下列監測項目未在記憶體中設定暫時性故障碼）
  • Linear A/F感測器監視
  • Linear A/F感測器加熱器監視
  • 失火監視
  • 燃油系統監視
感知器（下列感知器判定為正常）
  • 空氣流量感測器
  • 引擎冷卻液溫度感測器
  • 第1進氣溫度感測器
  • 大氣壓力感測器
  • 節氣門位置感測器
  • 歧管絕對壓力感測器
故障碼設定條件 <Slow Response rate>
檢查條件
  • 引擎轉速高於1,200 r/min且低於3,000 r/min。
  • 空氣流量感測器輸出高於5 g/sec且低於44 g/sec。
  • 引擎冷卻液溫度高於60°C。
  • 處於閉迴路空燃比控制下。
  • 短期燃油修正值高於-25%且低於+25%。
  • 符合上述條件後已經過3秒以上。
判定基準
  • 監視50秒期間，長期燃油修正值與加熱型氧氣感測器（前）訊號的比率高於規定值。
故障碼設定條件 <Delayed Response rate>
檢查條件
  • 引擎冷卻液溫度高於60°C。
  • DFCO (Deceleration fuel cut-關閉)
判定基準
  • DFCO開始時，由濃混合氣至稀混合氣的反應延遲。
  • DFCO結束時，由稀混合氣至濃混合氣的反應延遲。
失效保護與備援功能
無。
OBD-II 駕駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 21駕駛循環模式.
故障排除提示（此故障碼最可能的原因如下：）
  • Linear A/F感測器失效
  • Linear A/F感測器電路開路或線束損壞或接頭接觸不良
診斷
所需特殊工具：
  • MB993028：含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
1.檢查Linear A/F感測器接頭與ECM接頭之間L+FL線路之開路及損壞。
  • 斷開ECM接頭及Linear A/F感測器，並於線束側進行測量。
  • ECM L+FL線路端子與車身搭鐵間之電阻。
    OK：導通（2 Ω或以下）
  • 檢查線束及接頭是否損壞。
問：檢查結果是否正常？
是
前往步驟 2。
否
修復接頭或線路。然後前往步驟 4。
2.檢查Linear A/F感測器接頭與ECM接頭之間L-FL線路之開路及損壞。
  • 斷開ECM接頭及Linear A/F感測器，並於線束側進行測量。
  • ECM L-FL線路端子與車身搭鐵間之電阻。
    OK：導通（2 Ω或以下）
  • 檢查線束及接頭是否損壞。
問：檢查結果是否正常？
是
前往步驟 3。
否
修復接頭或線路。然後前往步驟 4。
3.使用 M.U.T.-III SE 讀取故障碼。
  • 再次確認診斷碼。
Q：是否設定故障碼P0133-00？
是
更換Linear A/F感測器（請參閱引擎<4B4> - Intake and Exhaust - Catalytic Converter -CATALYTIC CONVERTER 拆卸與安裝<2WD>,CATALYTIC CONVERTER 拆卸與安裝<4WD>）。然後前往步驟 4。
否
間歇性故障（請參閱General Information - General Information - Basic Inspection - Service information for Electrical Incident -間歇性故障).
4.測試 OBD-II 駕駛循環。
依行駛循環模式進行試車。請參閱Diagnostic Function, OBD-II Drive Cycle – Pattern 21駕駛循環模式.
檢查故障碼。
Q：是否設定故障碼P0133-00？
是
重新執行故障排除。
否
檢查完成。
