煞車 - 煞車控制系統 - 含 VDC - 基本檢查 - 減速 G 感測器校正
作業程序
N5060305A0003600ENG
警告：
減速 G 感測器校正一律使用 M.U.T.-III SE。（無法以 M.U.T.-III SE 以外的方式進行調整。）
1.檢查車輛狀態
  1. 將方向盤轉至直行位置。在平坦地面停車。
  2. 停止引擎。
  3. 點火開關關閉（Auto ACC 功能關閉）。
車輛是否已停在直行位置的平坦地面？
是
前往步驟 2.
否
將方向盤轉至直行位置。在平坦地面停車。
2.執行減速 G 感測器校正
警告：
  • 校正期間禁止乘客或貨物留在車內。
  • 校正期間開關車門時，不可對車身施加振動。
使用 M.U.T.-III SE
  1. 點火開關開啟。
    警告：
    請勿啟動引擎。
  2. 依序選取「ABS」、「感測器校正（在「特殊功能」內）」及「DECEL G 感測器校正」。
  3. 選取「OK」。
  4. 顯示「Completed」後，等待約 10 秒，然後按下「OK」。
  5. 點火開關 關閉（Auto ACC 功能 關閉），然後再 開啟。
    警告：
    務必執行上述作動。
GO TO 3.
3.檢查資料監視器
使用 M.U.T.-III SE
  1. 行駛車輛。將方向盤轉至直行位置。在平坦地面停車。
  2. 依序選取「ABS」、「資料清單」及「Decel G 感測器」。確認訊號在規定數值範圍內。請參閱參考值.
檢查結果是否正常？
是
GO TO 4.
否
GO TO 1.
4.清除自我診斷記憶
使用 M.U.T.-III SE
清除「ABS」的自我診斷結果。
記憶是否已清除？
是
作業結束。
否
檢查自我診斷所指示的項目。
已加入書籤書籤數量過多。
請刪除後重新加入書籤。
