詳細流程
1.故障訪談
開始檢查前，確認客戶反映的問題也非常重要。請仔細訪談客戶所反映的問題，並充分了解症狀。
注意：
客戶並非專業人員。切勿假設「也許客戶指的是···」或「也許客戶提到了這個症狀」。
GO TO 2.
2.使用 M.U.T.-III SE 進行自我診斷
  1. 使用 M.U.T.-III SE 執行「Read All DTCs」。
  2. 檢查是否偵測到故障碼，並開啟下列自我診斷結果。
    • "ACC/ADAS 2"
是否偵測到任何故障碼？
是
前往 5。
否
前往 3。
3.作動測試
執行 RAB 系統作動測試以檢查作動狀態。請參閱作業程序.
檢查是否發生其他故障。
前往 4。
4.症狀診斷
依症狀診斷表執行適用的診斷。請參閱症狀表.
前往 6。
5.依故障碼進行故障診斷
  1. 檢查自我診斷結果中的故障碼。
  2. 針對下列偵測到的故障碼執行故障診斷。
    • "ACC/ADAS 2"：請參閱 故障碼 Index故障碼索引.
注意：
若偵測到「故障碼: U1000–01」，請先診斷 CAN 通訊系統。
前往 6。
6.故障零件維修
維修或更換已判定的故障零件。
前往 7。
7.維修確認（使用 M.U.T.-III SE 自我診斷）
  1. 清除自我診斷結果。
  2. 在維修或更換特定項目後，再次執行「Read All DTCs」。
  3. 檢查下列自我診斷結果中是否偵測到任何故障碼。
    • "ACC/ADAS 2"
是否偵測到任何故障碼？
是
前往 5。
否
前往 8。
8.維修確認（作動測試）
執行 RAB 系統作動測試。確認故障症狀已排除，或未發生其他症狀。
是否有故障症狀？
是
前往 4。
否
