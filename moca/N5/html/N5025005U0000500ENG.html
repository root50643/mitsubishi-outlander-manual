引擎<4B4> - 直接噴射與多點燃油噴射（DI 與 MPI）- 故障排除 - 故障碼程序
Code No. P0140-00: 後氧感測器線路無訊號偵測
N5025005U0000500ENG
電路作動
  • 檢查 code No. P0137-00: 後氧感測器線路低電壓 (請參閱Code No. P0137-00: 加熱式後氧感測器線路低電壓).
技術說明
  • 後氧感測器會將排氣中氧濃度轉換為電壓，並將訊號輸入至 ECM。
  • 當空燃比比理論空燃比濃時，後氧感測器輸出約 1 V 的電壓。當空燃比比理論空燃比稀時，則輸出約 0 V 的電壓。
  • ECM 依據此訊號控制燃油噴射量，使空燃比接近理論空燃比。
監視方法說明
在包含重複斷油在內的指定走停操作期間，後氧感測器輸出電壓未發生變化。
監視執行
連續。

其他監視（下列監視項目未在記憶體中設定暫時性故障碼）
  • 線性空燃比感測器監視
  • 後氧感測器監視
  • 線性空燃比感測器加熱器監視
  • 後氧感測器加熱器監視
感測器（下列感測器判定為正常）

  • 進氣歧管絕對壓力感測器
  • 增壓壓力感測器
故障碼設定條件
檢查條件
  • 引擎冷卻液溫度高於 76°C。
  • 線性空燃比感測器為作用中。
  • 重複 1 次以上：行駛*1, 停止*2.
    • 行駛*1:
      • 引擎轉速高於 1,500 r/min。
      • 容積效率高於 40%。
      • 車速高於 30 km/h。
      • 在上述條件下合計超過 60 秒，且斷油關閉超過 3 秒。
    • 停止*2:
      • 車速低於 1.5 km/h。
判定準則
  • 後氧感測器輸出電壓變化量小於 0.313 volts。
或
  • 後氧感測器最大輸出電壓小於 0.508 volts。
注意：
斷油關閉超過 64 秒後，監視停止。
