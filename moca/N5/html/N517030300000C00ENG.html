詳細流程
1.取得症狀資訊
向客戶取得詳細症狀資訊。
進行步驟 2.
2.檢查 故障碼
使用 M.U.T.-III SE
  1. 檢查「Read All DTCs」的故障碼。
  2. 若顯示故障碼，執行下列程序。
    • 記錄故障碼及定格資料。（或寫下來。）
  3. 檢查相關服務通報以取得資訊。
是否偵測到任何 故障碼？
是
對顯示的故障碼執行故障診斷。
否
進行步驟 3.
3.確認症狀
嘗試確認客戶所描述的症狀。
同時了解與症狀相關的正常作動。請參閱 Drive Mode 排檔桿Drive Mode 排檔桿.
進行步驟 4.
4.檢查 DRIVE MODE SELECT SWITCH CIRCUIT
檢查行駛模式選擇開關電路。請參閱診斷程序.
檢查結果是否正常？
是
進行步驟 5.
否
修理/更換線束或接頭。
5.檢查 DRIVE MODE SELECT SWITCH 及儀表指示
  1. 點火開關關閉，並至少等待 10 秒。
  2. 點火開關開啟。
  3. 檢查儀表資訊顯示螢幕是否顯示 STANDARD。（2WD 車型）
  4. 檢查儀表資訊顯示螢幕是否顯示 AUTO。（AWD 車型）
  5. 檢查切換行駛模式選擇開關至上或下時，資訊顯示畫面是否改變。（2WD 車型）
  6. 檢查切換行駛模式選擇開關至左或右時，資訊顯示畫面是否改變。（AWD 車型）
檢查結果是否正常？
是
檢查結束
否
執行間歇性故障診斷。請參閱 間歇性故障間歇性故障.
