STEERING - STEERING CONTROL SYSTEM - 症狀診斷 - 方向盤轉向力道過重或過輕
診斷程序
N507020170016K00ENG
1.執行自我診斷
使用 M.U.T.-III SE
  1. 拉動駐車煞車開關。
    注意：
    確認駐車煞車開關指示燈已點亮。
  2. 點火開關關閉。
  3. 下車並關閉所有車門。
  4. 等待 65 秒。
    注意：
    • 確認駐車煞車開關指示燈已熄滅。
    • 若後煞車卡鉗溫度偏高，請等待一小時，以免駐車煞車開關指示燈熄滅。
  5. 點火開關開啟。
  6. 對「EPS/DAST 3」執行自我診斷。
是否顯示故障系統？
是
檢查故障碼。請參閱故障碼索引.
否
進入步驟 2。
2.檢查動力輔助轉向警告燈點亮狀況
確認點火開關開啟時動力輔助轉向警告燈點亮。接著，引擎啟動後動力輔助轉向警告燈熄滅。
檢查結果是否正常？
是
進行步驟 3.
否
執行動力輔助轉向警告燈故障診斷。請參閱元件功能檢查.
3.檢查動力輔助轉向控制模組訊號 (1)
使用 M.U.T.-III SE
  1. 啟動引擎。
    注意：
    請勿駕駛車輛。
  2. 將方向盤由左側全轉極限轉至右側全轉極限。
  3. 依序選取「EPS/DAST 3」、「資料清單」及「Assistance Level」。
「資料清單」中的項目是否顯示「100%」？
是
進行步驟 6.
否
進行步驟 4.
4.檢查動力輔助轉向控制模組訊號 (2)
使用 M.U.T.-III SE
依序選取「EPS/DAST 3」、「資料清單」及「電瓶電壓」。
顯示值是否為「10.5 V」或以上？
是
進行步驟 5.
否
執行動力輔助轉向控制模組電源與搭鐵故障診斷。請參閱診斷程序.
5.檢查動力輔助轉向控制模組訊號 (3)
使用 M.U.T.-III SE
  1. 依序選取「EPS/DAST 3」、「資料清單」及「Assistance Level」
  2. 停止 EPS 系統直到項目變為「100%」。
    注意：
    停止 EPS 系統時，請勿轉動方向盤。
  3. 確認症狀是否持續。
症狀是否持續？
是
進行步驟 6.
否
輔助扭力因保護功能而降低。此非故障。檢查結束
6.檢查動力輔助轉向控制模組訊號 (4)
使用 M.U.T.-III SE
  1. 啟動引擎。
    注意：
    請勿駕駛車輛。
  2. 將方向盤由左側全轉極限轉至右側全轉極限。
  3. 依序選取「EPS/DAST 3」、「資料清單」及「Input torque (from torque 感知器)」。
  4. 確認訊號在規定值範圍內。請參閱參考值.
檢查結果是否正常？
是
GO TO 7.
否
更換動力輔助轉向控制模組（轉向齒條總成）。請參閱拆卸與安裝.
7.檢查轉向力道
檢查方向盤轉向力道。請參閱檢查.
檢查結果是否正常？
是
檢查結束
否
可能有機械故障。檢查轉向系統。請參閱檢查.
