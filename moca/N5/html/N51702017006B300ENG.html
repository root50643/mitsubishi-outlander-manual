定速控制與駕駛輔助 - 駕駛輔助系統 - 底盤控制 - 故障碼/電路診斷 - U2448-87 CAN comm err (ABS)
診斷程序
N51702017006B300ENG
1.執行自我診斷
使用 M.U.T.-III SE
  1. 清除「底盤控制」的自我診斷結果。
  2. 點火開關關閉並等待 10 秒或以上。
  3. 點火開關開啟。
  4. 對「底盤控制」執行自我診斷。
是否偵測到故障碼「U2448-87」？
是
進行步驟 2.
否
檢查結束
2.檢查 ABS 作動器與電氣單元 (控制單元) 系統 (1)
使用 M.U.T.-III SE
  1. 清除「ABS」自我診斷結果。
  2. 點火開關關閉並等待 10 秒或以上。
  3. 點火開關開啟。
  4. 執行「ABS」自我診斷。
是否偵測到故障碼？
是
檢查故障碼。請參閱故障碼索引.
否
進行步驟 3.
3.檢查 ABS 作動器與電氣單元 (控制單元) 系統 (2)
  1. 點火開關關閉。
  2. 斷開 ABS 作動器與電氣單元（控制單元）線束接頭。
  3. 檢查 ABS 作動器與電氣單元 (控制單元) 線束接頭端子 (CAN 通訊線路與底盤通訊線路) 是否損壞或連接鬆脫。
檢查結果是否正常？
是
進行步驟 4.
否
修理/更換線束、接頭或端子。進行步驟 4.
4.清除自我診斷結果
使用 M.U.T.-III SE
  1. 連接 ABS 作動器與電氣單元（控制單元）線束接頭。
  2. 清除「底盤控制」的自我診斷結果。
  3. 點火開關關閉並等待 10 秒或以上。
