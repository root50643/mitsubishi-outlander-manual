1.使用 M.U.T.-III SE 讀取故障碼。
  1. 將點火開關轉至「開啟」位置。
  2. 檢查是否設定與皮帶驅動啟動馬達發電機或 DC-DC 轉換器相關的故障碼。
  3. 將點火開關轉至「LOCK」（關閉）位置。

請參閱故障碼檢查表.
然後進入步驟 3。
否
進入步驟 2。
2.測試 OBD-II 行程循環。
  1. 將點火開關轉至「開啟」位置並清除故障碼。
  2. 依駕駛循環模式執行測試駕駛。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行程循環模式.
  3. 檢查故障碼。
