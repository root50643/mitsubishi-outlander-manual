1.檢查症狀
檢查當 ASC 功能、TCS 功能、ABS 功能、EBD 功能、煞車限滑差速器 (BLSD) 功能、煞車輔助功能、煞車力分配功能或斜坡起步輔助功能作動時，車輛是否抖動。
檢查結果是否正常？
是
正常
否
前往步驟 2.
2.執行自我診斷 (1)
使用 M.U.T.-III SE
執行「ABS」自我診斷。
是否偵測到故障碼？
是
檢查故障碼。請參閱故障碼索引.
否
前往步驟 3.
3.檢查 接頭
使用 M.U.T.-III SE
  1. 斷開/拔除 12V 電池負極端子。
  2. 斷開 ABS 作動器及電動單元（控制單元）線束接頭。
  3. 檢查接頭端子是否有變形、斷線及鬆動。
  4. 連接 ABS 作動器及電動單元（控制單元）線束接頭，並再次執行 "ABS" 自我診斷。
檢查結果是否正常？
是
前往步驟 4.
否
接頭端子連接不良。修理或更換接頭端子。
4.執行自我診斷 (2)
使用 M.U.T.-III SE
  1. 連接 12V 電池負極端子。
  2. 執行 "引擎" 及 "變速箱" 自我診斷。
是否偵測到故障碼？
是
檢查故障碼。
  • ECM：請參閱故障碼索引.
  • TCM：請參閱故障碼索引.
否
更換 ABS 作動器與電動單元（控制單元）。請參閱拆卸與安裝.
