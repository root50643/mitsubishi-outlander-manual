引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P1D0A-00：48V 電瓶收到碰撞訊號
N5025010X0000A00ENG
監視執行
連續。
監視執行條件（其它監視與感測器）
其它監視（下列監視項目的記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關置於開啟位置後 2 秒。
  • 點火開關置於開啟位置或引擎啟動後 2 秒。
  • 電瓶電壓為 10.0 - 16.5 volts。
  • CAN（引擎 Local）ECM 與 48V 電瓶（鋰離子電瓶管理器）之間的通訊正常。
判定標準
  • 48V 電瓶（鋰離子電瓶管理器）自 ECM 收到碰撞訊號。
失效保護與備援功能
  • 48V 輕度混合動力系統停止運作。
    1. 停止對 12V 側供電。
    2. 皮帶驅動啟動馬達發電機的引擎輔助與再生制動停止。
  • 充電警示燈亮起。
  • 禁止自動熄火。
  • AS&G 關閉燈閃爍。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
故障排除提示（設定此代碼最可能的原因為：）
  • 氣囊作動（發生碰撞）
  • CAN 匯流排線路故障
  • 48V 電瓶故障
  • ECM 故障
診斷
所需特殊工具：
  • MB993028: VCI-3 kit with wireless adapters
    1. -: VCI-3 device

    3. MB993030: USB cable
    4. MB993031: Wireless USB adapter (Qty:2)
  • MB993040: VCI-3 kit without wireless adapters
    1. -: VCI-3 device

    3. MB993030: USB cable
1.使用 M.U.T.-III SE 進行 CAN bus 診斷。
使用 M.U.T.-III SE 進行 CAN bus 線路診斷（請參閱 Electrical and Power Control - LAN System - CAN Fundamental - Basic Inspection - Diagnosis and Repair Workflow -M.U.T.-III SE CAN 匯流排診斷說明).
Q：檢查結果是否正常？
是
前往 2。
否
修復 CAN bus 線路（請參閱 Electrical and Power Control - LAN System - CAN Fundamental - Basic Inspection - Diagnosis and Repair Workflow -M.U.T.-III SE CAN 匯流排診斷說明）。然後GO TO 7.
2.使用 M.U.T.-III SE 讀取其他系統故障碼。
  • 確認氣囊診斷感測器單元中已設定故障碼。
Q：是否有設定故障碼？
是
對氣囊診斷感測器單元執行故障排除（請參閱 Restraints - 氣囊 Airbag Control System - ECU Diagnosis Information - Air Bag Diagnosis 感知器 Unit -故障碼索引).
否
前往步驟 3。
3.使用 M.U.T.-III SE 讀取故障碼。
斷開/拔除 12V 電瓶負極端子。
至少等待 3 分鐘。
重新連接 12V 電瓶負極端子。
檢查氣囊診斷感測器單元中是否已設定故障碼 P1D0A-00。
Q：是否已設定故障碼 P1DA-00？
是
GO TO 4.
否
間歇性故障 (請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障).
4.使用 M.U.T.-III SE 讀取故障碼。
使用 M.U.T.-III SE 檢查是否已設定 P1D0A-00 以外的故障碼。
Q：是否已設定 P1D0A-00 以外的故障碼？
是
對已設定的故障碼執行故障排除（請參閱故障碼檢查表).
否
GO TO 5.
5.故障碼再檢查
點火開關：關閉
點火開關：開啟
確認是否設定故障碼。
Q：是否已設定故障碼 P1D0A-00？
是
GO TO 6.
否
檢查完成。
6.故障碼再檢查
更換 48V 電瓶（請參閱 48V Mild Hybrid - 拆卸與安裝 - 48V 電瓶 -拆卸與安裝).
啟動引擎並以怠速運轉 5 分鐘以上。
確認是否設定故障碼。
Q：是否已設定故障碼 P1D0A-00？
是
重新執行故障排除。
否
檢查完成。
7.測試 OBD-II 行駛循環。
  1. 依驅動循環模式執行試車。請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
  2. 檢查故障碼。
Q：是否已設定故障碼 P1D0A-00？
是
重新執行故障排除。
否
檢查完成。
