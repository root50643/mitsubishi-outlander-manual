引擎<4B4> - 引擎潤滑 - 開啟-車輛保養
引擎機油更換
N502411080001000ENG
啟動引擎並讓其暖機，直到冷卻液溫度達到 80°C 至 90°C。
拆下引擎機油加注蓋。
警告：
注意引擎機油可能很燙。
拆下引擎室下護蓋前 B（請參閱車身外觀、車門、車頂及車輛安全 - 外觀 - 拆卸與安裝 - 下護蓋拆卸與安裝).
拆下引擎油底殼放油塞以排放引擎機油。
安裝新的引擎油底殼放油塞墊片， 然後將引擎油底殼放油塞鎖緊至 規定扭力。
鎖緊扭力：39 ± 5 N·m
加注規定量的引擎機油。
規定引擎機油：
  • 依據大氣溫度選用適當 SAE 黏度等級的引擎機油。
  • 建議使用符合 API 等級分類的引擎機油。
    • API 等級分類：「For service SN」或更高等級。
      若使用上述以外之機油，請使用下列其中一種類型。
    • ILSAC 認證機油
    • ACEA 等級分類：
      「For service A3/B3、A3/B4 或 A5/B5」*
      *: 僅允許同時符合 API 等級分類「SN 或更高」之機油。
  • SAE 0W-20、0W-30、5W-20、5W-30 及 5W-40 引擎機油僅在符合 ACEA A3/B3、A3/B4 或 A5/B5 以及 API「SN 或更高」規格時方可使用。
引擎機油量：
  • 含機油濾清器更換：約 4.3 L
  • 不含機油濾清器更換：約 4.1 L
注意：
  • 依據大氣溫度選用適當 SAE 黏度等級的引擎機油。
  • 建議使用三菱汽車原廠 0W-20 合成引擎機油，以獲得最佳燃油經濟性與低溫啟動性能。
    若無法取得三菱汽車原廠 0W-20 合成引擎機油，可使用標示 ILSAC 認證之 5W-20 等級機油。然而，下次換油時應改回使用三菱汽車原廠 0W-20 合成引擎機油，以維持最佳燃油經濟性與低溫啟動性能。
裝上引擎機油加注蓋。
讓引擎運轉數分鐘。
停止引擎，數分鐘後使用引擎機油油尺檢查引擎機油液位。
安裝引擎室下護蓋前 B（請參閱車身外觀、車門、車頂及車輛安全 - 外觀 - 拆卸與安裝 - 下護蓋拆卸與安裝).
