概要
方向燈及危險警告燈由組合開關讀取功能及 BCM 的閃光器控制功能控制。
方向燈作動
  • BCM 透過組合開關讀取功能偵測組合開關狀態。
  • 當點火開關開啟且方向燈開關位於右（左）位置時，BCM 向右（左）方向燈電路供應電壓。BCM 使方向燈閃爍。
  • 在循序方向燈規格中，LED 從車輛中央向外側依序點亮。
危險警告燈作動
當危險警告燈開關開啟時，BCM 向兩側方向燈電路供應電壓。BCM 使危險警告燈閃爍。
方向燈指示燈及方向燈音作動
  • 當方向燈及危險警告燈作動時，BCM 透過 CAN 通信將方向燈指示訊號傳送至儀表。
  • 儀表依據方向燈指示訊號，在使方向燈指示燈閃爍的同時向儀表喇叭輸出方向燈音。
  • 儀表喇叭依據來自儀表的訊號輸出方向燈音。
3 次閃光器功能
  • 透過短暫撥動方向燈撥桿，BCM 使方向燈在所選方向閃爍 3 次。
  • 在 3 次閃光器功能作動期間，若向反方向短暫撥動方向燈撥桿，則取消作動。
備註：
3 次閃光器功能的閃光器設定可使用 M.U.T.-III SE 變更。請參閱 M.U.T.-III SE Function (BCM - BCM)M.U.T.-III SE Function (BCM - BCM).
高速閃光器作動
  • BCM 從電流值偵測方向燈電路狀態。
  • 當方向燈作動時若偵測到燈泡或線束斷路，BCM 會提高方向燈閃爍速度。
    備註：
    作動危險警告燈時，閃爍速度為正常。
