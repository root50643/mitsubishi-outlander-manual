懸吊－車輪與輪胎－症狀診斷－ID 登錄無法完成
診斷程序
N505040180007X00ENG
1.檢查胎壓感測器安裝
目視檢查各車輪是否正確安裝胎壓感測器。
備註：
下列情況下，胎壓監控系統（TPMS）無法作動。
  • 未安裝胎壓感測器。
  • 安裝了其他車輛的胎壓感測器。
是否正確安裝三菱汽車原廠胎壓感測器？
是
前往步驟 2.
否
更換及/或安裝胎壓感測器。請參閱拆卸 & 安裝. GO TO 3.
2.檢查胎壓感測器啟動工具
檢查胎壓感測器啟動工具。
檢查結果是否正常？
是
GO TO 3.
否
更換胎壓感測器啟動工具的電池，或修理/更換胎壓感測器啟動工具。
3.胎壓感測器 ID 登錄
執行胎壓感測器 ID 登錄。請參閱說明.
注意：
執行 ID 登錄時，請遵守下列要點：
  • 切勿在電波受干擾的場所登錄 ID（例如：電台發射塔）。
  • 切勿在鄰近含 TPMS 的車輛之處登錄 ID。
胎壓感測器 ID 登錄是否完成？
是
檢查結束
否
GO TO 4.
4.檢查胎壓訊號
變更作業地點並再次執行 ID 登錄。
備註：
依胎壓感測器位置而定*，存在死角，且胎壓接收器接收不良。若在此狀況下執行 ID 登錄，可能無法完成登錄。此時請依下列指示改善電波接收環境。
  • 將輪胎旋轉 90°、180° 或 270°。（此步驟用於變更胎壓感測器位置。）
  • 開啟鄰近正在進行 ID 登錄之輪胎的車門。
＊：電波接收狀況取決於車輛結構（例如：車身線束配置、輪胎輪圈設計）或環境。
執行 ID 登錄時，哪些車輪沒有反應？
所有車輪皆有反應，可完成 ID 登錄。
檢查結束
僅特定車輪沒有反應。
更換適用之胎壓感測器。請參閱拆卸 & 安裝.
所有車輪皆無反應。
更換 BCM。請參閱拆卸與安裝.
