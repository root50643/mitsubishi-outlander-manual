故障碼設定條件
檢查條件
  • 點火開關位於「開啟」位置。
判定標準
  • MAC Key 未註冊。
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
故障排除提示 (本故障碼最可能設定原因：)
  • MAC KEY 寫入失敗
  • ECM 故障
診斷
所需特殊工具：
  • MB993028: VCI-3 套件（含無線轉接器）
    1. -: VCI-3 裝置
    2. MB993029: DLC 線束
    3. MB993030: USB 線束
    4. MB993031: 無線 USB 轉接器 (Qty:2)
  • MB993040: VCI-3 套件（不含無線轉接器）
    1. -: VCI-3 裝置
    2. MB993029: DLC 線束
    3. MB993030: USB 線束
1.檢查故障碼是否再次設定。
  1. 使用 M.U.T.-III SE，對 ECM 執行 MAC KEY 寫入（請參閱 MAC KEY WritingMAC KEY 寫入).
  2. 清除已設定的故障碼。
  3. 檢查故障碼是否再次設定。
是否設定故障碼？
是
更換 ECM（請參閱 ECM 拆卸與安裝引擎-ECU 拆卸與安裝）。然後GO TO 2.
否
程序完成。
2.測試 OBD-II 行駛循環。
  1. 依行駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  2. 檢查故障碼。
