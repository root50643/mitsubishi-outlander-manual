定速控制 & 駕駛輔助 - 駕駛輔助系統 - 底盤控制 - 故障碼/電路診斷 - U2140-57 MAC 通訊錯誤 (ECM)
診斷程序
N517020170064W00ENG
1.檢查故障碼優先順序
若同時顯示故障碼 U2140-57 與故障碼 U1327-52 或 U1327-54，請先對故障碼 U1327-52 或 U1327-54 執行故障診斷。
是否偵測到故障碼 U1327-52 或 U1327-54？
是
  • U1327–52：請參閱故障碼說明.
  • U1327–54：請參閱故障碼說明.
否
前往 2。
2.檢查 MAC 診斷
使用 M.U.T.-III SE
使用 M.U.T.-III SE 執行「CHASSIS CONTROL」的「MAC Diagnosis」模式。
是否同時偵測到故障碼 U2140-57 與故障碼 U214F-57、U2152–57（配備 MI-PILOT Assist）及 U2165–57（配備雷達控制單元）？
是（所有故障碼同時被偵測到）
更換底盤控制模組。請參閱拆卸與安裝.
否（所有故障碼並非同時被偵測到）
前往步驟 3.
3.檢查 網路-故障碼
使用 M.U.T.-III SE
執行「CAN Diag」。
檢查結果是否正常？
是
聯絡 Techline 並回報車輛狀況。
否
修復或更換根本原因。
