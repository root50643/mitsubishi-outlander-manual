1.檢查點火開關訊號
使用 M.U.T.-III SE
  1. 依序選擇「EPS/DAST 3」、「資料清單」及「點火開關」。
  2. 點火開關關閉。
  3. 確認該項目為「關閉」。
  4. 點火開關開啟。
  5. 確認該項目為「開啟」。
檢查結果是否正常？
是
進行步驟 2.
否
執行 USM 故障診斷。請參閱故障碼索引
2.檢查動力轉向控制模組 ACC 電源
  1. 拉動駐車煞車開關。
    注意：
    確認駐車煞車開關指示燈已點亮。
  2. 點火開關關閉。
  3. 下車並關閉所有車門。
  4. 等待 65 秒。
    注意：
    • 確認駐車煞車開關指示燈已熄滅。
    • 若後煞車卡鉗溫度偏高，請等待一小時，以免駐車煞車開關指示燈熄滅。
  5. 斷開/拔除動力轉向控制模組線束接頭。
