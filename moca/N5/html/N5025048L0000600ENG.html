引擎<4B4> - 直接噴射與多點燃油噴射 (DI 與 MPI) - 故障排除 - 故障碼程序
Code No. P2F93-00：引擎熄火監視 <Vehicles for Taiwan>
N5025048L0000600ENG
監控方法說明
在特定運轉條件下偵測到非預期的引擎熄火。
監視器執行
連續。
監視器執行條件（其他監視器與感知器）
其他監視器（以下監視項目之記憶體中未設定暫時性故障碼）
  • 失火監視
  • 燃油系統監測
  • 空燃比回授控制系統監視
感知器（以下感知器判定為正常）
  • 燃油液位感測器監視
  • 空氣流量感測器
  • 引擎冷卻液溫度感測器
  • 進氣溫度感測器
  • 大氣壓力感測器
  • 節氣門位置感測器
  • 進氣歧管絕對壓力感測器
  • 燃油噴油嘴（高壓）
  • 燃油壓力感測器
  • 高壓燃油泵
  • 增壓壓力感測器
故障碼設定條件
檢查條件
  • 引擎起動後 20 秒內
判定標準
  • 引擎熄火
失效保護與備用功能
無。
OBD-II 駕駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 9駕駛循環模式.
故障排除提示（設定此故障碼最可能的原因為：）
  • 點火系統失效。
  • 燃油系統失效。
  • 空燃比控制系統失效。
  • 進氣系統失效。
  • EGR 系統作動失效。
  • 節氣門周圍污染
  • 正時鏈條位置不正確
  • 壓縮壓力不當
  • 曲軸箱正壓通風系統失效。
  • 可變氣門正時控制系統失效。
  • 燃油液位感測器組件與燃油泵失效。
  • ECM 失效。
診斷
所需特殊工具：
  • MB993028：附無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
1.使用 M.U.T.-III SE 讀取故障碼。
  1. 將點火開關轉至「開啟」位置。
  2. 檢查是否設定與 DI 及 MPI 故障碼相關的故障碼。
  3. 將點火開關轉至「LOCK」（關閉）位置。
Q：是否設定 P2F93-00 以外的診斷碼？
是
請參閱 故障排除 -故障碼檢查表.
否
前往 2。
2.檢查初始化 EGR 汽門時的作動聲音。
  • 請參閱 引擎 <4B4> - 引擎 and Emission Control - Emission Control - Exhaust 氣體 Recirculation (EGR) System -EGR 汽門 (DC MOTOR) 檢查.
Q：是否聽得到作動聲音？
是
GO TO 3.
否
檢查 EGR 汽門的驅動電路，如有必要則進行修復。若電路正常，更換 EGR 汽門（請參閱 引擎 <4B4> – 引擎 and Emission Control – Emission Control – Exhaust 氣體 Recirculation (EGR) System – EGR 汽門 –EGR 汽門拆卸與安裝).
3.使用 M.U.T.-III SE，檢查資料清單。
  • 資料清單 參考表 (請參閱資料清單 參考表).
    1. Item 5：進氣溫度感測器
    2. Item 6：冷卻液（水）溫度感測器
    3. Item A8709：MAP 感測器
    4. Item 8：空氣流量感測器
    5. Item 12：APS (Main)
    6. Item 13：APS (Sub)
    7. Item 9：TPS (Main)
    8. Item 10：TPS (Sub)
    9. Item 24：V.V.T. RA (Intake-bank1)
    10. Item 27：V.V.T. RA (Exhaust-bank1)
    11. Item A1501：氧氣感測器（後）
    12. Item A3301：大氣壓力感測器
    13. Item A6817：No. 2 進氣溫度感測器
    14. Item A3417：LAFS (Bank1 Sensor1)
Q：檢查結果是否正常？
是
GO TO 4.
否
針對顯示異常資料值的感測器，執行該故障碼分類檢查程序。故障碼檢查表（請參閱 故障排除 -故障症狀檢查表).
4.檢查進氣軟管與進氣歧管的進氣狀況。
Q：檢查結果是否正常？
是
GO TO 5.
否
修理。然後前往 15。
5.檢查正時鏈條上的正時記號。
Q：檢查結果是否正常？
是
GO TO 6.
否
對正正時記號。然後前往 15。
6.檢查節氣門體（節氣門部位）污染。
Q：檢查結果是否正常？
是
GO TO 7.
否
清潔節氣門體（節氣門部位）（請參閱 開啟-車輛 Service -節氣門體（節氣門區域）清潔）。然後前往 15。
7.點火火星的目視檢查。
  • 拆下火花塞並安裝至點火線圈。
  • 連接點火線圈接頭。
  • 斷開/拔除所有燃油噴油嘴接頭。
  • 引擎起動時，檢查每支火星塞是否產生火星。
Q：檢查結果是否正常？
是
GO TO 8.
否
檢查 Inspection Procedure - Ignition Circuit System（請參閱 故障排除 - Symptom Procedure -IGNITION CIRCUIT SYSTEM).
8.檢查淨化控制電磁閥本身。
  • 檢查淨化控制電磁閥本身（請參閱 引擎 <4B4> - 引擎 and Emission Control - Emission Control - Evaporative Emission Control System -淨化控制系統檢查).
Q：檢查結果是否正常？
是
前往 9。
否
更換淨化控制電磁閥（請參閱 引擎 <4B4> - 引擎 Overhaul -電磁閥與真空軟管拆卸與安裝）。然後前往 15。
9.檢查燃油噴射器噴射狀況。
  • 檢查各燃油噴射器噴射狀況（請參閱 開啟-車輛 Service -噴油嘴 檢查).
Q：檢查結果是否正常？
是
前往 10。
否
更換燃油噴射器（請參閱 Fuel 噴油嘴 -噴油嘴拆卸與安裝）。然後前往 15。
10.檢查壓縮壓力。
  • 檢查壓縮壓力（請參閱 引擎 <4B4> - 引擎 Mechanical - 開啟-車輛 Service -COMPRESSION PRESSURE 檢查).
Q：檢查結果是否正常？
是
前往 11。
否
修理。然後前往 15。
11.檢查曲軸箱正壓通風系統。
  • 請參閱 引擎 <4B4> - 引擎 and Emission Control - Emission Control - Crankcase Emission Control System -曲軸箱正壓通風系統檢查.
Q：檢查結果是否正常？
是
更換汽缸蓋罩總成（含 PCV 閥）（請參閱 引擎 Mechanical - Cylinder Head Cover -汽缸蓋罩拆卸與安裝。然後前往 12。
否
修復它。然後前往 15。
12.檢查燃油液位感測器組件與燃油泵訊號電路（元件功能檢查）。
  • 請參閱 Driver Information & Multimedia - 儀表, Warning light & Indicator - Full TFT 儀表 - 故障碼/Circuit Diagnosis - Fuel Level 感知器 訊號 Circuit -元件功能檢查.
Q：檢查結果是否正常？
是
前往 13。
否
修復它。然後前往 15。
13.檢查燃油中是否有異物（水、煤油等等）。
Q：檢查結果是否正常？
是
前往 14。
否
更換燃油。然後前往 15。
14.檢查故障症狀。
  1. 將點火開關轉至「開啟」位置並刪除故障碼。
  2. 依驅動循環模式進行試車。請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 9駕駛循環模式.
  3. 檢查故障碼。
Q：是否設定故障碼 P2F93-00？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後前往 15。
否
檢查完成。
15.測試 OBD-II 駕駛循環。
  1. 將點火開關轉至「開啟」位置並刪除故障碼。
  2. 依驅動循環模式進行試車。請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 9駕駛循環模式.
  3. 檢查故障碼。
Q：是否設定故障碼 P2F93-00？
是
重新進行故障排除。
否
檢查完成。
