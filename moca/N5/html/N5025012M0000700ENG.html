引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. U2152-57：與 ADAS 之 MAC 通訊失效/故障
N5025012M0000700ENG
故障碼設定條件
檢查條件
  • 點火開關為「開啟」位置。
判定條件
  • 與 ADAS 之 MAC 通訊失效/故障達 2 秒。
備註
目前故障
  • 失效/故障可能由 ECM 與 ADAS 控制單元 2 之間 CAN 匯流排解線上之線束與接頭故障、ADAS 控制單元 2 故障或 ECM 故障所造成。
過去故障
  • 進行故障排除，著重於 ECM 與 ADAS 控制單元 2 之間 CAN 匯流排解線上線束與接頭之開路故障。
備註：
就過去故障而言，即使 CAN 匯流排存在異常，M.U.T.-III SE 的 CAN 匯流排線路診斷也可能無法偵測到故障。因此，請依間歇性故障的處理方式檢查 CAN 匯流排線路（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障）。可從執行 CAN 通訊的各 ECU 所設定的診斷碼，縮小故障可能性較高的區域（請參閱 Electrical and Power Control - LAN System - CAN Fundamental - Basic Inspection - Diagnosis and Repair Workflow -M.U.T.-III SE CAN 匯流排診斷說明).
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
故障排除提示（設定此故障碼最可能的原因為：）
  • ADAS 控制單元 2 故障
  • ECM 故障
診斷
所需專用工具：
  • MB993028：含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
1.使用 M.U.T.-III SE 讀取其他故障碼。
檢查故障碼 No. U1327-52 是否與故障碼 No. U214F-57 同時設定。
Q：是否設定故障碼 U1327-52？
是
執行故障碼 No. U1327-52 之診斷（請參閱故障碼檢查表故障碼檢查表).
否
前往 2。
2.使用 M.U.T.-III SE，讀取故障碼。
Q：MAC 通訊診斷碼 U214F-57、U2176-57 與故障碼 U2152-57 是否同時設定？
是（所有診斷碼同時偵測到）
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後前往 4。
否（所有診斷碼並非同時偵測到）
前往 3。
3.使用 M.U.T.-III SE 進行 CAN 匯流排診斷
  • 使用 M.U.T.-III SE 執行 CAN 匯流排解線診斷。
問：檢查結果是否正常？
是
聯絡 Tecline 並報告車輛狀況。
否
修復 CAN 匯流排解線（請參閱 Electrical and Power Control - LAN System - CAN Fundamental - Basic Inspection - Diagnosis and Repair Workflow -M.U.T.-III SE CAN 匯流排診斷說明）。修復 CAN 匯流排解線後。然後前往 4。
4.測試 OBD-II 行駛循環。
  1. 以驅動循環模式執行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  2. 檢查故障碼。
Q：是否設定故障碼 U2152-57？
是
重新執行故障排除。
否
檢查完成。
