使用 M.U.T.-III SE 資料清單與作動器測試進行檢查
N5025003X0000800ENG
使用 M.U.T.-III SE 讀取資料清單或執行作動器測試，可檢查車輛車身線束與元件是否有異常。資料清單中可顯示感知器對作動器的輸入或輸出數值或圖形；作動器測試中可在指定時間內強制驅動作動器（開啟/關閉）。
診斷程序
  1. 連接 M.U.T.-III SE 以使用資料清單與作動器測試功能進行檢查。
  2. 若發現任何異常，請檢查並修復車輛車身線束與元件。
  3. 修復後，確認輸入與輸出已恢復正常。
  4. 若因檢查與修復作業而產生失效/故障碼，請清除該失效/故障碼。
  5. 斷開 M.U.T.-III SE 並執行路試，確認故障現象已排除。
