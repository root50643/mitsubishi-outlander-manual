CRUISE CONTROL & DRIVER ASSISTANCE - DRIVE MODE SYSTEM - SYSTEM DESCRIPTION - SYSTEM - 駕駛模式選擇開關
系統說明（2WD 車型）
N5170303A0000C00ENG
  • 所有車輛均配備駕駛模式選擇開關，可透過撥動開關於 ECO、NORMAL、TARMAC、GRAVEL 及雪等車輛模式間切換。
  • 駕駛模式選擇開關可變更動力系統、儀表、底盤機能及駕駛輔助系統之車輛模式。

控制說明
  • 駕駛模式選擇開關（drive mode select switch）安裝於中控台上方，可透過撥動開關切換車輛模式，並變更動力系統、儀表、底盤機能及駕駛輔助系統之控制特性。
  • 當點火開關由關閉狀態切換至開啟時，不論上次點火開關開啟時之駕駛模式為何，駕駛模式選擇開關均以 NORMAL 模式啟動。
  • 車輛特性由 NORMAL 模式控制，可切換至下列任一模式：
    ECO
    此模式透過最佳化動力系統特性，支援環保且經濟的駕駛。
    TARMAC
    此模式在乾燥鋪裝道路上提供靈活動態的駕駛樂趣，例如靈敏且強勁的加速、靈敏且線性的轉向手感，以及過彎時的穩定性與循跡性。
    GRAVEL
    此模式適用於平坦未鋪裝路面或潮濕鋪裝路面等粗糙路面行駛，可改善粗糙路面之直進性與強勁起步加速。部分 ADAS 功能受限。
    雪
    此模式適用於積雪路面等濕滑路面行駛，可提供良好的初始轉向反應及濕滑路面之高過彎穩定性。部分 ADAS 功能受限。
