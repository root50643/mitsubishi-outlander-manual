煞車 - 煞車控制系統 - 配備 VDC - 基本檢查 - 後煞車來令片或後煞車卡鉗拆卸/更換
作業程序
N5060305A0003900ENG
1.後煞車來令片或後煞車卡鉗總成拆卸/更換前
使用 M.U.T.-III SE
  1. 點火開關由關閉（自動 ACC 功能關閉）轉至開啟。
    注意：
    請勿啟動引擎。
  2. 依此順序選取 "ABS"、"Learning"（於 "Special function" 內）及 "START BRAKE PAD REPLACEMENT"。
    注意：
    • 請勿操作駐車煞車開關。
    • 請勿踩下煞車踏板。
  3. 點選 "OK"。
前往 2.
2.後煞車來令片或後煞車卡鉗總成拆卸與安裝/更換
更換後煞車來令片或後煞車卡鉗。
  • 後煞車來令片：請參閱拆卸與安裝.
  • 後煞車卡鉗總成：請參閱拆卸與安裝.
前往 3.
3.後煞車來令片或後煞車卡鉗總成安裝/更換後
使用 M.U.T.-III SE
  1. 依此順序選取 "ABS"、"Learning"（於 "Special function" 內）及 "FINISH BRAKE PAD REPLACEMENT"。
    注意：
    • 請勿操作駐車煞車開關。
    • 請勿踩下煞車踏板。
  2. 點選 "OK"。
前往 4.
4.執行 INITIALIZATION 位置 調整
使用 M.U.T.-III SE
  1. 依此順序選取 "ABS"、"Learning"（於 "Special function" 內）及 "INITIALIZATION 位置 調整"。
    注意：
    • 請勿操作駐車煞車開關。
    • 請勿踩下煞車踏板。
  2. 點選 "OK"。
GO TO 5.
5.執行自我診斷
使用 M.U.T.-III SE
  1. 拉起駐車煞車開關以啟動電動駐車煞車。
  2. 按下駐車煞車開關以解除電動駐車煞車。
  3. 對「ABS」執行自我診斷。
是否偵測到故障？
是
檢查故障碼。請參閱故障碼索引. GO TO 6.
否
GO TO 6.
6.檢查 DATA MONITOR
使用 M.U.T.-III SE
依此順序選取 "ABS"、"資料清單"、"BR FORCE EST (LH)" 及 "BR FORCE EST (RH)"。確認訊號在規定值範圍內。請參閱參考值.
檢查結果是否正常？
是
GO TO 7.
否
前往 1.
7.清除自我診斷記憶體
使用 M.U.T.-III SE
  1. 點火開關由關閉（自動 ACC 功能關閉）轉至開啟。
  2. 清除 "ABS" 的自我診斷結果記憶體。
記憶體是否已清除？
是
檢查結束
否
檢查自我診斷所指示的項目。
已加入書籤書籤數量過多。
請刪除後重新加入書籤。
