引擎<4B4> - 直接噴射與多點燃油噴射 (DI 與 MPI) - 故障排除 - 故障碼程序
Code No. U2276-00：CAN 逾時 (CDM)
N5025048R0000300ENG
注意：
  • 量測 CAN 匯流排線路電阻時，請斷開/拔除 12V 電池負極端子。
  • 量測 CAN 匯流排線路電阻或電壓時，請使用指定數位電表。
監控方法說明
於指定時間內未收到底盤控制模組資料。（底盤控制模組亦偵測到與 ECM 之通訊錯誤。）
監視器執行
連續。
監視器執行條件（其他監視器與感知器）
其他監視器（以下監視項目之記憶體中未設定暫時性故障碼）
  • 不適用
感知器（以下感知器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關轉至「開啟」位置後，經過 2 秒。
  • 電池正極電壓大於 10.5 volts 且小於 16.5 volts。
判定標準
  • 無法透過 CAN 匯流排線路接收底盤控制模組訊號達 4 秒。
失效保護與備用功能
無。
OBD-II 駕駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 3駕駛循環模式.
故障排除提示（設定此故障碼最可能的原因為：）
  • CAN 匯流排線路故障
  • 8CH CAN 網關故障
  • 底盤控制模組故障
  • 8ch CAN 網關電源供應電路故障
  • 底盤控制模組電源供應電路故障
診斷
所需特殊工具：
  • MB993028：附無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
1.使用 M.U.T.-III SE 讀取其他系統故障碼。
  1. 將點火開關轉至「開啟」位置。
  2. 檢查其他 ECU 是否設定故障碼 U2176-87。
  3. 將點火開關轉至「LOCK」（關閉）位置。
Q：是否設定故障碼 U2176-87？
是
請參閱 Electrical & Power Control - LAN System - CAN Fundamental - Basic Inspection - Diagnosis and Repair Workflow -M.U.T.-IIISE CAN 匯流排診斷說明.
否
前往 2。
2.使用 M.U.T.-III SE 讀取其他系統故障碼。
  1. 將點火開關轉至「開啟」位置。
  2. 讀取底盤控制模組故障碼。
  3. 將點火開關轉至「LOCK」（關閉）位置。
Q：是否設定底盤控制模組故障碼？
是
請參閱 Cruise Control & Driver Assistance - Driver Assistance System - Chassis Control - ECU Diagnosis Information - Chassis Control Module -故障碼索引。然後GO TO 3.
否
請參閱 Electrical & Power Control - LAN System - CAN - 故障碼/Circuit Diagnosis - Drivetrain CAN Communication 1 Circuit -診斷程序.
3.測試 OBD-II 駕駛循環。
  1. 以驅動循環模式執行路試。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 3駕駛循環模式.
  2. 檢查故障碼。
Q：是否設定故障碼 U2276-00？
是
重新進行故障排除。
否
檢查完成。
