車身外觀、車門、車頂與車輛安全 - 車門與鎖 - 基本檢查 - 配置（免鑰匙操作 KEY UNIT）
說明
N51101011000Q800ENG
更換免鑰匙操作 key unit 後，因尚未寫入，須使用 M.U.T.-III SE 寫入車輛規格。
配置需要網路連線。M.U.T.-III SE 連接網路後，從伺服器下載配置資料，然後將車輛規格寫入免鑰匙操作 key unit。
請參閱作業程序.
注意：
有關網路連線及作動詳細內容，請參閱「M.U.T.-III SE 作動手冊」。
配置無需從免鑰匙操作 key unit「儲存」配置資料。配置資料一律於伺服器端產生重新生成後，再下載至 M.U.T.-III SE。
警告：
  • 請依序完成「配置」作業程序。
  • 若「配置」不正確，可能導致異常。
  • 除新的免鑰匙操作 key unit 外，切勿執行「配置」。
