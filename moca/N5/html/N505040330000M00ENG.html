使用訊號 Tech II 工具 (MB993012) 進行 TPMS 登錄
注意：
訊號 Tech II 必須更新至 1.1.48 版或更新版本的軟體，才能執行下列程序。訊號 Tech II 軟體更新僅能從配備 ASIST 的 M.U.T.-III SE 單元下載。其他版本的 ASIST 將不會顯示更新項目。
使用 M.U.T.-III SE
  1. 將所有輪胎胎壓調整至建議值。請參閱輪胎空氣壓力.
  2. 將點火開關轉至開啟。
  3. 使用 M.U.T.-III SE，在「BCM」中選擇「Special Function」，然後選擇「TPMS ID Registration」。
  4. 選擇「OK」以開啟「TPMS ID Registration」畫面。
  5. 開啟訊號 Tech II 工具 (MB993012)。
  6. 將訊號 Tech II 貼近左前輪胎側面，靠近汽門嘴位置。
    CF100AIRAA00ENG
  7. 將工具以與輪胎呈 0 至 15 度角的方式持握，從主選單選擇「Activate 感知器」，然後按下並放開「OK」按鈕以啟動感測器。感測器啟動後，車輛駐車燈會閃爍，且感測器 ID 會顯示於 M.U.T.-III SE 畫面上。
  8. 依下列順序對其餘輪胎重複步驟 6 及 7：右前、右後及左後。
  9. ID 登錄完成後，檢查每個車輪的下列模式。

  10. 所有感測器啟動完成後，在 M.U.T.-III SE 上選擇「End」以完成 ID 登錄。
