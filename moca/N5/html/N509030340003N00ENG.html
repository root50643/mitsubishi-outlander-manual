VENTILATION, HEATER & AIR CONDITIONER - HEATER & AIR CONDITIONING CONTROL SYSTEM - AUTOMATIC AIR CONDITIONING - BASIC INSPECTION - 作動檢查
作業程序
N509030340003N00ENG
說明
作動檢查的目的是確認各個系統運作正常。
檢查條件
: 引擎於正常運轉溫度下運轉。
作動檢查
1.檢查記憶功能
  1. 按下 AUTO 開關以啟動空調。
  2. 操作溫度控制旋鈕（駕駛側），將溫度設定為 32.0°C (89°F)。
  3. 按下開啟·關閉開關。
  4. 點火開關關閉。
  5. 點火開關 開啟。
  6. 按下 AUTO 開關。
  7. 確認設定的溫度 32.0°C (89°F) 維持不變。
檢查結果是否正常？
是
前往步驟 2.
否
GO TO 10.
2.檢查風扇車速
  1. 啟動引擎。
  2. 操作風扇開關，並確認風扇車速有變化。
  3. 檢查所有風扇車速的作動。
檢查結果是否正常？
是
前往步驟 3.
否
GO TO 10.
3.檢查出風口
  1. 操作風扇開關，將風扇車速設定為最高車速。
  2. 操作 MODE 開關及 DEF 開關。
  3. 將手置於出風口前方，確認出風口依各指示出風口改變。
檢查結果是否正常？
是
前往步驟 4.
否
GO TO 10.
4.檢查進氣口
  1. 按下進氣開關，將進氣口設定為內循環。進氣開關指示燈亮起。
  2. 聆聽進氣聲音，確認進氣口有改變。
  3. 再次按下進氣開關，將進氣口設定為外氣進氣。進氣開關指示燈熄滅。
  4. 聆聽進氣聲音，確認進氣口有改變。
檢查結果是否正常？
是
前往步驟 5.
否
GO TO 10.
5.檢查 A/C 壓縮機
  1. 按下 A/C 開關。A/C 開關指示燈亮起。
  2. 以目視及聽覺確認 A/C 壓縮機運作。
  3. 再次按下 A/C 開關。A/C 開關指示燈熄滅。
  4. 確認 A/C 壓縮機停止。
檢查結果是否正常？
是
前往步驟 6.
否
GO TO 10.
6.檢查出風溫度
  1. 操作溫度控制旋鈕（駕駛側）。
  2. 確認出風溫度（駕駛側）有變化。
  3. 操作溫度控制旋鈕（乘客側）。
  4. 確認出風溫度（乘客側）有變化。
  5. 操作溫度控制開關（後座空調控制）。
  6. 確認後座出風溫度有變化。
  7. 按下 SYNC 開關。SYNC 開關指示燈亮起。
  8. 確認空調溫度設定 [前座（駕駛側/乘客側）/ 後座] 統一為駕駛側溫度設定。
檢查結果是否正常？
是
前往步驟 7.
否
GO TO 10.
7.檢查溫度設定降低
  1. 作動 A/C 壓縮機。
  2. 操作溫度控制旋鈕（駕駛側），將設定溫度降低至 "Lo"。
  3. 確認冷空氣從出風口吹出。
檢查結果是否正常？
是
前往步驟 8.
否
GO TO 10.
8.檢查溫度上升
  1. 將引擎暖機至正常運轉溫度。
  2. 操作溫度控制旋鈕（駕駛側），將設定溫度提高至 "Hi"。
  3. 確認暖空氣從出風口吹出。
檢查結果是否正常？
是
前往步驟 9.
否
GO TO 10.
9.檢查 AUTO 模式
  1. 按下 AUTO 開關，並確認 AUTO 指示燈亮起。
  2. 操作溫度控制開關（駕駛側），確認風扇車速或出風口有變化（出風口或風扇車速會依環境溫度、車內溫度、設定溫度等而變化）。
檢查結果是否正常？
是
檢查結束
否
GO TO 10.
10.使用 M.U.T.-III SE 檢查自我診斷
  1. 使用 M.U.T.-III SE 執行自我診斷。
  2. 確認是否偵測到任何故障碼。
是否偵測到任何故障碼？
是
請參閱故障碼索引，並執行適當的診斷。
否
GO TO 11.
11.檢查失效保護啟動
確認症狀適用於失效保護啟動。請參閱失效保護.
請參閱Symptom Table，並執行適當的診斷。
