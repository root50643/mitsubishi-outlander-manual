定速控制與駕駛輔助 - 駕駛輔助系統 - 底盤控制 - 基本檢查 - 更換底盤控制模組時的額外服務
作業程序 [更換底盤控制模組後]
N517020DH0000W00ENG
1.寫入 MAC 金鑰
使用 M.U.T.-III SE
執行 MAC 金鑰寫入。請參閱說明.
前往 2。
2.執行程式設計
使用 M.U.T.-III SE
依 M.U.T.-III SE 作動手冊中「程式設計」程序，執行底盤控制模組程式設計。請參閱 M.U.T.-III SE 作動手冊。
注意：
程式設計期間，維持下列條件：
  • 點火開關：開啟
  • 電氣負載：關閉
  • 煞車踏板：未踩下
  • 12V 電池電壓：12 – 13.5 V（檢查 M.U.T.-III SE 螢幕上顯示的數值。）
前往 3。
3.執行設定
使用 M.U.T.-III SE
執行設定。請參閱說明.
前往 4。
4.執行必要作業
  1. 執行「底盤控制」自我診斷。
  2. 清除自我診斷結果記憶。
前往 5。
5.執行原廠模式關閉
  1. 點火開關開啟。
  2. 在「底盤控制」的「特殊功能」畫面中，選擇「原廠模式 關閉」。
  3. 檢查項目No.1：原廠模式，並依設定值執行下列程序。
    開啟：選擇「確定」並將設定值變更為「關閉」。
    關閉：無需動作，作業完成。
