2.檢查永久故障碼
使用 M.U.T.-III SE
  1. 點火開關關閉，並等待至少 60 秒。
  2. 點火開關開啟。
  3. 點火開關關閉，並等待至少 60 秒。
  4. 點火開關開啟。
  5. 使用 M.U.T.-III SE 選擇「PERMANENT 故障碼 STATUS」模式。
使用 GST
  1. 點火開關關閉，並等待至少 60 秒。
  2. 點火開關開啟。
  3. 點火開關關閉，並等待至少 60 秒。
  4. 點火開關開啟。
  5. 使用 GST 選擇 Service $0A。

3.如何清除永久故障碼
注意：
一直以安全車速行駛。
  1. 執行已偵測永久故障碼的「故障碼確認程序」。
  2. 依行駛模式駕駛車輛。
    • 以 40 km/h (25 MPH) 行駛的狀態累計達 300 秒或以上。
    • 怠速車速維持 30 秒或以上。
    • 引擎啟動後經過 600 秒或以上。
GO TO 4.
