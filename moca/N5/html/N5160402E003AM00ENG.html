1.檢查故障碼優先順序
若故障碼 U2352-57 與故障碼 U1327-52 或故障碼 U1327-54 同時顯示，請先執行故障碼 U1327-52 或故障碼 U1327-54 的故障診斷。
是否偵測到故障碼 U1327-52 或 U1327-54？

否

2.檢查自我診斷結果
使用 M.U.T.-III SE
使用 M.U.T.-III SE 執行「環景監控系統」的「自我診斷」。
故障碼 U2352-57 是否與其他 MAC 通訊錯誤 故障碼（故障碼 U2140-57、U2143-57、U214F-57、U2152-57、U2165-57、U2176-57、U234F-57 及 U2376-57）同時偵測到？

更換環景監控控制單元。請參閱拆卸與安裝.
否（並非所有 MAC 通訊錯誤 故障碼 同時被偵測到）
前往步驟 3。
