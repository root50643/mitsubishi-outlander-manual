1.檢查前軸與後軸
  1. 斷開/拔除 12V 電瓶負極端子。
  2. 檢查前後軸是否無過大鬆動。
    • 前軸
      • 2WD 車型：請參閱 Inspection檢查.
      • AWD 車型：請參閱 Inspection檢查.
    • 後軸
      • 2WD 車型：請參閱 Inspection檢查.
      • AWD 車型：請參閱 Inspection檢查.
檢查結果是否正常？
是
前往 2.
否
修理或更換偵測到異常的零件。
2.檢查碟盤
檢查碟盤。
  • 前輪：請參閱檢查與調整.
  • 後部：請參閱檢查與調整檢查與調整.
檢查結果是否正常？
是
前往 3.
否
整修或更換碟盤。
3.檢查煞車油洩漏
檢查液體洩漏。
  • 前部：請參閱檢查檢查.
  • 後部：請參閱檢查檢查.
檢查結果是否正常？
是
前往 4.
否
修理或更換偵測到異常的零件。
4.檢查 煞車踏板
檢查煞車踏板的各項。請參閱檢查與調整.
檢查結果是否正常？
是
GO TO 5.
否
調整煞車踏板的各項。請參閱檢查與調整.
5.檢查煞車力
使用煞車力試驗台檢查煞車力。
檢查結果是否正常？
是
GO TO 6.
否
檢查煞車系統各零件。
6.檢查煞車性能
  1. 斷開 ABS 作動器及電動單元（控制單元）接頭，使 ABS 不作用。
  2. 檢查在此狀態下煞車力是否正常。檢查後連接線束接頭。
