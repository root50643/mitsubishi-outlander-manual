  1. 執行 M.U.T.-III SE 的「資料清單」，檢查是否有異常項目。
  2. 檢查資料監視器顯示是否隨組合開關作動而切換。
  3. 若有開關的顯示未改變，請依該開關所用電路，以組合開關電路確認表指定適用的組合開關電路（INPUT 1 - 6 及 OUTPUT 1 - 5）。
    備註：
    由於組合開關電路為多個開關共用，若除故障開關外，其他使用相同電路的開關均正常，則可判定該組合開關電路正常。
    範例：若該開關所用電路對應組合開關電路的 INPUT 1 及 OUTPUT 2，但其他使用 INPUT 1 電路的開關均正常，則判定 INPUT 1 電路正常，並檢查 OUTPUT 2 電路。若其他使用 OUTPUT 2 電路的開關均正常，則判定組合開關電路（INPUT 1 及 OUTPUT 2）正常，可判定為組合開關故障。
