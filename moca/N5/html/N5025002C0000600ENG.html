初始化程序
警告：
為避免損壞 M.U.T.-III SE，在連接或斷開 M.U.T.-III SE 之前，務必將點火開關轉至關閉位置。
點火開關處於關閉位置後，將 M.U.T.-III SE 連接至診斷接頭。
將點火開關轉至開啟位置。
從 M.U.T.-III SE 的 System select Screen 選取「引擎」。
從引擎 Screen 選取「Special Function」。
從 Special Function Screen 選取「Reset」。
從 Learned value reset Screen 選取「Learned value reset」。
按下「OK」按鈕以初始化學習值。
初始化學習值後，須進行 DI 與 MPI 引擎怠速學習值學習。DI 與 MPI 引擎怠速學習程序（請參閱DI 與 MPI 引擎怠速學習程序).
