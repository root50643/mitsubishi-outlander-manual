ELECTRICAL & POWER CONTROL - LAN SYSTEM - CAN FUNDAMENTAL - SYSTEM DESCRIPTION - 故障診斷
異常偵測條件
N5140304Y0000A00ENG
若 CAN 通訊訊號在單元之間超過 2 秒未傳送或接收，則 M.U.T.-III SE 的自我診斷結果中會顯示 CAN 通訊的故障碼（例如 U1000 和 U1001）。
CAN 通訊系統錯誤
  • CAN 通訊線路斷路（CAN-H、CAN-L 或兩者）
  • CAN 通訊線路短路（搭鐵、CAN 通訊線路之間、其他線束）
  • 已連接至 CAN 通訊線路之單元的 CAN 通訊控制電路錯誤
當 CAN 通訊系統正常時仍顯示 CAN 通訊故障碼
  • 零件拆卸/安裝：在點火開關開啟狀態下拆卸及安裝 CAN 通訊單元及相關零件時，可能偵測到錯誤。（可能偵測到 CAN 通訊以外的故障碼。）
  • 保險絲燒毀/熔斷（拔除）：單元的 CAN 通訊可能停止。
  • 電壓降：若因電池放電導致點火開關開啟時電壓下降，可能偵測到錯誤。（依執行 CAN 通訊之控制單元而定。）
  • 若執行 CAN 通訊之控制單元的電源供應電路故障，可能偵測到錯誤。（依執行 CAN 通訊之控制單元而定。）
  • 若重編程式未正常完成，可能偵測到錯誤。
注意：
在上述條件下，若 M.U.T.-III SE 的自我診斷結果中顯示 CAN 通訊故障碼，則 CAN 通訊系統為正常。清除各單元自我診斷的記憶。
