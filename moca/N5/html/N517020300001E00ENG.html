詳細流程
1.客戶訪談
檢查前先釐清客戶抱怨。首先，利用診斷工作表重現症狀並充分理解。仔細詢問客戶其抱怨內容。如有必要，與客戶一同試車檢查症狀。
注意：
客戶並非專業人員。切勿輕易臆測，例如「也許客戶是指……」或「也許客戶提到的是這個症狀」。
前往 2.
2.檢查症狀
根據訪談所獲得的客戶資訊，重現客戶所描述的症狀。同時檢查該症狀是否由失效保護模式所造成。請參閱失效保護失效保護.
注意：
當症狀為正常作動所致時，應完整檢查各部位，並取得客戶理解，確認該症狀並非由故障所造成。
前往 3.
3.執行自我診斷
使用 M.U.T.-III SE
對「CHASSIS CONTROL」執行自我診斷。
是否偵測到故障碼？
是
記錄或列印自我診斷結果與凍結畫面資料（FFD）。前往 4.
否
檢查結束
4.執行故障碼診斷程序
使用 M.U.T.-III SE
對偵測到錯誤的系統執行故障碼確認程序。
注意：
若同時偵測到多個 故障碼，請根據故障碼檢查優先順序圖.
是否偵測到故障碼？
是
GO TO 5.
否
根據訪談所獲得的資訊檢查線束與接頭。
5.維修或更換偵測到錯誤的零件
  1. 修理或更換偵測到異常的零件。
  2. 維修或更換後重新連接零件或接頭。
  3. 偵測到故障碼時，清除「底盤控制」的自我診斷結果。
GO TO 6.
6.最終檢查
使用 M.U.T.-III SE
  1. 檢查「底盤控制」的參考值。
  2. 重新檢查症狀，並確認在相同條件下症狀未再重現。
症狀是否重現？
是
前往 3.
否
檢查結束
