懸吊系統 - 道路車輪 & 輪胎 - 注意事項 - 預防措施/注意事項
TPMS 服務告示及預防措施/注意事項
N505170040000G00ENG
  • 當胎壓低於警告胎壓值時，胎壓警告燈亮起。請將所有車輪胎壓調整至規定值。
  • 發生除胎壓過低以外的任何故障或未安裝感知器時，胎壓警告燈閃爍 1 分鐘後常亮。請修復故障；若未安裝感知器，請安裝胎壓感知器並註冊 ID 以熄滅胎壓警告燈。有關 ID 註冊，請參閱說明.
  • 更換或調換輪胎及/或車輪、更換胎壓感知器或 BCM 時，須進行 ID 註冊。請參閱 更換或調換輪胎及/或車輪、更換胎壓感知器或 BCM 時，須進行 ID 註冊。
    注意：
    若拆下及安裝車輪前後，各車輪（胎壓感知器）位置未變更，則無須進行 ID 註冊。
  • 自車輪拆下胎壓感知器時，務必更換胎壓感知器的汽門心及汽門蓋。請參閱分解圖.
    更換各輪胎達磨耗極限時，建議更換胎壓感知器的汽門心及汽門蓋。請參閱分解圖.
  • 調整胎壓時，切勿對充氣嘴施加過大力量，以免損壞汽門及胎壓感知器。
  • 排空輪胎全部空氣時，請將車輛頂起以免損壞胎壓感知器（例如：在車輛上加注 N2氣體至輪胎時）。有關頂升支撐點及千斤頂支撐點，請參閱頂升及千斤頂支撐位置.
  • 由於胎壓感知器須符合各國無線電法規，必須遵守下列事項。
    • 感知器僅可在各國境內使用。
    • 不得使用規定方法以外的方式使用。
    • 不得拆解或改裝。
  • 切勿安裝其他車輛的胎壓感知器。若未安裝指定的三菱原廠胎壓感知器，胎壓監測系統 (TPMS) 將無法運作。
