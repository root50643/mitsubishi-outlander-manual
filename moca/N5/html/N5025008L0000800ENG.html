引擎<4B4> - 直接燃油噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0638-00：節氣門控制伺服馬達電路範圍/性能異常
N5025008L0000800ENG
電路作動
  • 控制由 ECM 接頭端子 ETV+、ETV- 施加至電子控制節氣門的電流。
技術說明
  • ECM 檢查電子控制節氣門系統是否有異常狀況。
監控方法說明
節氣門位置感測器（主）輸出值與目標開度之差大於規定值。
監控執行
連續。
監控執行條件（其他監控及感測器）
其他監控（下列監控項目之記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件 <Rationality - Return spring>
偵測條件
  • 點火開關位於 開啟 位置。
  • 電池正極電壓超過 6.2 volts。
判定基準
  • 節氣門回位彈簧異常。
故障碼設定條件 <Throttle motor power supply>
偵測條件
  • 點火開關位於 開啟 位置。
  • 電池正極電壓超過 6.2 volts。
判定基準
  • 節氣門電源狀況異常。
故障碼設定條件 <Throttle motor duty>
偵測條件
  • 點火開關位於 開啟 位置。
  • 電池正極電壓超過 6.2 volts。
判定基準
  • 節氣門控制占空比持續高電位超過 0.4 秒。
故障碼設定條件 <Throttle overcurrent>
偵測條件
  • 點火開關位於 開啟 位置。
  • 電池正極電壓超過 6.2 volts。
判定基準
  • 節氣門控制微電腦異常。
故障碼設定條件 <Full close learnt value 檢查>
偵測條件
  • 點火開關位於 開啟 位置。
  • 電池正極電壓超過 6.2 volts。
判定基準
  • 節氣門位置感測器（主）全閉學習值大於 3.26 度。
或
  • 節氣門位置感測器（主）預設開度學習值小於節氣門位置感測器（主）全閉學習值 + 2.03 度。
失效保護及備援功能
節氣門開度位置處於預設位置。
OBD-II 行程循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 3行程循環模式.
故障排除提示（此故障碼最可能之設定原因如下：）
  • 節氣門體總成故障。
  • 電子控制節氣門電路斷路或線束損壞，或接頭接觸不良。
  • ECM 故障。
診斷
所需特殊工具：
  • MB993028：VCI-3 kit with wireless adapters
    1. -：VCI-3 device
    2. MB993029：DLC cable
    3. MB993030：USB cable
    4. MB993031：Wireless USB adapter (Qty:2)
  • MB993040：VCI-3 kit without wireless adapters
    1. -：VCI-3 device
    2. MB993029：DLC cable
    3. MB993030：USB cable
1.使用 M.U.T.-III SE 讀取故障碼。
Q：是否設定故障碼 P0121-00、P0122-00、P0123-00、P0222-00 或 P0223-00？
是
故障碼診斷檢查表（請參閱故障碼檢查表).
否
進入步驟 2。
2.檢查電子控制節氣門的作動聲音。
Q：檢查結果是否正常？
是
GO TO 6.
否（有異音。）
更換電子控制節氣門（請參閱節氣門體總成拆卸與安裝）。然後GO TO 12.
否（異音以外）
進入步驟 3。
3.檢查電子控制節氣門線圈電阻
  • 電子控制節氣門線圈檢查（請參閱節氣門控制伺服馬達檢查).
Q：檢查結果是否正常？
是
轉至 4.
否
更換電子控制節氣門（請參閱節氣門體總成拆卸與安裝）。然後GO TO 12.
4.檢查電子控制節氣門接頭與 ECM 接頭間 ETV+ 線路斷路及短路。
  • 斷開/拔除接頭，並於線束側進行量測。
  • 電子控制節氣門接頭與 ECM 接頭間 ETV+ 線路導通檢查
OK：導通（2 Ω 或以下）
  • 電子控制節氣門接頭與搭鐵間 ETV- 線路導通檢查
OK：開路
Q：檢查結果是否正常？
是
GO TO 5.
否
修理接頭或線路。然後GO TO 12.
5.檢查電子控制節氣門接頭與 ECM 接頭間 ETV- 線路斷路及短路。
  • 斷開/拔除接頭，並於線束側進行量測。
  • 電子控制節氣門接頭與 ECM 接頭間 ETV+ 線路導通檢查
OK：導通（2 Ω 或以下）
  • 電子控制節氣門接頭與搭鐵間 ETV- 線路導通檢查
OK：開路
Q：檢查結果是否正常？
是
GO TO 6.
否
修理接頭或線路。然後GO TO 12.
6.使用 M.U.T.-III SE，檢查資料清單。
  • 請參閱 資料清單 參考表資料清單 參考表.
    1. 項目 40：TPS(MAIN) 學習值（全閉位置）
    2. 項目 41：TPS(MAIN) 學習值（全開位置）
    3. 項目 42：TPS(SUB) 學習值（全閉位置）
    4. 項目 43：TPS(SUB) 學習值（全開位置）
Q：檢查結果是否正常？
是
GO TO 7.
否
將點火開關由關閉轉至開啟並執行學習。然後GO TO 7.
7.檢查電子控制節氣門是否髒污。
Q：檢查結果是否正常？
是
GO TO 8.
否
清潔電子控制節氣門。然後GO TO 8.
8.檢查電子控制節氣門接頭與 ECM 接頭間 ETV+ 線路損壞
Q：檢查結果是否正常？
是
GO TO 9.
否
修理接頭或線路。然後GO TO 12.
9.檢查電子控制節氣門接頭與 ECM 接頭間 ETV- 線路損壞
Q：檢查結果是否正常？
是
GO TO 10.
否
修理接頭或線路。然後GO TO 12.
10.使用 M.U.T.-III SE 讀取故障碼。
  • 故障碼再確認。
Q：是否設定故障碼？
是
GO TO 11.
否
間歇性故障（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障).
11.更換節氣門體總成
  • 更換節氣門體總成 (請參閱節氣門體總成拆卸與安裝). 然後重新確認是否設定診斷碼。
Q：是否設定故障碼？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後GO TO 12.
否
檢查完成。
12.測試 OBD-II 行程循環。
  1. 依驅動循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 3行程循環模式.
  2. 檢查故障碼。
Q：是否設定故障碼？
是
重新執行故障排除。
否
檢查完成。
