故障碼說明
N5160101C003SW00ENG
CAN (Controller Area 網路) 為即時應用的串列通訊系統。其為開啟-車輛 multiplex communication system，具備高 data communication 車速及優異的 error detectability。車輛上裝備許多 electronic control units，各 control unit 在作動期間共享資訊並與其他 control units 連結（非獨立運作）。在 CAN communication 中，control units 以兩條通訊線路（CAN-H line、CAN-L line）已連接，可在減少配線的情況下實現高資訊傳輸速率。各 control unit 傳送/接收 data，但僅選擇性讀取所需 data。
