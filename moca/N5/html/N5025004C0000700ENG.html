引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0013-00：凸輪軸位置作動器電路（排氣側）
N5025004C0000700ENG
電路作動
  • 引擎控制繼電器整合於B IPDM E/R。
  • 電源由引擎控制繼電器供應至排氣供油控制閥。
  • ECM 接頭端子 OCVE 使單元內功率電晶體處於開啟位置，使電流流經排氣供油控制閥。
技術說明
  • ECM 依引擎運轉狀況控制排氣供油控制閥之滑閥位置，並持續改變排氣凸輪軸相位。
監視方法說明
排氣供油控制閥電路電流超出規定範圍。
監視執行
連續。
監視執行條件（其它監視與感測器）
其它監視（下列監視項目在記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 凸輪軸位置感測器
  • 曲軸角度感知器
  • 引擎冷卻液溫度感測器
  • 引擎機油控制閥
故障碼設定條件
檢查條件
  • 點火開關在 開啟 位置。
  • 電池正極電壓大於 10.5 volts 且小於 16.5 volts。
判定準則
  • 排氣供油控制閥處於開啟時，排氣供油控制閥驅動器狀態變為短路至高電位之故障狀態。或排氣供油控制閥處於關閉時，排氣供油控制閥驅動器狀態變為短路至低電位之故障狀態。
失效保護與備援功能
無。
OBD-II 驅動循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 18驅動循環模式.
故障排除提示（此故障碼最可能的設定原因如下：）
  • 排氣供油控制閥故障
  • 排氣供油控制閥電路開路/短路或線束損壞，或接頭接觸鬆動
  • ECM 故障
診斷
所需特殊工具：
  • MB993028：VCI-3 套件（含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：VCI-3 套件（不含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
1.檢查排氣供油控制閥本體。
  • 排氣機油控制閥檢查（請參閱供油控制閥 檢查).
Q：檢查結果是否正常？
是
GO TO 2.
否
更換排氣供油控制閥（請參閱 引擎 <4B4> - 引擎機械 - 供油控制閥 -供油控制閥拆卸與安裝）。然後GO TO 7.
2.於排氣供油控制閥接頭進行電壓測量。
  • 斷開接頭，在線束側測量。
  • 點火開關：開啟
  • 端子 IPDM E/R ACT 線與車身搭鐵間之電壓。
OK：系統電壓
Q：檢查結果是否正常？
是
GO TO 3.
否
修復接頭，或檢查並修復 ACT 線對搭鐵短路及開路（介於 IPDM E/R 接頭與排氣供油控制閥接頭之間）。然後GO TO 7.
3.於 ECM 接頭進行電壓測量。
  • 斷開接頭，在線束側測量。
  • 點火開關：開啟
  • 端子 OCVE 與車身搭鐵間之電壓。
OK：系統電壓
Q：檢查結果是否正常？
是
GO TO 4.
否
修復接頭，或檢查並修復 OCVE 線對搭鐵短路及開路（介於排氣供油控制閥接頭與 ECM 接頭之間）。然後GO TO 7.
4.檢查 IPDM E/R 接頭與排氣供油控制閥接頭之間 ACT 線之損壞。
Q：檢查結果是否正常？
是
GO TO 5.
否
修理接頭或線路。然後GO TO 7.
5.檢查排氣供油控制閥接頭與 ECM 接頭之間 OCVE 線之損壞。
Q：檢查結果是否正常？
是
GO TO 6.
否
修理接頭或線路。然後GO TO 7.
6.使用 M.U.T.-III SE 讀取故障碼。
  • 故障碼再確認。
Q：是否設定故障碼 P0013-00？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後GO TO 7.
否
間歇性故障（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障).
7.測試 OBD-II 驅動循環。
以驅動循環模式進行試車。請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 18驅動循環模式.
檢查故障碼。
Q：是否設定故障碼 P0013-00？
是
重新執行故障排除。
否
檢查完成。
