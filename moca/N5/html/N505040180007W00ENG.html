懸吊 - 車輪與輪胎 - 症狀診斷 - 胎壓位置指示器持續顯示
診斷程序
N505040180007W00ENG
1.檢查胎壓
  1. 將點火開關轉至開啟。
    注意：
    請勿啟動引擎。
  2. 檢查所有車輪胎壓並調整至規定值。請參閱輪胎氣壓.
檢查結果是否正常？
是
前往 2。
否
檢查或修復輪胎或車輪。
2.檢查胎壓位置指示器
檢查胎壓位置指示器。
胎壓位置指示器是否持續顯示？
是
GO TO 3.
否
檢查結束
3.執行自我診斷
使用 M.U.T.-III SE
執行「BCM」的「自我診斷」。
是否偵測到故障碼？
是
執行故障碼診斷程序。請參閱故障碼索引.
否
GO TO 4.
4.檢查 BCM 電源與搭鐵電路
執行電源與搭鐵電路故障診斷。請參閱診斷程序.
檢查結果是否正常？
是
更換 BCM。請參閱拆卸與安裝.
否
修理或更換偵測到異常的零件。
