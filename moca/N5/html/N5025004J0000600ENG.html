引擎<4B4> - 直接噴射與多點燃油噴射 (DI 與 MPI) - 故障排除 - 故障碼程序
Code No. P0037-00: 氧氣感測器 (rear) 加熱器控制線路低電位
N5025004J0000600ENG
CIRCUIT 作動
  • 引擎控制繼電器整合於 IPDM E/R 內。
  • 電源由引擎控制繼電器供應至氧氣感測器 (rear) 接頭的加熱器電源端子。
  • 氧氣感測器 (rear) 接頭的加熱器由 ECM 接頭端子 OHRL 的功率電晶體控制。
技術說明
  • 氧氣感測器 (rear) 加熱器的電源供應由 ECM 內功率電晶體的開啟/關閉控制。
  • 加熱氧氣感測器 (rear) 加熱器可使氧氣感測器 (rear) 即使排氣溫度較低時仍能提供良好反應。
監控方法說明
氧氣感測器 (rear) 加熱器電流或電壓超出規定範圍..
監視器執行
連續。
監視器執行條件（其他監視器與感知器）
其他監視器（以下監視項目之記憶體中未設定暫時性故障碼）
  • 不適用
感知器（以下感知器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 引擎起動程序完成後已超過 2 秒。
  • 當氧氣感測器 (rear) 加熱器為開啟狀態時。
  • 電池正極電壓大於 10.5 volts 且小於 16.5 volts。
判定標準
  • O 的狀態2加熱器驅動器呈現失效狀態，為短路-低電位。
失效保護與備用功能
無。
OBD-II 駕駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 6駕駛循環模式.
故障排除提示（設定此故障碼最可能的原因為：）
  • 氧氣感測器 (rear) 加熱器失效
  • 氧氣感測器 (rear) 加熱器線路中發生開路/短路或線束損壞，或接頭接觸不良
  • ECM 失效
