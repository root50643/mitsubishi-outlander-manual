引擎<4B4> - 直接燃油噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. U0431-00: 資料無效 (BCM)
N502501270000700ENG
警告：
若 ECM 中設定故障碼 U0431-00，請務必執行 CAN 匯流排線路診斷。
警告：
確認通訊電路正常後，再更換 ECU。
監控方法說明
從 BCM（車身控制模組 車身 Control Module）接收到無效的 CAN 資料。
監控執行
連續。
監控執行條件（其他監控項目及感測器）
其他監控項目（下列受監控項目的記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器已判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關置於「開啟」位置或引擎啟動後 2 秒。
  • 12V 電池正極電壓大於 10.5 volts 且小於 16.5 volts。
  • Code No. U0141-00: BCM 逾時未發生。
判定標準
  • 來自 BCM 的 CAN 接收訊號異常。
備註
目前故障
  • 此失效／故障可能由 ECM 與 BCM 間 CAN 匯流排線路上之線束與接頭故障、BCM 內部故障或 ECM 內部故障所造成。
過去故障
  • 進行故障排除，著重檢查 ECM（巡迴控制部分）與 BCM 之間 CAN 匯流排線路的線束及接頭是否開路故障。
    注意：
    若為過去發生之故障，即使 CAN 匯流排存在故障，以 M.U.T.-III SE 執行之 CAN 匯流排線路診斷亦可能無法偵測到。因此，請依間歇性故障對應方式檢查 CAN 匯流排線路（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障）。可透過各執行 CAN 通訊之 ECU 所設定之診斷碼，縮小可能故障區域之範圍（請參閱 Electrical and Power Control - LAN System - CAN Fundamental - Basic Inspection - Diagnosis and Repair Workflow -關於 M.U.T.-III SE CAN 匯流排診斷的說明).
失效保護與備援功能
  • 正常作動時，禁止自動熄火。
  • 若在自動熄火期間偵測到故障，則禁止自動啟動。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
故障排除提示 (本故障碼最可能設定原因：)
  • 線束及接頭故障
  • 透過 CAN 通訊由 BCM 傳送至 ECM 的訊號失效／故障
  • BCM 故障
  • ECM 故障
診斷
所需特殊工具：
  • MB993028: VCI-3 套件（含無線轉接器）
    1. -: VCI-3 裝置
    2. MB993029: DLC 線束
    3. MB993030: USB 線束
    4. MB993031: 無線 USB 轉接器 (Qty:2)
  • MB993040: VCI-3 套件（不含無線轉接器）
    1. -: VCI-3 裝置
    2. MB993029: DLC 線束
    3. MB993030: USB 線束
1.STEP 1. 使用 M.U.T.-III SE 讀取其他故障碼。
Q: 是否設定故障碼 U13F0-87 或 U0141-00？
是
診斷碼檢查表（請參閱 檢查表 FOR 故障碼故障碼檢查表).
否
進入 Step 2。
2.STEP 2. 使用 M.U.T.-III SE 讀取其他系統故障碼。
  • 確認 BCM 中是否設定故障碼。
Q: 是否設定故障碼？
是
執行 ETACS 系統故障排除（請參閱 Electrical & Power Control - 車身控制系統 - ECU Diagnosis Information - BCM -故障碼索引).
否
進入 Step 3。
3.STEP 3. 使用 M.U.T.-III SE 讀取故障碼。
  • 故障碼再確認。
再次確認 ECM 中是否設定故障碼。
  1. 清除已設定的故障碼。
  2. 點火開關：關閉 → 開啟
  3. 確認是否設定故障碼。
Q: 是否設定故障碼 U0431-00？
是
更換ECM（請參閱引擎-ECU 拆卸與安裝）。然後進入 Step 4。
否
ECM 與 BCM 之間 CAN 匯流排線路間歇性故障（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障).
4.STEP 4. 使用 M.U.T.-III SE 讀取故障碼。
  • 故障碼再確認。
再次確認 ECM 中是否設定故障碼。
  1. 清除已設定的故障碼。
  2. 點火開關：關閉 → 開啟
  3. 確認是否設定故障碼。
Q: 是否設定故障碼 U0431-00？
是
更換 BCM（請參閱 Electrical & Power Control – 車身控制系統 – 拆卸與安裝 – BCM –拆卸與安裝）。然後進入 Step 5。
否
ECM 與 BCM 之間 CAN 匯流排線路間歇性故障（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障).
5.STEP 5. 測試 OBD-II drive cycle。
  1. 依行駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  2. 檢查故障碼。
