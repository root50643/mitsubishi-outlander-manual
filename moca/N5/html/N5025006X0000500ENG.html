引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0344-00：進氣凸輪軸位置感測器線路間歇性故障（第1列汽缸或單一感測器）
N5025006X0000500ENG
CIRCUIT 作動
請參閱 Code No. P0340-00：進氣凸輪軸位置感測器線路Code No. P0340-00：進氣凸輪軸位置感測器線路
技術說明
進氣凸輪軸位置感測器偵測第1缸壓縮行程的上死點，並將脈衝訊號輸入至 ECM。
監視方法說明
ECM 檢查引擎運轉時，進氣凸輪軸位置感測器的訊號波形是否正常。
監視執行
連續。
監視執行條件（其它監視器與感測器）
其它監視器（下列監視項目的記憶體中未設定暫時故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 引擎運轉期間。
判定條件
  • 進氣凸輪軸位置感測器訊號波形異常。
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱診斷功能 – OBD-II 行駛循環 – Pattern 6行駛循環模式.
故障排除提示（設定此故障碼最可能的原因為：）
  • 進氣凸輪軸位置感測器故障。
  • 進氣凸輪軸位置感測器線路線束損壞或接頭接觸鬆動。
  • ECM 故障。
診斷
所需專用工具：
  • MB993028：含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜

  • 檢查搭鐵線路是否斷路及損壞。

4.檢查進氣凸輪軸位置感測器接頭端子與 ECM 接頭端子 CPI 之間的線束。
  • 檢查輸出線路是否損壞。

修理或更換接頭，或修理損壞的線束導線。然後前往 6。
5.使用 M.U.T.-III SE，讀取故障碼。
