定速控制與駕駛輔助 - 駕駛輔助系統 - 駕駛輔助系統 - 基本檢查 - 更換駕駛監控控制單元時之附加服務
作業程序
N51702032000E300ENG
更換駕駛監控控制單元後，務必執行駕駛監控控制單元配置。
注意：
執行駕駛監控控制單元配置後，必須執行「Factory Mode 關閉」及「Get ECU Information & Send it to MMC Server」。
1.駕駛監控控制單元配置
使用 M.U.T.-III SE 執行駕駛監控控制單元配置。請參閱作業程序.
進至 2.
2.M.U.T.-III SE SYSTEM 資料清單
檢查下列 DMC 資料清單。
  • 項目編號 1：臉部辨識
    OK：「Detected (w/o normal area)」
檢查結果是否正常？
是
GO TO 3.
否
檢查駕駛監控控制單元之安裝狀況（例如：安裝位置、規定扭力、支架彎曲等）。
3.執行自我診斷
使用 M.U.T.-III SE 執行駕駛監控控制單元自我診斷。檢查是否偵測到任何故障碼。
是否偵測到任何故障碼？
是
對偵測到的故障碼執行故障診斷。請參閱故障碼 Index.
否
GO TO 4.
4.執行駕駛輔助控制單元自我診斷
使用 M.U.T.-III SE 執行駕駛輔助控制單元自我診斷。檢查是否偵測到任何故障碼。
是否偵測到任何故障碼？
是
對偵測到的故障碼執行故障診斷。請參閱故障碼 Index.
否
前往 5.
5.GET ECU INFORMATION & SEND IT TO MMC SERVER
注意：
  • 執行「Get ECU Information & Send it to MMC Server」前，務必完成上述程序。
  • 若 ECU 資訊傳送失敗，務必執行「Data Upload」。
  1. 從系統選擇選單中選擇「DMC」。
  2. 進入「Special function」，並選擇「ECU information」。
  3. 在 M.U.T.-III SE 顯示畫面底部按下「Get ECU Information & Send it to MMC Server」。
前往 6.
6.執行原廠模式關閉
  1. 將電動馬達開關的電源開關切換至開啟。
  2. 在「DMC」的「Special Function」畫面中選擇「Factory Mode 關閉」。
  3. 檢查項目編號 1：Factory Mode，並依設定值執行下列程序。
    • 開啟：選擇「確定」並將設定值變更為「關閉」。
    • 關閉：無需動作，作業完成。
作業結束
