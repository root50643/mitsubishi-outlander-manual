引擎<4B4> - 直接噴射與多點燃油噴射（DI 與 MPI）- 故障排除 - 故障碼程序
Code No. P0630-00：車輛識別號碼 (VIN) 故障
N5025008K0000800ENG
技術說明
  • ECM 檢查車輛底盤號碼是否已儲存。
監控方法說明
ECM 檢查 VIN 是否正在輸入。
監測執行
連續。
監測執行條件（其他監測項目與感知器）
其他監測項目（下列監測項目未在記憶體中設定暫時性故障碼）
  • 不適用
感知器（下列感知器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關為「開啟」位置。
判定基準
  • 底盤號碼尚未寫入。
失效保護與備援功能
無。
OBD-II 駕駛循環模式
請參閱 Diagnostic Function、OBD-II Drive Cycle – Pattern 5駕駛循環模式.
故障排除提示（此故障碼最可能的原因如下：）
  • 底盤號碼尚未寫入。
  • ECM 故障。
診斷
所需特殊工具：
  • MB993028：含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
1.檢查底盤號碼是否已寫入。
Q：底盤號碼是否已寫入？
是
前往步驟 2。
否
寫入正確之底盤號碼。然後前往步驟 3。
2.使用 M.U.T.-III SE 讀取故障碼。
  • 再次確認故障碼。
Q：故障碼 P0630-00 是否已設定？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後前往步驟 4。
否
間歇性故障（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障).
3.使用 M.U.T.-III SE 讀取故障碼。
  • 再次確認故障碼。
Q：故障碼 P0630-00 是否已設定？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後前往步驟 4。
否
檢查結束。
4.測試 OBD-II 駕駛循環。
  1. 執行駕駛循環測試。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5駕駛循環模式.
  2. 檢查故障碼。
Q：故障碼 P0630-00 是否已設定？
是
重新執行故障排除。
否
檢查完成。
