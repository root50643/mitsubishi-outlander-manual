詳細流程
1.故障問診
開始檢查前，確認客戶訴求亦相當重要。請仔細詢問客戶訴求，並充分了解症狀。
注意：
客戶並非專業人員。切勿臆測「也許客戶是指···」或「也許客戶提到的是這個症狀」。
前往步驟 2.
2.使用 M.U.T.-III SE 進行自我診斷
使用 M.U.T.-III SE
使用 M.U.T.-III SE 對「MULTI AV」執行自我診斷。請參閱 M.U.T.-III SE 功能M.U.T.-III SE 功能.
注意：
若未顯示「MULTI AV」，則跳至診斷程序之步驟 4。
是否偵測到任何故障碼？
是
GO TO 3.
否
GO TO 4.
3.故障碼故障診斷
  1. 檢查「自我診斷結果」中指示之故障碼。
  2. 偵測到故障碼時，依下列指示進行：
    • 記錄故障碼
    • 凍結畫面資料 (FFD)
  3. 請參閱故障碼索引，執行相關診斷。故障碼索引.
GO TO 5.
4.症狀診斷
請參閱依症狀診斷圖表，執行適用之診斷。症狀表.
GO TO 5.
5.故障零件維修
維修或更換已確認之故障零件。
前往步驟 6.
6.維修確認 (使用 M.U.T.-III SE 自我診斷)
使用 M.U.T.-III SE
  1. 清除自我診斷結果。
  2. 維修或更換特定項目後，再次對「MULTI AV」執行自我診斷。
  3. 檢查「MULTI AV」自我診斷結果中是否偵測到任何故障碼。
是否偵測到任何故障碼？
是
GO TO 3.
否
前往步驟 7.
7.維修確認 (作動測試)
執行作動測試。確認故障症狀已排除或未發生其他症狀。
是否有故障症狀？
是
GO TO 4.
否
