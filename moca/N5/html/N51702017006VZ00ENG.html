1.執行全部故障碼讀取
  1. 警告：
    等待期間，切勿操作車輛（例如鎖定、開啟及關閉車門）。
    將引擎開關關閉，關閉駕駛員車門，並等待 3 分鐘或以上。
  2. 將引擎開關開啟。
  3. 使用 M.U.T.-III SE 執行「全部故障碼」。
  4. 檢查「ICC/ADAS 2」的「自我診斷結果」中是否偵測到乙太網路相關 故障碼（故障碼「U19B5-87」、「U2752-87」<2025 年式以前>和/或「U2752-88」），並檢查「LASER/RADAR」的「自我診斷結果」中是否偵測到乙太網路相關 故障碼（故障碼「C2599-13」和/或「U275F-88」）。

前往步驟 2
否

2.檢查距離感測器接頭
  1. 警告：
    等待期間，切勿操作車輛（例如鎖定、開啟及關閉車門）。
    將引擎開關關閉，關閉駕駛員車門，並等待 3 分鐘或以上。
  2. 斷開/拔除距離感測器的乙太網路線束接頭端子一次，並檢查端子是否有損壞或鬆動。然後，重新連接端子。
  3. 將引擎開關開啟。
  4. 使用 M.U.T.-III SE 執行「全部故障碼」。
  5. 檢查「ICC/ADAS 2」的「自我診斷結果」中是否偵測到乙太網路相關 故障碼（故障碼「U19B5-87」、「U2752-87」<2025 年式以前>和/或「U2752-88」），並檢查「LASER/RADAR」的「自我診斷結果」中是否偵測到乙太網路相關 故障碼（故障碼「C2599-13」和/或「U275F-88」）。
是否偵測到 故障碼「U19B5-87」、「U2752-87」<2025 年式以前>、「U2752-88」、「C2599-13」和/或「U275F-88」？
是
修復或更換故障零件，確實鎖緊線束接頭，並GO TO 3.
否
檢查結束
