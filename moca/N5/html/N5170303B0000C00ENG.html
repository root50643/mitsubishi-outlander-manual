CRUISE CONTROL & DRIVER ASSISTANCE - DRIVE MODE SYSTEM - SYSTEM DESCRIPTION - SYSTEM - Drive Mode 選擇開關
系統說明（AWD Models）
N5170303B0000C00ENG
  • 所有車輛皆配備 drive mode select switch，可透過切換開關在 ECO、NORMAL、TARMAC、GRAVEL、雪及 MUD 之間切換車輛模式。
  • Drive mode 選擇開關會變更動力總成、儀表、底盤功能、AWD 功能及駕駛輔助系統的車輛模式。

控制說明
  • Drive mode 選擇開關透過切換開關（drive mode select switch）切換車輛模式，該開關安裝於中央控制台上方，並變更動力總成、儀表、底盤功能、駕駛輔助系統及 AWD 功能的控制特性。
  • 當點火開關由關閉狀態轉為開啟時，不論點火開關開啟前為何種 drive mode，drive mode select switch 皆以 NORMAL 模式啟動。
  • 車輛特性可自 NORMAL 模式控制至以下任一模式：
    ECO
    此模式透過最佳化動力總成特性，支援環保且經濟的駕駛。
    TARMAC
    此模式於乾燥鋪面道路提供敏捷動態的駕駛樂趣，例如靈敏且強勁的加速、靈敏且線性的轉向手感，以及轉彎時的穩定性與循跡性。
    GRAVEL
    此模式適用於平坦未鋪面道路或濕潤鋪面道路等 rough road 路面行駛，可改善 rough road 上的直進性與強勁的起步加速。部分 ADAS 功能受限。
    雪
    此模式適用於雪地等 slippery road 路面行駛，可提供良好的初始轉向反應及 slippery road 上的高轉彎穩定性。部分 ADAS 功能受限。
    MUD
    此模式適用於泥濘道路及深雪道路等需要最大牽引力的 slippery road 行駛，可提升牽引性能。部分 ADAS 功能受限。
