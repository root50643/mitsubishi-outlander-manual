DRIVER INFORMATION & MULTIMEDIA - AUDIO, VISUAL & NAVIGATION SYSTEM - MULTI AROUND MONITOR - 基本檢查 - 更換環景監視器控制單元時的附加服務
作業程序
N5160407Q0007100ENG
更換環景監視器控制單元後，執行以下程序。
1.更換 MULTI-AROUND MONITOR CONTROL UNIT
更換環景監控控制單元。請參閱拆卸與安裝.
前往步驟 2.
2.寫入 MAC KEY
執行 MAC KEY 寫入。請參閱說明.
GO TO 3.
3.執行配置
注意：
寫入環景監視器控制單元配置之前，一定要先寫入 MAC KEY。
執行設定。請參閱說明.
GO TO 4.
4.校正資料寫入
使用 M.U.T.-III SE 寫入儲存於攝影機內的校正資料。請參閱工作程序診斷程序.
GO TO 5.
5.執行自我診斷
  1. 使用 M.U.T.-III SE (Multi Around Monitor) 執行環景監視器控制單元的自我診斷。
  2. 檢查是否有故障碼被偵測到。
是否偵測到任何故障碼？
是
針對偵測到的故障碼執行故障診斷。請參閱故障碼索引.
否
GO TO 6.
6.作動 檢查
確認環景監視器及攝影機影像（參考線、預期路徑）之作動正常。
GO TO 7.
7.執行 FACTORY MODE 關閉
  1. 將點火開關轉至開啟。
  2. 在 "Multi Around Monitor" 的 "Special Function" 畫面中選取 "Factory Mode 關閉"。
  3. 檢查項目 No.1：Factory Mode，並依設定值執行以下程序。
    • 開啟：選取 "OK"，並將設定值變更為 "關閉"。
    • 關閉：無需動作，工作完成。
工作結束
已加入書籤書籤數量過多。
請刪除後重新加入書籤。
