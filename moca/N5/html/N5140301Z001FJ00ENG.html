診斷程序

1.檢查 接頭
  1. 將點火開關關閉。
  2. 斷開負極端子之電瓶線。
  3. 檢查免鑰匙操作 key unit 之端子與接頭是否有損壞、彎曲及鬆脫（單元側與接頭側）。
檢查結果是否正常？
是
前往步驟 2.
否
修理端子及接頭。
2.檢查線束開路
  1. 斷開/拔除免鑰匙操作 key unit 之接頭。
  2. 檢查免鑰匙操作 key unit 線束接頭端子間之電阻。

是
GO TO 3.
否
修復免鑰匙操作 key unit 分支線路。
3.檢查電源與搭鐵電路
檢查免鑰匙操作 key unit 之電源供應與搭鐵電路。請參閱診斷程序.
檢查結果是否正常？
是 (目前故障)
更換免鑰匙操作 key unit。請參閱拆卸與安裝.
是 (過去故障)
免鑰匙操作 key unit 分支線路偵測到錯誤。
否
修理電源與搭鐵電路。
