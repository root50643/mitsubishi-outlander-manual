引擎<4B4> - 直接噴射與多點燃油噴射（DI 與 MPI）- 故障排除 - 故障碼程序
Code No. P0301-00：第 1 缸失火偵測
N5025006O0000500ENG
技術說明
  • 若引擎運轉時發生失火，引擎轉速會瞬間改變。
  • ECM 會檢查這類引擎轉速變化。
監視方法說明
監視引擎轉速波動，當引擎轉速負向波動過大時判定為故障。
監視執行
連續。
監視執行條件（其他監視與感測器）
其他監視（下列監視項目未在記憶體中設定暫時性故障碼）
  • 燃油系統監視
  • 蒸發排放吹掃系統監視
感測器（下列感測器判定為正常）
  • 車輛 車速 感知器
  • 曲軸角度感知器
  • 空氣流量感測器
  • 引擎冷卻液溫度感測器
  • 大氣壓力感測器
  • 節氣門位置感測器
  • 進氣歧管絕對壓力感測器
  • 燃油噴油嘴（高壓）
  • 燃油壓力感測器
  • 高壓燃油泵
  • 增壓壓力感測器
  • 第 2 進氣溫度感測器
  • 第 3 進氣溫度感測器
故障碼設定條件
檢查條件
  • 引擎轉速大於 600 r/min 且小於 6,000 r/min。
  • 引擎冷卻液溫度高於 -10°C。
  • 大氣壓力高於 76 kPa。
  • 容積效率高於依引擎轉速而定的規定值。
  • 節氣門偏差穩定。
判定準則（以引擎轉速波動用於失火偵測）。
  • 在最近 200 次轉動中，失火發生頻率高於允許值<當觸媒溫度高於 1,000°C 時>。
或
  • 在最近 1,000 次轉動中，失火發生比例達 2.0% 或以上（相當於排氣標準限值之 1.5 倍）。
失效保護與備援功能
可能會切斷失火氣缸的燃油供應。
OBD-II 行駛循環模式
請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 23行駛循環模式.
故障排除提示（設定此故障碼最可能的原因如下：）
  • 點火系統相關零件故障。
  • 第 1 缸燃油噴油嘴故障。
  • 燃油噴油嘴電路線束損壞。
  • 壓縮壓力過低。
  • ECM 故障。
診斷

1.對故障氣缸進行點火花目視檢查。
  • 拆下火花塞並安裝至點火線圈。
  • 連接點火線圈接頭。
  • 斷開/拔除所有燃油噴油嘴接頭。
  • 在引擎啟動時，檢查火花塞是否產生火花。
問：檢查結果是否正常？
是
GO TO 2.
否
檢查檢查程序 - 點火電路系統（請參閱點火電路系統).
2.檢查燃油噴油嘴本體。
  • 燃油噴油嘴檢查（請參閱噴油嘴 檢查).
問：檢查結果是否正常？
是
前往 3。
否
更換燃油噴油嘴（請參閱 –噴油嘴拆卸與安裝）。然後前往 8。
3.檢查大電流保險絲、保險絲座與燃油噴油嘴繼電器接頭之間電源供應線路損壞。
問：檢查結果是否正常？
是
前往 4。
否
修理接頭或線路。然後前往 8。
4.檢查燃油噴油嘴繼電器接頭與第 1 缸燃油噴油嘴接頭之間電源供應線路損壞。
問：檢查結果是否正常？
是
前往 5。
否
修理接頭或線路。然後前往 8。
5.檢查第 1 缸燃油噴油嘴接頭與 ECM 接頭之間 INJ1 線路損壞。
問：檢查結果是否正常？
是
前往 6。
否
修理接頭或線路。然後前往 8。
6.檢查故障氣缸之壓縮壓力。
  • 檢查壓縮壓力（請參閱 引擎<4B4> – 引擎機械 – 車上服務 –壓縮壓力檢查.
問：檢查結果是否正常？
是
前往 7。
否
修理。然後前往 8。
7.使用 M.U.T.-III SE 讀取故障碼。
  • 故障碼再確認。
問：是否設定故障碼 P0301-00？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後前往 8。
否
間歇性故障（請參閱 General Information – General Information – Basic Inspection – Service Information for Electrical Incident –間歇性故障).
8.測試 OBD-II 行駛循環。
  1. 依行駛循環模式進行試車。請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 23行駛循環模式.
  2. 檢查故障碼。
問：是否設定故障碼 P0301-00？
是
重新執行故障排除。
否
檢查完成。
