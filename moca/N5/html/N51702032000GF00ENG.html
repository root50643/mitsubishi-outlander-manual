更換 ADAS 控制單元 2 後，務必執行額外服務。
1.執行程式設計
M.U.T.-III SE
依 M.U.T.-III SE User's Manual 中「Programming」之程序，執行 ADAS 控制單元 2 程式設計。請參閱 M.U.T.-III SE User's Manual。
警告：
  • 程式設計期間，維持下列條件：
    • 點火開關：開啟
    • 電氣負載：關閉
    • 煞車踏板：未踩下
    • 12V 電池電壓：12 – 13.5 V（檢查 M.U.T.-III SE 螢幕上顯示的數值。）
  • ECU 更新後，必須傳送 ECU 更新結果。若 ECU 更新結果傳送失敗，務必執行「Data Upload」。詳細程序請參閱「M.U.T.-III SE User's Manual」。
GO TO 2.
2.ADAS 控制單元 2 配置
執行 ADAS 控制單元 2 配置。請參閱作業程序.
GO TO 3.
3.寫入 MAC 金鑰
執行 MAC 金鑰寫入。請參閱作業程序.
有 MI-PILOT Assist
GO TO 4.
無 MI-PILOT Assist
前往第5步。
4.轉向扭力校正
執行轉向扭力校正。請參閱作業程序.
前往第5步。
5.執行 Factory Mode 關閉
  1. 將點火開關轉至開啟。
  2. 在「ICC/ADAS 2」的「Special Function」畫面中，選擇「Factory Mode 關閉」。
  3. 檢查項目 No.1：Factory Mode，並依設定值執行下列程序。
    • 開啟：選擇「OK」，並將設定值變更為「關閉」。
    • 關閉：無需作業，作業完成。
