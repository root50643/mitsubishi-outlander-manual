引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P219A-00: 氣缸空燃比不均衡 <Vehicles for Taiwan>
N5025048J0000600ENG
技術說明
認為氣缸間的空燃比因氣缸間偏差或燃燒環境差異而不均衡。
監視執行
連續。
監視執行條件（其它監視器與感測器）
其它監視器（下列監視項目的記憶體中未設定暫時故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 在閉迴路空燃比控制下。
  • 引擎轉速介於 1,500 r/min 與 3,000 r/min 之間。
  • 容積效率介於 50 與 160% 之間。
  • 線性空燃比感測器輸出介於 13.5 與 15.5 之間。
  • 燃油噴射模式為 MFI+DFI 模式。
  • 短期燃油修正介於 -25 與 +25% 之間
  • 引擎冷卻液溫度高於 60°C (140°F)。
判定標準
  • 濃淡空燃比峰值次數超過規定值。
  • 在行駛循環期間，ECM 以累計總點火次數 400、執行 5 次監測。
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 18行駛循環模式.
故障排除提示（設定此故障碼最可能的原因為：）
  • 燃油噴射器故障。
  • 燃油噴油嘴（高壓）失效。
  • 進氣口污染。
  • 進氣與排氣氣門周圍有異物。
  • 點火系統相關零件故障。
  • 壓縮不良。
  • 線性空燃比感測器失效。
  • ECM 故障。
診斷
所需專用工具：
  • MB993028：含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器的 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
1.使用 M.U.T.-III SE，讀取故障碼。
  1. 將點火開關轉至「開啟」位置。
  2. 檢查是否設定與 DI 及 MPI 相關的故障碼。
  3. 將點火開關轉至「LOCK」（關閉）位置。
Q: 是否設定了 P219A-00 以外的故障碼？
是
請參閱 故障排除 -故障碼檢查表.
否
前往 2。
2.目視檢查點火花。
  1. 拆下火花塞並安裝至點火線圈。
  2. 連接點火線圈接頭。
  3. 拆下所有燃油噴油嘴接頭。
  4. 引擎啟動時，檢查各火花塞是否產生火花。
Q: 是否有火花？
是
前往 3。
否
請參閱 故障排除 - 症狀程序 -點火電路系統.
3.檢查壓縮。
請參閱 引擎機械 - 開啟車輛維修 -壓縮壓力檢查.
Q: 是否有異常？
是
修理。前往步驟 13。
否
前往 4。
4.檢查燃油噴油嘴。
請參閱 開啟車輛維修 - 燃油噴油嘴檢查 -噴油嘴 檢查.
Q: 測量電阻是否正常？
是
前往 5。
否
更換故障的燃油噴油嘴（請參閱噴油嘴拆卸與安裝）。然後前往步驟 13。
5.檢查進氣歧管污染及進氣口污染。
Q: 進氣歧管與進氣口是否堵塞？
是
修理進氣歧管及進氣口污染。然後前往步驟 13。
否
前往 6。
6.檢查進氣與排氣氣門周圍是否有異物。
Q: 是否有異物？
是
修理後，前往步驟 13。
否
前往 7。
7.檢查燃油噴油嘴（高壓）。
請參閱 開啟車輛維修 - 燃油噴油嘴（高壓）檢查 -噴油嘴 檢查.
Q: 測量電阻是否正常？
是
前往 8。
否
更換故障的燃油噴油嘴（高壓）（請參閱噴油嘴（高壓）拆卸與安裝）。然後前往步驟 13。
8.檢查高壓燃油管路。
以目視檢查及氣味檢查，檢查從燃油泵（高壓）至燃油噴油嘴（高壓）的高壓燃油管路周圍。確認無燃油滲漏及燃油洩漏。
Q: 是否有異常？
是
修理後，前往步驟 13。
否
前往 9。
9.檢查線性空燃比感測器與 ECM 接頭之間 LHFL、L+FL 及 L-FL 線路的線束損壞。
Q: 線束導線是否正常？
是
GO TO 10.
否
修理接頭或線路。然後前往步驟 13。
10.更換線性空燃比感測器。
  1. 更換線性空燃比感測器（請參閱 引擎 <4B4> - 進排氣 - 觸媒轉換器 -三元催化器拆卸與安裝<FWD (FRONT)>,三元催化器拆卸與安裝<AWD (FRONT)>).
  2. 依行駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle – Pattern 18行駛循環模式.
  3. 檢查故障碼。
Q: 是否設定故障碼 P219A-00？
是
GO TO 11.
否
檢查完成。
11.更換燃油噴油嘴。
  1. 更換燃油噴油嘴（請參閱噴油嘴拆卸與安裝).
  2. 依行駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle – Pattern 18行駛循環模式.
  3. 檢查故障碼。
Q: 是否設定故障碼 P219A-00？
是
進行步驟 12。
否
檢查完成。
12.更換燃油噴油嘴（高壓）。
  1. 更換燃油噴油嘴（高壓）（請參閱噴油嘴（高壓）拆卸與安裝).
  2. 依行駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle – Pattern 18行駛循環模式.
  3. 檢查故障碼。
Q: 是否設定故障碼 P219A-00？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後前往步驟 13。
否
檢查完成。
13.測試 OBD-II 行駛循環。
  1. 將點火開關轉至「開啟」位置並清除故障碼。
  2. 依行駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle – Pattern 18行駛循環模式.
  3. 檢查故障碼。
Q: 是否設定故障碼 P219A-00？
是
重新執行故障排除。
否
檢查完成。
