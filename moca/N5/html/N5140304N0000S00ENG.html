電氣與電源控制 - LAN系統 - CAN網關 - 基本檢查 - 更換CAN網關時的附加服務 - 8CH CAN網關
作業程序
N5140304N0000S00ENG
說明
更換8CH CAN網關時，必須執行以下程序。
作業程序
1.更換8CH CAN網關
更換8CH CAN網關。請參閱拆卸及安裝.
進行步驟 2.
2.執行8CH CAN網關程式設計
注意：
ECU更新後，必須傳輸ECU更新結果。
若ECU更新結果傳輸失敗，務必執行「Data Upload」。
詳細程序請參閱「M.U.T.-III SE User's Manual」。
M.U.T.-III SE
執行8CH CAN網關程式設計。請參閱「M.U.T.-III SE User's Manual」。
注意：
程式設計期間，維持以下條件：
  • 點火開關：開啟
  • 電氣負載：關閉
  • 12V電池電壓：10.5 V以上
進行步驟 3.
3.底盤號碼（CHASSIS NO.）寫入
M.U.T.-III SE
  1. 在系統選擇畫面選擇「8ch CAN網關」。
  2. 選擇「Special Function」，然後選擇「Chassis No./VIN Registration」
  3. 依畫面上的指示寫入底盤號碼。
注意：
詳細程序請參閱「M.U.T.-III SE User's Manual」。
進行步驟 4.
4.檢查所有ECU自我診斷結果
  1. 使用M.U.T.-III SE清除所有ECU自我診斷結果。
  2. 將點火開關關閉。
  3. 將點火開關轉至開啟位置，並等待2秒以上。
  4. 檢查所有ECU自我診斷結果是否無CAN通訊故障碼（例如U1000及U1001）。
進行步驟 5.
5.更換KOS&OSS-ECU
更換KOS&OSS-ECU。請參閱 車身外觀、車門、車頂與車輛安全 - 車門與鎖 - 拆卸與安裝 - KEYLESS OPERATON KEY UNIT -拆卸及安裝.
