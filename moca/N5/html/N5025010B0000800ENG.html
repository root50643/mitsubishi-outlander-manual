引擎<4B4> - 直接噴射與多點燃油噴射 (DI 與 MPI) - 故障排除 - 故障碼程序
代碼編號 P1603-00：電瓶備援電路故障
N5025010B0000800ENG
CIRCUIT 作動
  • 電源直接由電瓶供應至 ECM 接頭端子 +BB。
技術說明
  • ECM 檢查電瓶備援線路之開路。
監控方法說明
電瓶備援線路電壓低於規定值。
監視器執行
連續。
監視器執行條件（其他監視器與感知器）
其他監視器（以下監視項目之記憶體中未設定暫時性故障碼）
  • 不適用
感知器（以下感知器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關位於「開啟」位置。
判定條件
  • 電瓶備援電壓狀態變為短路偏低之故障狀態。
失效保護與備用功能
無。
OBD-II 駕駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 3駕駛循環模式.
故障排除提示（設定此故障碼最可能的原因為：）
  • 電瓶備援線路電路開路/短路或線束損壞，或接頭接觸鬆動
  • ECM 失效
診斷
所需特殊工具：
  • MB993028：附無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
1.使用 M.U.T.-III SE 讀取故障碼。
  • 暫時將點火開關置於 LOCK（鎖定）位置，10 秒後再將其置於 開啟（開啟）位置。
問：是否設定故障碼 P1603-00？
是
前往 2。
否
檢查完成。
2.於 ECM 接頭執行電壓測量。
  • 斷開接頭，並於線束側測量。
  • 端子 +BB 與車身搭鐵之間的電壓。
OK: 系統電壓
Q：檢查結果是否正常？
是
GO TO 3.
否
修復接頭，或檢查並修復電瓶與 ECM 接頭之間 +BB 線路之開路及短路。然後GO TO 5.
3.檢查電瓶與 ECM 接頭之間 +BB 線路之損壞。
Q：檢查結果是否正常？
是
GO TO 4.
否
修理接頭或線路。然後GO TO 5.
4.使用 M.U.T.-III SE 讀取故障碼。
  • 故障碼再確認。
問：是否設定故障碼 P1603-00？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後GO TO 5.
否
間歇性故障（請參閱一般資訊 - 一般資訊 - 基本檢查 - 電氣事件維修資訊 -間歇性故障).
5.測試 OBD-II 駕駛循環。
  1. 以驅動循環模式執行路試。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 3駕駛循環模式.
  2. 檢查故障碼。
