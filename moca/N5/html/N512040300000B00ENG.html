駕駛控制 - 雨刷與清洗器 - 基本檢查 - 診斷與維修作業流程

詳細流程
1.取得症狀資訊
  1. 向客戶取得症狀的詳細資訊（事件/故障發生時的狀況與環境）。
  2. 檢查故障功能的作動狀況。
前往步驟 2.
2.檢查 故障碼
  1. 檢查 故障碼.
  2. 若偵測到故障碼，執行下列程序。
    • 記錄故障碼及凍結框架資料（使用 M.U.T.-III SE 列印。）
    • 清除故障碼.
    • 研究故障碼所偵測到的原因與客戶所述症狀之間的關係。
  3. 檢查相關服務公告以取得資訊。
是否有描述症狀且是否偵測到故障碼？
有描述症狀，有偵測到故障碼
前往步驟 3.
有描述症狀，未偵測到故障碼
前往步驟 4.
未描述症狀，有偵測到故障碼
前往步驟 5.
3.確認症狀
試著確認客戶所描述的症狀。
同時研究與該症狀相關的正常作動及失效保護。
確認症狀與症狀被偵測到時的狀況之間的關係。
前往步驟 5.
4.確認症狀
試著確認客戶所描述的症狀。
確認症狀與症狀被偵測到時的狀況之間的關係。
前往步驟 6.
5.執行故障碼確認程序
執行所偵測故障碼之故障碼確認程序, 然後確認該故障碼是否再次出現。此時務必保持 M.U.T.-III SE 與車輛連接, 並即時檢查自我診斷結果。
若偵測到兩個或更多 故障碼，請參閱故障碼檢查優先順序表，並決定故障診斷順序。
注意：
  • 若未偵測到故障碼，凍結畫面資料很有用。
  • 若維修手冊中未包含故障碼確認程序，則執行元件功能檢查。此簡化檢查程序雖然在此檢查期間無法偵測故障碼，但仍是有效的替代方法。
    若元件功能檢查結果為 NG，則與故障碼確認程序偵測到故障碼相同。
是否偵測到故障碼？
是
前往步驟 7.
否
依間歇性故障進行檢查間歇性故障.
6.以症狀診斷偵測故障系統
依據步驟 4 所確認的症狀，以症狀診斷偵測故障系統，並依可能原因與症狀決定故障診斷順序。
是否有描述症狀？
是
前往步驟 7.
否
使用 M.U.T.-III SE 監控相關感測器的輸入資料，或檢查相關模組端子的電壓。
7.依診斷程序偵測故障零件
依系統的診斷程序進行檢查。
是否偵測到故障零件？
是
前往步驟 8.
否
依間歇性故障進行檢查間歇性故障.
8.維修或更換故障零件
  1. 維修或更換故障零件。
  2. 維修與更換後，重新連接診斷程序期間斷開的零件或接頭。
  3. 檢查故障碼。若偵測到故障碼，將其清除。
前往步驟 9.
9.最終檢查
當在步驟 2 偵測到故障碼時，再次執行故障碼確認程序，然後確認故障已確實修復。
當客戶有描述症狀時，請參閱步驟 3 或 4 所確認的症狀，並確認症狀不再出現。
是否偵測到故障碼且症狀仍存在？
是-1
偵測到故障碼：前往步驟 7.
是-2
症狀仍存在：前往步驟 4.
否
將車輛交還客戶前，務必清除故障碼。
