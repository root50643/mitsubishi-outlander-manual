系統說明
N5110102T0007W00ENG
系統圖
DF100B7GAE00ENG
說明
  • 免鑰匙操作 key unit 內建功耗控制功能，可依車輛狀態降低功耗。
  • 免鑰匙操作 key unit 依透過 CAN 通訊自 BCM 接收到的睡眠喚醒訊號，變更其狀態（控制模式）。
    正常模式（喚醒）
    • 與其他控制單元的 CAN 通訊正常執行。
    • 免鑰匙操作 key unit 的個別單元控制正常執行。
    低功耗模式（睡眠）
    • 低功耗控制作用中。
    • CAN 傳輸已停止。
睡眠模式啟動
  • 當點火開關關閉且下列條件均不存在時，免鑰匙操作 key unit 判定睡眠就緒條件已滿足。然後透過 CAN 通訊向 BCM 傳送睡眠就緒訊號（ready）。
    • 輸出訊號至作動器
    • 正透過 CAN 通訊自控制單元接收輸出請求。
  • 當免鑰匙操作 key unit 自 BCM 接收到睡眠喚醒訊號（sleep）且睡眠就緒條件已滿足時，停止 CAN 通訊並進入低功耗模式。
喚醒作動
  • 當免鑰匙操作 key unit 自 BCM 接收到睡眠喚醒訊號（wake up），或符合下列任一條件時，由低功耗模式變更為正常模式。此外，透過 CAN 通訊.sessionDisplay 向 BCM 傳送睡眠就緒訊號（not-ready），以通報 CAN 通訊開始。
    • 點火開關開啟
    • 按鈕式點火開關狀態變化。
    • 各車門需求開關狀態變化。
    • 透過 CAN 通訊自控制單元接收到輸出需求。
