詳細流程
1.故障訪談
開始檢查前，確認客戶反映的問題也非常重要。請仔細訪談客戶所反映的問題，並充分了解症狀。
注意：
顧客並非專業人員。切勿臆測「也許顧客是指···」或「也許顧客曾提到此症狀」。
前往 2.
2.使用 M.U.T.-III SE 進行自我診斷
使用 M.U.T.-III SE
使用 M.U.T.-III SE 對「E-HUD」執行自我診斷。請參閱 M.U.T.-III SE 功能CONSULT 功能.
注意：
若未顯示「E-HUD」，則跳至診斷程序步驟 4。
是否偵測到任何故障碼？
是
前往 3.
否
GO TO 4.
3.故障碼故障診斷
  1. 檢查「自我診斷結果」中所指示的故障碼。
  2. 偵測到故障碼時，請依下列指示操作：
    • 記錄故障碼
    • Freeze Frame Data (FFD)
  3. 參閱故障碼索引執行相關診斷。請參閱故障碼索引.
注意：
若偵測到故障碼「U1000‐01」，請先診斷 CAN 通訊系統。
前往 5.
4.症狀診斷
依症狀診斷表執行適用之診斷。請參閱症狀表症狀表.
前往 5.
5.故障零件維修
維修或更換已判定的故障零件。
GO TO 6.
6.維修確認（使用 M.U.T.-III SE 自我診斷）
使用 M.U.T.-III SE
  1. 清除自我診斷結果。
  2. 修復或更換特定項目後，再次對「E-HUD」執行自我診斷。
  3. 檢查「E-HUD」自我診斷結果中是否偵測到任何故障碼。
是否偵測到任何故障碼？
是
前往 3.
否
GO TO 7.
7.維修確認（作動測試）
執行作動測試。確認故障症狀已排除，且未出現其他症狀。
是否有故障症狀？
是
GO TO 4.
否
