煞車 - 煞車控制系統 - 配備 VDC - 故障碼/電路診斷 - C1073-55 真空感知器
診斷程序
N50603026001LH00ENG
1.檢查 接頭
  1. 斷開/拔除 12V 電池負極端子。
  2. 檢查煞車真空感知器線束接頭是否斷開或鬆脫。
  3. 檢查 ABS 作動器及電動單元（控制單元）線束接頭是否脫開或鬆動。
檢查結果是否正常？
是
進至 2.
否
修復/更換線束或接頭。進至 2.
2.檢查 端子
  1. 斷開/拔除煞車真空感知器線束接頭。
  2. 檢查煞車真空感知器端子是否損壞，或與線束接頭連接鬆脫。
  3. 斷開/拔除 ABS 作動器及電動單元（控制單元）線束接頭。
  4. 檢查 ABS 作動器及電動單元（控制單元）端子是否有損壞，或與線束接頭連接鬆動。
檢查結果是否正常？
是
GO TO 3.
否
修復／更換線束、接頭或端子。

4.更換煞車真空感知器
使用 M.U.T.-III SE
  1. 連接 ABS 作動器及電動單元（控制單元）線束接頭。
  2. 更換煞車真空感知器。請參閱拆卸與安裝拆卸與安裝.
  3. 連接 12V 電池負極端子。
  4. 清除「ABS」之自我診斷結果。
  5. 點火開關關閉（Auto ACC 功能關閉）→ 開啟 → 關閉（Auto ACC 功能關閉）。
  6. 啟動引擎。
    備註：
    引擎啟動後至少等待 10 秒。
  7. 執行「ABS」之自我診斷。
