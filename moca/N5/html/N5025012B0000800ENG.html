引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. U0651-00：EGR 感測器 SENT 通訊
N5025012B0000800ENG
線路作動
  • ECM接頭端子EGRT向EGR氣體溫度感知器輸出端子施加5 V電源電壓。
  • 電源電壓從 EGR 排氣溫度感測器接頭端子搭鐵至 ECM 接頭端子 ETSE。
監控方式說明
與 EGR 感測器的 SENT 通訊在指定期間內中斷或無效。
監視執行
連續。
監視執行條件（其它監視與感測器）
其它監視（下列監視項目的記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 引擎起動後 2 秒。
  • 12V 電瓶正極電壓大於 10.5 volts 且小於 16.5 volts。
判定標準
  • SENT 訊號設定為失效狀態值，或 SENT 訊號未傳送。
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 3行駛循環模式.
故障排除提示（設定此代碼最可能的原因為：）
  • EGR 差壓感測器
  • EGR 差壓感測器線路開路／短路或線束損壞，或接頭接觸鬆脫
  • ECM 故障
診斷
所需特殊工具：
  • MB993028: VCI-3 kit with wireless adapters

    2. MB993029: DLC cable
    3. MB993030: USB cable
    4. MB993031: Wireless USB adapter (Qty:2)
  • MB993040: VCI-3 kit without wireless adapters
    1. -: VCI-3 device
    2. MB993029: DLC cable
    3. MB993030: USB cable

  • 端子 ECM EGR5 線路與搭鐵之間的電壓。
