2.檢查 ABS 作動器及電動單元（控制單元）電源與搭鐵電路
檢查 ABS 作動器及電動單元（控制單元）電源與搭鐵電路。請參閱診斷程序.
檢查結果是否正常？
是
GO TO 3.
NO
修理/更換線束、接頭、端子、保險絲或大電流保險絲。
3.檢查接頭與端子
  1. 斷開/拔除 12V 電池負極端子。
  2. 斷開/拔除 ECM 線束接頭。
  3. 斷開/拔除 ABS 作動器及電動單元（控制單元）線束接頭。
  4. 檢查接頭是否脫落或鬆動。
  5. 檢查端子是否損壞，或與線束接頭的連接是否鬆動。
檢查結果是否正常？
是
GO TO 4.
NO
修理/更換線束、接頭或端子，並確實鎖緊接頭。GO TO 4.
4.執行自我診斷
使用 M.U.T.-III SE
  1. 連接 ECM 線束接頭。
  2. 連接 ABS 作動器及電動單元（控制單元）線束接頭。
  3. 連接 12V 電池負極端子。
  4. 清除「ABS」的自我診斷結果。
  5. 點火開關關閉（Auto ACC 功能關閉）。
  6. 啟動引擎。
    注意：
    引擎起動後至少等待 10 秒。
  7. 執行「ABS」自我診斷。
是否偵測到故障碼？
是
