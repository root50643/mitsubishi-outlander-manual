功能
BCM
辨識以下狀態，並經由 CAN 通訊傳送至駕駛座控制單元。
  • 點火 開啟 訊號
  • 車門鎖定狀態訊號（經由免鑰匙操作鑰匙、前車門請求開關作動）
  • 鑰匙 ID 訊號
駕駛座控制單元
請參閱駕駛座控制單元.
說明
  • 透過連結免鑰匙操作鑰匙與自動駕駛位置調整器系統，當免鑰匙操作鑰匙或駕駛側車門請求開關執行解鎖作動時，將執行記憶功能及進出輔助功能。
  • 免鑰匙操作鑰匙連鎖功能的登錄可將不同的鑰匙 ID 逐一登錄至駕駛座控制單元，分別對應記憶開關 1 和 2。合計可登錄 2 個鑰匙 ID。
  • 當點火開關為 關閉，且使用免鑰匙操作鑰匙或駕駛側車門請求開關執行車門解鎖作動時，駕駛座除座椅滑動外將自動調整至駕駛位置。座椅滑動執行復位作動並設定為待命狀態。
  • 在待命狀態下，當點火開關從 關閉 操作至 開啟 時，復位作動將座椅滑動設定至已登錄位置。
注意：
  • 當將另一個鑰匙 ID 新登錄至已登錄鑰匙 ID 的鑰匙開關時，先前登錄的鑰匙 ID 將被覆寫而無法使用。
  • 當復位作動期間點火開關訊號轉為 開啟 時，作動將中斷；點火開關訊號從 開啟 轉為 關閉 後，作動重新開始。
  • 有關免鑰匙操作鑰匙連鎖儲存程序的更多資訊。請參閱說明.
作動程序
  1. 使用免鑰匙操作鑰匙、前車門請求開關解鎖駕駛側車門。
  2. 執行座椅滑動記憶功能以外的作動。座椅滑動執行離車輔助作動。
  3. 點火開關為開啟。
  4. 駕駛座將從離車位置復位至進車位置。
作動條件
須符合以下所有項目。若未符合這些項目，則不執行免鑰匙操作鑰匙連鎖功能。
