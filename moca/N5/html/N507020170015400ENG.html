轉向 - 轉向控制系統 - 故障碼/電路診斷 - C1608-52 CONTROL UNIT
診斷程序
N507020170015400ENG
1.檢查 FFD
使用 M.U.T.-III SE
  1. 檢查動力轉向控制模組的 FFD。
  2. 讀取 Item No.28 "Internal fault code (for 故障碼)" 的數值。
是否設定 "0111"？
是
檢查動力轉向控制模組過熱保護控制。請參閱說明。然後前往 2.
否
前往 2.
2.執行自我診斷
使用 M.U.T.-III SE
  1. 點火開關由關閉轉至開啟。
  2. 清除 "EPS/DAST 3" 的自我診斷結果。
  3. 拉動駐車煞車開關。
    注意：
    檢查駐車煞車開關指示燈是否亮起。
  4. 點火開關關閉。
  5. 離開車輛並關閉所有車門。
  6. 等待 65 秒。
    注意：
    • 檢查駐車煞車開關指示燈是否熄滅。
    • 若後煞車卡鉗溫度偏高，請等待一小時，以免駐車煞車開關指示燈誤熄滅。
  7. 啟動引擎。
  8. MI-PILOT 系統為 開啟*1, 行駛車輛。
    注意：
    請務必安全駕駛。
    注意：
    *1:配備 MI-PILOT 系統的車輛
  9. 停止車輛。
  10. 對「EPS/DAST 3」執行自我診斷。
是否偵測到故障碼 "C1608–52"？
是
更換動力轉向控制模組（轉向齒條總成）。請參閱拆卸與安裝.
否
檢查各線束接頭端子及連接是否有故障狀況。
