Code No. P2138-00：加速踏板位置感測器（主與副）範圍/性能問題

CIRCUIT 作動
  • 請參閱 Code No. P2122-00：加速踏板位置感測器（主）電路低輸入Code No. P2122-00：加速踏板位置感測器（主）電路低輸入.
  • 請參閱 Code No. P2127-00：加速踏板位置感測器（副）電路低輸入Code No. P2127-00：加速踏板位置感測器（副）電路低輸入.
技術說明
  • ECM 檢查加速踏板位置感測器輸出訊號特性是否有異常狀況。
監控方法說明
若加速踏板位置感測器（主）與加速踏板位置感測器（副）之間的關係異常，則判定為故障。
監視器執行
連續。
監視器執行條件（其他監視器與感知器）
其他監視器（以下監視項目之記憶體中未設定暫時性故障碼）
  • 不適用
感知器（以下感知器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關位於「開啟」位置。
  • 加速踏板位置感測器（主）輸出電壓大於 0.2 V 且小於 4.8 V。
  • 加速踏板位置感測器（副）輸出電壓大於 0.2 V 且小於 4.8 V。
  • 電瓶正極電壓高於 6.2 V。
判定條件
  • 加速踏板位置感測器（副）與加速踏板位置感測器（主）輸出之間的差異為 4.25% - 23.6% 或以上。
失效保護與備用功能
節氣門開度位置處於預設位置。
OBD-II 駕駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 3駕駛循環模式.
故障排除提示（設定此故障碼最可能的原因為：）
  • 加速踏板故障
  • 線束與接頭故障
  • ECM 失效
診斷
所需特殊工具：
  • MB993028：附無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
