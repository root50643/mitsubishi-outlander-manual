N506030260060100ENG
1.調整轉向角感測器之中立位置
使用 M.U.T.-III SE
執行轉向角感測器中立位置調整。請參閱作業程序.
前往 2.
2.執行自我診斷 (1)
使用 M.U.T.-III SE
  1. 點火開關關閉（Auto ACC 功能關閉）。
  2. 啟動引擎。
    注意：
    引擎啟動後至少等待 10 秒。
  3. 執行「ABS」自我診斷。
是否偵測到故障碼 "C106E-64"？
是
顯示 "作用中故障碼"：前往 3.
是
顯示 "儲存故障碼"：檢查結束（清除自我診斷結果的記憶。）
否
檢查結束
3.檢查 接頭
  1. 斷開 12V 電瓶負極端子。
  2. 檢查 ABS 作動器與電動單元（控制單元）線束接頭是否脫開或鬆脫。
  3. 檢查轉向角感測器線束接頭是否脫落或鬆動。
檢查結果是否正常？
是
前往 5.
否
修理／更換線束或接頭，並確實鎖緊接頭。GO TO 4.
4.執行自我診斷 (2)
使用 M.U.T.-III SE
  1. 連接 12V 電瓶負極端子。
  2. 啟動引擎。
    注意：
    引擎啟動後至少等待 10 秒。
  3. 執行「ABS」自我診斷。
是否偵測到故障碼 "C106E-64"？
是
顯示 "作用中故障碼"：前往 5.
是
顯示 "儲存故障碼"：檢查結束（清除自我診斷結果的記憶。）
否
檢查結束

8.檢查 ABS 作動器與電動單元（控制單元）電源及搭鐵電路

9.檢查 端子
  1. 斷開 12V 電瓶負極端子。
  2. 檢查轉向角感測器端子是否損壞，或與線束接頭連接鬆動。
檢查結果是否正常？
是
GO TO 10.
否
修理／更換線束、接頭或端子。
10.檢查 CAN 通訊線路
  1. 連接轉向角感測器線束接頭。
  2. 連接保險絲座 (J/B) 線束接頭。
  3. 連接 12V 電瓶負極端子。
  4. 檢查 CAN 通訊線路。請參閱故障診斷流程圖.
檢查結果是否正常？
是
GO TO 11.
否
修復/更換線束或接頭。
11.檢查資料監視器
使用 M.U.T.-III SE
  1. 依序選取 "ABS"、"資料清單" 及 "Steering wheel angle"。
  2. 檢查從中立位置左右轉動方向盤時，指示是否隨轉向角變化。請參閱參考值.
檢查結果是否正常？
是
更換 ABS 作動器與電動單元（控制單元）。請參閱拆卸與安裝.
否
更換轉向角感測器。請參閱拆卸與安裝.
