引擎<4B4> - 直接燃油噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P059F-00: Active Grille Air Shutter Performance/Stuck 關閉
N5025008C0000400ENG
電路作動
  • 引擎控制繼電器合併於 IPDM E/R 內。
  • 電源由 IPDM E/R 接頭端子 ACT4 供應至主動進氣格柵接頭電源端子 (P+)。
  • 主動進氣格柵接頭搭鐵端子 (E) 搭鐵至車身。
  • 訊號經由 LIN 通訊（區域連網通訊）於 ECM 接頭端子 LNGS 與主動進氣格柵接頭通訊端子 (S) 之間傳送與接收。
技術說明
  • ECM 依行駛狀況經由 LIN 通訊（區域連網通訊）指示主動進氣格柵開啟或關閉。
注意：
引擎警告燈不會點亮，可能僅顯示 GPF 警告標記（紅色）。此為鼓勵駕駛以使 GPF 得以再生。
監控方法說明
實際格柵活板位置與目標格柵活板位置之間的差值超過規定值。
監控執行
連續。
監控執行條件（其他監控及感測器）
其他監控（下列監控項目之記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 引擎冷卻液溫度感測器
  • No. 1 進氣溫度感測器
故障碼設定條件
檢查條件
  • 點火開關位於 開啟 位置。
  • 電瓶正極電壓大於 10.96 V 且小於 16 V。
判定基準
  • 來自主動進氣格柵的訊號狀態為「circuit fail」、「high temperature fail」或「functional fail」
失效保護及備援功能
無。
OBD-II 行程循環模式
請參閱診斷功能、OBD-II Drive Cycle – Pattern 16行程循環模式.
故障排除提示（此故障碼最可能之設定原因如下：）
  • 主動進氣格柵凍結或卡住異物。
  • 作動器故障。

1.主動進氣格柵目視檢查
確認主動進氣格柵未凍結且未卡住異物。
Q：檢查結果是否正常？
是
進入步驟 2。
否
修理主動進氣格柵（請參閱車身 Exterior, Doors, Roof & 車輛 Security - Exterior - 系統說明 - 元件 - Active Grille Shutter System -元件位置）。然後轉至 4.
2.主動進氣格柵作動檢查
依下列程序檢查主動進氣格柵之作動。
點火開關為「LOCK（關閉）」位置。
以手關閉主動進氣格柵。
點火開關為「開啟」位置。
主動進氣格柵自動開啟。
Q：檢查結果是否正常？
是
間歇性故障（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障).
否
進入步驟 3。
3.使用 M.U.T.-III SE 讀取故障碼。
  • 故障碼再確認。
問：是否設定故障碼 P059F-00？
是
修理主動進氣格柵（請參閱車身 Exterior, Doors, Roof & 車輛 Security - Exterior - 系統說明 - 元件 - Active Grille Shutter System -元件位置）。然後轉至 4.
否
檢查完成。
4.測試 OBD-II 行程循環。
  1. 以驅動循環模式執行試車。請參閱診斷功能 - OBD-II Drive Cycle - Pattern 16行程循環模式.
  2. 檢查故障碼。
問：是否設定故障碼 P059F-00？
是
重新執行故障排除。
否
檢查完成。
