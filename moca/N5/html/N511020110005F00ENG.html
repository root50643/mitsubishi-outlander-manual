執行下列程序可自動啟動 ECM 與免鑰匙操作鑰匙單元的重新通訊，但僅限於以更換新 ECM 時*。詳情請參閱作業程序.
*：新件係指未曾通電的原廠 ECM。
（在此步驟中，無需使用 M.U.T.-III SE 進行初始化程序）
警告：
更換 ECM 時，務必以更換新件。
若重複使用其他車輛的 ECM，則 ECM 所控制的功能將無法正常運作。
注意：
  • 若更換的 ECM 並非全新件，則必須使用 M.U.T.-III SE 執行指定程序（免鑰匙操作鑰匙單元初始化及免鑰匙操作鑰匙註冊）。
  • 若鑰匙座上附有多把鑰匙，開始作業前請將其分開。
  • 區分未註冊鑰匙 ID 的鑰匙與已註冊 ID 的鑰匙。
