詳細流程
1.故障問診
開始檢查前，釐清客戶疑慮亦十分重要。請仔細向客戶問診並充分瞭解症狀。
注意：
客戶並非專業人員。切勿臆測「也許客戶是指···」或「也許客戶提到這個症狀」。
GO TO 2.
2.使用 M.U.T.-III SE 進行自我診斷
使用 M.U.T.-III SE
使用 M.U.T.-III SE 對「Wireless charger」執行自我診斷。請參閱 M.U.T.-III SE 功能M.U.T.-III SE 功能.
注意：
若未顯示「Wireless charger」，則跳至診斷程序第 4 步驟。
是否偵測到任何故障碼？
是
GO TO 3.
NO
GO TO 4.
3.故障碼故障診斷
  1. 檢查「Self Diagnostic Result」中所指示的故障碼。
  2. 偵測到故障碼時，請依下列指示進行：
    • 記錄故障碼
    • 定格資料 (FFD)
  3. 請參閱故障碼索引，執行相關診斷。請參閱故障碼索引.
GO TO 6.
4.重設系統
斷開並重新連接電瓶負極 (-) 端子。請參閱「Required Procedure After 電池 Disconnection」（一般資訊 - 基本檢查 - 檢查與調整 - 拆下電瓶負極端子時之額外服務）電瓶斷開後必要程序.
GO TO 8.
5.症狀診斷
請依症狀診斷圖執行適用之診斷。請參閱症狀表依症狀診斷表.
GO TO 6.
6.故障零件維修
維修或更換已確認之故障零件。
GO TO 7.
7.維修檢查 (使用 M.U.T.-III SE 自我診斷)
使用 M.U.T.-III SE
  1. 清除自我診斷結果。
  2. 維修或更換特定項目後，請再次對「Wireless charger」執行自我診斷。
  3. 檢查「Wireless charger」自我診斷結果中是否偵測到任何故障碼。
是否偵測到任何故障碼？
是
GO TO 3.
NO
GO TO 8.
8.維修檢查 (作動測試)
執行作動測試。確認故障症狀已排除或未出現其他症狀。
是否有故障症狀？
是
GO TO 5.
NO
