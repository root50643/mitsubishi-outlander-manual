引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0132-00：線性空燃比感測器電路電壓過高
N5025005O0000900ENG
電路作動
線性空燃比感測器與 ECM 透過下列 3 條線路連接，以偵測空燃比。
  • 線性空燃比感測器與 ECM 接頭端子 L+FL 之間的線路，用於偵測空燃比。
  • 線性空燃比感測器與 ECM 接頭端子 L-FL 之間的線路連接至搭鐵。
技術說明
  • ECM 依據線性空燃比感測器訊號進行空燃比回饋控制。
  • 若線性空燃比感測器劣化，將由氧氣感測器（後）進行修正。
監控方法說明
若三條線路電壓中有一條過高，或三條線路電壓皆過高，則設定故障碼為故障。
監視執行
連續。
監視執行條件 (其他監視器與感知器)
其他監視器 (以下監視項目在記憶體中未設定暫時性故障碼)
  • 線性空燃比感知器監控
  • 線性空燃比感知器加熱器監控
  • 氧氣感知器（後）加熱器監控
  • 失火監測
  • 燃油系統監測
感知器 (以下感知器判定為正常)
  • 空氣流量感測器
  • 引擎冷卻液溫度感測器
  • 1號進氣溫度感測器
  • 大氣壓力感測器
  • 節氣門位置感測器
  • 進氣歧管絕對壓力感知器
故障碼設定條件
檢查條件
  • 電池正極電壓大於 10.5 volts 且小於 16.5 volts。
  • 自引擎啟動程序完成後已超過 40 秒。
判定基準
  • 線性空燃比感測器正極端子輸出電壓超過 4.7 volts 達 2 秒。
或
  • 線性空燃比感測器負極端子輸出電壓超過 4.4 volts 達 2 秒。
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 6行駛循環模式.
故障排除提示 (此故障碼最可能的設定原因為：)
  • 線性空燃比感測器失效
  • 線性空燃比感測器電路短路或接頭接觸不良
  • ECM 故障
