更換 ADAS control unit 2 時，必須向 ADAS control unit 2 寫入 MAC key。請依「M.U.T.-III SE 作動手冊」的「MAC Key writing」程序向 ADAS control unit 2 寫入 MAC key。
注意：
MAC key 寫入期間，請維持以下條件：
  • 點火開關 開啟
  • M.U.T.-III SE 已連接至網際網路
1.執行 MAC 金鑰寫入
  1. 點火開關開啟。
  2. 使用 M.U.T.-III SE 在「ACC/ADAS 2」的「Special Function」中選擇「MAC Key writing」。
  3. 觸碰「OK」。
