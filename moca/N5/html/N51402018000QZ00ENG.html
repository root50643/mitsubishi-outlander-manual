電氣與動力控制 - 車身控制系統 - 故障碼/電路診斷 - U2176-57 CAN 通訊錯誤（CCM/方向盤角度感測器）

1.檢查故障碼優先順序
若故障碼U2176-57與故障碼U1327-52或故障碼U1327-54同時顯示，請先對故障碼U1327-52或故障碼U1327-54進行故障診斷。
是否偵測到故障碼U1327-52或U1327-54？
是
請參閱故障碼說明(U1327-52)或故障碼說明(U1327-54)。
否
GO TO 2.
2.MAC診斷檢查
使用 M.U.T.-III SE
使用 M.U.T.-III SE 執行「BCM」的「MAC 診斷」模式。
故障碼 U2176-57 是否與故障碼 U2140–57、故障碼 U2152–57（配備 MI-PILOT）及故障碼 U2175–57（配備環景監視控制單元）同時偵測到？
是（所有故障碼同時偵測到）
更換 BCM。請參閱拆卸與安裝.
否（所有故障碼並非同時偵測到）
GO TO 3.
3.檢查 網路-故障碼
使用 M.U.T.-III SE
執行「CAN Diag」。
檢查結果是否正常？
是
聯絡 Techline 並回報車輛狀況。
否
修理或更換根本原因零件。
