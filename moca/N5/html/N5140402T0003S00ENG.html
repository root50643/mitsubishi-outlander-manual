說明
概述
  • IPDM E/R 內建耗電控制功能，可依車輛狀態降低耗電量。
  • IPDM E/R 依透過 CAN 通訊自 BCM 接收的睡眠喚醒訊號改變其狀態（控制模式）。
    正常模式（喚醒）
    • 與其他控制單元正常執行 CAN 通訊。
    • IPDM E/R 個別單元控制正常執行。
    低耗電模式（睡眠）
    • 低耗電控制作用中。
    • CAN 傳輸停止。
睡眠模式啟動
  • 當點火開關關閉且下列條件均不存在時，IPDM E/R 判定睡眠就緒條件已滿足。隨後透過 CAN 通訊向 BCM 傳送睡眠就緒訊號（ready）。
    • 向作動器輸出訊號
    • 正透過 CAN 通訊接收來自控制單元的輸出要求。
  • 當 IPDM E/R 接收來自 BCM 的睡眠喚醒訊號（sleep）且睡眠就緒條件已滿足時，停止 CAN 通訊並進入低耗電模式。
喚醒作動
  • 當 IPDM E/R 接收來自 BCM 的睡眠喚醒訊號（wake up）或滿足下列任一條件時，由低耗電模式切換至正常模式。此外，透過 CAN 通訊向 BCM 傳送睡眠就緒訊號（not-ready）以通報 CAN 通訊啟動。
    • 點火開關開啟
    • 引擎蓋開關狀態變更。
    • 透過 CAN 通訊接收來自控制單元的輸出需求。
