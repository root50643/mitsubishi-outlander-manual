注意：
開始前，務必確認：
  • ASSIST 確認 M.U.T.-III SE 已同步至目前日期。
  • 所有 M.U.T.-III SE 軟體更新（如有）均已安裝完成。
1.更換
  1. 點火開關為關閉。
  2. 更換 AWD 控制單元（與作動器總成合併）或電液耦合器總成。請參閱拆卸與總成.
GO TO 2.
2.執行 AWD 控制單元程式設計
使用 M.U.T.-III SE
依 M.U.T.-III SE 作動手冊中「Programming（程式設計）」之程序執行 AWD 控制單元程式設計。請參閱 M.U.T.-III SE 作動手冊。
注意：
程式設計期間，請維持下列條件：
  • 點火開關：開啟
  • 引擎：停止
  • 電氣負載：關閉
  • 煞車踏板：未踩下
  • 電池電壓：11 V 以上（務必於 M.U.T.-III SE 的「資料清單」中選擇「電池電壓」以確認電池電壓數值。）
GO TO 3.
3.執行排氣及機油劣化程度初始化
對電液耦合器機油執行排氣及機油劣化程度初始化。請參閱說明.
進行步驟 4。
4.執行 Factory Mode 關閉
  1. 將點火開關轉至開啟。
  2. 於「ALL MODE AWD / 4WD」的「Special Function（特殊功能）」畫面中選擇「Factory Mode 關閉」。
  3. 檢查項目 No.1：Factory Mode，並依設定值執行下列程序。
    • 開啟：選擇「OK」並將設定值變更為「關閉」。
    • 關閉：無需作業，作業完成。
