DRIVER INFORMATION & MULTIMEDIA - AUDIO, VISUAL & NAVIGATION SYSTEM - MITSUBISHI CONNECT - 基本檢查 - 更換 AV CONTROL UNIT 時之附加服務
作業程序
N5160407Q0007000ENG
1.更換 AV CONTROL UNIT
更換 AV 控制單元。請參閱拆卸與安裝.
前往步驟 2.
2.執行程式設計
M.U.T.-III SE
依 M.U.T.-III SE 作動手冊中「Programming（程式設計）」程序，執行 AV control unit 程式設計。請參閱 M.U.T.-III SE 作動手冊。
注意：
程式設計期間，須維持下列條件：
  • 點火開關：開啟
  • 電氣負載：關閉
  • 煞車踏板：未踩下
  • 12V 電池電壓：12 – 13.5 V（檢查 M.U.T.-III SE 螢幕上顯示之數值。）
GO TO 3.
3.設定 (AV CONTROL UNIT)
M.U.T.-III SE 設定
執行設定。請參閱作業程序.
GO TO 4.
4.WRITE VIN DATA (AV CONTROL UNIT)
M.U.T.-III SE work support
執行「WRITE VIN (SAVED DATA)」或「WRITE VIN (MANUAL INPUT)」以寫入 VIN 資料。
GO TO 5.
5.檢查網路 INITIAL SETTINGS
M.U.T.-III SE Special Function
1. 確認點火開關開啟後已經過 90 秒或以上，然後選取「IVC」的「網路 initial settings」。
2. 檢查「Radio wave condition」。若正常，進行下一步驟。若狀態異常或無法偵測，將車輛移至電波環境良好之處所。然後從步驟 1 重新開始。
3. 選取「MULTI AV」的「網路 initial settings」。
4. 檢查「網路 initial setting state」數值。若顯示「Completed」，表示設定已完成。若 15 分鐘內未變為「Completed」，網路設定可能發生錯誤。
