Code No. P0E9D-00: DC-DC Converter module#2 電流感測器偏低
N5025045R0000600ENG
監視執行
連續。
監視執行條件（其它監視與感測器）
其它監視（下列監視項目在記憶體中未設定暫時性故障碼）
  • DC-DC Converter 控制模組
  • DC-DC Converter 控制電壓
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關在 開啟 位置。
  • 12V 電池電壓介於 10.0 至 16.5 volts 之間。
  • 起動馬達已關閉。
  • 上述條件達成後已經過 2 秒以上。
判定標準
  • 感測器電流在 2.5 秒內維持 -100 ampere 或更低。
失效保護與備援功能
  • 48V MILD HYBRID 系統已停止。
    1. 已停止對 12V 側供電。
    2. 皮帶驅動起動馬達發電機之引擎輔助與再生功能已停止。
  • 充電警告燈已點亮。
  • Auto Stop 已禁止。
  • AS&G 關閉燈閃爍中。
OBD-II 驅動循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5驅動循環模式.
故障排除提示（此故障碼最可能的設定原因如下：）
DC-DC converter 故障。
診斷
所需特殊工具：
  • MB993028：VCI-3 套件（含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：VCI-3 套件（不含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
1.測試 OBD-II 驅動循環。
  1. 將點火開關轉至「開啟」位置並清除故障碼。
  2. 依驅動循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5驅動循環模式.
  3. 檢查故障碼。
