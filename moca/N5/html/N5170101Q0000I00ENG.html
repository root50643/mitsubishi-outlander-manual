使用 ACC 的預防措施/注意事項
若未遵守 ACC 系統正確使用的警告與指示，可能導致嚴重受傷或死亡。
  • ACC 並非自動駕駛系統。在本手冊所述能力範圍內，可協助駕駛進行特定駕駛作業。
  • ACC 系統無法取代正確駕駛程序，亦無法修正粗心、疏忽或心不在焉的駕駛行為。ACC 不會持續轉向以維持車輛在車道內行駛。ACC 系統並非設計用來防止車輛失控。駕駛者有責任隨時保持警覺、安全駕駛、維持車輛在行車車道內，並隨時掌控車輛。
  • ACC 系統能力有其限制。ACC 系統並非在所有駕駛、交通、天候及道路狀況下均能運作。駕駛者有責任隨時保持警覺、安全駕駛、維持車輛在行車車道內，並隨時掌控車輛。
  • ACC 系統僅為輔助駕駛之裝置，並非碰撞警告或迴避裝置。
  • ACC 系統僅供高速公路使用，不適用於市區駕駛。若未在必要時踩煞車或轉向，可能導致嚴重事故。
  • 務必遵守標示車速限制，勿將車速設定超過限制。
  • 駕駛時切勿將雙手離開方向盤。務必將雙手握住方向盤並安全駕駛。
  • 使用 ACC 時切勿解開安全帶。
  • ACC 系統在接近靜止及慢速移動車輛時不會反應。
  • 使用 ACC 系統時務必謹慎且專心駕駛。使用 ACC 系統前請詳閱並了解車主手冊。為避免嚴重受傷或死亡，請勿依賴本系統防止事故或在緊急情況下控制車速。僅在適當的道路及交通狀況下使用 ACC 系統。
當踩下加速踏板且車輛接近前方車輛時，ACC 系統既不控制煞車，亦不會以蜂鳴器及顯示警告駕駛。駕駛者必須手動控制車速以維持與前方車輛的安全距離。若未如此做，可能導致嚴重人身傷害或死亡。
為防止車輛意外移動或滑動而導致嚴重人身傷害或財物損壞，下車前務必確認按下 ACC 開關關閉系統、按下駐車按鈕換至 P（駐車）位置，並關閉引擎。
若未遵守 ACC 系統正確使用的警告與指示，可能導致嚴重受傷或死亡。
  • ACC 系統僅為輔助駕駛之裝置，並非碰撞警告或迴避裝置。建議僅供高速公路使用，不適用於市區駕駛。駕駛者有責任隨時保持警覺、安全駕駛，並隨時掌控車輛。
  • ACC 系統能力有其限制。ACC 系統並非在所有駕駛、交通、天候及道路狀況下均能運作。駕駛者有責任隨時保持警覺、安全駕駛、維持車輛在行車車道內，並隨時掌控車輛。
  • 務必遵守標示車速限制，勿將車速設定超過限制。
  • ACC 系統對靜止及慢速移動車輛不會反應。
  • 使用 ACC 系統時務必謹慎且專心駕駛。使用 ACC 系統前請詳閱並了解車主手冊。為避免嚴重受傷或死亡，請勿依賴本系統防止事故或在緊急情況下控制車速。僅在適當的道路及交通狀況下使用 ACC 系統。
為降低可能導致嚴重受傷或死亡的碰撞風險，請注意下列事項：
  • 此功能僅在右轉方向燈作動時啟用，即使未開始變換車道，車輛亦會短暫加速。此情況可能包含非超車狀況，例如右側出口。
  • 超車時請確認相鄰車道淨空後再開始超車。超車過程中交通狀況可能突然改變。務必依需要手動轉向或煞車。切勿僅依賴本系統。
以下為車速限制連結之系統限制。若未依此等系統限制操作車輛，可能導致嚴重受傷或死亡 <Vehicles for Australia>：
  • 選擇適當車速、遵守所有交通法規並注意其他道路使用者，為駕駛者之責任。
  • 在下列情況下，車速限制連結可能無法正常運作，實際車速限制標誌可能無法正確套用至車輛設定車速。駕駛者必須手動控制車速。
    • 當交通標誌辨識 (TSR) 系統未正常運作或已關閉時。
    • 跨越國界時。
    • 在附近有平行道路之區域行駛時（例如高速公路旁有平行服務道路）。
    • 在各行車車道有不同車速限制標誌之區域行駛時。
    • 在施工道路或施工區域行駛時。
以下為 ACC 系統之系統限制。若未依此等系統限制操作車輛，可能導致嚴重受傷或死亡：
  • ACC 系統主要供高速公路及快速道路使用。不建議在市區/都市交通中使用 ACC 系統。
  • ACC 系統不會自動適應道路狀況。本系統應在車流平穩時使用。請勿在彎道急劇或結冰路面、大雨或濃霧時使用本系統。
  • 由於車距控制功能有效能極限，切勿僅依賴 ACC 系統。本系統無法修正粗心、疏忽或心不在焉的駕駛行為，亦無法克服雨天、濃霧或其他惡劣天候下的能見度不良。請依前方車輛距離及周圍情況踩下煞車踏板減速，以維持車輛間安全距離。
  • 當 ACC 系統自動使車輛停止時，若停車時間少於約 3 秒，車輛可能自動加速。請隨時準備在必要時停止車輛。
  • 重新起步前務必檢查周圍環境。
  • 務必注意車輛作動，並隨時準備手動控制適當跟車距離。在某些情況下，ACC 系統可能無法維持所選車距（跟車距離）或所選車速。
  • ACC 系統無法偵測下列物體：
    • 靜止或慢速移動車輛（當車輛接近時）
    • 行人或道路上的物體
    • 同車道對向來車
    • 在車道內偏移行駛的機車
  • 在某些道路、天候或駕駛條件下，ACC 系統可能無法偵測前方車輛。為避免事故，請勿在下列情況下使用 ACC 系統：
    • 在車流量大、高速或彎道急劇的道路上
    • 在濕滑路面，例如結冰或積雪等
    • 在顛簸路面，例如不平整的土路
    • 在陡峭下坡道路（車輛可能超過設定車速，頻繁煞車可能導致煞車過熱）
    • 在反覆上下坡道路
    • 在惡劣天候（雨、霧、雪等）
    • 當感知器偵測能力降低時（如雨、雪、霧、塵暴、沙暴及其他車輛濺起的路面水花等情況）
    • 當污垢、冰、雪或其他物質附著於雷達感知器區域時
    • 當因頻繁加速或減速而難以維持適當車距時
    • 當前方車輛附近為形狀複雜的車輛，例如汽車運輸拖車或平板卡車/拖車時
    • 當有其他雷達源干擾時
    • 當後座或行李區載入過重行李時
    • 當拖曳拖車或其他車輛時
  • 在某些道路或交通狀況下，車輛或物體可能意外進入感知器偵測區而觸發自動煞車。務必保持警覺，並避免在本警告章節不建議之處使用 ACC 系統。
  • ACC 系統亦使用多感測前方攝影機。下列為攝影機可能無法正確偵測車輛、導致前方車輛偵測延遲之部分情況：
    • 能見度不良（如雨、雪、霧、塵暴、沙暴及其他車輛濺起的路面水花等情況）
    • 擋風玻璃攝影機區域起霧或覆有污垢、水滴、冰、雪等
    • 強光（例如陽光或對向車輛遠光燈）照射前方攝影機
    • 亮度突然改變（例如車輛進出隧道或陰影區域，或閃電）
  • 過大噪音干擾警告蜂鳴聲，可能聽不到蜂鳴。
  • 為使 ACC 系統正常運作，攝影機前方擋風玻璃必須清潔。請更換磨損的雨刷片。必須使用正確尺寸的雨刷片以協助保持擋風玻璃清潔。僅可使用三菱原廠雨刷片，或同等且專為該車型及年式設計的雨刷片。
  • 在傳統（固定車速）定速控制模式下，若與前方車輛過近，蜂鳴器不會響起警告駕駛，因為既不偵測前方車輛存在，亦不偵測車間距離。
  • 請特別注意本車與前方車輛之距離，否則可能發生碰撞。
  • 務必確認 ACC 系統顯示中的設定。
  • 請勿在下列情況下使用傳統（固定車速）定速控制模式：
    • 無法維持設定車速時
    • 在車流量大或車速變化頻繁的交通中
    • 在蜿蜒或丘陵道路
    • 在濕滑道路（雨、雪、冰等）
    • 在強風區域
  • 如此做可能導致車輛失控並發生事故。
為避免意外啟用定速控制，不使用 ACC 系統時務必確認將 ACC 開關關閉。
