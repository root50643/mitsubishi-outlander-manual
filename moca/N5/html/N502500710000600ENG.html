引擎<4B4> - 直接燃油噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0369-00：排氣凸輪軸位置感測器線路間歇性故障 Bank 1
N502500710000600ENG
線路作動
請參閱 Code No. P0365-00：排氣凸輪軸位置感測器線路Code No. P0365-00：排氣凸輪軸位置感測器線路
技術說明
排氣凸輪軸位置感測器偵測排氣凸輪軸位置，並將脈衝訊號輸入至ECM。
監控方法說明
ECM在引擎運轉期間，檢查來自排氣凸輪軸位置感測器的訊號波形是否正常。
監控執行
連續。
監控執行條件（其他監控項目及感測器）
其他監控項目（下列受監控項目的記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器已判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 引擎運轉期間。
判定標準
  • 排氣凸輪軸位置感測器訊號波形不正常。
失效保護與備援功能
無。
OBD-II 行駛循環模式
請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 6行駛循環模式.
故障排除提示 (本故障碼最可能設定原因：)
  • 排氣凸輪軸位置感測器故障。
  • 排氣凸輪軸位置感測器線路線束損壞或接頭接觸不良。
  • ECM故障。
診斷
所需特殊工具：
  • MB993028: VCI-3 套件（含無線轉接器）
    1. -: VCI-3 裝置
    2. MB993029: DLC 線束
    3. MB993030: USB 線束
    4. MB993031: 無線 USB 轉接器 (Qty:2)
  • MB993040: VCI-3 套件（不含無線轉接器）
    1. -: VCI-3 裝置
    2. MB993029: DLC 線束
    3. MB993030: USB 線束
1.排氣凸輪軸位置感測器安裝檢查
  • 檢查排氣凸輪軸位置感測器是否正確安裝。
Q：檢查結果是否正常？
是
GO TO 2.
否
修理或更換排氣凸輪軸位置感測器（請參閱 引擎<4B4> - 引擎電系 - 點火系統 - 凸輪軸位置感測器 -凸輪軸位置感測器 拆卸與安裝）。然後前往第6步。
2.檢查排氣凸輪軸位置感測器接頭端子與ECM接頭端子SGC5之間的線束。
  • 檢查電源線路是否開路/短路及損壞。
Q：檢查結果是否正常？
是
GO TO 3.
否
修理或更換接頭，或修理損壞的線束線路。然後前往第6步。
3.檢查排氣凸輪軸位置感測器接頭端子與ECM接頭端子SGCE之間的線束。
  • 檢查搭鐵線路是否開路及損壞。
Q：檢查結果是否正常？
是
GO TO 4.
否
修理或更換接頭，或修理損壞的線束線路。然後前往第6步。
4.檢查進氣凸輪軸位置感測器接頭端子與ECM接頭端子SGC之間的線束。
  • 檢查輸出線路是否損壞。
Q：檢查結果是否正常？
是
前往第5步。
否
修理或更換接頭，或修理損壞的線束線路。然後前往第6步。
5.使用 M.U.T.-III SE，讀取故障碼。
  • 故障碼再確認。
Q：是否設定故障碼 P0369-00？
是
更換ECM（請參閱引擎-ECU 拆卸與安裝）。然後前往第6步。
否
間歇性故障（請參閱 General Information – General Information – Basic Inspection – Service Information for Electrical Incident –間歇性故障).
6.測試 OBD-II 行駛循環。
  1. 依驅動循環模式執行試車。請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 6行駛循環模式.
  2. 檢查故障碼。
Q：是否設定故障碼 P0369-00？
是
重新執行故障排除。
否
檢查完成。
