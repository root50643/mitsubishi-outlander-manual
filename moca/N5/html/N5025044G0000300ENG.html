引擎<4B4> - 直接噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. P0AFB-00：48V 電池端子電壓過高
N5025044G0000300ENG
監視執行
連續。
監視執行條件（其它監視與感測器）
其它監視（下列監視項目在記憶體中未設定暫時性故障碼）
  • 不適用
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關在 開啟 位置。
  • BECM 初始化已完成。
  • 12V 電池電壓介於 10.0 至 16.5 volts 之間。
  • 起動馬達已關閉。
  • 上述條件達成後已經過 2 秒以上。
判定標準
  • 電池包電壓超過 62.0 volts 達 2.5 秒。
失效保護與備援功能
  • 48V MILD HYBRID 系統已停止。
    1. 已停止對 12V 側供電。
    2. 皮帶驅動起動馬達發電機之引擎輔助與再生功能已停止。
  • 充電警告燈已點亮。
  • Auto Stop 已禁止。
  • AS&G 關閉燈閃爍中。
OBD-II 驅動循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5驅動循環模式.
故障排除提示（設定此故障碼最可能的原因為：）
  • 48V 電池故障。
診斷
所需特殊工具：
  • MB993028：VCI-3 套件（含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：VCI-3 套件（不含無線轉接器）
    1. -：VCI-3 裝置
    2. MB993029：DLC 電纜
    3. MB993030：USB 電纜
1.使用 M.U.T.-III SE 讀取故障碼。
  1. 將點火開關轉至「開啟」位置。
  2. 檢查是否設定與皮帶驅動起動馬達發電機或 DC-DC 轉換器相關的故障碼。
  3. 將點火開關轉至「LOCK」（關閉）位置。
Q: 是否有設定任何故障碼？
是
請參閱故障碼檢查表.
否
GO TO 2.
2.使用 M.U.T.-III SE 檢查資料清單。
  1. 將點火開關轉至「開啟」位置。
  2. 檢查資料清單中的下列項目（請參閱資料清單 參考表).
    1. Item 139：48V 電池 Pack Link 電壓
Q：檢查結果是否正常？
是
GO TO 3.
否
更換 48V 電池（請參閱 Electrical & Power Control - Power Supply, Ground & Circuit Elements - 48V 電池 -服務程序）。然後GO TO 3.
3.測試 OBD-II 驅動循環。
  1. 將點火開關轉至「開啟」位置並清除故障碼。
  2. 依驅動循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5驅動循環模式.
  3. 檢查故障碼。
問：是否設定故障碼 P0AFB-00？
是
更換 48V 電池（請參閱 Electrical & Power Control - Power Supply, Ground & Circuit Elements - 48V 電池 -服務程序）。然後GO TO 4.
否
檢查完成。
4.測試 OBD-II 驅動循環。
  1. 依驅動循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5驅動循環模式.
  2. 檢查故障碼。
問：是否設定故障碼 P0AFB-00？
是
重新執行故障排除。
否
檢查完成。
