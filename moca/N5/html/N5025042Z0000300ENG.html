引擎<4B4> - 直接燃油噴射與多點燃油噴射 (DI AND MPI) - 故障排除 - 故障碼程序
Code No. C1366-00: G-感知器（側向）合理性
N5025042Z0000300ENG
技術說明
VDC 監控 G 感知器，並將診斷結果（OK/NOK）的 CAN 訊號傳送至 ECM。
監控方法說明
當 ECM 從 VDC 收到 G 感知器的 NOK 資訊時，會顯示故障碼。
監控執行
連續。
監控執行條件（其他監控項目及感測器）
其他監控項目（下列受監控項目的記憶體中未設定暫時性故障碼）
  • U0121-00：ASC 逾時
感測器（下列感測器已判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 引擎 is running.
  • 電瓶正極電壓大於10.5伏特且小於16.5伏特。
判定準則
  • ECM 持續 3 秒接收到 VDC 失效/故障資訊。
失效保護與備援功能
Auto Stop 禁止。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
故障排除提示 (本故障碼最可能設定原因：)
檢查 VDC，並依 VDC 故障排除程序進行檢查。
診斷
所需特殊工具：
  • MB993028: VCI-3 套件（含無線轉接器）
    1. -: VCI-3 裝置
    2. MB993029: DLC 線束
    3. MB993030: USB 線束
    4. MB993031: 無線 USB 轉接器 (Qty:2)
  • MB993040: VCI-3 套件（不含無線轉接器）
    1. -: VCI-3 裝置
    2. MB993029: DLC 線束
    3. MB993030: USB 線束
1.使用 M.U.T.-III SE 讀取其他系統故障碼。
  1. 將點火開關轉至「開啟（開啟）」位置。
  2. 讀取 ABS 作動器與電子單元（控制單元）-故障碼（側向 G 感知器相關故障碼）。
  3. 將點火開關轉至「LOCK（關閉）」位置。
問：ABS 作動器與電子單元（控制單元）-故障碼（側向 G 感知器相關故障碼）是否已設定？
是
請參閱 煞車 - 煞車控制系統 - 附 VDC - ECU 診斷資訊 - ABS 作動器與電氣單元（控制單元） -故障碼索引.
否
GO TO 2.
2.測試 OBD-II 行駛循環。
  1. 將點火開關轉至「開啟」位置並清除故障碼。
  2. 依行駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  3. 檢查故障碼。
問：故障碼 C1366-00 是否已設定？
是
更換 ECM（請參閱 拆卸與安裝引擎-ECU 拆卸與安裝）。然後GO TO 3.
否
檢查完成。
3.測試 OBD-II 行駛循環。
  1. 依行駛循環模式進行試車。請參閱 Diagnostic Function - OBD-II Drive Cycle - Pattern 5行駛循環模式.
  2. 檢查故障碼。
問：故障碼 C1366-00 是否已設定？
是
重新執行故障排除。
否
檢查完成。
