M.U.T.-IIISE CAN 匯流排診斷說明
N5140308V0000J00ENG
使用 M.U.T.-IIISE 的「Read all DTCs and FFD」功能診斷 CAN 匯流排。
「Read all DTCs and FFD」會自動讀取系統清單中所選 ECU 的全部故障碼，並在螢幕左側結果欄及螢幕右側故障碼狀態欄顯示對應的診斷結果。
在 M.U.T.-IIISE 使用「Read all DTCs and FFD」進行 CAN 匯流排診斷時，係依螢幕左側結果欄所顯示的診斷結果，判斷 CAN 匯流排線路是否異常。
M.U.T.-IIISE 畫面（Read all DTCs and FFD）
結果欄（螢幕左側）
處置
所有系統均顯示「OK」或「–」。
執行一般故障現象診斷。
一個或多個系統顯示「TC」，且完全未顯示「NC」。
讀取故障碼後，依故障碼鎖定故障位置，或執行一般故障現象診斷。
一個或多個系統顯示「NC」。
記錄所有顯示「NC」的系統，並繼續進行 CAN 匯流排診斷表。
注意：
當顯示「NC」時，可藉由檢查系統圖判斷哪條通訊匯流排出現故障。（系統圖請參閱 LAN SYSTEM – CAN – SYSTEM DESCRIPTION – SYSTEM – CAN COMMUNICATION SYSTEM – System Description系統說明.)
CAN 匯流排線路診斷流程
CAN 匯流排診斷程序
將 M.U.T.-IIISE 連接至診斷接頭。
啟動 M.U.T.-IIISE 系統，並將點火開關轉至「開啟」位置。
注意：
M.U.T.-IIISE 使用方法詳情，請參閱「M.U.T.-IIISE User's Manual」。
在「System Select」畫面中，於系統清單選取「8ch CAN 網關」，然後按下檢查圖示。
注意：
若顯示功能選擇畫面，返回「System Select」畫面。若顯示通訊錯誤視窗，表示 CAN-C (Diag) 匯流排線路故障。
在「System Selection」畫面按下「ALL 故障碼」圖示。
注意：
在所有選項皆已選取前，無法按下「ALL 故障碼」圖示。
在下一畫面選取「Read all DTCs and FFD」。
在「Read all DTCs and FFD」畫面中，檢查螢幕左側核取方塊內是否正確選取車輛所安裝的系統（必要時移除核取記號）。若選取無誤，按下「OK」按鈕。
注意：
若在未安裝的系統上顯示核取記號，請注意可能在步驟 7 或之後做出錯誤判斷，而耗費不必要的診斷時間。
由於顯示「Read all DTCs and FFD」執行確認畫面，按下「OK」按鈕以執行。
完成步驟 6 所選系統的診斷讀取後，依螢幕左側結果欄所顯示內容，判斷 CAN 匯流排線路是否異常。
注意：
所有診斷功能均可列印結果。
若讀取全部診斷後結果顯示「NC」，請檢查該系統是否安裝於車輛上。必要時在選取畫面移除核取記號，然後再次讀取全部診斷。
