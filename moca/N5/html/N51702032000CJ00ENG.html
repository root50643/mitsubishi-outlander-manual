CRUISE CONTROL & DRIVER ASSISTANCE - DRIVER ASSISTANCE SYSTEM - DRIVER ASSISTANCE SYSTEM - BASIC INSPECTION - 側向雷達校正
作業程序
N51702032000CJ00ENG
  • 執行下列作業後，務必進行側向雷達校正。
    • 拆裝或更換側向雷達後。
    • 拆裝、更換或重新烤漆後保險桿後。
  • 側向雷達校正條件如下：
    • 車輛車速為 50 km/h (31 MPH) 或更高。
    • 能反射雷達波的物體位於距離車輛 8 m 以上處。
    • 方向盤保持直行。
注意：
  • 若在完成前將鑰匙開關關閉，側向雷達校正程序將重置（回到 0%）。
  • 當車輛車速為 0 km/h（車輛停駐）時，側向雷達校正程序會停止；滿足校正條件時會重新啟動。
  • 若開始側向雷達校正後 15 分鐘內未滿足校正條件，將發生逾時。
  • 側向雷達發射雷達波，並在固定時間內接收反射波以進行校正。
  • 因無法接收反射波，在下列環境下側向雷達校正可能無法繼續進行。
    • 當行駛在道路兩側有高大雪堆的道路上時。
    • 當行駛在沒有物體可反射雷達波的道路上時，例如海岸線道路。
    • 當行駛在高出周圍地面的道路上時，例如位於堤防頂部或土壩頂部的道路。
1.選擇作業支援項目
  1. 停止車輛。
  2. 選擇「側向雷達 (Rear left)」或「側向雷達 (右後)」的「作業支援」。
    注意：
    無論選擇「側向雷達 (Rear left)」或「側向雷達 (右後)」，安裝資訊均可寫入左右兩側側向雷達 LH/RH。
  3. 選擇「側向雷達校正」。
是否顯示選擇目標側向雷達的畫面？
是
進行步驟 2.
否
顯示錯誤訊息時：進行步驟 4.
2.開始側向雷達校正
選擇「開始」。
是否顯示「準備開始側向雷達校正。」？
是
進行步驟 3.
NO-1
顯示「側向雷達安裝異常。」時：進行步驟 5.
NO-2
顯示「偵測故障碼。」時：進行步驟 6.
NO-3
顯示「已停止」時：再次執行側向雷達校正。
3.執行側向雷達校正
  1. 駕駛車輛。
    注意：
    • 務必安全駕駛。
    • 下列條件下無法進行側向雷達校正；
      • 大雨或降雪
      • 雷達周圍的保險桿受到汙染。
  2. 確認顯示「側向雷達校正已完成。」，並選擇「結束」。
作業結束。
4.未偵測到雷達之確認
  1. 確認未偵測到的雷達並修復故障零件。
  2. 再次執行側向雷達校正。
作業結束。
5.檢查側向雷達 LH/RH 接頭
  1. 確認 M.U.T.-III SE 上的說明，檢查相關雷達安裝狀況（安裝位置、鎖緊扭力、支架彎曲等），並修復故障零件。
  2. 再次執行側向雷達校正。
作業結束。
6.檢查側向雷達自我診斷結果
  1. 執行「Read All DTCs」。
  2. 檢查下列自我診斷結果中是否偵測到故障碼。
    • 「側向雷達 (Rear left)」：請參閱故障碼索引故障碼索引.
    • 「側向雷達 (右後)」：請參閱故障碼索引故障碼索引.
  3. 對偵測到的故障碼進行故障診斷，並修理或更換已確認故障的零件。
  4. 將點火開關由關閉轉至開啟，並再次執行側向雷達校正。
作業結束。
