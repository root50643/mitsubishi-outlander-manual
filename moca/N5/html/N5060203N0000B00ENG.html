煞車 - 駐車煞車系統 - 基本檢查 - 診斷與維修作業流程
作業流程

故障診斷流程圖詳細說明
1.蒐集客戶資訊
在開始檢查之前，釐清客戶疑慮也很重要。首先，利用訪談診斷工作表重現症狀並充分瞭解。視情況而定，與客戶一同試車並檢查症狀。
警告：
客戶並非專業人員。切勿輕易臆測，例如「也許客戶是指……」或「也許客戶所指的是這個症狀」。
前往步驟 2.
2.檢查症狀
根據訪談所獲得的客戶資訊，重現客戶所述的症狀。並檢查該症狀是否非由失效保護模式所造成。請參閱失效保護.
警告：
當症狀係由正常作動所造成時，應完整檢查各部分，並取得客戶理解，確認該症狀並非由故障所造成。
前往步驟 3.
3.執行自我診斷
使用 M.U.T.-III SE
  1. 點火開關關閉。
    警告：
    Auto ACC 關閉，並檢查駐車煞車開關指示燈是否熄滅。
  2. 點火開關 開啟。
  3. 按下駐車煞車開關。
    警告：
    • 將電子排檔桿設定於 P 位置。
    • 踩下煞車踏板。
  4. 拉起駐車煞車開關。
  5. 執行「ABS」自我診斷。
是否偵測到故障碼？
是
記錄或列印自我診斷結果與凍結畫面資料（FFD）。前往步驟 4.
否
前往步驟 4.
4.維修或更換偵測到異常的零件
  1. 修理或更換偵測到異常的零件。
  2. 維修或更換後，重新連接零件或接頭。
  3. 當偵測到故障碼時，清除「ABS」的自我診斷結果。
    警告：
    點火開關關閉或開啟後，務必等待 10 秒。
前往步驟 5.
5.依症狀診斷判定異常系統
依症狀診斷推定異常系統並執行檢查。
能否判定異常系統？
是
前往步驟 6.
否
根據訪談所獲得的資訊檢查線束與接頭。請參閱間歇性故障間歇性故障.
6.最終檢查
使用 M.U.T.-III SE
  1. 檢查「ABS」的參考值。
  2. 執行「ABS」自我診斷。
是否偵測到故障碼？
是-1
顯示「CRNT」時：檢查故障碼。請參閱故障碼索引.
是-2
顯示「Stored 故障碼」：檢查結束（清除自我診斷結果的記憶。）
否
檢查結束
已加入書籤書籤數量過多。
請刪除後重新加入書籤。
