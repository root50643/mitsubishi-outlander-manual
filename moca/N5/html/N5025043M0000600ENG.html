Code No. P063B-00：48V-BSG B 端子電壓感測器合理性
N5025043M0000600ENG
技術說明
皮帶驅動啟動馬達發電機（BSG）控制器檢查皮帶驅動啟動馬達發電機電壓感測器是否正常。
監視器執行
連續。
監視器執行條件（其他監視器與感知器）
其他監視器（以下監視項目之記憶體中未設定暫時性故障碼）
  • 不適用
感知器（以下感知器判定為正常）
  • 馬達發電機電壓感測器
故障碼設定條件
檢查條件
  • 點火開關位於開啟位置。
  • 12V 電池電壓介於 10.0 至 16.5 伏特之間。
  • 48V 輕度混合動力系統為啟用狀態。
  • 起動馬達關閉。
  • 符合上述條件後已經過 2 秒以上。
判定標準
  • 與閘極驅動器電壓的差異達 5 伏特或以上，持續 2.5 秒。
  • 電壓大於 0.1 伏特且小於 4.9 伏特，持續 2.5 秒。
失效保護與備用功能
  • 48V 輕度混合動力系統停止運作。
    1. 停止對 12V 側供電。
    2. 皮帶驅動起動馬達發電機之引擎輔助與再生停止運作。
  • 充電警示燈點亮。
  • 禁止自動熄火。
  • AS&G 關閉燈閃爍。
OBD-II 駕駛循環模式
請參閱診斷功能，OBD-II 駕駛循環 - 模式 5駕駛循環模式.
故障排除提示（設定此故障碼最可能的原因為：）
  • 皮帶傳動啟動發電機故障（內部電路）。
診斷

  2. 依駕駛循環模式執行試車。請參閱診斷功能 - OBD-II 駕駛循環 - 模式 5駕駛循環模式.
