詳細流程
1.客戶訪談
檢查前先釐清客戶申訴。首先，利用下列方式進行訪談診斷工作表並重現症狀以充分了解。仔細詢問客戶申訴內容。若有必要，與客戶一同試車以確認症狀。
警告：
客戶並非專業人員。切勿輕易臆測，例如「也許客戶指的是…」，或「也許客戶說的是這個症狀」。
前往步驟 2.
2.檢查症狀
依訪談所得客戶資訊，重現客戶所述症狀。並檢查該症狀是否由保護功能引起。請參閱保護功能.
警告：
若症狀為正常作動所致，應完整檢查各部分，並向客戶說明該症狀並非故障所致。
GO TO 3.
3.執行自我診斷
使用 M.U.T.-III SE
執行「ALL MODE AWD/4WD」的自我診斷。
是否偵測到任何故障碼？
是
記錄或列印自我診斷結果。GO TO 4.
否
前往步驟 6.
4.再次確認症狀
使用 M.U.T.-III SE
  1. 清除「ALL MODE AWD/4WD」的自我診斷結果。
  2. 對故障系統執行故障碼確認程序。
注意：
若同時偵測到多個 故障碼，請依下列內容決定診斷順序故障碼檢查優先順序表.
是否偵測到任何故障碼？
是
GO TO 5.
否
依訪談所得資訊檢查線束及接頭。請參閱 間歇性故障間歇性故障.
5.維修或更換故障零件
  • Repair or 更換 error-detected parts.
  • 維修或更換後重新連接零件或接頭。
  • 偵測到故障碼時，清除「ALL MODE AWD/4WD」的自我診斷結果。
前往步驟 7.
6.依症狀診斷辨識故障系統
依症狀診斷推定故障系統並執行檢查。
能否辨識出故障系統？
是
前往步驟 7.
否
依訪談所得資訊檢查線束及接頭。請參閱 間歇性故障間歇性故障.
7.最終檢查
使用 M.U.T.-III SE
  1. 檢查 AWD 控制單元的參考值。
  2. 再次確認症狀，並檢查在相同條件下是否無法重現症狀。
症狀是否重現？
是
GO TO 3.
否
