引擎<4B4> - 直接噴射與多點燃油噴射（DI 與 MPI）- 故障排除 - 故障碼程序
Code No. U0126-00: CAN 逾時 (SAS)
N5025011U0000400ENG
注意：
若 ECM 中設定了診斷故障碼 U0126-00，務必執行 CAN 匯流排線路診斷。
注意：
確定通訊電路正常後，再更換 ECU。
故障碼設定條件
檢查條件
  • 點火開關置於「開啟」位置或引擎啟動後 2 秒。
  • 電瓶正極電壓高於 9 V 且低於 16 V。
判定基準
  • 無法接收來自轉向角感知器的訊號達 4 秒。
備註
目前故障
  • 失效／故障可能的原因為：ECM 與轉向角感知器間 CAN 匯流排線路之線束及接頭故障、轉向角感知器故障，或 ECM 故障。
過去故障
  • 進行故障排除時，著重於 ECM 與轉向角感知器間 CAN 匯流排線路之線束及接頭故障。
注意：
對於過去的故障，即使 CAN 匯流排存在故障，M.U.T.-III SE 的 CAN 匯流排線路診斷也可能無法偵測到故障。因此，請依間歇性故障的處理方式檢查 CAN 匯流排線路（請參閱 General Information – Basic Inspection – Service Information for Electrical Incident –間歇性故障）。可根據各進行 CAN 通訊的 ECU 中所設定的診斷故障碼，縮小故障可能性較高的區域（請參閱 Electrical and Power Control – LAN System – CAN Fundamental – Basic Inspection – Diagnosis and Repair Workflow –M.U.T.-III SE CAN 匯流排診斷說明).
失效保護與備援功能
  • 正常作動時，禁止自動停引擎。<Vehicles with AS&G system>
  • 若在自動停引擎期間偵測到故障，禁止自動起動。<Vehicles with AS&G system>
OBD-II 駕駛循環模式
請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 3駕駛循環模式.
故障排除提示（此故障碼最可能的原因如下：）
  • CAN 匯流排線路故障
  • 8ch CAN 閘道器電源供應電路故障
  • 8ch CAN 閘道器故障
  • 底盤控制模組電源電路故障
  • 底盤控制模組故障
  • 轉向角感知器電源電路故障
  • 轉向角感知器故障
  • ECM 故障
診斷
所需特殊工具：
  • MB993028：含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置
    2. MB993029：DLC 線束
    3. MB993030：USB 線束
    4. MB993031：無線 USB 轉接器（數量：2）
  • MB993040：不含無線轉接器之 VCI-3 套件
    1. -：VCI-3 裝置

1.使用 M.U.T.-III SE 讀取故障碼。
  • 再次確認故障碼。
再次確認 ECM 是否設定故障碼。
  1. 清除已設定的故障碼。
  2. 點火開關：LOCK（關閉）→ 開啟
  3. 確認是否設定故障碼。
Q：是否設定了故障碼 U0126-00？
是
使用 M.U.T.-III SE 執行 CAN 匯流排線路診斷。（請參閱 Electrical and Power Control – LAN System – CAN Fundamental – Basic Inspection – Diagnosis and Repair Workflow –M.U.T.-III SE CAN 匯流排診斷說明）。然後前往步驟 2。
否
間歇性故障（請參閱 General Information – General Information – Basic Inspection – Service Information for Electrical Incident –間歇性故障).
2.測試 OBD-II 駕駛循環。
  1. 依 drive cycle pattern 執行試車。（請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 3駕駛循環模式).
  2. 檢查故障碼。
