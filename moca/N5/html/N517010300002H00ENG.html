詳細流程
1.故障問診
開始檢查前，釐清客戶訴求同樣重要。請仔細向客戶問診並充分了解症狀。
備註：
客戶並非專業人員。切勿臆測「也許客戶是指···」或「也許客戶提到的是這個症狀」。
前往 2。
2.使用 M.U.T.-III SE 進行自我診斷
  1. 使用 M.U.T.-III SE 執行「Read All DTCs」。
  2. 檢查「LASER/RADAR」、「LANE 攝影機」及「ACC/ADAS 2」自我診斷結果中，是否偵測到任何故障碼。
是否偵測到任何故障碼？
是
前往 5。
否
前往 3。
3.作動測試
執行 ACC 系統作動測試以檢查作動狀態。請參閱作業程序工作流程.
檢查是否發生其他任何故障。
前往 4。
4.症狀診斷
依症狀診斷表執行適用的診斷。
前往 6。
5.依故障碼進行故障診斷
  1. 檢查自我診斷結果中的故障碼。
  2. 對偵測到的項目執行故障診斷。
    • LASER/RADAR：請參閱故障碼索引故障碼 Index.
    • LANE 攝影機：請參閱故障碼索引故障碼 Index.
    • ACC/ADAS 2：請參閱故障碼索引故障碼 Index.
備註：
若偵測到網路-故障碼，請先診斷 CAN 通訊系統。
前往 6。
6.故障零件維修
修復或更換已確認故障的零件。
前往 7。
7.維修確認（使用 M.U.T.-III SE 進行自我診斷）
  1. 清除自我診斷結果。
  2. 維修或更換故障零件後，再次執行「Read All DTCs」。
  3. 檢查「LASER/RADAR」、「LANE 攝影機」及「ACC/ADAS 2」自我診斷結果中，是否偵測到任何故障碼。
    • LASER/RADAR：請參閱故障碼索引故障碼 Index.
    • LANE 攝影機：請參閱故障碼索引故障碼 Index.
    • ACC/ADAS 2：請參閱故障碼索引故障碼 Index.
是否偵測到任何故障碼？
是
前往 5。
否
前往 8。
8.維修確認（作動測試）
執行 ACC 系統作動測試。檢查故障症狀是否已排除，或未出現其他症狀。
是否存在任何故障症狀？
是
前往 4。
否
