ECM
  • ECM 控制引擎。
  • 當點火開關轉至開啟位置時，免鑰匙操作鑰匙單元開始與 ECM 通訊，並執行免鑰匙操作鑰匙單元與 ECM 之間的 ID 驗證。
  • 若驗證結果為 OK，引擎可以啟動。若驗證結果為 NG，引擎無法啟動。
IPDM E/R

BCM

  • 免鑰匙操作鑰匙單元依按鈕式點火開關作動變更點火開關位置。
  • 免鑰匙操作鑰匙單元在按鈕式點火開關未操作時維持點火開關位置狀態。

免鑰匙操作鑰匙
免鑰匙操作鑰匙系統是一種可攜帶免鑰匙操作鑰匙，依免鑰匙操作鑰匙與車輛（免鑰匙操作鑰匙單元）之間雙向通訊電子 ID 驗證結果作動，以鎖定及解鎖車門鎖（車門鎖定/解鎖功能）的系統。
免鑰匙操作鑰匙單元
  • 免鑰匙操作鑰匙單元控制免鑰匙操作系統（引擎啟動功能）
  • 當免鑰匙操作鑰匙攜入車內鑰匙天線偵測範圍內且按下按鈕式點火開關時，免鑰匙操作鑰匙單元執行免鑰匙操作鑰匙單元與免鑰匙操作鑰匙之間的 ID 驗證。若 ID 驗證結果為 OK，即可作動點火開關。
  • 接著，當點火開關轉至開啟位置時，免鑰匙操作鑰匙單元執行免鑰匙操作鑰匙單元與 ECM 之間的 ID 驗證。若 ID 驗證結果為 OK，ECM 即可啟動引擎。
TCU
當 TCU 自 Infiniti Connection™ 資料中心收到引擎啟動需求時，將引擎啟動需求訊號傳送至 BCM。

系統說明
  • 免鑰匙操作鑰匙系統的引擎啟動功能，可依電子 ID 驗證結果，無須使用鑰匙即可啟動及停止引擎。當免鑰匙操作鑰匙位於車內鑰匙天線偵測範圍內且按下按鈕式點火開關時，免鑰匙操作鑰匙單元與免鑰匙操作鑰匙之間執行電子 ID 驗證。
    注意：
    駕駛人應隨時攜帶免鑰匙操作鑰匙。
  • 免鑰匙操作鑰匙具有 ID（鑰匙 ID）。攜帶已註冊的免鑰匙操作鑰匙時，可執行車門鎖定/解鎖作動及按鈕式點火開關作動。
  • 若 ID 驗證成功，按下按鈕式點火開關時即可啟動引擎。
  • 依客戶需求，最多可註冊 4 支免鑰匙操作鑰匙（含標準免鑰匙操作鑰匙）。
    注意：
    免鑰匙操作鑰匙系統引擎啟動功能以外之功能，請參閱系統說明.
免鑰匙操作系統預防措施/注意事項
轉發器（NATS ID 驗證用晶片）整合於免鑰匙操作鑰匙內，並整合於機械鑰匙中。因此，僅使用機械鑰匙無法執行 ID 驗證。
在此情況下，踩下煞車踏板並將免鑰匙操作鑰匙背面接觸按鈕式點火開關時，可執行 NATS ID 驗證。若驗證結果為 OK，即可啟動引擎。
攜帶免鑰匙操作鑰匙時之作動
  1. 按下按鈕式點火開關時，免鑰匙操作鑰匙單元啟動車內鑰匙天線，並將需求訊號傳送至免鑰匙操作鑰匙。
  2. 免鑰匙操作鑰匙接收需求訊號，並將 NATS ID 訊號傳送至免鑰匙操作鑰匙單元。
  3. 免鑰匙操作鑰匙單元接收 NATS ID 訊號，並與已註冊 ID 進行驗證。
  4. 當點火開關轉至開啟位置時，免鑰匙操作鑰匙單元與 ECM 執行 ID 驗證。當結果為 OK 時，允許引擎啟動。
  5. 當 ECM 偵測到引擎啟動條件*已滿足時，將起動馬達切斷繼電器需求訊號傳送至 BCM。
  6. 當 BCM 自 ECM 收到起動馬達切斷繼電器需求訊號時，起動馬達切斷繼電器開啟。
  7. 當起動馬達切斷繼電器開啟時，IPDM E/R 開啟起動馬達繼電器並驅動起動馬達。
  8. 當 BCM 自 ECM 收到引擎狀態訊號時，關閉起動馬達繼電器及起動馬達切斷繼電器，並停止曲柄作動。
    注意：
    當電源供應處於開啟位置時，若免鑰匙操作鑰匙攜至車外（車外鑰匙天線偵測範圍外），即使引擎啟動條件*已滿足，引擎也無法啟動。
*：有關引擎啟動條件，請參閱「按鈕式點火開關作動之點火開關位置變更表」。

遠端引擎啟動功能
遠端引擎啟動功能可透過操作免鑰匙操作鑰匙的遠端引擎啟動按鈕或行動電話，從車外啟動引擎。
與免鑰匙操作鑰匙相同，亦可透過操作行動電話使用遠端資通系統功能來啟動引擎。
引擎啟動程序
下列作動可啟動引擎。
  • 使用行動電話執行引擎啟動作動。
車輛處於下列狀態時，引擎無法啟動。
  • 所有車門為解鎖狀態或任一車門開啟。
  • 引擎蓋開啟。
  • 已註冊的免鑰匙操作鑰匙在車廂內。
  • 排檔位置為 P 以外。
  • 車輛防盜警報系統作動中。
  • 危險警告燈作動中。
引擎停止程序
下列作動可停止引擎。
  • 按下免鑰匙操作鑰匙的遠端引擎啟動按鈕。
  • 使用行動電話執行引擎停止作動。
  • 操作按鈕式點火開關。
當車輛狀態變更為下列狀態時，引擎停止。
  • 自引擎啟動起已過 10 分鐘。
  • 引擎蓋開啟。
  • 排檔位置切換至 P 以外位置。
  • 車輛防盜警報系統開始作動。
注意：
引擎由免鑰匙操作鑰匙作動期間，引擎作動時間可延長 10 分鐘。若要延長引擎作動時間，按下免鑰匙操作鑰匙的 LOCK 按鈕，並在 5 秒內按住免鑰匙操作鑰匙的遠端引擎啟動按鈕 2 秒以上。
作動區域
車輛符合下列條件時，引擎可以啟動。
  • 遠端引擎啟動作動範圍約為距離車輛 60 m (197 ft.)。
  • 車輛位於 Infiniti Connection™ 資料中心通訊範圍內。
