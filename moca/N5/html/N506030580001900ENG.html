詳細流程
1.客戶問診
檢查前先釐清客戶抱怨。首先，利用下列方式進行問診診斷工作表並重現症狀且完全掌握症狀內容。仔細詢問客戶其抱怨事項。必要時，與客戶一同試車確認症狀。
注意：
客戶並非專業人員。切勿輕易臆測，例如「也許客戶是指…」或「也許客戶是指這個症狀」。
進至 2.
2.確認症狀
根據問診所獲得的客戶資訊，重現客戶所述症狀。同時確認該症狀並非由失效保護模式所造成。請參閱失效保護.
注意：
若症狀係正常作動所造成，請完整檢查各部位，並使客戶了解該症狀並非故障所致。
GO TO 3.
3.執行自我診斷
使用 M.U.T.-III SE
執行 "CHASSIS CONTROL" 自我診斷。
是否偵測到故障碼？
是
記錄或列印自我診斷結果及凍結資料 (FFD)。GO TO 4.
否
檢查結束
4.執行故障碼診斷程序
使用 M.U.T.-III SE
對偵測到錯誤的系統執行故障碼確認程序。
備註：
若同時偵測到數個 故障碼，請根據下列內容決定診斷執行順序故障碼檢查優先順序表.
是否偵測到故障碼？
是
前往 5.
否
根據問診所獲得的資訊檢查線束與接頭。
5.維修或更換故障零件
  1. 修理或更換發生故障的零件。
  2. 維修或更換後，重新連接零件或接頭。
  3. 偵測到故障碼時，清除「底盤控制」的自我診斷結果。
前往 6.
6.最終檢查
使用 M.U.T.-III SE
  1. 檢查「底盤控制」的參考值。
  2. 重新確認症狀，並檢查在相同條件下症狀是否未再出現。
症狀是否重現？
是
GO TO 3.
否
檢查結束
