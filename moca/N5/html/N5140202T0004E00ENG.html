  • BCM 讀取組合開關狀態，並識別各開關的狀態。
  • BCM 具有 6 個輸入端子（INPUT 1 - 6）與 6 個輸出端子（OUTPUT 1 - 6）的組合，最多可讀取 22 個開關狀態與 6 個檢知二極體狀態。

組合開關讀取功能
說明
  • BCM 以 10 ms 間隔正常讀取組合開關狀態。
    CF100C0QAA00ENG
  • BCM 依下列方式作動，並判定組合開關狀態。
    • 依序開啟 INPUT 側電晶體作動：OUTPUT 6–> 5 –> 4 –> 3 –> 2 –> 1，並輸出電壓波形。
    • 若有任一（1 個或以上）開關為開啟狀態，則對應形成電路的 OUTPUT 電壓波形會輸入至 INPUT 側介面。
    • 將此電壓變化讀取為組合開關的狀態訊號。
      CF100C0RAA00ENG
作動範例
在下列作動範例中，組合開關狀態訊號的組合替換如下：將 INPUT 1 - 6 替換為「 - 」，而將 OUTPUT 1 - 6 替換為「 - ”.
範例 1：當開關（右方向燈）開啟時
  • 當右方向燈開啟時，INPUT 3（）與 OUTPUT 5（）之間形成電路。
    DF100C0SAC00ENG
  • BCM 偵測到組合開關狀態訊號「」當 INPUT 3 訊號輸入至 OUTPUT 5 時。
  • 當偵測到訊號「」時，BCM 判定右方向燈為開啟。
範例 2：當部分開關（前霧燈開關、右方向燈）開啟時
  • 於 INPUT 1（）與 OUTPUT 5（）之間以及 INPUT 3（）與 OUTPUT 5（）之間的電路於前霧燈開關與右方向燈開啟時形成。
    DF100C0TAC00ENG
  • BCM 偵測到組合開關狀態訊號「」當 INPUT 1 與 INPUT 3 訊號輸入至 OUTPUT 5 時。
  • 當偵測到訊號「」時，BCM 判定右方向燈為開啟。
