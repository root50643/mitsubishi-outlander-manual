BRAKES - 煞車控制系統 - WITH VDC - 故障碼/電路診斷 - C105D-7B BRAKE FLUID LEVEL SWITCH
診斷程序
N50603026001JJ00ENG
1.檢查煞車油液位
  1. 點火開關關閉（Auto ACC 功能關閉）。
  2. 檢查煞車油液位。請參閱檢查檢查.
檢查結果是否正常？
是
前往 3.
否
補充煞車油。請參閱煞車系統排氣. 前往 2.
2.執行自我診斷 (1)
使用 M.U.T.-III SE
  1. 清除「ABS」的自我診斷結果。
  2. 點火開關關閉（Auto ACC 功能關閉）→ 開啟 → 關閉（Auto ACC 功能關閉）。
  3. 啟動引擎。
    注意：
    啟動引擎後至少等待 10 秒。
  4. 對「ABS」執行自我診斷。
是否偵測到故障碼 "C105D-7B"？
是
前往 3.
否
檢查結束
3.檢查 接頭
  1. 斷開/拔除 12V 電瓶負極端子。
  2. 檢查煞車油液位開關線束接頭是否脫開或鬆動。
  3. 檢查儀表線束接頭是否脫開或鬆動。
檢查結果是否正常？
是
GO TO 5.
否
修理/更換線束或接頭。前往 4.
4.執行自我診斷 (2)
使用 M.U.T.-III SE
  1. 連接 12V 電瓶負極端子。
  2. 啟動引擎。
    注意：
    啟動引擎後至少等待 10 秒。
  3. 對「ABS」執行自我診斷。
是否偵測到故障碼 "C105D-7B"？
是
GO TO 5.
否
檢查結束
5.檢查煞車油液位開關
檢查煞車油液位開關。請參閱元件檢查.
檢查結果是否正常？
是
GO TO 7.
否
更換儲液罐。請參閱拆解與組裝. GO TO 6.
6.執行自我診斷 (3)
使用 M.U.T.-III SE
  1. 清除「ABS」的自我診斷結果。
  2. 點火開關關閉（Auto ACC 功能關閉）→ 開啟 → 關閉（Auto ACC 功能關閉）。
  3. 啟動引擎。
    注意：
    啟動引擎後至少等待 10 秒。
  4. 對「ABS」執行自我診斷。
是否偵測到故障碼 "C105D-7B"？
是
GO TO 7.
否
檢查結束
7.檢查接頭及端子
  1. 斷開/拔除 12V 電瓶負極端子。
  2. 斷開/拔除煞車油液位開關線束接頭。
  3. 檢查煞車油液位開關線束接頭是否脫開或鬆動。
  4. 檢查煞車油液位開關端子是否損壞或與線束接頭接觸不良。
  5. 斷開/拔除 儀表 線束 接頭.
  6. 檢查儀表線束接頭是否脫開或鬆動。
  7. 檢查儀表端子是否損壞或與線束接頭接觸不良。
檢查結果是否正常？
是
前往 9.
否
修理/更換線束、接頭或端子。前往 8.
8.執行自我診斷 (4)
使用 M.U.T.-III SE
  1. 連接煞車油液位開關線束接頭。
  2. 連接儀表線束接頭。
  3. 連接 12V 電瓶負極端子。
  4. 清除「ABS」的自我診斷結果。
  5. 點火開關關閉（Auto ACC 功能關閉）→ 開啟 → 關閉（Auto ACC 功能關閉）。
  6. 啟動引擎。
    注意：
    啟動引擎後至少等待 10 秒。
  7. 對「ABS」執行自我診斷。
是否偵測到故障碼 "C105D-7B"？
是
前往 9.
否
檢查結束

11.檢查 儀表
