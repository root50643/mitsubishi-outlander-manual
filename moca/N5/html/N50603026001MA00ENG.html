煞車 - 煞車控制系統 - 附 VDC - 故障碼/電路診斷 - C10B2-64 駐車煞車開關
診斷程序
N50603026001MA00ENG
1.檢查 DATA MONITOR
使用 M.U.T.-III SE
  1. 點火開關開啟。
    注意：
    點火開關開啟後，務必等待 10 秒。
  2. 依此順序選擇「ABS」、「資料清單」及「PB 開關」。檢查駐車煞車開關處於拉起、中立或按下時，資料監視器是否正確顯示。請參閱參考值.
檢查結果是否正常？
是
GO TO 6.
否
前往 2.
2.檢查 接頭
  1. 斷開/拔除 12V 電瓶負極端子。
  2. 檢查駐車煞車開關線束接頭是否斷線或鬆脫。
  3. 檢查 ABS 作動器與電裝單元（控制單元）端子是否損壞，或與線束接頭連接鬆動。
檢查結果是否正常？
是
前往 3.
否
修理/更換線束或接頭。前往 3.
3.檢查駐車煞車開關電路
  1. 斷開/拔除駐車煞車開關線束接頭。
  2. 斷開/拔除 ABS 作動器與電裝單元（控制單元）線束接頭。
  3. 檢查 ABS 作動器與電裝單元（控制單元）線束接頭與駐車煞車開關線束接頭之間的導通。

4.檢查駐車煞車開關
檢查駐車煞車開關。請參閱元件檢查.
檢查結果是否正常？
是
GO TO 5.
否
更換駐車煞車開關。請參閱拆卸與安裝.
5.檢查 端子
  1. 檢查駐車煞車開關端子是否損壞，或與線束接頭連接鬆動。
  2. 檢查 ABS 作動器與電裝單元（控制單元）端子是否損壞，或與線束接頭連接鬆動。
檢查結果是否正常？
是
GO TO 6.
否
修理/更換線束、接頭或端子。GO TO 6.
6.執行自我診斷
使用 M.U.T.-III SE
  1. 連接駐車煞車開關線束接頭。
  2. 連接 ABS 作動器與電裝單元（控制單元）線束接頭。
  3. 連接 12V 電瓶負極端子。
  4. 點火開關開啟。
  5. 拉緊並放開駐車煞車五次。
  6. 對「ABS」執行自我診斷。
是否偵測到故障碼「C10B2-64」？
是-1
顯示「CRNT」：更換 ABS 作動器與電裝單元（控制單元）。請參閱拆卸與安裝.
是-2
顯示「儲存故障碼」時：檢查結束（清除自我診斷結果記憶體。）
否
檢查結束
