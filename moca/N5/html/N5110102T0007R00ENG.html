免鑰匙操作鑰匙
依據免鑰匙操作鑰匙與車輛（免鑰匙操作 key 單元）之間雙向通訊進行電子 ID 驗證的結果運作
系統說明
  • 免鑰匙操作鑰匙系統是一種攜帶免鑰匙操作鑰匙即可鎖定及解鎖車門鎖（車門鎖定/解鎖功能）的系統，其運作依據免鑰匙操作鑰匙與車輛（免鑰匙操作 key 單元）之間雙向通訊進行電子 ID 驗證的結果。
    注意：
    駕駛應隨時攜帶免鑰匙操作鑰匙
  • 各功能的設定可使用 M.U.T.-III SE 變更。
  • 若免鑰匙操作鑰匙遺失，可登錄新的免鑰匙操作鑰匙。最多可登錄 4 把免鑰匙操作鑰匙。
  • 可使用 M.U.T.-III SE 對系統進行診斷及登錄免鑰匙操作鑰匙。
