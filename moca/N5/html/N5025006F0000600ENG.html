引擎<4B4> - 直接噴射與多點燃油噴射（DI 與 MPI）- 故障排除 - 故障碼程序
Code No. P0268-00: 噴油嘴電路高輸入 - 3號汽缸
N5025006F0000600ENG
電路作動
  • 電源由 ECM 繼電器供應至燃油噴油嘴。
  • ECM 接頭端子 INJ3 使單元內的功率電晶體處於開啟位置，使電流流經燃油噴油嘴。
技術說明
  • ECM 控制燃油噴油嘴的供電間隔。
  • 燃油噴油嘴的噴油量取決於供電間隔。
監控方法說明
ECM 偵測到短路故障。
監測執行
連續。
監測執行條件（其他監測項目與感知器）
其他監測項目（下列監測項目未在記憶體中設定暫時性故障碼）
  • 不適用
感知器（下列感知器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 引擎運轉中。
  • 電瓶正極電壓大於 10.5 V 且小於 16.5 V。
判定基準
  • 低壓噴油嘴驅動器的狀態變為故障狀態，即短路至高。
失效保護與備援功能
單缸燃油切斷。
OBD-II 駕駛循環模式
請參閱 Diagnostic Function – OBD-II Drive Cycle – Pattern 6駕駛循環模式.
故障排除提示（此故障碼最可能的原因如下：）
  • 燃油噴油嘴故障。
  • 燃油噴油嘴控制線路對電源短路。
  • 燃油噴油嘴接頭損壞。
  • ECM 故障。
