變速箱與傳動系 - 變速箱與變速機 - CVT<F1CJE, W1CJE> - 基本檢查 - 更換控制閥時的追加服務

注意：
開始前，務必確認：
  • 所有 M.U.T.-III SE 軟體更新（若有）均已安裝。
1.列印目前校正資料
使用 M.U.T.-III SE
  1. 點火開關為開啟。
  2. 連接 M.U.T.-III SE。
  3. 在「TRANSMISSION」中選擇「校正資料」。
  4. 列印頁面。
    注意：
    此螢幕列印用於保固文件。
前往 2.
2.檢查序號（第一部）
  1. 記下新控制閥的序號（校正檔案編號）。
  2. 比對 CD、QR 碼標籤與新控制閥上的序號（校正檔案編號）。所有編號必須一致。
CF3004JEAA00ENG
前往 3.
3.更換控制閥
  1. 點火開關關閉。
  2. 更換控制閥。請參閱拆卸與安裝.
GO TO 4.
4.檢查序號（第二部）並寫入校正資料（IP 特性值）
使用 M.U.T.-III SE
  1. 點火開關為開啟。
  2. 將隨附 CD 插入 M.U.T.-III SE。
  3. 在「TRANSMISSION」中選擇「Special Function」。
  4. 在「IP characteristics data writing」中選擇「WRITE IP CHARA - Using import data」。
  5. 輕觸「OK」。
  6. 輕觸「File import」開啟選擇 IP 特性資料檔視窗，然後從 CD 將資料檔匯入 M.U.T.-III SE。
  7. 在選擇 IP 特性資料檔視窗中選擇資料。
  8. 輕觸「OK」。
  9. 確認 M.U.T.-III SE 螢幕上顯示的序號（校正檔案編號）與新控制閥上的序號（校正檔案編號）一致。
  10. 輕觸「OK」。
  11. 將車輛設定為下列條件：
    1. 點火開關 開啟，引擎 關閉。
    2. 將排檔位置設定為 P 位置。
    3. 踩下煞車踏板。
    4. 將油門踏板踩至一半並維持。
  12. 輕觸「OK」。
  13. 執行 IG-關閉/開啟 作動，然後輕觸「OK」。
  14. 輕觸「OK」。
    注意：
    當校正資料寫入 TCM 後，將顯示「Completed」訊息。
  15. 輕觸「OK」完成。
前往 5.
5.列印新校正資料
使用 M.U.T.-III SE
  1. 在「TRANSMISSION」中選擇「校正資料」。
  2. 列印頁面。
    注意：
    此螢幕列印用於保固文件。
GO TO 6.
6.執行扭力轉換器鎖定點學習
執行扭力轉換器鎖定點學習。請參閱說明.
GO TO 7.
7.執行選檔學習（前進/倒檔學習）
注意：
務必在選檔學習之前執行鎖定點學習。
執行選檔學習。請參閱作業程序.
GO TO 8.
8.清除 CVT 油液劣化程度資料
使用 M.U.T.-III SE
  1. 在「TRANSMISSION」中選擇「Special Function」。
  2. 在「Confirm CVTF deterioration (clear)」中選擇「Item No. 2: Confirm CVTF deterioration (clear)」。
  3. 輕觸「OK」。
  4. 清除可能已設定的所有 故障碼，然後進行路試。
