1.檢查故障碼優先順序
If 故障碼 “C258E-87” is displayed with 網路-故障碼, first diagnose the 網路-故障碼.
是否偵測到適用之故障碼？
是
對適用之故障碼執行診斷。請參閱故障碼索引故障碼索引.
否
前往步驟 2.
2.檢查 ABS 作動器 AND ELECTRIC UNIT (CONTROL UNIT) 自我診斷 RESULTS
檢查 if any 故障碼 is detected in “Self Diagnostic Result” of “ABS”.
是否偵測到任何故障碼？
是
依偵測到之故障碼執行診斷，並維修或更換故障零件。請參閱故障碼索引.
否
GO TO 3.
3.檢查 DISTANCE 感知器 自我診斷 RESULTS
檢查 if “C258E-87” is detected as the current malfunction in “Self Diagnostic Result” of “LASER/RADAR”.
是否偵測到任何故障碼？
是
更換 the distance 感知器. 請參閱拆卸與安裝.
否
