說明
開始診斷前，檢查車輛是否處於「車輛條件」所示條件，並檢查各症狀。
備註：
免鑰匙操作鑰匙系統中的引擎起動功能、車門鎖定功能、配電系統及 NATS-IVIS/NVIS 在控制方面彼此密切相關。僅當車門鎖定及配電系統正常作動時，車輛安全功能才能作動。
車輛條件（作動條件）
  • 使用 M.U.T.-III SE 設定開啟時，「HANDS FREE MODULE」的「Setting change」（「Special Function」模式）中「引擎 START BY I-KEY」為「開啟」。
  • 一個或多個已登錄免鑰匙操作 key ID 的免鑰匙操作鑰匙在車內。
