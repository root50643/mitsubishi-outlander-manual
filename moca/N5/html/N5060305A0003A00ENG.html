煞車 - 煞車控制系統 - 附 VDC - 基本檢查 - 系統模式變更
作業程序
N5060305A0003A00ENG
警告：
執行下列操作時，必須使用 M.U.T.-III SE。（無法以 M.U.T.-III SE 以外的方式執行。）
  • 更換 ABS 作動器及電動單元（控制單元）
1.系統模式變更
使用 M.U.T.-III SE
  1. 依此順序選擇 "ABS"、"WORK SUPPORT" 及 "SYSTEM MODE CHANGE"。
    警告：
    切勿操作駐車煞車開關。
  2. 選擇 "Mode 1" 並點觸 "OK"。
  3. 檢查顯示項目 "Electric PARKING mode"。
檢查結果是否為 "Mode 1"？
是
前往步驟 2.
否
再次執行系統模式變更。
2.執行自我診斷
使用 M.U.T.-III SE
  1. 拉起駐車煞車開關以啟動電動駐車煞車。
  2. 按下駐車煞車開關以鬆開電動駐車煞車。
  3. 執行 "ABS" 自我診斷。
是否偵測到故障？
是
檢查故障碼。請參閱故障碼索引.
否
