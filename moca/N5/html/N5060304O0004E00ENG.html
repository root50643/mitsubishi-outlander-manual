BRAKES - BRAKE CONTROL SYSTEM - WITH VDC - SYSTEM DESCRIPTION - SYSTEM - TCS 功能
系統說明
N5060304O0004E00ENG
  • 以四輪的輪速感測器偵測驅動輪的空轉狀態。控制引擎出力及變速箱換檔狀態，使驅動輪的滑移率維持在適當範圍內。當驅動輪發生空轉時，ABS 作動器及電子單元（控制單元）對左右驅動輪執行煞車力控制（透過提高驅動輪煞車油壓來施加煞車力），並透過引擎扭力控制降低引擎扭力。空轉量減少。引擎扭力被控制至適當程度。
    CF100AMVAA00ENG
  • TCS 功能可切換至非作動狀態（關閉）。此時 ASC 關閉指示燈會亮起。
  • TCS 功能作動期間 ASC 警告燈閃爍，向駕駛人指示該功能正在作動。
  • 可使用 M.U.T.-III SE 進行系統診斷。
  • 採用失效保護功能。當 TCS 功能發生故障時，ASC 功能、TCS 功能、煞車限滑差速（BLSD）功能、煞車輔助功能、煞車力分配功能及斜坡起步輔助功能的控制皆停止。車輛狀態與未配備 ASC 功能、TCS 功能、煞車限滑差速（BLSD）功能、煞車輔助功能、煞車力分配功能、斜坡起步輔助功能及陡坡緩降控制之車型相同。然而 ABS 功能及 EBD 功能仍正常作動。請參閱失效保護.
