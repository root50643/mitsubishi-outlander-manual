監視方法說明
自 48V-BSG（皮帶起動馬達發電機）模組接收到無效的 CAN 資料。

連續。
監視執行條件（其他監視與感測器）
其他監視（下列監視項目未在記憶體中設定暫時性故障碼）
  • 控制器區域網路 - 引擎區域 CAN（48V 輕度混合動力系統用）
感測器（下列感測器判定為正常）
  • 不適用
故障碼設定條件
檢查條件
  • 點火開關處於開啟位置。
  • 12V 電池正極電壓介於 10.0 至 16.5 伏特之間。
  • 起動馬達停止運轉。
  • 上述條件滿足後已經過 2 秒以上。
判定準則
  • 通訊 CRC 狀態失敗持續 2.0 秒。
備註
目前故障
  • 失效／故障可能由 ECM 與皮帶驅動起動馬達發電機（BSG）之間 CAN 匯流排線路的線束及接頭故障、皮帶驅動起動馬達發電機（BSG）故障，或 ECM 故障所造成。
過去故障
  • 請以 ECM 與皮帶驅動起動馬達發電機（BSG）之間 CAN 匯流排線路的線束及接頭故障為重點進行故障排除。
失效保護與備援功能
  • 48V 輕度混合動力系統停止。
    1. 停止對 12V 側供電。
    2. 引擎輔助與皮帶驅動啟動馬達發電機再生停止。
  • 充電警告燈亮起。
  • 禁止自動停引擎。
  • AS&G 關閉指示燈閃爍。
OBD-II 行駛循環模式
請參閱 Diagnostic Function, OBD-II Drive Cycle – Pattern 5行駛循環模式.
故障排除提示（設定此故障碼最可能的原因如下：）
  • 局部 CAN 匯流排線路（雜訊干擾）
  • 皮帶驅動起動馬達發電機（BSG）故障
  • ECM 故障

1.步驟 1. 使用 M.U.T.-III SE 讀取故障碼。
問：是否有其他與皮帶驅動起動馬達發電機組相關的故障碼？
是
故障碼診斷檢查表（請參閱 故障碼檢查表故障碼檢查表).
否
進行步驟 2。
2.步驟 2. 使用 M.U.T.-III SE 讀取故障碼。
  • 故障碼再確認。
再次確認 ECM 中是否設定故障碼。
  1. 清除已設定的故障碼。
  2. 點火開關：關閉 → 開啟
  3. 確認是否設定了故障碼。
問：是否設定故障碼 U0469-00？
是
更換 ECM（請參閱引擎-ECU 拆卸與安裝）。然後進行步驟 3。
否
ECM 與皮帶驅動起動馬達發電機 (BSG) 之間 CAN 匯流排線路間歇性故障（請參閱 General Information - General Information - Basic Inspection - Service Information for Electrical Incident -間歇性故障).
3.步驟 3. 使用 M.U.T.-III SE 讀取故障碼。
  • 故障碼再確認。
再次確認 ECM 中是否設定故障碼。
  1. 清除已設定的故障碼。
  2. 點火開關：關閉 → 開啟
  3. 確認是否設定了故障碼。
問：是否設定故障碼 U0469-00？
是
更換皮帶驅動起動馬達發電機（請參閱 引擎 <4B4> - 引擎電氣 - 充電系統 - 皮帶驅動起動馬達發電機 -皮帶驅動啟動馬達發電機拆卸與安裝）。然後進行步驟 4。
否
ECM 與皮帶驅動起動馬達發電機（BSG）之間 CAN 匯流排線路之間歇性故障。（請參閱 一般資訊 - 一般資訊 - 基本檢查 - 電氣事故服務資訊 -間歇性故障).

  2. 檢查故障碼。
